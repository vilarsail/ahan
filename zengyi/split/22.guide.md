# 增壹阿含经卷第二十二 导读

## 一、内容总览
本卷为《增壹阿含经》卷二十二，属「须陀品第三十」，收三经。前两经短，以少年沙弥显佛法的新旧译名交替（如「明行成为」即「明行足」、「苦、习、尽、道」即四圣谛），是增一阿含的典型译风。

## 二、结构层次
- **第一经（问答立智）**：世尊连发五问——常色/无常色、有漏/无漏、聚法/散法、受/阴、有字/无字，须陀沙弥一一以「二义各异、非一义」作答 → 佛五次印可「善哉」，许其为大比丘，并嘱诸比丘学其「说法无滞碍，亦无怯弱」。
- **第二经（恭敬立品）**：长老舒脚而睡 ↔ 八岁沙弥端坐系念，一反一正 → 佛说偈「长老不在须发年齿，而在见谛离恶」 → 点出业果：无恭敬者五百世堕龙身，有恭敬者七日得四神足、四谛、四禅 → 结劝「恒当勤加恭敬佛、法、僧」。
- **第三经（叙事证法，约占全卷五分之四）**：求婚（佛弟子之女许嫁外道之城）→ 满富城违制罚饭六千梵志 → 修摩提女拒礼裸形外道，举「有惭、有愧」二法 → 满财愁闷高楼 → 五通梵志修跋述均头沙弥于阿耨达泉浣尸衣、历四禅八定入灭尽定之神变 → 女焚香请佛 → 佛敕行筹，上座君头波汉以学地受舍罗、即证无学 → 十大弟子各现神变飞临，长者隔城问女、女以偈报师名，一问一偈层层排比 → 佛与天龙八部凌空七仞而至 → 满财自归礼赞、六千梵志如兽闻狮吼遁走 → 佛化其屋作琉璃、次第说法，八万四千人得法眼净 → 佛溯迦叶佛时王女誓愿之宿缘 → 结以「四事最是福田，亲近者获四谛」。

## 三、关键结论
1. 有漏是生死、无漏是涅槃；「有字」（有生有终始）是生死、「无字」是涅槃——辨析法义须明其「若干非一」。
2. 长老不在须发年齿，而在见谛离恶；对佛法僧的恭敬心是升进之因，无恭敬则堕龙畜。
3. 惭、愧二法是人异于禽兽、世间尊卑有序之本；裸形外道无惭无愧，不足为礼。
4. 佛与弟子以神变摄受外道：均头浣尸衣而入诸禅定，众弟子各现化物绕城，终令满富城举国得法眼净。
5. 宿世誓愿感果：迦叶佛时所发「值佛闻法、不堕恶趣、不失人身、得法眼净」之愿，于今成熟，故嫁女入外道之城反成度众之缘。

## 四、易混辨析
- **有漏 vs 无漏**：有漏是生死结使 ↔ 无漏是涅槃之法。
- **聚法之色 vs 散法之色**：四大所成之色身 ↔ 苦尽谛（苦灭之涅槃）。
- **受 vs 阴**：受无形不可见 ↔ 阴有色可见（本卷的独特分判）。
- **四事供养（衣食卧药）vs 卷末「四事」**：后者实指施、爱敬、利人、等利四摄法，名同义异。
- **四神足 vs 四意断**：前者是成就神通的四种定力，后者即四正勤，勿混为一。

## 五、阅读提示
带着两个问题读：其一，八岁沙弥与五百世堕龙的对比，说明佛教评价体系里「恭敬心」重于「年资」；其二，第三经为何不厌其烦地让十大弟子逐一现神变、一问一偈？这是本经以「神变叙事」摄伏外道的典型写法，神变的次第（先役使、次弟子、后佛）本身就是一场层层升高的「说法」。
