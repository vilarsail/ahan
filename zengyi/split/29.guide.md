# 增壹阿含经卷第二十九 导读

## 一、内容总览
《增壹阿含经》以法数递增编集，本卷为第二十九卷，「六重品第三十七」的前半（之一），收五经，多以「六」为目：第一经说比丘当敬重的六重法；第二经记目连与舍利弗在阿耨达泉比试神通、佛为东方来比丘说六界法；第三经记诸大声闻在牛师子园各说「园中之乐」；第四经说咒愿六德；第五经说一切修行所求皆以戒德具足为本。

## 二、结构层次（文章的骨架与逻辑推进）
- **第一经（一）六重法立宗**：佛告比丘「思念六重之法，敬之、重之」→ 依次展开：身行念慈 → 口行念慈、意行念慈 → 得利养与梵行者共之 → 禁戒完具、分布与人同其味 → 正见得出要、与梵行者共 → 结劝「常当修行身口意行，得利养莫起贪想」。
- **第二经（二）神通比试 → 六界法收束**：佛在阿耨达泉，众中缺舍利弗 → 龙王请唤 → 目连奉命去催 → 舍利弗解下竭支带与目连试力：带系阎浮树、四天下、须弥山、三千大千世界，目连皆能动，独系于如来座则不动 → 佛说四神足，判「舍利弗神力最大」→ 诸比丘反生轻慢目连之想 → 目连奉敕现神力：至东方奇光如来土，以钵盂盛五百比丘携归 → 佛为彼说六界、六入、六识 → 送还彼土，其众得法眼净 → 结「目连神足第一」，轻慢之疑全消。
- **第三经（三）牛师子园论乐**：诸大声闻晨聚园中 → 舍利弗依次问阿难（多闻总持说法）、离越（闲静坐禅）、阿那律（天眼观众生）、迦叶（阿练若、头陀、教人）、目连（神足变化）各说「何等比丘宜住此园」→ 舍利弗自说「能降心、随意入三昧」→ 共往问佛 → 佛逐一印可，末了自说：入村乞食、树下端坐、要当尽有漏成无漏——以解脱为至乐。
- **第四经（四）咒愿六德**：施主三法（信根、戒德、闻）＋施物三法（物色、味、香）→ 六事具足则「获大功德，名德远闻，获甘露之报」。
- **第五经（五）戒德为本**：比丘意欲求利养、知足、名闻、四禅、四神足、八解脱、天耳、他心、神变、宿命、天眼、漏尽解脱——逐一归到「当念戒德具足」→ 结归五分法身具足，「是世福田，无能过者」。

## 三、关键结论
1. 身口意行慈、利养与戒见共享，是比丘应当敬重受持的六法。
2. 神通的胜负不在外相而在三昧：目连能动三千大千世界，却举不动舍利弗系于如来座的带子——「舍利弗所入三昧，目连不知名字」。
3. 解了六界、六入、六识，能度诸天受形而尽结使、得涅槃。
4. 施主信戒闻三法与施物色味香三法具足，咒愿方得大福。
5. 凡有所求——从四禅、神通到漏尽解脱——皆以戒德具足为根本，五分法身具足者是人天福田。

## 四、易混辨析
- **神足（神通）vs 三昧（定）**：神足是外显的力用，三昧是所依的定心。目连「神足第一」是就声闻中一般神变而言；舍利弗所入三昧深不可测，故举带不动、天地俱震而如来座岿然。
- **六界 vs 六入 vs 六识**：六界（地水火风空识）是构成身心的元素，六入（眼耳鼻舌身意）是六界所生的接触门户，六识是依入而起的了别作用——由「禀精气而生」到「依六入便有六识身」，层层相依。
- **弟子诸乐 vs 佛说之乐**：阿难乐说法、离越乐闲静、阿那律乐天眼、迦叶乐头陀、目连乐神变、舍利弗乐降心入定，佛皆印可而不止于此——乞食端坐、尽有漏成无漏才是园中至乐。
- **咒愿之德 vs 布施之财**：福报不系于财物多少，而在施主三法与施物三法相应具足。

## 五、阅读提示
带着两个问题读：「神足第一的目连为何比不过舍利弗？」（第二经），「诸大弟子各自称道的园中之乐，佛的答案为何偏偏最朴素？」（第三经）——可见阿含一贯以定慧与解脱、而非神变，为究竟。
