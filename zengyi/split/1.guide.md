# 增壹阿含经卷第一 导读

## 一、内容总览
本卷是东晋罽宾三藏瞿昙僧伽提婆所译《增壹阿含经》的第一卷，由「序品第一」与「十念品第二」两部分组成。序品是全经总序：以偈颂追述佛灭度后，大迦叶击揵椎召集八万四千阿罗汉结集法藏，阿难诵出经法，分为契经、律、阿毗昙三藏，契经再分增一、中、长、杂四部；继而说明「增一」因法数从一递增至十一而得名的缘由，兼说六度与菩萨发趣大乘，最后述阿难将此经嘱累优多罗比丘。十念品收录十段格式全同的短经，逐一示范「一法」的修习——念佛、念法、念众、念戒、念施、念天、念休息、念安般、念身、念死。

## 二、结构层次
- **序品·偈颂**：佛灭度 → 迦叶结集、诸天劝请阿难说法 → 阿难升座，立三藏、分四部阿含 → 点出「增一」得名（一法至十一法，如连珠相从）→ 弥勒与诸天称善劝持 → 列举六度无极与十念。
- **序品·长行**：诸天会集 → 弥勒劝讽诵受持 → 阿难嘱累优多罗 → 迦叶三番问难，阿难层层作答 → 举过去诸佛皆以此法嘱累同一人的宿缘 → 摩诃提婆王见白发出家的故事 → 阿难说偈劝诵四阿含，诸天散华证成。
- **问答主线（迦叶问 → 阿难答）**：增一阿含为何能出生三十七道品？→「诸恶莫作，诸善奉行，自净其意，是诸佛教」一偈出生一切法 → 余四阿含亦出生乎？→ 四阿含义皆摄于一偈 → 为何独嘱优多罗？→ 增一阿含即是诸法，观其器而后授法。
- **十念品第二**：十经并列，每经同一格式——闻如是 → 一时佛在舍卫国祇树给孤独园 → 世尊告诸比丘「当修行一法」→ 云何为一法（念佛／法／众／戒／施／天／休息／安般／身／死）→ 欢喜奉行；卷末以四句偈总结十念。这正是「增一」体例的第一次实演。

## 三、关键结论
- 「诸恶莫作，诸善奉行，自净其意，是诸佛教」一偈总摄诸佛、辟支佛、声闻之教，三十七道品由此出生。
- 增一阿含以法数递增编排，义丰慧广、便于忆持，「增一阿含则是诸法，诸法则是增一阿含」。
- 十念各是一法，修之便成神通、去众乱想、逮沙门果、自致涅槃。
- 受持此经莫令缺漏；轻慢者堕凡夫行，凡夫长处三涂、八难。

## 四、易混辨析
- **三藏 vs 四部阿含**：三藏＝契经、律、阿毗昙（经律论）；四部阿含是契经内部的再分类——增一、中、长、杂，即「契经今当分四段」。
- **四阿含得名**：增一法数递增如连珠；「中」者不长不短；「长」者经篇绵长（偈称「长多璎珞」，如璎珞贯珠）；「杂」者后出别行。
- **迦叶如来 vs 大迦叶**：前者是贤劫第三佛（过去七佛之第六），后者是主持结集的头陀第一尊者，本卷两人并见。
- **十念译语**：念「众」即念僧伽；「休息」指止息寂静之境（禅寂乃至涅槃），与数息摄心的「安般」入手不同。

## 五、阅读提示
带着两个问题读：其一，从一数到十一的「增一」编排如何「出生诸法」；其二，摩诃提婆王八万四千岁修梵行、生梵天而「犹不至究竟」，对比「如来善业，乃名究竟安隐之处」，体会本卷劝诵此经的分量。
