# 增壹阿含经卷第三十四 导读

## 一、内容总览
《增壹阿含经》卷三十四，属「七日品第四十」之首（之一），收六经，皆围绕「七」数立义：七日并出的世界坏灭、护国护僧的七法、七使与七觉、七种可敬之人，再以十念、净漏收束。全卷是增一阿含「以数为编、随数立义」体例的典型一卷，前半说宇宙成坏与四姓起源，后半说僧团修行。

## 二、结构层次
- **（一）七日经**：比丘聚论须弥山高大必坏 → 佛说须弥山构造（四宝城郭、四种天、四天王、群山海岸地理）→ 七日并出：一日至七日，小河、四驶河、大海、大地、三千大千刹土次第枯竭、洞然烧尽，火炎至梵天（一切行无常的正观推演）→ **劫还成就**：风起成山，光音天子食地肥落地、生男女、起屋舍、生粳米、生盗生杀 → 刹利、婆罗门、毗舍、首陀罗四姓渐次出现，五谷五阴，结归「无常」。
- **（二）七不退转法**：阿阇世王欲伐拔祇国，遣婆罗门问佛 → 佛说拔祇修七法则「不为外寇所坏」→ 婆罗门去后，佛即转教比丘「七不退转法」——护国七法即护僧七法，一义两用，内外相映。
- **（三）七使**：佛说七使（贪欲、瞋恚、憍慢、痴、疑、见、欲世间）如二牛共一轭，牵人流转 → 「七使之法复有七药」：七觉意一一为对治 → 佛自叙成道前于道树思惟七觉意、漏尽心解。
- **（四）七种之人**：行慈、悲、喜、护、空、无想、无愿七人可事可敬 → 阿难问何不说四果诸圣 → 佛答：供四果报在未来，供此七人现世即得报。
- **（五）毗罗先长者**：长者七日当堕涕哭地狱，犹恋五欲 → 阿难六日催逼，剃度出家、教修十念 → 当夜命终生四天王，七变周旋天人，终尽苦际 → 校量「搆牛顷」修十念之福胜供养一洲之人。
- **（六）净诸漏法**：总起列「见、亲近、远离、娱乐、威仪、思惟」六断，问答展开时补出「恭敬（忍受）所断」，共七门 → 每门先明「不断则生漏、能断则不生」→ 结以「断结去爱，度四流，渐渐越苦」。

## 三、关键结论
- 七日并出，劫火烧至梵天，三千大千刹土悉为灰土——国土尚且坏尽，一切行无常，唯业缘果报随身不移。
- 僧团如拔祇国：集一处和顺、上下相奉、不著事务、除睡眠、修禅念，则魔王不得其便。
- 七使是病，七觉意是药；佛自己也是由此药得度而成正觉。
- 宿福会尽，恶业必堕；临终出家系念（十念）犹能转生善趣、七返天上人间而尽苦际。
- 断漏有门：正见除身见、戒盗、疑三结，其余由忍受、如法受用、远离恶缘、舍离恶想、守护根门、修七觉意而断。

## 四、易混辨析
- **四天王 vs 四天王天**：提头赖吒等四位天王是护世之神；「生四天王中」的「四天王」指欲界第一重天，两个所指相关而不同。
- **七使 vs 七觉意**：一是随眠烦恼（病），一是觉悟法门（药），本卷一一相配，勿混为一类。
- **拔祇七法 vs 七不退转法**：同一骨架，前者护邦国，后者护道业。
- **欲界诸天异译**：三十三天即忉利天，艳天即夜摩天，兜术天即兜率天，化自在、他化自在即欲界顶二天；皆译名差异，非不同天。
- **「有漏」两义**：泛指一切烦恼（本卷多用）与三漏中专指对生存之贪，读时随文取义。

## 五、阅读提示
带着两条线读：一是「无常线」——从须弥山到劫火到人间起源，看佛如何用宇宙论讲无常；二是「自护线」——护国、护僧、护心（七觉意）、护戒（十念）、护根（断漏），层层收向自身修行。
