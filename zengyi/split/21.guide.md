# 增壹阿含经卷第二十一 导读

## 一、内容总览
本卷为《增壹阿含经》卷二十一，即「苦乐品第二十九」全品，共十经。《增壹阿含》以法数递增编集，本卷十经每经各说一个「四」。品名取自第一经「四种苦乐人」；其后诸经看似分散——梵福、四食、四辩、不可思议、四神足、爱起之法、四河、四等心——实则大体围绕福业、资生之具与修行资粮展开，末二经以「四河入海」「四梵堂」两个总括性譬喻收束。

## 二、结构层次（文章骨架与推进）
- **体例总纲**：十经并列、各自成篇，皆以「闻如是：一时，佛在舍卫国祇树给孤独园」起首，以「闻佛所说，欢喜奉行」收尾；经内一律「总问云何为四 → 逐一分释 → 『当作是学』劝修」，是增一部「以数统法」的标准格式。
- **（一）（二）正说苦乐**：（一）立四种人——先苦后乐、先乐后苦、先苦后苦、先乐后乐，根子在邪见或正见、布施有无 → 有比丘据现世所见追问 → 佛以「人寿百岁，正可十十」作答：百岁中先作福者先受乐，先造罪者先受罪 → 劝欲「先乐后乐」者当行布施。（二）换个角度重组：以「得不得四事供养」（身）与「免不免恶趣」（心）两缘交叉出四种人，举尸波罗比丘为「身乐心亦乐」的榜样。
- **（三）～（五）福与说法**：（三）四梵之福（起塔、补治故寺、和合圣众、劝请转法轮）→ 以四洲人民、轮王（转轮圣王）、诸天乃至梵天王层层较量其量；（四）四食——众生依抟、更乐（触）、念（思）、识四食流转生死，故劝舍离；（五）四辩（义、法、辞、应），举摩诃拘絺罗为标准。
- **（六）～（八）修行关口**：（六）四不可思议（众生、世界、龙界、佛境）→ 插入舍卫城狂人池边思世界、误见四种兵的因缘故事 → 收在「当思议四谛」；（七）四神足，教修定发通；（八）四爱起之法，教于衣、食、床、药「起善不起恶」。
- **（九）（一○）二喻收束**：（九）四大河入海而失本名 → 四姓出家同称「沙门释迦子」，以法为姓；（一○）四等心（慈、悲、喜、护）名「梵堂」，能度欲界诸天、生梵天处。

## 三、关键结论
- 苦乐先后由作业时节决定：先作福者先受乐，先造罪者先受罪；欲「先乐而后乐」，当勤行布施。
- 身乐在四事供养，心乐在永离恶趣；「作功德阿罗汉」福慧兼得，是当学之例。
- 众生依抟食、更乐食、念食、识食流转生死，当共舍离。
- 众生、世界、龙界、佛境四事不可思议，思之令人狂惑；唯四谛「有义、有理」，当思议四谛。
- 入佛法者无复本姓，「从法而起、从法而成」，四姓同称释迦子。

## 四、易混辨析
- **先乐后苦 vs 先苦后乐**：差别不在命遇偶然，而在百岁中作福与造罪的先后。
- **身乐 vs 心乐**：身乐＝现得四事供养；心乐＝不堕恶趣。凡夫有供养仍心不乐，阿罗汉不营福业仍心乐——福德与解脱各是一事。
- **四食 vs 四辩 vs 四神足**：四食说「以何滋养而流转」（当舍），四辩说「以何说法利人」（当成），四神足说「以何修定发通」（当修）。
- **四等心 vs 四梵之福**：同名「梵」，一者是心行之修（慈悲喜护，能生梵天、超出欲界），一者是福业之事（起塔、补寺、和合僧、请转法轮）。

## 五、阅读提示
带着一问读：同样一生，为何有人先苦后乐、有人先乐后苦？另外，（六）经「梵天造人民」一偈有四言、七言两种译笔并存，义同文异，取其义可也。
