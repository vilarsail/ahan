# 增壹阿含经卷第四 导读

## 一、内容总览

本卷为《增壹阿含经》第四卷，收两品二十经：《一子品》第九与《护心品》第十，各十经。《增壹阿含经》按法数递增编集，本卷仍以「一法」为纲：前半借「笃信父母教养独子（女）」立出在家、出家的榜样，后半以「护心＝无放逸行」为宗，兼说布施与福业。全卷主旨：降伏其心是道之本，修福布施是道之资。

## 二、结构层次

**一子品第九**——以「教养一子」为喻，答比丘当立何榜样：
- **（一）（二）男女对称**：在家男当如质多长者、象童子 ↔ 在家女当如拘仇多罗、难陀母；出家男当如舍利弗、目犍连 ↔ 出家女当如谶摩、优钵花色二比丘尼 → 警告：生染着之想，便堕三恶趣。
- **（三）（四）同题双演**：「不见一法疾于心」，猕猴舍一取一喻心不专定 → 常降伏心，令趣善道。
- **（五）（六）一堕一生**：一念恶心，屈伸臂顷堕泥黎 ↔ 一念善心，屈伸臂顷生天上，各配一偈点题。
- **（七）（八）男女互照**：男见女色、女见男色皆「缚着牢狱，无有解已」，回转五道 → 当除诸色、莫起想着。
- **（九）（十）正反收束**：不作乱想则欲、瞋恚、睡眠、调戏、疑五想不起 ↔ 观恶露不净则已起能灭 → 品末摄颂归前十经。

**护心品第十**——由内护其心，到外修福业：
- **（一）立宗**：修行一法＝无放逸行＝护心 → 三漏（欲漏、有漏、无明漏）未生不生、已生令灭，得沙门果、至泥洹。
- **（二）护心及于众生**：不触娆、不害、不恼一切众生 → 举贤圣八道品；偈叹「法施胜财施」。
- **（三）（四）转向施主**：云何观檀越 → 比丘当如子孝父母般恭敬施主；（四）阿那邠持长者登场，请佛应供，佛听弟子自取三衣钵器。
- **（五）（六）布施心法**：长者以菩萨心平等普施，飞鸟猪狗无所拣择 ↔ 众生不知施报，故恒怀悭嫉。
- **（七）（八）福业为证**：佛忆七年行慈、历劫受乐，诫「莫畏福报，当畏无福」；又忆道树下以福德大力降魔，功德具足则魔波旬不能得其便。
- **（九）（十）归趣**：心行笃信趣善处、恒专心念至泥洹 → 一人（如来至真等正觉）出现于世，众生增寿益算 → 以专精念佛收卷。

## 三、关键结论

1. 心之疾速无物可喻，前想后想刹那变易，凡夫不能自观，故当降伏心意。
2. 苦乐升坠系于当下一念：恶心秽行堕地狱，善心净行生天上。
3. 无放逸行即是护心，能伏三漏，是得果证涅槃的正因。
4. 男女色想最眩惑人，「缚着牢狱，无有解已」，当以不净观除之。
5. 修福莫倦、布施莫悔：佛以历劫福德降魔成道；施者受者两获大果，而法施胜于财施。

## 四、易混辨析

- **在家榜与出家榜**：质多长者、象童子（拘仇多罗、难陀母）只是「在家」修行的限量；舍利弗、目犍连（谶摩、优钵花色）才是「出家」的限量——佛许在家、出家两途，各有所极。
- **调戏（盖）与今语「调戏」**：此处为五盖中「掉举」的旧译，指心躁动不宁，与言语轻薄无关。
- **三漏**：欲漏（欲界贪惑）、有漏（生存之惑）、无明漏（愚痴）——同称「漏」，所对烦恼层次不同。
- **泥黎与泥洹**：一为地狱旧译，一为涅槃旧译，形近义反，勿混。
- **财施与法施**：「虽施众生福，一人法施胜」——财施感福报，法施令人解脱，故胜。

## 五、阅读提示

带着三个问题读：佛为何以「教养一子」教比丘立身？护心与无放逸行是一是二？阿那邠持「平等普施」与「福田」义如何相成？
