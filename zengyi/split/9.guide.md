# 增壹阿含经卷第九 导读

## 一、内容总览
本卷为《增壹阿含经》卷第九（东晋罽宾三藏瞿昙僧伽提婆译），即「惭愧品第十八」全品，收十经。增一经以法数递增为纲，本品诸经几乎都以「二法／二人」对举成篇：惭愧二法、二种无厌足之人、法施与食施、真沙门与真婆罗门、佛降醉象、难陀修梵行、礼敬如来、谤法与称叹之二人。主旨在家出家并重：以惭愧立人禽之别，以布施、法施教在家人，以离欲梵行、止观双修教出家人。

## 二、结构层次
- **（一）立宗**：惭、愧二法拥护世间 → 无此二法则人同六畜 → 当习惭愧。
- **（二）二种无厌足**：藏举财物者（财为王、贼、火、水所散）↔ 得物广施者（福利眷属沙门，种天上之福）→ 舍藏举、学布施。
- **（三）法施勿食施**：佛说略义 → 举往事（二比丘饥困，受食者活、不受者更可贵）→ 众比丘诣舍利弗广演 → 贪利养者于三处有羞耻 ↔ 修法者于三处有名称 → 结归贪恚灭则得处中之道＝贤圣八品道。
- **（四）真婆罗门之辨**：佛指大迦叶为真婆罗门 → 偈明漏尽阿罗汉方名梵志 → 迦叶受梵志妇请，次第说法（施、戒、生天之论 → 四谛）→ 妇得法眼净，夫妇归佛 → 答沙门即婆罗门、结缚即三毒。
- **（五）降醉象**：提婆达兜教阿阇世王纵醉象害佛 → 佛以四天下、三千大千世界明如来终不被害 → 四王诸天侍从入城 → 化狮子火坑，神手降象 → 象命终生四天王宫，六万人得法眼净。
- **（六）（七）难陀二经承接**：着妙衣被呵（何日能修阿练、头陀）→ 不堪梵行欲还俗 → 佛以神力携历香山瞎猕猴、三十三天五百天女、地狱空镬 → 难陀怖悔求忏 → 教修止观（及智辩）→ 成阿罗汉，尽舍前所许天女。
- **（八）大爱道问礼**：佛言精进、平等视声闻即是礼如来 → 记大爱道广识多知第一。
- **（九）（一○）收束**：谤法二人 ↔ 不谤二人；称叹得福二人 ↔ 妄叹妄谤受罪二人。

## 三、关键结论
- 惭愧是世间伦理的堤防：有惭愧，方有人伦上下之别。
- 布施胜于藏积；法施于中最尊，贪着利养则毁坏佛教。
- 真沙门、真婆罗门以断结缚（欲爱、瞋恚、愚痴）为准，不在种姓与咒术。
- 淫欲、饮酒终无厌足，障无为之道；止观双修是解脱正路。
- 瞋恚之报堕地狱、受蛇蚖之身；佛降暴象以慈定，不以力胜。

## 四、易混辨析
- **惭 vs 愧**：惭是自惭己恶（对己），愧是耻于他人讥嫌（对人），合称二妙法。
- **法施 vs 食施（财施）**：财施济一身之命，法施令人得解脱，故「施中之上无过财施，然复法施于中最尊」。
- **止 vs 观**：止摄心专一（定），观以慧照法（慧），二者兼修方成道果。
- **慢 vs 增上慢**：慢是自高凌他；增上慢是未得圣法而自谓已得——二者俱灭，得处中之道。

## 五、阅读提示
带着问题读：难陀从「为生五百天女而修梵行」到睹地狱空镬而怖悔，动机被佛如何层层转化？佛先前「许证五百天女」，在难陀证果后又如何自行「舍之」？
