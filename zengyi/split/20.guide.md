# 增壹阿含经卷第二十 导读

## 一、内容总览
本卷为《增壹阿含经》卷第二十，属「声闻品第二十八」。「增一」以法数递增编集，本卷除首经是长篇度化叙事外，其余六经皆依「四法」立义：四翳四结、四种之坐、四大内外、四大广演、四先苦后乐、四种沙门。首经讲四大声闻分头度化悭贪的跋提长者与其姊难陀，兼及佛为在家弟子制定授戒授归的仪则，是全经中少见的完整叙事群。

## 二、结构层次
- **首经（一）度化悭吝长者**：四大声闻相约寻访可劝化者 → 目连从地踊出向跋提乞食，为说「五大施」（即五戒）→ 长者欢喜供养，闻施戒生天、四谛之论，得法眼净、自归受戒 → 迦叶、阿那律劝宾头卢去度其姊难陀 → 宾头卢以眼脱、倒悬、出烟、燃身、出水、假死等神变层层逼拶，悭姊就范 → 饼越施越多，佛令遍施僧尼、居士、贫者，余饼投水即起火焰 → 为说法得法眼净 → 其弟优婆迦尼转告阿阇世王，王下令「事佛之家」免赋税、加礼遇 → 由「优婆塞当持几戒、食何等食」引出佛制：比丘可授优婆塞五戒与三自归，戒可随力受一条至五条（余封四戒）。
- **（二）～（四）三则四法门**：（二）日月有云、尘、烟、阿须伦四翳 → 比况欲、瞋恚、愚痴、利养四结覆心；（三）长者子手阿罗婆问佛何以「善眠」 → 归结于三毒永尽、坐「四神足坐」；（四）佛携鹿头梵志入塳间击髑髅，辨性别、病因、来生 → 唯阿罗汉髑髅「都无音向」 → 梵志出家证果，引出四大内外之别、命终各归其本。
- **（五）四大广演**：四方来比丘自称博学多闻，皆「不应承受」 → 当以契经、律、阿毗昙、戒四准绳勘验：相应者受持，违者发遣；与经不相应而义相应者「取义勿受经本」；解味不解义者以戒行问之；能解义者叹誉供养——「供养法即供养佛」。
- **（六）（七）由修而证**：（六）波斯匿王平贼来见，佛举世间四事（早起、服油酥、服药、家业娉娶）先苦后乐 → 对比丘说梵行、诵经、坐禅、数息四事先苦后乐 → 次第游四禅 → 断结证四果；（七）以黄蓝花、邠陀利花、柔软、柔软中柔软四种花喻四果沙门，收束全卷。
- 品末「修陀．修摩均……」数句是结集摄颂，把七经名目缩成韵语便于记诵。

## 三、关键结论
1. 化导悭贪者：先以「五大施」（不杀、不盗、不淫、不妄语、不饮酒）接引，再以施、戒、生天、四谛次第引导，即得法眼净。
2. 欲、瞋恚、愚痴、利养四结如云烟翳日，覆蔽人心，当求方便灭除。
3. 判定教说真伪：不轻信来者的博学名头，以契经、律、阿毗昙、戒四准绳勘验；义与经违者不受，「义者解经之源」。
4. 沙门四果次第：断三结成须陀洹（极迟七死七生）→ 三结尽、淫怒痴薄成斯陀含 → 断五下分结成阿那含 → 漏尽成阿罗汉。
5. 阿罗汉入无余涅槃，来去之迹全然不可测知，故精于星宿医药的鹿头梵志也「都无音向」。

## 四、易混辨析
- **法施 vs 财施**：目连先明「今当说法施」——财施济身命，法施济慧命。
- **四禅 vs 四果**：（六）中四禅是「先苦后乐」的修定阶段，四果是断结证真的阶位；经文由修定引向证果，相承而不同层。
- **向须陀洹 vs 得须陀洹**：「向」是正趣向该果的道位，「得」是已证果位；（三）四种之坐即用这组对配。
- **内地种 vs 外地种**：内四大指身中发毛爪齿、筋骨脏腑等，外四大指外界坚湿暖动之物；经言「虽有八种，其实有四」。
- **家家、一种 vs 七死七生**：同为须陀洹，钝者极迟七返生死，利根者只经两家（家家）乃至一受生（一种）。

## 五、阅读提示
带着三个问题读：悭吝人如何被一步步度化？佛说如何鉴别「伪经」？四禅、四果、四种沙门如何对应？
