# 增壹阿含经卷第三十五 导读

## 一、内容总览
本卷为《增壹阿含经》卷三十五：前四经（七～一○）是“七日品之余”，后五经（一～五）是“莫畏品第四十一”的开端。十经各自成篇，而暗线贯通——如何面对死亡、如何判别真修行、正法如何相传：论七种增益功德、辨修死想之真伪、斥裸形苦行非阿罗汉、解“不著世不住世”深义、慰摩呵男临终之疑、度老梵志丧亲出家、说七处善与四意止、明八正道与七觉支相配，末以佛付嘱法藏于迦叶、阿难收卷。

## 二、结构层次
- **七日品之余**
  - 经（七）问答立宗：均头问“功德可否增益” → 佛历数七事（建寺、施床座、施食、施雨衣、施药、旷野凿井、道旁作客舍）→ 以“福随其人如影随形”“大海不可升斗量”收束。
  - 经（八）递进否定：诸比丘各以“再存七日、六日……乃至一日”为死想 → 佛一一斥为放逸 → 独许婆迦利：系念出入息、于中思惟七觉意、厌患身不净 → 结以“诸行皆空皆寂，起灭如幻”。
  - 经（九）由事入理：波斯匿王误赞裸形外道为阿罗汉 → 佛说过去七梵志咒骂天师阿私陀而“慈能灭瞋”的因缘 → 归结“不以裸形名阿罗汉，摄心乃生天上”。
  - 经（一○）略说广解：佛答执杖释种“非天世人所能及，不著世、不住世” → 迦栴延广演根境识三事和合生触→受→觉→想→称量之链、七使滋长斗讼 → 阿难请名“甘露法味”。
- **莫畏品第四十一**
  - 经（一）慰安：摩呵男以“见暴牛恐惧”自疑非须陀洹 → 佛举“酥瓶沉水”喻、自述优留毗六年苦行 → 立“不可从乐至乐，要当由苦至乐”，余苦如一渧水，极七返生、勇猛者“家家”得道迹。
  - 经（二）个案度化：老梵志连丧亲眷而反赞比丘“于乐中最快乐” → 那伽婆罗偈破咒术祠祀无益，点出“恩爱无明本” → 授三衣出家，观身谛观成阿罗汉，天散华证成。
  - 经（三）法数直陈：观七处之善（慈、悲、喜、护＋空、无相、愿）与四法（身、痛、心、法四意止），现法中即名上人。
  - 经（四）临行嘱别：诸比丘北游弘化 → 佛命先辞舍利弗 → 舍利弗预设北方问难，授“色无常→苦→无我→空”答词，再解“八种之道，将从有七”，一道配一觉支。
  - 经（五）付嘱收卷：佛劝老迦叶受供养，迦叶以头陀自守并预记末法比丘堕落之相 → 佛预言千岁后法凋寺毁 → 以三阿僧祇劫所集法宝付授迦叶（留身待弥勒）、阿难（未发语便解）→ 偈“一切行无常”结卷。

## 三、关键结论
1. 建寺、施床座、施食、施衣、施药、凿井、作客舍七种布施，福不可称量，命终福随其人，如影随形。
2. 真修死想不在预筹余命几日，而在出入息中系念、思惟七觉意、厌患不净、了知诸行如幻。
3. 判圣者不凭外形：裸形非阿罗汉；慈能灭瞋，摄心不乱方生天上。
4. “不著世、不住世”即于欲得解脱、断诸狐疑——根境识三事和合生触受想，勿于中起七使。
5. 须陀洹断三结使、不堕三恶道，余苦如一渧水；修行“要当由苦至乐”；恩爱与无明是众苦之本；八正道一道起一觉支，修之漏尽心解，正法付嘱迦叶、阿难而不断。

## 四、易混辨析
- **裸形苦行者 vs 阿罗汉**：外形同是露形苦行，佛明言“不以裸形名为阿罗汉”——凡夫不知凡夫之行，真人方能知。
- **“存七日”式死想 vs 婆迦利式死想**：前者盘算寿限，佛斥为放逸；后者系念出入息、思惟七觉意，方名正修。
- **八种之道 vs 七觉意**：八正道为所行之路，七觉支为随之而起的觉法；正见→念觉意、等治→法觉意……等念→护觉意，末“等三昧”令未获者获、未证者证。
- **家家 vs 七死七生**：七死七生是初果极七返生、尽苦际的通途；烦恼轻而勇猛者不历七返，只再受生二三家即得道迹，称“家家”。

## 五、阅读提示
带着三个问题读：外形苦行能否等于修行成就？临终之际心当安放何处？佛灭之后正法靠什么不断？——本卷十经正依次作答。
