# 增壹阿含经卷第四十九 导读

## 一、内容总览
本卷属《增壹阿含经》「非常品第五十一」，收十经，同在舍卫国祇树给孤独园所说。「非常」即无常：前六经总说生死无常、护戒护心；后四经以须达（阿那邠祁）长者一家为线索，说归依三宝之福、病中念佛念法念僧、度化骄慢儿媳、及「受生皆苦」之训。

## 二、结构层次（★重点）
- **（一）（二）恒水喻起问**：问生死中涕泪、流血何者多 → 答皆多于恒河水 → 结论「当厌患生死，去离此法」「当念舍离」，两经同一结构反复演练。
- **（三）长篇因缘故事**：国王无子 → 祷天求息 → 天子五瑞应 → 降神生为王子 → 观身不净、于座上证辟支佛 → 王依塔法供养舍利 → 归结主题「思惟无常想，广布无常想」，尽断欲爱、色爱、无色爱；文中借问答带出「四种人应起偷婆（塔）」。
- **（四）对举说理**：心五弊（疑佛、疑法、疑僧、犯戒不悔、为求生天修梵行）↔ 五结（懈怠、贪眠、心乱、根门不定、乐处市井），以孵鸡卵为喻：护念得法则善法增益，失护则善法减损。
- **（五）（六）反面警戒**：持戒如王威远接，恶比丘如盗贼竞兴 → 「宁常眠寐，不于觉寤兴起乱想」，宁烧烙眼耳鼻舌，不令兴想为识所败，收束于「将护六情」。
- **（七）～（一○）须达长者系列**：（七）劝四子归依三宝，举四大藏、弥勒世蠰佉王之福，明「归佛法僧其德不可量」；（八）长者病重，舍利弗教念佛、念法、念僧，进而演十二缘起「空行第一之法」，长者命终生三十三天；（九）骄慢儿媳善生女，闻「四妇」之训（如母、如亲、如贼、如婢）改行如婢，得法眼净；（一○）舍利弗不叹豪尊、不说卑贱，佛显「夫生甚苦」「众生长夜为心所缚，不为豪族所缚」，当降伏于心。

## 三、关键结论
1. 生死流转中涕泪、流血多于恒水，应厌患生死、念舍离。
2. 思惟、广布无常想，能尽断欲爱、色爱、无色爱及无明、憍慢。
3. 五弊五结不断则善法日夜减损；断除则日夜增益。
4. 归依三宝其德不可量：不堕恶趣、得四大藏、生天尽苦际。
5. 众生长夜为心所缚，不受生分可贪，当求方便降伏于心。

## 四、易混辨析
- **心五弊 vs 心五结**：弊通「蔽」，是于三宝的疑覆与染污动机；结是懈怠、贪眠、散乱等缠缚，一遮一缚。
- **辟支佛 vs 阿罗汉**：辟支佛无师自悟、不遇佛世；阿罗汉是佛弟子闻法漏尽。二者皆应起塔供养，果德不及如来。
- **转轮圣王 vs 如来**：王以正法治世、身不行杀盗淫，塔法用铁椁香油；如来十力、四无所畏具足，塔法从之而更胜。
- **念佛念法念僧 vs 空观**：三念对治重病怖畏、令生善处；十二缘起观「空行第一之法」直显无我生灭，先安慰后导归实相，二者是次第关系。

## 五、阅读提示
读时可带着两个问题：无常想如何落到「观身三十六物不净」的实修？须达长者的四子、四妇、病中三念，各对治哪种人的病？
