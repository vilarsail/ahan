# 增壹阿含经卷第十六 导读

## 一、内容总览
本卷是《增一阿含经·高幢品》的第三部分（"高幢品第二十四之三"），收本品经六至经十共五经，东晋罽宾僧人瞿昙僧伽提婆译。依"增一"数法渐次收摄的传统，本卷以"三"为纲：三斋日与八关斋法、三事现在前、三族姓子和合共修、三结、三三昧；中间插入一段长寿王本生故事，是全卷篇幅最大、最动人的叙事。

## 二、结构层次
- **经六（斋戒）**：先立框架——每月八日、十四日、十五日三个斋日，四天王遣辅臣、太子乃至亲自下界巡查人间善恶 → 世人行善持斋则天众增益、阿须伦减损，反之天众愁忧 → 佛应请详说八关斋受法：自报名字、逐条效法阿罗汉发戒（不杀、不盗、不淫、不妄语、不饮酒、过午不食、不坐高广床、不著香华脂粉），并发愿远离八难 → 广说持斋功德：人中、天上随愿往生，乃至成就声闻、缘觉、佛乘。
- **经七（现在前）**：信、财、梵行三事现在前则获福无量 → 偈颂劝智者随时布施持戒之人。
- **经八（长寿）**：拘深比丘斗讼，佛劝阻不听 → 转说本生：长寿王弃国避战、终被梵摩达王杀戮；长生太子匿身王侧伺机复仇，三次拔剑又三次收剑，忆父遗教"怨怨不休息……无怨能胜怨" → 释放梵摩达王，二王互赦 → 归结劝诫：出家以信坚固，当忍辱和合、勿共斗讼 → 再举正面榜样：跋耆国阿那律、难提、金毗罗三族姓子共约而行，从初禅到灭尽定同步共修，以四无量心遍满诸方，佛赞其所生之处为福田。
- **经九（结）→ 经十（三昧）**：由事入理收束全卷——身邪、戒盗、疑三结如两牛同一轭，系缚众生不得从此岸至彼岸 → 当求方便灭三结；继而说空、无想（无相）、无愿三三昧，不得者"久在生死"。
- 卷末摄颂"斋戒．现在前　长寿．结．三昧"正是这五经的题目索引。

## 三、关键结论
- 三斋日受持八关斋，随愿得生人天善处，乃至成就三乘道果，"所愿者得"。
- 以怨报怨，怨终不能息；唯有无报（不报复）才能断怨——僧团当如水乳和合，不忍则斗诤。
- 身邪、戒盗、疑三结不断，众生不能从此岸到彼岸。
- 空、无想（无相）、无愿三三昧是超出生死的要门。

## 四、易混辨析
- "三斋日"（每月三个持斋日）≠ "八关斋"（一日一夜受持的八条戒）：前者是日期，后者是在该日受持的戒法。
- 经九"三结"（身邪、戒盗、疑）是系缚，经十"三三昧"（空、无想、无愿）是解脱之定，一缚一解，前后呼应。
- "四部众"（比丘、比丘尼、优婆塞、优婆夷四众弟子）≠ 本生故事中的"四部之兵"（象、马、车、步四兵种）。
- 本卷"无想三昧"即通途所说"无相三昧"的异译，指于一切法离相无著，不是外道"无想天"的禅定。

## 五、阅读提示
带着三个问题读：天神监察持斋之说反映了怎样的护法观念？长生太子"三拔三收"的内心拉锯如何诠释"无怨能胜怨"？三结与三三昧为何恰好构成"缚"与"解"的一对？
