# 增壹阿含经卷第四十五 导读

## 一、内容总览

本卷为《增一阿含经》卷四十五，卷首品题「不善品第四十八入前品中」，所收三经（四）（五）（六）承接前卷品次编排。三经主题各异而同显圣德：（四）记过去七佛的本末因缘，显佛的宿命智；（五）记师子长者平等施众，显布施之道；（六）记舍利弗入金刚三昧、恶鬼击头反堕地狱，显圣者定力威德。

## 二、结构层次

全卷三经并列，各以问答推进：

- **（四）记佛名号**：诸比丘共论「如来知过去佛事，是自力通明、还是诸天告知」→ 佛现身自答 → 依「劫数 → 种姓 → 姓氏 → 道树 → 弟子众 → 侍者 → 寿量」七项逐一宣说七佛本末，每项长行之后即以偈颂重述一遍 → 阿难追问「恒沙诸佛皆知，何故但说七佛」→ 佛答：将来弥勒、师子应等诸佛出世，亦各记七佛本末 → 结出经名「记佛名号」。
- **（五）平等施**：师子长者请舍利弗等五百上首罗汉应供 → 佛借与罗云的问答立义：从众中「僧次」请一沙门供养，其福胜于别请五百罗汉（饮尽江河之水喻——唯饮海水可尽，众如大海，十类圣者皆从众出）→ 长者发心「不择人施」→ 诸天两番现身，劝其拣择「施此福多、施此福少」→ 长者忆佛教诫，坚持平等心施 → 佛印可「菩萨所施心恒平等」→ 长者于座上得法眼净，佛记为优婆塞中「平等施第一」。
- **（六）金刚三昧**：一万梵迦夷天从梵天命终，来礼舍利弗，叹其定境深不可测 → 二鬼从虚空过，恶鬼伽罗欲击其头，善鬼优波伽罗力谏不听 → 一击之下地裂二分，恶鬼全身堕阿鼻地狱 → 佛问舍利弗病（唯苦头痛），显金刚三昧不可坏之德 → 追叙贤劫拘屡孙佛时等寿比丘入定被焚不损的本事 → 劝诸比丘「当求方便，行金刚三昧」→ 总叹舍利弗种种智德，以「弟子花」偈收束。

## 三、关键结论

- 七佛出现于三劫：九十一劫前毗婆尸，三十一劫前式诘、毗舍罗婆，今贤劫拘屡孙、拘那含牟尼、迦叶、释迦——名号、种姓、道树、弟子、寿量，如来以自身神智悉知，非由诸天告知。
- 从僧众中依僧次请一人供养，其福胜于别请五百罗汉——「三乘之道皆出乎众」，僧是世间无上福田。
- 布施贵在心平等：不拣择持戒犯戒，「此应施、此不应施」之念不起，方是菩萨之行，长夜获福无量。
- 金刚三昧不可破坏：火不能烧、刀不能斫、鬼不能伤；舍利弗常游空三昧与金刚三昧二处。

## 四、易混辨析

- **择施 vs 平等施**：择施挑持戒、犯戒而施，计较福多福少；平等施不加拣别，佛所赞的正是后者。
- **别请（私施）vs 僧次请**：指定请某位圣者 vs 从僧团中依座次差遣一人；佛以「江流归海」喻显后者福大。
- **向须陀洹 vs 得须陀洹**：「向」是趣向其果而未证（四向），「得」是已证其果（四果），合成四双八辈，余三双例此。
- **空三昧 vs 金刚三昧**：观诸法空寂之定 vs 如金刚不可坏之定，舍利弗兼修，故称「多游二处」。

## 五、阅读提示

读（四）可留意七项信息排比的节律（长行一项、偈颂一义）；读（五）要抓「天人之言」与「佛之教诫」的张力——本经正要破「择福而施」的心；读（六）自问：一鬼一拳何以撼不动圣者毫毛？
