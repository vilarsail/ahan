# 增壹阿含经卷第五 导读

## 一、内容总览
《增壹阿含经》卷第五，东晋罽宾三藏瞿昙僧伽提婆译，含两品：**不逮品第十一**（十经）与**壹入道品第十二**（十经）。全卷以「增一」体例展开：前品围绕「当灭一法」与利养之害，后品围绕「一入道」与头陀行。两大主题一以贯之——贪欲利养使人「不逮」（不能证得圣果），一心修道则直达泥洹（涅槃）。

## 二、结构层次
**不逮品第十一**（灭障 → 证果）：
- **排比立宗**：（一）～（四）灭贪欲、瞋恚、愚痴、悭贪各「一法」→ 佛保证得阿那含；每经长行之后附同型偈颂（「～之所染，众生堕恶趣」），长行释义、偈颂收束。
- **对比推进**：（五）（六）心难调伏则「难得时宜、受诸苦报」↔ 心易调伏则「易得时宜、受诸善报」→ 教人「当分别心，当思惟心」。
- **因果递进**：（七）（八）染着财物 → 于大众中作妄语；即使「正使命断」不妄语，仍会因财染而破戒。
- **举事为证**：（九）（十）提婆达兜二经：深厕之喻（愚痴偏着利养、作五逆罪，无一处可捉拔）→ 比丘疑「一劫受罪」之记别，佛显「如来所说终不虚设」→ 比丘悔过，佛说悔过灭罪偈。
- 品末结偈「四种阿那含　二心及二食　婆达二契经」总摄十经（「婆达」即提婆达兜）。

**壹入道品第十二**（立正道 → 举典范 → 再警利养）：
- **长经总纲**：（一）一入道＝专一心＋贤圣八品道 → 灭五盖 → 详演四意止：观身（不净观、地水火风四大、九孔不净、死尸九观）、观痛（苦乐舍三受，食／不食之分）、观心（爱欲、瞋恚、三昧、解脱等诸心相）、观法（七觉意、初禅至四禅）→ 得泥洹证。
- **短经排比**：（二）～（四）修慈忍、一人出世为最上福田、瞻视病者即是瞻视佛。
- **举迦叶为范**：（五）叹誉／毁辱阿练若、乞食、一坐一食、冢间坐等头陀诸行，即是叹誉／毁辱佛本身；（六）大迦叶年老不舍头陀，佛赞「头陀行在世者，我法亦当久在于世」。
- **回收利养主题**：（七）～（一○）婆罗留支王子五百釜食供养成提婆达兜五逆 → 堕摩诃阿鼻；提婆达兜否定善恶报 → 师利罗比丘贪利养退失神通、堕屠杀业 → 利养之报「断皮、断肉、断骨、彻髓」，层层收警。

## 三、关键结论
1. 灭贪欲、瞋恚、愚痴、悭贪四种法，即证阿那含——烦恼是「不逮」（不得圣果）的总因。
2. 利养之害由皮入髓：败善本、退神通、堕地狱，提婆达兜、师利罗即其明证。
3. 正修路线是「一入道」：专注一心，行八正道，灭五盖，修四意止（身、受、心、法），直证涅槃。
4. 叹誉或毁谤头陀行，等于叹誉或毁谤佛；头陀行住世，正法久住。
5. 瞻视病人即瞻视如来，是施中最上，获大福报。

## 四、易混辨析
- **贪欲 vs 悭贪**：贪欲泛指五欲贪着；悭贪特指于己财物的吝啬不舍。
- **痛 vs 受**：本卷「痛」即「受」（感受）的古译——乐痛＝乐受，苦痛＝苦受，「痛痛」犹言种种感受，切勿以疼痛字面理解。
- **习法 vs 尽法**：习＝集（生起），尽＝灭（消散）；「观习法、观尽法」即观诸法缘生缘灭，非「学习之法」。
- **记别 vs 猜测**：记别是佛对特定人未来果报的确定宣说，经中强调「如来所说终不虚设、身口所行而无有异」。
- **三乘之道（本卷特殊用法）**：经谓「须陀洹、斯陀含、阿那含三乘之道」，此处指三种道果，非通途「声闻、缘觉、菩萨」三乘。

## 五、阅读提示
带着「利养为何被喻为断皮彻髓之害」的问题读提婆达兜、师利罗二事，再回到壹入道品（一）看正修的全程路线，本卷的警戒与引导便一目了然。
