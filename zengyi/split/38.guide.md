# 增壹阿含经卷第三十八 导读

## 一、内容总览
本卷为《增壹阿含经》卷三十八，属「马血天子问八政品第四十三」，收五经。全卷以「八」为纲：「八政」即贤圣八品道（八正道）；又有八关斋戒、漂流木之八种障难、利养引生之八邪，皆围绕「修行之路如何走完」展开。

## 二、结构层次（文章的骨架与逻辑推进）
- **经一（步度世界）**：马血天子问「步行能否走尽世界」 → 佛以人、日月、三十三天、艳天的神足层层对比，证神速终不能尽 → 佛自述过去作仙人「马血」时神足虽妙、涉世界而不能尽其方域 → 结归「要当乘圣贤八品之径路，然后乃得尽生死边际」 → 天子得法眼净、散华说偈。
- **经二（八关斋法）**：佛应优波离问 → 先列八戒条目 → 次说八日、十四、十五日从比丘受斋之法与发愿之文（愿离八难、值遇弥勒三会）→ 复以宝藏如来世「供灯老比丘」与「王女牟尼」的本生故事证「无愿不果」 → 末后揭明：老比丘即灯光如来（燃灯佛），王女牟尼即释迦自身；顺带详说授记时佛光出入部位之别。
- **经三（漂流木喻）**：江中大木「不着两岸、不中没、不搁岸、不被捉、不回转、不腐败，便渐渐至海」 → 佛逐项配释：此岸是身、彼岸是身灭、中没是欲爱、岸上是五欲、被捉是求王位或生天福、回转是邪疑、腐败是八邪 → 牧牛人难陀闻喻求出家，佛令先还牛于主，后成阿罗汉。
- **经四（诫利养）**：提婆达兜失神足犹受阿阇世日供五百釜食 → 佛以「求木」三重之喻（取枝叶、舍根持枝、识根而取）配比丘得利养后的三种情形 → 判定戒、定、神足皆「世俗常数」，唯智慧是「第一之义」 → 贪利养则习八邪、离八正。
- **经五（船筏喻）**：先教被贼所缚当如地水火风遍满慈心 → 次说缚筏渡河、到岸舍筏 → 答比丘「云何舍法」：依憍慢灭憍慢 → 佛忆念成道前树下思降魔王波旬，魔于虚空说偈，卷终。

## 三、关键结论
1. 神足飞行不能尽世界边际，唯乘八正道之「舟船」能得尽生死之边——世界之边即生死之边。
2. 持八关斋必发誓愿，「无愿不果」；供灯老比丘以愿成佛即其明证。
3. 女人之身当生不能作转轮圣王乃至如来，然非永绝无上道，未来佛前终当受记。
4. 戒、定、神足是世俗常数，智慧是第一之义；贪着利养则习八邪而离八正。
5. 善法尚可舍，何况非法——法如渡筏，到岸不携。

## 四、易混辨析
- **贤圣八品道 vs 八关斋法**：前者是八正道（正见至正定），为解脱通途；后者是在家居士一日一夜受持的八戒（杀、盗、淫、妄、酒、非时食、高广大床、歌舞香华），两「八」并出，须分清。
- **此岸 / 彼岸**：漂流木喻中此岸指「身」（执身为实），彼岸指「身灭」（涅槃），不是空间上的两岸。
- **授决 / 授莂**：同即「授记」，佛预记当来之果；本卷并说光入顶为记成佛、入肩为记声闻、入脚底为记生地狱等。
- **憍慢灭憍慢**：非以慢斗慢，而是借「我必当胜」的向上之慢为方便，次第降伏诸慢，最终连此方便之慢也灭去。

## 五、阅读提示
带着两问读：一、「世界之边」与「生死之边」如何是一事？二、钝根老比丘与女身王女这两个「不可能」如何在漫长时间里翻转为成佛因缘——由此体会「誓愿」在本卷修行观中的枢纽地位。
