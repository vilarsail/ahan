# 增壹阿含经卷第二十五 导读

## 一、内容总览
本卷为《增壹阿含经》卷第二十五，属「五王品第三十三」，共收十经，皆以「五」为纲立目：五王论五欲之优劣、尊者尸婆罗的福报因缘、两篇「五战斗人」喻比丘护戒、两篇扫地与扫塔功德、多游行与一处住的正反五事，末以「无戒受施必堕恶趣」的枯树火喻收束。全卷围绕两件事：如何看破五欲（知其味、知其患、知其出离之道），如何守好戒行（防欲、惜施）。

## 二、结构层次
- **（一）五王论五欲**：波斯匿等五王各执一欲为「最妙」→ 共问佛陀 → 佛答「各随时宜」（随各人性行所着，各以其所着者为最妙）→ 再对色、声、香、味、细滑五段排比，套用同一公式：有「气味」故众生染着、有「过失」故可厌患、有「出要」故得出离至涅槃 → 小结「所乐之处，心即染着」。
- **（二）尸婆罗因缘**：月光长者无子、遍祷诸神 → 婴儿手握摩尼珠出生、开口说偈 → 家人惊走、尼犍子劝杀 → 天神点醒「四事不可轻」→ 佛赐名尸婆罗、为说施戒生天诸论令得法眼净 → 出家速证阿罗汉，福报第一却处处避供养 → 以神足度悭贪叔父、说达嚫 → 佛追述九十一劫以来四段宿缘，逐一点认「岂异人乎」→ 结归「我弟子中第一福德者」。先果后因，是典型的本生因缘结构。
- **（三）（四）两篇五战斗人**：先列军阵五等（见风尘而怖 → 闻鼓角而怖 → 见高幢而怖 → 临阵被擒 → 破军无惧），再一一配比丘五等（一见女色即还戒……第五人观三十六物不净，欲漏、有漏、无明漏心得解脱）。两篇同构互补：（四）增出「宁吞热铁丸，不以无戒受人信施」的重话，并以偈点题「欲从想生」。
- **（五）（六）两篇扫地**：扫地五事不成 ↔ 五事成德 → 扫偷婆（塔）五不成 ↔ 五成——日常作务即是修行。
- **（七）（八）（九）**：多游行五难 ↔ 不多游行五德；恒一处住五非法 ↔ 不一处住五德——正反对照，两边遮止。
- **（一○）枯树火喻**：佛见大树为火所烧，连发五问（投火？断手足？热铁缠身？吞热铁丸？卧铁床？），一一判言宁受其苦、不以无戒受人信施，末劝修戒、定、慧、解脱、解脱所见五分法身；同座闻法，六十比丘漏尽意解，六十比丘还俗，两途对照，最见警策。

## 三、关键结论
1. 五欲本无高下，「最妙」只随个人性行执着而定，故当平等论之。
2. 对任何一欲都应作三重观察：有气味（引贪）、有过失（致苦）、有出要（可解脱）。
3. 欲从想生：除去想念、观身不净，欲漏、有漏、无明漏心得解脱。
4. 宁吞热铁丸、卧热铁床，不以无戒受人信施——信施之重逾于身命。
5. 尸婆罗「福德第一」非天授，皆由过去供佛施僧之誓愿而来。

## 四、易混辨析
- **气味**（本卷）≠ 嗅觉之气味：指五欲中引人贪爱的「滋味／爱味」。
- **细滑**：即「触」尘的旧译，身根所对的乐受，非形容「细软光滑」。
- **一处住之过 ↔ 多游行之处**：一者执着屋舍亲族，一者散乱忘失教法，两篇对症相反。
- **尼犍子**（又作尼揵子）：耆那教外道，断言杀儿；与佛记「福第一」恰成对照。

## 五、阅读提示
带着一问去读：我心里把哪一欲当作「最妙」？再看佛如何把它拆成「有味—有过失—有出要」三句——这是全卷最可搬运的观察框架。
