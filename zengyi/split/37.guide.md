# 增壹阿含经卷第三十七 导读

## 一、内容总览
本卷为《增壹阿含经》卷第三十七，属「八难品第四十二」之二，承前卷收本品第三经后半至第十经，凡十篇，皆以「八」数贯串：梵法罚、八未曾有、八种地动、八大人念、八部之众、八处惠施、施之八功德、八正道邪正两途。开篇正值佛涅槃前夕（克在夜半），是全经中最珍贵的临终教诫场景。

## 二、结构层次
- **卷首·第三经（承前）**：阿难问如何处置恶比丘车那 → 佛教以「梵法罚」（不与语、默摈）→ 拘尸那竭五百摩罗人夜半前赶来作最后归依 → 外道须拔（须跋陀罗）求见，阿难三阻，佛以天耳闻之，许其入问 → 须拔问六师优劣，佛言：无八贤圣道则无沙门四果，随演说八道 → 须拔座上得法眼净，出家即证有漏心解脱，为佛最后弟子 → 求先佛入灭，佛默许（诸佛常法），须拔即于无余涅槃界灭度 → 佛遗嘱比丘相称之礼：小称大「长老」，大称小「姓字」，立字当依三尊。
- **（四）海法对辨**：阿须伦举大海八未曾有 → 佛以佛法八未曾有一一相应（戒律、四姓去名同一味、八道味、七觉意宝、出家灭度无增减、种种三昧）→ 阿须伦误计佛「与诸天说五谛」，天子纠正：诸佛终无二言，唯说四谛。
- **（五）地动八因缘**：先说世界构造（阎浮里地下有水、火、风，风下际有金刚轮）→ 风动则火动、水动、地动 → 次列菩萨入胎、出胎、成道、涅槃、神通自在、天人生为帝释梵王、福尽刀兵饥俭八缘。
- **（六）八大人念**：阿那律自思知足、少欲、闲居、持戒、三昧、智慧、多闻七念，复问戒与闻孰胜 → 佛言戒为先导（戒→定→慧→多闻→解脱→灭度），补「精进」为第八念，举释尊以精进力先弥勒三十劫成佛，喻如乳酪酥中醍醐最上。
- **（七）八部之众**：佛自述历住刹利、婆罗门、长者、沙门、四天王、三十三天、魔、梵天八种大众之中，独步无侣，无能见顶。
- **（八）～（一○）施法收卷**：给孤独长者八处昼夜惠施、其心平等 → 施于四向四果贤圣众，则施少福多、施多福多 → 惠施八功德（随时、鲜洁、手自斟酌、誓愿、解脱、求灭、良田、回向众生）→ 终以八正道「邪见趣泥犁、正见向涅槃」正邪对举作结，卷末摄颂总括十经。

## 三、关键结论
- 八贤圣道（八正道）是沙门四果之因：无八道则无道果，佛道亦由之而成。
- 诸佛说法终无二言、平等普施，唯说四谛；「五谛」之想是妄计。
- 八大人念以「精进」为最上，释尊正以精进力先弥勒三十劫成佛。
- 戒为入道先导：戒成就→定意→智慧→多闻→解脱→无余涅槃。
- 平等普施福已第一；更择贤圣福田，则施少获福多、施多获福多；施之归趣在灭度，不在生天。

## 四、易混辨析
- **摩罗 ≠ 魔王**：「五百摩罗」是拘尸那竭的末罗族人（佛涅槃地之部族），非天魔。
- **贤圣八品道 ≠ 八大人念**：前者是八正道（等见、等治、等语、等业、等命、等方便、等念、等三昧）；后者是大人八种心行——知足、少欲、闲居、持戒、三昧、智慧、多闻、精进。
- **等治／正治**：本经以「治」译「思惟」，等治、正治即八正道第二之正思惟，「邪治」即邪思惟。
- **苦、习、尽、道**：四圣谛异译，「习」＝集谛（苦因之招集），「尽」＝灭谛，勿另作他解。
- **施少获福多 vs 施多获福多**：差别不在数量而在福田与用心——施贤圣众、心无增减（偏党）者福增。

## 五、阅读提示
带三问读：佛临终如何调伏恶性比丘（梵法罚即默摈）？最后一位弟子因何得度（唯八正道是道）？同样布施为何果报悬殊（心之平等、田之胜劣）？
