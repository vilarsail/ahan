# 增壹阿含经卷第五十 导读

## 一、内容总览
本卷为《增壹阿含经》卷五十，属“大爱道般涅槃品第五十二”，含三经。经（一）记佛陀姨母、第一比丘尼大爱道闻佛将灭度，率五百比丘尼先行入灭，佛亲自抬床火化、起塔供养；经（二）借婆陀（即劫毗罗）比丘尼“独坐而笑”，自述九十一劫来供佛求女身的宿命；经（三）以铁城芥子喻说明“劫”的长远。一“死”、一“生”、一“时间”，合起来是一场完整的生死教育。

## 二、结构层次
**经（一）“灭度—供养”一条主线层层推进：**
- 闻讯求灭：大爱道闻佛三月后当灭 → 自念不堪见佛与阿难灭度 → 请先灭度，佛默然可之（沉默即许可）→ 临别请“比丘尼还与比丘尼说禁戒”，是留给尼团的制度遗嘱。
- 示现众灭：大爱道闭门击干椎，腾空坐卧经行、身出水火，顺逆出入九次第定，终由四禅灭度 → 差摩等五百比丘尼同样示现十八变而灭 → 二沙弥尼本欲护师，闻师已灭，观“有习之法皆是尽法”即证三明六通而灭——灭度本身成了一场示范教学。
- 备葬供养：大将耶输提奉命备五百床具、酥油画薪 → 帝释、梵王、四大天王率众争相求供养，佛以“父母恩重，要当报恩”一概谢绝，与难陀、罗云、阿难各举床一脚飞至冢间火化 → 说偈“一切行无常……此灭为最乐” → 起偷婆，说如来、辟支佛、声闻、转轮圣王四类人应起塔，大众得法眼净。

**经（二）宿命自传，由一个“笑”字层层展开：**
- 婆陀忆宿命而笑 → 众尼请问 → 九十一劫六段履历依次排开：毗婆尸佛世，童子执盖见人观美色，发愿“作端正女人” → 生天上为天女，诸天说偈相争 → 式诘、毗舍罗婆佛世，作长者妇供食供衣 → 无佛之世作月光长者的婢女，以一升细麨供养各佛（辟支佛），夫人以饭钱、金钱、脱籍、易位乃至酷刑相诱，她坚决不让出福德 → 贤劫拘楼孙、拘那含牟尼、迦叶诸佛世继续供佛求女身 → 今世与摩诃迦叶结为夫妇、先后出家。
- 收束点题：“我以无智自蔽，供养六如来，求作女人身”——一念之愿牵引九十一劫，故自笑 → 佛印证她为尼众中“自忆宿命第一”。

**经（三）劫喻收束：** 比丘问“劫为长短” → 佛说铁城芥子喻：百岁取一芥子，满城芥子尚有取尽之日，而劫极长远 → 点出“生死长远……恩爱缚着……当求巧便，免此爱着之想”，为前两经的生死轮回作结。

## 三、关键结论
- 圣者灭度是从容的示现：出入诸定、空中现变，非可怖之死。
- 报父母恩是如来亲行之事：佛谢绝诸天，亲自抬床供养养母遗体。
- 应起塔者四人：如来、辟支佛、声闻、转轮圣王；起塔者长夜受福。
- 一念誓愿引九十一劫之报：供佛功德不失，“求作女身”的愿也如实成熟。
- 劫再长，芥子终有取尽之日；轮回恩爱缚着却“无有穷已”，当求巧便断爱着。

## 四、易混辨析
- 般涅槃 vs 取灭度：同指圣者究竟入灭。“般涅槃”重“圆满寂灭”，“灭度”重“灭惑度脱生死”，经中互用无别。
- 四禅与空处～有想无想处 vs 想知灭：前者是色界、无色界的八种禅定（九次第定之前八），凡夫亦可修；“想知灭”即灭尽定，想与受俱息，唯圣者能入，大爱道由此灭度。
- 佛 vs 各佛（辟支佛）：佛应世说法、建立僧团；各佛是无佛之世独自觉悟的圣者，月光长者所供养的“沙门”即是，勿读作“各位佛”。
- 耶维（蛇旬）vs 偷婆：前者是火化遗体，后者是奉安舍利的塔，一葬一藏，前后相续。

## 五、阅读提示
带着三个问题读：佛为何“默然”即是许可？佛为何坚持亲自供养、不肯让与诸天？婆陀之笑，笑的是供养六佛也改不掉的一念愚愿——可对照经（三）“恩爱缚着”四字来回味。
