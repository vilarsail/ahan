# 增壹阿含经卷第四十七 导读

## 一、内容总览
本卷为《增壹阿含经》卷四十七，卷首题「放牛品第四十九今分品」，属《增壹阿含经》「放牛品」。开篇是前经的后半（施罗梵志见佛相好、请问「同一道」得解脱），其后依次为四经：经七「一坐而食」、经八「沙门法行与婆罗门法行」、经九「提婆达兜始末」（全卷最长、故事性最强）、经十「慈心解脱十一果报」。

## 二、结构层次
- **开篇（承接前经）**：施罗梵志问解脱 → 佛答「更有解脱得涅槃界」，说八种道（正见乃至正定）→ 梵志诸尘垢尽、得法眼净，率五百弟子出家 → 应供翅宁梵志家，饭后说偈而去。
- **经七（一坐而食）**：佛倡一坐而食 → 跋提婆罗再三辞不堪 → 迦留陀夷暮夜乞食、惊吓妊妇致堕胎，恶声流布 → 佛集众立制：一坐而食、乞食之法，并举迦叶头陀十一法、面王着弊衣为范 → 佛自说累劫贪食之报（如火获薪、大海吞流）→ 跋提婆罗克责成阿罗汉。由个案引出立制，由立制归于自省，一条「食戒」线贯穿。
- **经八（二种沙门）**：先分「习行沙门 ↔ 誓愿沙门」 → 阿难问沙门法行 → 以诸根寂静、饮食知足、恒知景寤三层展开 → 婆罗门要行＝如实知四谛、离三漏 → 结以词源释义收束：沙门＝息心、梵志＝清净、刹利＝断淫怒痴、沐浴＝洗二十一结……由「名」问「实」。
- **经九（提婆达兜）**：求出家被拒 → 自剃头冒称释种 → 从修罗陀学威仪、得神足通 → 以神通猎阿阇世供养 → 教王害父、掷石出血、放醉象、杀法施比丘尼 → 毒爪害佛不成，地火出身、堕阿鼻地狱 → 阿难悲泣，佛记其经一劫狱苦，出狱后六十劫不堕恶趣，终成辟支佛号「南无」 → 目连入阿鼻慰问，说宿业对应偈 → 佛诫勤修身三、口四、意三。恶行逐级升级，果报逐条对应，是全卷重心。
- **经十（慈心）**：修慈心解脱得十一种果报，从「卧安觉安」直到「生梵天上」，以偈总收全卷。

## 三、关键结论
1. 八正道是通向涅槃解脱的完整道路。
2. 一坐而食、少欲知足是行道要法；贪食如大火获薪、大海吞流，永无厌足。
3. 沙门者息心，梵志者清净——名号随德而立，断淫怒痴方称其实。
4. 神通敌不过业力：提婆达兜得神足而生慢、贪利养，恶念一起神足即失，终堕阿鼻；然临终一称「南无」，善种不灭，六十劫后成辟支佛。
5. 修慈心解脱，现世卧安觉安、天护人爱，命终生梵天上。

## 四、易混辨析
- **习行沙门 vs 誓愿沙门**：前者威仪戒行如法，以「学行」得名；后者尽有漏成无漏、现身证果，境界更高。
- **神足 vs 漏尽**：提婆达兜有神足通而未断诸漏——神通不能断惑，一见利养便堕。
- **沙门 vs 梵志**：经中一名两用——既指出家众与婆罗门教徒，卷末又重新定义其实：沙门＝息心，梵志＝清净。
- **大劫 vs 小劫**：阿鼻狱寿「一劫」指大劫，即贤劫；劫尽行尽，还复人身。

## 五、阅读提示
带着两个问题读：神通与道力孰重（经九）？出家人的名与实如何相符（经七、八、九）？再以经十的慈心对照提婆达兜的瞋害，善恶两条线索一目了然。
