# 增壹阿含经卷第三十二 导读

## 一、内容总览
本卷为《增壹阿含经》卷三十二，属「力品」（第三十八品）下半，收第七至第十二经。六经各成一单元，而同以「圣者威德」为底色：一山之圣（仙人山辟支佛）、一念之力（系六情）、一观之利（无常想破欲）、一王之赞（波斯匿王赞佛六德）、一国之难（佛降毗舍离疫鬼、挫六师外道），终于观六情入涅槃。叙事多、议论少，故事性为四阿含中所少见。

## 二、结构层次
- **（七）仙人山缘起**：佛在灵鹫山连问四山旧名 → 独许「仙人山」之名历劫不改 → 追溯五百辟支佛居山、闻佛将出世而烧身灭度（「世无二佛之号」）→ 补叙喜益王念三恶道苦、舍位出家成辟支佛 → 结劝比丘亲近承事此山。
- **（八）六虫系一处**：教「专念知时」，欲漏、有漏、无明漏未生不生 → 设六虫（狗、狐、猴、鱼、蛇、鸟）各驰其境之喻 ↔ 内六情各逐其尘 → 系六情于一处则魔不得便 → 具足眼根得二果。
- **（九）挑眼破欲**：劝广布无常想 → 善目辟支佛应长者女之请，右手挑眼示之：眼如痈疮浮泡、身如画瓶盛秽 → 说「缘是有是」之缘起 → 女思六情无常，得四等心而生梵天。
- **（一〇）波斯匿王赞佛**：王出游观，感园林寂然空虚 → 佛劝「以法治化」，生天增六事功德 → 王自数如来六功德，佛赞为「师子吼」 → 嘱比丘讽诵流通。
- **（一一）降疫挫外道**（全卷最长，三段推进）：阿阇世请夏坐 ↔ 毗舍离遭罗刹疫鬼 → 最大长者冒死请王放佛，佛记阿阇世灭罪生天、终成「除恶」辟支佛 → 路上二千五百宝盖应现，佛笑说善化王太子（自身前生）以盖覆儿神寺之因缘 → 至毗舍离说至诚语退疫鬼；六师议战，输卢尼比丘尼凌空一喝，六师屈服，佛记尼中第一。
- **（一二）观六情入涅槃**：凡夫染着六入、流转生死 ↔ 圣弟子观六情无常、苦、空、非身 → 得二果、入无余涅槃——与（八）一止一观，遥相呼应收卷。

## 三、关键结论
- 无佛之世，辟支佛自悟缘起成道；一世界无二佛并出，如一商队无二导师。
- 六根各逐其境，如六虫共系一绳；以专念系于一处，魔不得其便。
- 广布无常想，能尽断三界爱、憍慢与无明。
- 诸法「缘是有是，此起则起」；观身如画瓶盛秽，欲念自消。
- 忆念佛德者离三恶趣；以法治化者生天增福。
- 观六情无常、苦、空、非我，现生可证阿那含、阿罗汉。

## 四、易混辨析
- **辟支佛 vs 阿罗汉**：辟支佛于无佛之世独自觉悟，不从师教；阿罗汉依佛声教而证果。
- **六入 vs 内六情**：同指眼耳鼻舌身意；「六入」就根境相涉入处言，「六情」旧译就根中情识作用言。
- **「二果」vs 斯陀含**：本卷「得二果」非四果中之斯陀含（二果），乃谓「两种果位」——现生证阿那含或阿罗汉。
- **般涅槃 vs 无余涅槃界**：般涅槃通指究竟灭度；无余涅槃界特指烦恼与色身俱尽、更无残余。

## 五、阅读提示
带两问读：佛为何独许「仙人山」之名历劫不改？两位国王（波斯匿、阿阇世）与佛对答，各显如来何种威德？（一二）与（八）对照读，可见「系念」与「无常观」一止一观之别。
