# 增壹阿含经卷第十九 导读

## 一、内容总览
本卷《增一阿含经》卷十九，分两截：前半是《四意断品》（第二十六）的收尾——舍利弗灭度后，目连尊者随即辞佛，抱病回到本生处，遍入诸定而灭度；佛为诸比丘说供养舍利、四种人应起塔之法；又记婆迦梨比丘病中求刀自刺，临终思惟五蕴而证涅槃，魔王遍寻其神识不得。后半为《等趣四谛品》（第二十七）全品十经，以四谛为纲，旁及布施、菩萨六度、四无所畏、慈心护生与四种可敬人。

## 二、结构层次
**前半（四意断品之余）——叙事线：「二大弟子相继入灭」**
- 舍利弗灭度 → 佛亲捧舍利，叹其智慧（「大树无枝」喻僧团顿失依怙）→ 目连闻讯请辞，佛默然不答 → 目连出罗阅城回本生处，抱重病遍入四禅、四无色定、火光／水光三昧、灭尽定，往返出入、现十八变后取灭度 → 诸天下界散花供养。
- 佛说「二施业」（财施从二大弟子求、法施从佛求）→ 阿难问供养之法 → 四种人应起偷婆（塔），逐一说因缘。
- 婆迦梨经 → 病重求刀自刺 → 思惟五盛阴，有漏心得解脱，入无余涅槃 → 弊魔波旬遍寻神识所在而不得 → 佛说其「今日得四谛」→ 品末偈颂收束。

**后半（等趣四谛品）——十经并列，佛说与弟子说交替，同归趣于四谛**
- （一）佛自说四谛 → 舍利弗重演四谛义（全品总纲，品名所本）
- （二）外道挑战「沙门瞿昙教法与我何异」→ 佛以「一究竟／众多究竟」层层勘验 → 递进展开：二见 → 四受 → 四沙门
- （三）阿那邠邸长者问布施 → 毗罗摩旷世大施 < 一房施招提僧 < 三归 < 五戒 < 弹指慈愍 < 须臾不可乐想（逐层递进比较）
- （四）日初出四喻（如来／檀越／高德法师／弊魔）↔ （五）弥勒问檀波罗蜜——菩萨布施四法
- （六）四无所畏、师子吼转梵轮 ↔ （七）四人博古明今最为第一（附偈颂）
- （八）四种金翅鸟食四种龙，唯事佛、行四等心之龙免难 ↔ （九）善知识布施四功德，得甘露灭
- （一○）四种可敬可贵之人：持信、奉法、身证、见到 → 结劝「除上三人，念修身证之法」

## 三、关键结论
1. 二大弟子相继入灭，僧团如大树失枝，而如来无有愁忧——生死去来本是法尔。
2. 婆迦梨抱病求刀自刺，临终思惟五盛阴即证无余涅槃；证果者神识「永无所著」，魔不能见。
3. 应起塔供养者唯四种人，资格在德行果位（十善、漏尽、无师自悟、十力四无所畏），不在名位。
4. 布施果报不在多寡好丑，而在至诚用心、发愿、信心；毗罗摩旷世大施犹不及三归、五戒，更不及一念慈愍众生。
5. 外道与佛法之别在一「究竟」：唯一而非众多，无欲、无恚、无痴、无爱、无受，智者所究竟而非怒者所究竟。

## 四、易混辨析
- **舍利 vs 舍利弗**：「舍利」是火化后的遗骨，「舍利弗」是人名；「授舍利弗舍利」＝呈上舍利弗的遗骨，连用最易读混。
- **持信人 vs 奉法人 vs 身证人 vs 见到人**：持信凭笃信他语入道；奉法亲自观察法之真伪；身证亲身作证、任己性而游；见到断三结得须陀洹，以慧见契入。
- **四受 vs 十二支之「受」**：本卷「四受」（欲、见、戒、我受）实即「四取」（执取），由爱而生；与十二因缘中「受」（觉受）同名异实。
- **习谛／尽谛 vs 集谛／灭谛**：「习」＝集（苦之因，即爱结），「尽」＝灭（爱尽无余）；本卷用旧译「习、尽」，与通行「集、灭」不同。

## 五、阅读提示
带着两个问题读：布施的果报差别由什么决定？证果之人临终神识何在？——本卷正是这两问的答案。
