# 增壹阿含经卷第二十八 导读

## 一、内容总览
本卷属《增壹阿含经》「听法品第三十六」。前四经是典型的「增一」式短经，各以一组「五功德」劝行：随时听法、造浴室、施杨枝、勿杀生。第五经是本卷主体，长篇叙事：佛应帝释之请上三十三天为母说法，途中降伏难陀、优槃难陀二龙王，救护波斯匿王；人间四众思佛，优填王以牛头栴檀、波斯匿王以紫磨金造出世间最早的两尊佛像；三月后佛自金、银、水精三道降下僧迦尸池侧，说五盛阴苦，优钵华色比丘尼化转轮王先礼，须菩提以观空礼佛，五王建寺，佛说造像功德，结经名「游天法本」。

## 二、结构层次
- **短经群（一）～（四）**：同一格式「闻如是……告诸比丘……有五功德……欢喜奉行」，逐条并列——听法之功 → 沐浴之功 → 施杨枝之功 → 杀生之过（对比：屠者今生富贵皆前世宿福所致）。
- **长经（五）**：叙事一波三折——
  - **缘起**：帝释请佛上天为母说法 → 佛默然受之 → 二龙王嗔恚放火 → 诸弟子请战皆被止 → 目连先化巨龙慑之、再入微形戏于其口鼻耳眼，降伏二龙，携至舍卫城皈依受戒。
  - **插曲**：波斯匿王来问烟火 → 迁怒「二人」险遭龙报复 → 佛敕目连隐形护宫，雨刀剑瓦石皆化作莲华七宝 → 王供养、闻因缘而「更生」。
  - **转场**：佛入三昧隐于天上三月 → 人间四众与二王渴仰成疾 → 群臣建议造像（造像起源）→ 阿那律以天眼遍观三界觅佛不得 → 目连上天问讯，约七日后还。
  - **收束**：自在天子化三道 → 佛降下说五盛阴苦 → 优钵华色化转轮王先礼 ↔ 须菩提缝衣观空礼佛（色身 vs 法身）→ 五王自报家门、优填王问造像之福 → 佛从地中出迦叶如来寺为造寺范式，结经名「游天法本」。

## 三、关键结论
1. 随时听法五功德：闻所未闻、重加讽诵、见不邪倾、无有狐疑、即解甚深之义。
2. 杀生者不得乘车马大象，今生之福皆前世宿行；当于一切众生起慈心。
3. 「我身生于人间，长于人间，于人间得佛」，用人间饮食时节——佛法根本在人间。
4. 度父母是如来出世五事之一，故有上三十三天为母说法。
5. 真礼佛在观空无我：「空无解脱门，此是礼佛义」；造佛像亦有大福，阎浮提二像自此而始。

## 四、易混辨析
- **痛阴 vs 想阴 vs 行阴 vs 识阴**：痛＝觉受苦乐；想＝取相而知（知青黄白黑、知苦乐）；行＝造作（成善成恶）；识＝分别是非、识别诸味。
- **三十三天 vs 兜术天**：佛此番上三十三天（忉利天）为母说法；兜术天即兜率天，欲界第四天。卷末「始从兜术天来下」与前后文略有出入，读时以三十三天为主线。
- **转轮圣王 vs 如来**：世间出此「二珍宝」；优钵华色借转轮王七宝之形压过五王，抢先见佛。
- **神足 vs 天眼**：目连神足第一，任往返天上之责；阿那律天眼第一，却遍观三千大千刹土不见佛——因佛入三昧自隐，见制于定力。

## 五、阅读提示
带着两个问题读：佛像为何被造出来？礼佛到底礼什么？本卷正是佛教造像起源与「观空礼佛」两个著名母题的早期文本。
