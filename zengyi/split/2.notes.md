# 增壹阿含经卷第二 词语注释

① 罽宾　罽音jì。古西域国名，约当今克什米尔一带；此处为译者的籍贯标注。
② 闻如是　即「如是我闻」：佛经开卷套语，结集者自言「以下是我亲自听佛所说」。
③ 祇树给孤独园　舍卫城著名精舍：祇陀太子的树林、给孤独长者的园地，二人合力供佛，佛陀常年在此说法。
④ 无为处　无为即无造作生灭，涅槃的异名；「至无为处」谓到达涅槃之境。卷中「至无为道」同义。
⑤ 逮沙门果　逮（dài），及、获得之义（非今义「逮捕」）；沙门果指出家修道所证圣果（须陀洹至阿罗汉四果）。「逮沙门果」即证得沙门圣果。
⑥ 白世尊曰　白，禀告、陈述（下对上陈说曰「白」，非「白色」义）；谓诸比丘向世尊禀白启请。
⑦ 结跏趺坐　趺音fū，足背。两足交叠加于对侧大腿上而坐，即全跏趺坐（俗称莲花坐），佛家坐禅的标准威仪。
⑧ 系念在前　系念，把心念拴系于一个所缘上；「在前」谓将念头安放于当前，专注一境不使散失。
⑨ 十力　佛所具的十种智力，如知是处非处、知三世业报、知众生根器利钝、宿命通、天眼通、漏尽通等。
⑩ 四无所畏　佛在大众中说法无所畏惧的四种自信：正知一切智、永断漏尽、宣说障道之法、宣说尽苦之道。
⑪ 视之无厌　厌，通「餍」，满足；谓瞻仰如来相好永不满足。切勿误读为「厌烦」。
⑫ 三昧　音译词，即「三摩地」，意为定、心住一境；文中「入三昧定」之「三昧」同此。
⑬ 未始有减　未始，未尝、从来不曾；「未始有减」谓如来三昧从来不曾有丝毫减损。
⑭ 强梁　强横凶暴、刚愎不驯；「憍慢强梁」谓憍慢之心刚强难伏（「憍」同「骄」）。
⑮ 憺怕　憺音dàn；「憺怕」即「澹泊」，恬静安泊（「怕」通「泊」）。「诸情憺怕」谓一切情念皆恬淡寂静。
⑯ 恚想　恚（huì），嗔怒怨恨；「恚想」即嗔恚之念，与「欲意」（贪欲）、「愚惑」（愚痴）并举，即贪嗔痴三毒。
⑰ 犹豫网结　疑心缠缚如网如结（疑为五盖之一）；谓犹疑之结使皆已除尽。
⑱ 智无崖底　崖，边际；底，尽头。「智无崖底」谓如来智慧深广无边、无有限量。
⑲ 诸趣　趣，去往之处，指天、人、畜生、饿鬼、地狱等轮回去处；「诸趣已尽」谓不再流转诸趣受生。
⑳ 生分　再受生（后有）的因缘份限；「无复生分」谓不再有来生的因缘，故永不堕入生死。
㉑ 度知见城　度，越度、超越；谓如来智慧知见超迈无碍、如越出城垣，故能「知他人根」——彻知他人根器，应度不应度、死此生彼皆悉知之。
㉒ 尘劳　烦恼的异名：烦恼如尘垢染污身心，如劳役扰乱心神；「无有尘劳」即不为烦恼所扰。
㉓ 渴爱　贪爱执著，如渴者求水不能自止（即十二因缘中之「爱」）；「渴爱之心永不复兴」谓贪爱永不再生。
㉔ 永不复兴　兴，生起；谓渴爱之心永不再生起。「复兴」非今义，勿误读。
㉕ 诸盖　盖，覆盖心性、障蔽善法者，指贪欲、嗔恚、睡眠、掉悔、疑五盖；与之连言的「结缚」亦烦恼之总称（烦恼缠缚众生于生死）。
㉖ 所以然者　然，如此；「所以然者……故」是古汉语因果句式：「之所以这样，是因为……」。
㉗ 世福田　福田，喻能生长福报的田地；佛门圣众是世人种福之田，故应恭敬供养。「是世福田故」即「因为（圣众）是世间的福田」。
㉘ 缨络　同「璎珞」，贯串珠玉而成的颈饰；「戒缨络身」谓戒如璎珞庄严其身。
㉙ 吉祥瓶　能随愿出生宝物的吉祥宝瓶，喻持戒则所求如愿、一切善法从戒而出。
㉚ 所愿便克　克，成、遂（非「攻克」义）；「所愿便克」谓凡有所愿皆能成就。
㉛ 道品　通指趣向涅槃的修行科目，常指三十七道品（四念处、四正勤、四如意足、五根、五力、七觉支、八正道）；「诸道品法皆由戒成」谓一切道品以戒为根本。
㉜ 手卷相加　卷，通「拳」；「手卷相加」即挥拳相加。谓他人以拳脚、刀杖、瓦石加害于我，也当起慈心不瞋。
㉝ 念休息　十念之一。「休息」非今义歇息，指心念止息、烦恼寂灭（趣向涅槃寂静）；文中「心意想息」即自释。
㉞ 详谛　详，安详；谛，审确真切。「志性详谛」谓心志安详明审、精确不浮躁。
㉟ 卒暴　卒，同「猝」，仓卒急躁；「无有卒暴」谓心无急躁粗暴之气。
㊱ 方便　佛家术语，指达成目标的方法途径；「常求方便，入三昧定」谓常想方设法（用功之法）进入禅定。
㊲ 胜光上达　殊胜之光向上通达：承上「常念不贪」，谓不贪之念生起胜妙光明、上彻通达（此句诸解略异，大意如此）。
㊳ 安般　音译词，「安那般那」（ānāpāna）之略，指出息、入息即呼吸；「念安般」即以呼吸为所缘系心。文中「息」即指气息，「息长息短」谓觉知呼吸之长短；「数息」即默数呼吸以摄心。
㊴ 寻息出入　寻，循、跟随；谓心随气息之出入而觉知，「分别晓了」即分辨清楚明白。
㊵ 白䐈　念身观所列身分之一；「䐈」为生僻字，「白䐈」一般指体内白色薄膜状组织（白膜）。
㊶ 百叶　身分名，所指诸说不一：或谓肺叶，或谓如牛百叶之胃脏。
㊷ 溺　通「尿」，小便之义。
㊸ 㵪　音xián，同「涎」，口涎（唾液）。
㊹ 髑髅　音dú lóu，即骷髅、死人头骨。
㊺ 地种　种即「大种」（元素），地种、水种、火种、风种即地水火风四大；经文连问「地种是也？水种是也？……」谓逐一观此身由四大中何大所成。
㊻ 父种、母种　种，种子，指父精母血；谓反观此身为父母精血和合所造，从何而来。
㊼ 此没生彼　没，殁亡；谓在此处命终即在彼处受生，形容众生生死流转不息。
㊽ 命根　佛家谓维持寿命的机能（寿根）；「命根断绝」即寿命终了。
