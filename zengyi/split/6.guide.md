# 增壹阿含经卷第六 导读

## 一、内容总览
本卷为《增壹阿含经》卷第六，属"利养品第十三"，收该品七经，佛分别在舍卫国、罗阅城（王舍城）、拔祇国等处所说。全卷以"利养"为眼目，从贪著名利供养的祸害讲起，历数恩爱别离之苦、身病与心病之辨、心净胜于外浴、施福归于圣众、病苦从法而息，教人舍染著、净其心。

## 二、结构层次
七经并列而内有一条暗线：**贪染（利养、味欲、恩爱）→ 病（身病心病）→ 净（心净、法药）→ 空（归无我）**：
- **（一）修罗陀比丘**：以实例立宗——贪国王百味供养，渐废头陀行，还俗屠牛、堕地狱 → 结论"利养甚重，未生当制，已生当灭"。
- **（二）味欲**：由外境之"利养"收摄为内心之"味著"——灭此一法，则得神通、漏尽，短偈结之。
- **（三）恩爱别离**：全卷最长。丧子长者狂走问儿 → 误传"恩爱别离有乐"之语流布宫城 → 摩利夫人连环反问波斯匿王五重所爱（琉璃王子、伊罗王子、萨罗陀、夫人自身、迦尸拘萨罗人民）→ 王自证"有忧"、心服佛说 → 问答体层层推进，证明恩爱别离、怨憎会是苦。
- **（四）身病心无病**：那忧罗公问佛 → 佛答"身有患，当令心无患" → 复问舍利弗 → 广演：凡夫计五阴为我，色识败坏则愁忧（身心俱病）；圣弟子不于五阴计我，身病而心无病。教理由事入理（无我）。
- **（五）江侧婆罗门**：先列二十一结染心堕恶趣 ↔ 无结生善处（白㲲喻）→ 修慈、悲、喜、护四无量 → 成三昧 → 发宿命、天眼、漏尽通 → 以"孙陀罗江沐浴能否洗罪"一问收束，偈颂破外道水净，婆罗门出家证阿罗汉——真沐浴在心不在河。
- **（六）释提桓因偈问"施谁福最尊"**：体例极简，偈中"施僧获福多……获福不可计"既是问、也是所闻佛答。
- **（七）须菩提问疾**：帝释遣乐神波遮旬弹琴启请 → 须菩提说"法法自生，法法自灭；法法相动，法法自息""一切所有皆归于空"，病苦即除——以空观呼应（四）"身病心无病"，作全卷收束。
- 卷末两行五言偈是本品经题的记忆结颂（"调达""皮""利师罗"等与本卷正文不尽对应，属结集传诵痕迹）。

## 三、关键结论
1. 利养能坏道业：贪著名利供养可使比丘退失苦行、还俗造恶，故当未生制之、已生灭之。
2. 凡有所爱必有别离之忧：恩爱别离、怨憎会是苦，无乐可言。
3. 身可病，心不可病：不于五阴计我我所，则色识变坏时不生愁忧。
4. 净罪在内不在外：二十一结染心者堕恶趣，无结者生善处；持戒行慈是真沐浴，江水洗不去宿罪。
5. 万法归空：贪用不净治、瞋用慈治、痴用慧治，法法相动、法法自息，一切归于无我空寂，病苦自除。

## 四、易混辨析
- **利养 vs 味欲**：利养是外在的名利供养（衣食物敬），味欲是内在对口腹滋味之贪；一是境缘，一是心所。
- **身有患 vs 心有患**：身患＝色身老病之苦；心患＝于五阴起我、我所执而生的忧恼。身病难免，心执可断。
- **慈、悲、喜、护**：四无量心。慈＝予乐，悲＝拔苦，喜＝随喜而离妒，护＝此卷对"舍"（平等、不染著）的译语。
- **结、流、漏**：皆烦恼异名，取譬不同——结如系缚，流如漂溺，漏如渗漏。二十一结是本经别列的细目，四流指欲、有、见、无明四种瀑流。

## 五、阅读提示
带着"什么才是真正的清净"一问读本卷：利养污心、恩爱系心、河水不能洗罪，唯有不净观、慈心与智慧，及"一切归空"的正观，能净其心。
