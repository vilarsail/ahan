# 增壹阿含经卷第八 导读

## 一、内容总览
本卷为《增壹阿含经》卷八，属"安般品"的后半（接续前卷，经号自（二）至（一一）共十经）。"增壹"以数法递增编目：前半依"二法"开演——二人难得、二法烦恼、邪见正见一对；后半转入长篇故事与问答——顶生王本生、观月辨善恶知识、周利槃特论议降外道、提婆达兜教唆弑父警世。主旨可括为：欲贪无厌必堕落，正见善知识可贵，为政不正则天地失序。

## 二、结构层次
- **数法对举**：（二）（三）以"二人出现于世甚为难得"对举——如来 ↔ 转轮圣王、辟支佛 ↔ 漏尽阿罗汉 →（四）"二法甚为烦恼"：作众恶本与不修善本，劝断恶修善。
- **种子之喻**：（五）（六）一反一正 ↔ 邪见者如苦种（苦果、苦参子、葶苈子等）种于良田犹生苦苗；正见者如甘蔗、蒲桃等甘种，种良田皆得甘美——果报劣胜，根本在"见"。
- **本生长篇**：（七）阿难静处思"欲爱无厌足" → 白佛 → 佛说顶生王：统阎浮提 → 逐次吞并瞿耶尼、弗于逮、郁单越 → 升三十三天与帝释共坐 → 一念贪害帝释，即身退堕、七宝离散 → 偈结"贪欲延亿劫，福尽还入狱" → 归于"知欲而去欲"。
- **观月之喻**：（八）生漏婆罗门问观恶知识、善知识 → 佛以月末之月（渐损）↔ 月初至望（渐盛）喻信、戒、闻、施、智慧之减与增 → 婆罗门自归三宝；（九）随即对比丘细说：族姓、戒、三昧、智慧、利养五项，恶知识"自贡高、毁呰他人" ↔ 善知识"己身与彼无有增减"，是（八）的义理展开。
- **论议降伏**：（一〇）释种讥周利槃特愚陋、并轻佛 → 世典婆罗门来觅论议 → 槃特腾逝空中现十八变，舍利弗以天耳闻、化作槃特形代辩"盲与无目"之别、"五盛阴缘爱而生"之理 → 婆罗门得法眼净、刀风起而命终 → 耶维起鍮婆，释种惭愧供养。
- **王法感应**：（一一）提婆达兜教婆罗留支王子囚父谋弑，欲作"新王、新佛" → 佛演"上不正则下乱"的连锁推演：臣佐→太子→群臣→人民→兵众→日月失度→风雨不时→谷不生长→寿命极短；反之行正法则天下安 → "牛渡水"偈（导者不正，一切皆不正）→ 劝舍非法、行正法收束全卷。

## 三、关键结论
- 欲爱无有厌足；顶生王贵极人天，一念贪心即堕——"欲求厌足，当从圣贤智慧中求"。
- 邪见者身口意行皆劣如苦种，正见者诸行可贵如甘果：改行先改见。
- 善知识如望月，信、戒、闻、施、智慧日增；恶知识如晦月，日渐减损。
- 以族姓、戒、定、慧、利养自高而毁他，即恶知识之相；反之即善知识。
- 为导者（王、臣）行非法则灾变四起、万类受苦；行正法则风雨以时、五谷炽盛、民寿延长。

## 四、易混辨析
- **盲 vs 无目**（一〇）：盲＝不见今世后世、善恶果报的事实；无目＝无智慧之眼。二者义不相同，故槃特答"此义不同"。
- **善知识 vs 恶知识**（八）（九）：判准不在身份门第，而在信戒闻施慧的增减，及是否"自贡高、毁呰他人"。
- **如来 vs 转轮圣王**（二）：出世间之最 ↔ 世间之最，二者皆"甚为难得"。
- **辟支佛 vs 漏尽阿罗汉**（三）：无师自悟的圣者 ↔ 佛弟子闻法断漏所证的果位。

## 五、阅读提示
带着两问读：顶生王已与天帝同坐，为何还堕落？观月的喻体（月末／月初）各对应恶、善知识的什么特征？留意每经如何以"喻"起、以"结劝"收。
