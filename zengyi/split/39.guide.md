# 增壹阿含经卷第三十九 导读

## 一、内容总览
本卷为《增壹阿含经》卷三十九，属「马血天子品第四十三」之下半（之一在卷三十八），收该品第五至第十共六经。第五经（船筏）承接上卷：佛向比丘自述成道前与魔波旬大军对阵之事，并重提「一觉喻经」的筏喻；第六经（牧牛）以摩竭牧牛人渡恒河喻佛与弟子渡生死；第七经（无根信）是本卷最长的一经，记阿阇世王月夜访佛、忏悔弑父、闻「现世作福现受报」而归依；第八、九经（世法、善）说世间八法（利衰毁誉称讥苦乐），佛如莲华处泥不染；第十经（八人）说四双八辈「流转生死，不住生死」。

## 二、结构层次
全卷四条线索，由深到浅、由叙事到义理：
- **（五）魔战与筏喻**：魔军围道树 → 佛以「仁慈铠、三昧弓、智慧箭、福业兵众」应之 → 魔以王位五乐相诱，佛以「吾所愿者涅槃城」拒之 → 三三昧、八正道「以法灭法」→ 指案地为证，地神涌出，魔军溃退 → 收束于「依慢灭慢」的筏喻与野狸皮喻（慢尽则调柔）→ 法会得果。
- **（六）牧牛渡河**：愚牧牛人驱牛入水，肥瘦小犊皆溺 ↔ 黠慧牧牛人先观深浅，强牛、中牛、瘦牛、小犊次第得渡 → 一一配比：阿罗汉＝强牛、阿那含＝中流牛、斯陀含＝瘦牛、须陀洹＝瘦牛携犊、持信奉法者＝小犊；能渡者唯八正道。
- **（七）无根信**：受岁月夜，王遍询群臣 → 群臣各荐六师外道（不兰迦叶、阿夷专、瞿耶楼、休迦旃、毗卢持、尼揵子），王皆「不合其意」→ 耆婆伽荐佛 → 王惧弑父之罪，耆婆伽以「佛怨亲平等」劝行 → 圣众入炎光三昧放光，王礼佛悔过 → 佛以典酒厨宰、赏劳供养等一系列问答证成「现世作福得受现报」→ 王归依忏悔，佛说「为罪能改者生天上」，并点出王因弑父失初果、唯得「无根之信」。
- **（八）（九）（一○）短经并列**：世八法随世回转当除 → 佛如淤泥莲华、琉璃净水不为八法所染 → 八种之人（四向四果）流转生死而不住生死。
- 卷末偈颂「马血．斋．难陀　提婆达．船筏　牧牛．无根信　世法．善．八人」总摄本品十经名，是口诵结集的存留。

## 三、关键结论
- 降魔不靠兵刃，靠慈、悲、喜、舍与空、无愿、无相三三昧之力；「以法灭法」——八正道灭八邪道。
- 生死可渡，但唯八正道是「正船」；凡夫（外道）自溺复溺人，圣弟子依果位深浅次第得渡。
- 现世作福得受现报；为罪之人若能悔改，「如屈伸臂顷」得生善处。
- 阿阇世弑父障初果之证，唯得「无根之信」——重罪能夺圣果，悔过仍可免大恶报。
- 圣者生于世间而不为世间八法（利衰毁誉称讥苦乐）所染；四双八辈虽流转生死，终不住生死。

## 四、易混辨析
- **趣须陀洹 vs 得须陀洹**：「趣」是正在趋向（向果），「得」是已证（得果），向、得各配四果即成「四双八辈」。
- **须陀洹 vs 斯陀含 vs 阿那含**：初果断三结使；二果再薄淫怒痴，还来人间一次；三果断五下结，不再还生欲界。
- **三三昧 vs 四无量**：空、无愿、无相是观慧所成之定；慈、悲、喜、护（＝舍）是普缘众生之定，本卷佛兼以二者为「军」。
- **现报 vs 受岁**：「现报」谓今生造业今生受果，与「无根之信」同为第七经眼目；「受岁」是僧团七月十五安居自恣之日，只是叙事的时间背景，勿混。

## 五、阅读提示
带着两个问题读：佛降魔为何不用神通而说「慢」是真正的怨敌？阿阇世王问遍六师皆不契，佛答「现世作福现受报」为何句句能入其心？
