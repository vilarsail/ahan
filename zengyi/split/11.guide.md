# 增壹阿含经卷第十一 导读

## 一、内容总览
本卷为《增壹阿含经》卷第十一，收「善知识品第二十」全品十三经。诸经多依「二法」对照敷演——师子↔羊、精进↔懈惰、止↔观、难说法↔易说法、怨憎会↔恩爱别离，正见《增一阿含》按法数递增编排的体例。全卷从「亲近善知识」立宗，以定光佛授记的本生长经为核心，终于「怨憎会、恩爱离皆由爱生，当学除爱」。

## 二、结构层次
- **开篇立宗**（一）（二）：先立「近善知识则信、戒、闻、施、慧增益，近恶知识则反之」→（二）实景印证：提婆达兜领五百比丘从佛前经过，佛说偈警策，五百比丘悔过得信根，成阿罗汉。
- **本生长篇**（三）：全卷重心。昙摩留支入禅观见前身是大海长鱼 → 佛一句「久来此间」引众疑 → 佛溯定光佛时超术梵志（释迦前身）以五百金钱买五茎华供佛、散发布发、蒙授决「当作释迦文佛」，而同学昙摩留支一念讥嫌，堕畜生无数劫 → 点破：因亲近善知识、修习身口意行而得出离，故言「久来此间」。
- **二法排比**（四）～（一一）：并列教诫，层层对照——受利养如师子↔如羊（四）；知反复↔无反复，恩近怨远（五）；精进↔懈惰，以弥勒为鉴（六）；阿练比丘修止↔观（七）、恭敬↔懈慢（八）；无信、悭贪者难说法↔有信、不悭者易说法（九）；供养父母↔供养一生补处菩萨得大功德（一○）；父母恩重、肩担千万岁犹不能报（一一）。
- **公案点睛**（一二）：朱利槃特记性极劣、被兄驱摈 → 佛教诵「扫㨹」二字 → 由「除垢」转入内心：「缚结是垢，智慧是除」 → 思惟五盛阴成坏，证阿罗汉。
- **收束**（一三）：世人所弃的怨憎共会、恩爱别离与世人所喜的怨憎别离、恩爱共会，四法同源——「由爱兴」→ 当学除爱，不令使生。

## 三、关键结论
1. 近善知识则信、戒、闻、施、慧日增；近恶知识则五事尽失。
2. 昙摩留支一言之恶堕畜生无数劫，亦因亲近善知识而得度——口业可畏，善友可贵。
3. 三世诸佛皆由勇猛精进与止、观二法而成正觉。
4. 父母恩重难报：肩担父母经千万岁、衣食供养犹不能报，唯孝顺供养。
5. 怨憎会、恩爱别皆由爱起；除爱则苦本息。

## 四、易混辨析
- **师子食 vs 羊食**：同为受供养，师子不拣好恶、不起染着；羊出群饱食粪垢，还群自夸。差别在得利养后起不起贪着与贡高。
- **止 vs 观**：止使心息安住，成就戒律、降伏魔怨；观照见苦集灭道实相，成就三达智。佛于树下先修止，后成观。
- **槃特 vs 朱利槃特**：兄聪慧能持戒，弟鲁钝记一句忘一句；然弟以「扫㨹」一法深入，反先证阿罗汉。
- **知反复 vs 无反复**：知反复者（知恩图报）虽在千由旬外犹近佛；无反复者虽披僧伽梨侍侧犹远。远近以心论，不以形迹论。

## 五、阅读提示
带着两个问题读：其一，第（三）经的授记故事里，「买华、布发、蹈发」各象征什么，昙摩留支为何因一句话受报如此之久？其二，「扫㨹」二字为何能令人证果——注意朱利槃特把「除垢」从扫地转到烦恼上的一步步思惟。
