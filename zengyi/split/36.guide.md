# 增壹阿含经卷第三十六 导读

## 一、内容总览
本卷为《增壹阿含经》卷三十六，属「八难品第四十二」的前半，收三经：其一说「八难」，其一说「八大地狱」，其三是佛灭度前最后一月的行迹（毗舍离告别→拘尸那竭掷石→诸力较量→比丘尼先灭→双树敷座）。主旨一以贯之：**人身难得，值佛闻法更难；佛将灭度，当抓紧修行，远离八难、不堕地狱。**

## 二、结构层次
三经呈「障难→苦果→无常警策」的递进：
- **（一）八难**：佛列「八不闻时节」——佛出世说法，而众生在地狱、畜生、饿鬼、长寿天、边地，或生于中国而六情不完具、心怀邪见、不值佛世 → 反面立「一法」：生中国、值佛世、世智辩聪、修正见者能证阿罗汉 → 结偈劝「远离八难之处，莫愿其中」。
- **（二）八大地狱**：由「难」转入「苦报」——先列八狱名 → 一一释名（还活、黑绳、等害、涕哭、大涕哭、阿鼻、炎、大炎）→ 再出每狱所辖十六隔子（小狱）→ 说何业堕何狱、狱卒治罪之苦 → 借阎罗王之口劝善（行善者生光音天）→ 结劝「修八正道」以离八难八狱。
- **（三）灭度前事**：佛在毗舍离回望城郭，说「更后不复睹」告别偈 → 说四法本（一切行无常、苦、无我，涅槃灭尽）→ 化坑掷钵付嘱 → 至拘尸那竭：五百力士举巨石不动，佛一手掷石上梵天，自言用的是「父母遗体之力」 → 层层较量诸力（骆驼＜诸象＜……＜转轮圣王＜阿维越致＜补处菩萨＜如来），而最上更有「无常力」——佛夜半当灭 → 插叙目连神足（翻地、携众乞食皆被佛止）与舍利弗智慧（墨尽笔枯犹不能写）皆不及佛 → 君茶罗系头比丘尼思惟苦本，得三达智，于佛前先取灭度 → 佛敷座头北（预示法流北天竺）、分别三衣、口出五色光说宿世因缘 → 慰勉悲泣的阿难（转轮圣王与阿难各有「四未曾有法」）→ 嘱比丘远离女色 → 卷终。

## 三、关键结论
1. 八难之「难」不在处所而在闻不到法：地狱、畜生、饿鬼、长寿天、边地、根缺、邪见、不值佛世，皆令修行无门。
2. 业果决定：杀生、不与取、邪淫妄语、害父母、乱僧各有对应地狱，「要当人中罪毕，然后乃生」，纤毫不爽。
3. 佛之尊贵不在神变：掷石用父母所生之身力，目连神足、舍利弗智慧皆百千万倍不及佛——而一切力之上是「无常力」，佛亦不免夜半灭度。
4. 「一切行无常、一切行苦、一切行无我，涅槃为灭尽」四法本，是佛灭前留给大众的总纲。
5. 离难之道：生中国、具六情、修正见、遇善知识，勤修八正道。

## 四、易混辨析
- **八难 vs 八大地狱**：前者是「闻不到法的处境」（障碍义），后者是「造恶受苦的处所」（果报义）；离难靠机会与正见，离狱靠持戒悔过。
- **还活地狱 vs 阿鼻地狱**：还活（即「等活」）狱中罪人死而复苏、反复受苦；阿鼻即「无间」，害父母、坏佛塔、乱僧者所堕，苦无间断，最重。
- **中国（经义）vs 中国（今义）**：经中「中国」指中印度佛法盛行之地（Madhyadeśa），与「边地」相对，非现代国名。
- **父母遗体之力 vs 神足力**：「遗体」＝父母所遗之身（古义，非今义「尸体」），指与常人同的血肉之力；神足力则是禅定所成的神通。佛明言掷石用的是前者。

## 五、阅读提示
带着两个问题读：佛把「无常力」放在一切力之比的最后，与开头「八难」如何呼应？阿难的四未曾有法为何「默然」也算其一？——读懂这两处，本卷「珍惜闻法因缘」的命意自明。
