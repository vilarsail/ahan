# 增壹阿含经卷第三 导读

## 一、内容总览
本卷为《增一阿含经》卷第三，收「弟子品第四」至「阿须伦品第八」五品。前四品是佛弟子的“光荣榜”：佛在祇园一一宣布比丘、比丘尼、男居士（清信士／优婆塞）、女居士（清信女／优婆斯）中各持一项“第一”的人名，共列百位比丘、五十位比丘尼、四十位优婆塞、三十位优婆斯。末品阿须伦品十经，先以阿须伦巨身、魔波旬伺便引出“信施难消”之诫；再以九经说“一人（如来）出现于世”则诸法随现、佛灭则法灭，劝人常恭敬于佛。

## 二、结构层次
- **弟子品（第四）**：十经并列，每经佛举十位“第一比丘”，句式固定为「我声闻中第一比丘，〔德目一句〕，所谓某比丘是」；经末各附四句五言偈复述人名 → 十经百人，以「此百贤圣，悉应广演」收束。人物并列、无情节推进，偈颂是口诵结集的忆持韵语；有比丘一身两德而两见（如阿若拘邻、优波离）。
- **比丘尼品（第五）→ 清信士品（第六）→ 清信女品（第七）**：同一格式逐品递减：五经五十尼 → 四经四十优婆塞 → 三经三十优婆斯，各品末以总数小结。
- 四品合观，构成「出家男众 → 出家女众 → 在家男众 → 在家女众」的完整僧俗序列。
- **阿须伦品（第八）**：十经并列 →
  - （一）阿须伦身长八万四千由延、欲触犯日月而不得 → 喻魔波旬化极妙五欲，在比丘六根上「求其方便」（得眼便……意之便）→ 比丘不染着则魔愁忧退去 → 结劝「受人信施，极为甚难」，当专意求道以消化信施。
  - （二）～（一○）九经同构：「若有一人出现于世」（多萨阿竭）→ 一经一益：饶益众生（二）、依「增一」体例按数目递升列举二谛至「十一慈心解脱」诸法（三）、智慧光明（四）、无明大冥消灭（五）、三十七品现世（六）、佛没尽则法亦灭尽、天人失荫（七）、如秋月盛满天人蒙泽（八）、三恶趣道减少（九）、无与等者（一○）→ 每经末收「当恭敬于佛、当作是学」。

## 三、关键结论
- 「第一」皆就一德而言：圣弟子各有一行出众（智慧、神足、头陀、天眼、说法、持律、多闻……），是修行型态的清单，不是高下总排名。
- 信施难消：受供养而不修道，「堕坠五趣」；唯专意「未度者度」，方能消化信施。
- 魔波旬恒在身后，化极妙五欲觅六根之「便」；比丘不近色声香味细滑法，魔自愁忧退去。
- 如来一人出世，则二谛至三十七品诸法皆现；佛灭度则法亦灭尽、天人失荫——故常当恭敬承事于佛。

## 四、易混辨析
- **弟子品 vs 比丘尼品**：同为出家众「第一」名录，格式全同；前者男众百人，后者女众五十人。
- **优婆塞 vs 优婆斯**：优婆塞是在家男居士（清信士）；优婆斯即优婆夷的异译，在家女居士（清信女），本卷分品而列。
- **空定／无想定／无愿定**：对应三解脱门。空定观诸法无我、「分别空义」（须菩提）；无想定「除去诸念」、灭息心想（耆利摩难）；无愿定于诸法不起希求、「意不起乱」（焰盛）。
- **阿须伦 vs 波旬**：阿须伦（阿修罗）是身形巨大、与天相斗的非天，本卷只作「形大可畏」的引子；波旬是天魔，专以五欲诱惑修道人，才是正文的修道之敌。

## 五、阅读提示
读前四品，可带着「每个『第一』对应哪种修行方式」的问题，把头陀、坐禅、说法、供养、持戒当作修行生涯的模板；读阿须伦品，则紧扣「一人」与诸法俱现俱灭的关系，体会「增一」以数字统摄法义的编经特色。
