# 增壹阿含经卷第三十一 导读

## 一、内容总览
本卷为《增一阿含经》卷三十一，《力品》第一分（力品第三十八之一），东晋罽宾三藏瞿昙僧伽提婆译。全卷六经，以「力」字总摄：从世间六种凡常之力起首，中间经无常想、十二缘起、四食等法义，最终归到「福力最为胜，由福成佛道」。压轴一经是著名度化公案：杀人魔鸯掘魔（指鬘）屠刀将及亲母之际被佛调伏，出家证阿罗汉，并追溯其杀业的前世因缘——佛陀时代最惊心的「放下屠刀」故事之一，即出此卷。

## 二、结构层次
- **（一）六凡常之力**：小儿以啼、女人以瞋恚、沙门婆罗门以忍、国王以憍慠、阿罗汉以专精、诸佛以大悲为力 → 结劝「常念修行此大慈悲」，点出品名。
- **（二）无常想**：修无常想 → 断三界爱及无明、憍慢 → 能分别法义、不起斗诤 → 命终生三善处。一条修行线正面推演。
- **（三）梵志逐迹**：梵志见佛足迹生疑（天？龙？夜叉？）→ 层层追问 → 佛以「有爱则有受、有受则有爱」点出五苦盛阴相续之本 → 梵志得法眼净。问答式公案。
- **（四）佛自说观缘起（本卷法义核心）**：佛忆菩萨时逆观、顺观十二缘起：痴→行→识→名色→六入→更乐→痛→爱→受→有→生→老病死（顺），一一还灭（逆）→ 中间插「旧城古道」喻（重见古仙人道）→ 结劝「知苦、习、尽、道，当求方便灭于六入」。
- **（五）阿那律誓不睡眠**：听法睡着 → 佛以偈唤醒 → 立誓彻夜不眠致眼坏 → 佛说「一切诸法由食而存」、涅槃以无放逸为食 → 佛亲为穿针、自说于六法无有厌足 → 「福力最为胜」。先抑后扬，归于求福。
- **（六）鸯掘魔经（全卷主体）**：城中人民控诉指鬘杀人取指 → 佛独身上道 → 鸯掘魔欲杀母凑数，佛放眉间光 → 追而不得，佛言「我自住耳，汝自不住」 → 闻偈觉悟，舍剑出家 → 波斯匿王欲征讨，见其已为比丘 → 得阿罗汉后以真实语救难产妇人 → 被击流血，佛令忍之 → 佛说宿缘：迦叶佛后大果王之太子清净因淫女之计被国人冤杀，临死发愿「报怨＋值佛」，即今鸯掘魔 → 结归「第一聪明捷疾智者」。

## 三、关键结论
- 世出世间诸力之中，佛以大悲为力；学人当常修大慈悲。
- 广修无常想能断三界爱、无明与憍慢，是离斗诤、趋涅槃的下手处。
- 十二缘起是「古仙人道」：识为原首，还灭则五盛阴灭；知苦、习、尽、道四谛，从灭六入下手。
- 诸法依「食」而存：眠能养眼，涅槃以不放逸为食——修行也须调身养息，不可硬拼。
- 福力最为胜，如来于布施等六法无有厌足；成佛由福。
- 极恶之人念佛因缘亦可转恶成圣；但业报不失，阿罗汉仍须现受残报，唯以忍承受。

## 四、易混辨析
- **痛 vs 受**：本卷十二缘起中「痛」＝通常说的「受」（感受），而「痛缘爱、爱缘受」中的「受」＝「取」（执取），两字分工与今通行译名错开，切勿倒置。
- **更乐 vs 六入**：更乐＝触（根境识和合）；六入＝六根。是缘起链上紧邻的两环。
- **调戏盖 vs 结**：调戏＝掉举（心浮不静），懈怠与结（烦恼）相应——佛示精进与懈怠各有偏差，当处中道。
- **食 vs 饮食**：此处「食」是「滋养、资益」义（四食之食），眼以眠为食、意以法为食，非仅食物。
- **四部之众 vs 四部之兵**：前者指比丘、比丘尼、优婆塞、优婆夷四众弟子；鸯掘魔经中「四部之兵」则指王之四种兵。

## 五、阅读提示
带着两个问题读：其一，佛如何一步步用「问住」与「走不过」调伏一个杀魔（「住住」与「我自住」之问答是全篇眼目）；其二，缘起顺逆观与鸯掘魔的宿世因缘如何互相呼应——知生死之「原本」，才知放下屠刀何以可能。
