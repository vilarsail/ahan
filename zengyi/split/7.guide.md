# 增壹阿含经卷第七 导读

## 一、内容总览
本卷为《增一阿含经》卷第七，属按法数递增编集的"一法""二法"部分，含四品：五戒品第十四、有无品第十五、火灭品第十六、安般品第十七之一（该品之首经）。全卷主旨：先以五戒明罪福因果，再以成对的"二法"破邪立正，继而以难陀、阿那律、罗云三位尊者的事行点出"火灭"（贪瞋痴尽）之果，最后以罗云修安般（数息）历四禅、发三明而成阿罗汉，完整示范由戒入定、由定发慧的解脱次第。

## 二、结构层次
- **五戒品（一法·罪福对照）**：杀生↔不杀生，劫盗↔广施，邪淫↔不他淫，妄语↔不妄语，饮酒↔不饮酒——每对两经：一明恶报（堕地狱、饿鬼、畜生，若生人中则短命、贫匮、丑声等），一明善报（人中福、天上福、泥洹证），条条对应，末以偈结。
- **有无品（二法·破邪立正）**：有见、无见当舍 → 法施/法业/法恩皆胜于财施/财业/财恩 → 愚者智者二相反衬 → 以"智慧、灭尽""力、无畏""无与等、大慈大悲"内思礼如来 → 二因二缘（受法教化、内思止观）生正见。
- **火灭品（以人显法）**：难陀斥魔、自陈"淫欲如骨锁、蜜涂利刀、剑树毒果" → 明有余/无余二种涅槃界 → 乌、猪、驴、牛四喻责无惭愧、不护根门 → 列十善十恶 → 说"烛明"（贪瞋痴尽）与趣道之业（八正道） → 忍力、思惟力成道 → 阿那律教梵志除憍慢结、得天眼 → 罗云持戒而"有漏心不解脱"，伏下安般品。
- **安般品（修行实证）**：佛携罗云入城乞食，途中教观五阴无常 → 罗云中途还园，结跏趺坐念无常 → 佛教安般、不净、慈悲喜护四心 → 罗云系心鼻头、遍知出入息长短冷暖 → 依此入初禅至四禅 → 发宿命通、天眼通，观苦、苦习、苦尽、苦出要而成尽漏心 → 成阿罗汉，佛赞"持戒第一"。

## 三、关键结论
1. 五戒各有对报：不杀得长寿，远离劫盗（广行布施）得福泽，不淫得身洁无邪想，不妄语得口气香芬、名德远闻，不饮酒得聪明不惑。
2. 有见、无见皆属边执、"亦非真见"，如实知而后尽舍；法施、法业、法恩胜于财施、财业、财恩。
3. 不观淫欲如火坑（骨锁、蜜涂刀、毒果等喻），则不能度欲、有、见、无明四流；观了则必能度。
4. 涅槃分有余、无余二界，当求无余；忍力、思惟力是佛成道与众生证四果之本。
5. 持戒清净不必然漏尽——罗云"小罪尚避"而漏心未解，须修安般、由四禅发宿命天眼、知四谛，方得漏尽。

## 四、易混辨析
- **有余涅槃界 vs 无余涅槃界**：前者灭五下分结、般涅槃后不还来此世（如阿那含）；后者漏尽、意解脱慧解脱、更不受有（阿罗汉）。
- **乌喻 vs 猪喻**：同是犯欲作恶，能自羞、悔过、向人说者如乌（食不净犹知拭嘴）；不羞不悔、反自誉"我能得五欲"者如猪。
- **驴喻 vs 牛喻**：形似沙门而诸根不定、不护戒门者，如驴入牛群自称"我亦是牛"；诸根寂定、饮食知节、意游三十七道品者，如真牛入牛群。
- **有见 vs 无见**：有见执欲、色、无色三有及五欲为实有；本卷将常断、边无边、身命一异等六十二见归入"无见"——二见皆当舍离。

## 五、阅读提示
带着一个问题读：为何持戒第一的罗云仍未证漏尽？看本卷如何从"戒"（五戒品、罗云持戒）推进到"定"（安般四禅），再到"慧"（知苦习尽道、成尽漏心），即抓住全卷骨架。
