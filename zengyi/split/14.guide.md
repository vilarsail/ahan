# 增壹阿含经卷第十四 导读

## 一、内容总览
本卷为《增一阿含经》高幢品（第二十四品）前半，收五经。品名"高幢"出自第一经：帝释教三十三天怖畏时回望其高幢，佛借喻教比丘怖畏时忆念三宝。全卷围绕"谁堪依怙"展开：念三宝除怖 → 佛救那优罗、降毗沙恶鬼 → 法王胜转轮王 → 五蕴无常无可恃 → 追叙成道初转法轮、降毒龙，处处落在"佛为世间真皈依处"。

## 二、结构层次
五经并列，一总四分，各显佛德一面：
- **（一）立总纲**：帝释高幢喻 → 类比比丘怖时当念佛（十号）、念法、念僧 → 层层退守（不念我则念法，不念法则念僧）→ 小结"当念三尊"；关键对比：帝释犹有淫怒痴而诸天念之除怖，如来无之，何况。→
- **（二）降魔救危**：拔祇恶鬼日索一人 → 那优罗次应祠鬼、父母啼哭归命诸天及如来 → 佛以神足至鬼住处 → 教小儿施戒生天之论、进而四谛，得法眼净受五戒 → 与鬼斗法（霹雳化优钵莲华、石壁化饮食、象狮火龙相克）→ 问答"故行、新行、行灭" → 鬼忆迦叶佛时宿业，忏悔出家，施山谷与招提僧 → 入城宣化，八万四千人得法眼净，那优罗父供四部之众。→
- **（三）身份之争**：释种请佛还俗作王 → 佛自言"我今正是王身，名曰法王"，以七觉意宝、声闻眷属胜转轮圣王。→
- **（四）法义印证**：以爪上土喻说五蕴无恒常者 → 佛忆昔为转轮圣王八万四千象马车台之盛 → 会归"惠施、慈仁、自守"三福 → 正观六入处厌患 → 厌则解脱，比丘成阿罗汉。→
- **（五）追叙本缘**：成道后思先度罗勒迦蓝、郁头蓝弗（俱已命终）→ 度五比丘 → 途遇优毗伽问师 → 于波罗㮈说四谛三转十二行 → 阿若拘邻得法眼净，诸天展转传声 → 五比丘尽成阿罗汉 → 往优留毗降石室毒龙，迦叶始信。

## 三、关键结论
- 怖畏现前时忆念佛、法、僧，怖畏自灭；天主帝释尚有烦恼，佛宝远胜之。
- 眼等六根是宿业所感的"故行"，今生身口意造作是"新行"，故行灭尽、更不造新即"行灭"。
- 恒常不变之五蕴如爪上土，毕竟无有；五蕴非我非我所，厌患则解脱。
- 四谛于"三转十二行"中说尽，阿若拘邻先得法眼净，是为僧宝之始。
- 法王之位"无终无始"，胜过得而复失的转轮圣王之位。

## 四、易混辨析
- **故行 vs 新行 vs 行灭**：故行＝过去业感所成的果报六根；新行＝今生所造身三口四意三业；行灭＝故行灭尽、不更造作，业行永息。
- **转轮圣王 vs 法王**：前者以七宝千子统四天下，福报有尽；后者以七觉意为宝、声闻为营从，无终无始。
- **苦习谛 vs 苦尽谛 vs 苦出要谛**：即四谛中集、灭、道三谛之古译——"习"谓爱之集起，"尽"谓爱灭不更生，"出要"谓出离之道（贤圣八品道）。
- **罗勒迦蓝 vs 郁头蓝弗**：佛出家时的两位仙人老师，前者得无所有处定，后者得非想非非想处定，皆在佛成道前命终，未闻法而失解脱机缘。

## 五、阅读提示
带着两个问题读：帝释高幢与佛的十号名号如何充当"可依怙者"？毗沙鬼从食人恶鬼到施山出家，转折点——忆宿命与闻"故行新行"之问——发生在哪一步？
