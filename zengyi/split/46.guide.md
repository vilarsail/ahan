# 增壹阿含经卷第四十六 导读

## 一、内容总览
本卷为《增壹阿含经》卷四十六，属「放牛品第四十九·第四分别诵」。增一阿含随法数递增编品，本卷六经皆扣「十一法」展开：以牧牛十一法喻比丘道业，继说头陀十一法、罗汉所不习十一法，终以十二因缘深义与种姓论辩收束，是「放牛品」的代表作。

## 二、结构层次（★重点）
- **（一）牧牛喻立宗**：恶牧牛人十一过（不别色相、不摩刷、不护疮、不起烟、不知渡处……）→ 逐条对照比丘十一失 → 良牧十一德 → 比丘十一法 → 偈颂收束「六年成六通」。
- **（二）头陀十一法**：阿难问「何以正有十一法」→ 佛列阿练若至冢间十一头陀行 → 学一年乃至一月即证二果（阿那含、阿罗汉）→ 点出「十二因缘皆出十一法中」→ 举大迦叶为楷模，谓供养迦叶现身受报。
- **（三）以类相从**：佛见弟子各领众经行 → 逐一印可所擅（舍利弗智慧、目连神足、迦叶头陀、阿那律天眼、离越入定、迦旃延论议、满愿子说法、优波离持律、须菩提解空、罗云持戒、阿难多闻）→ 对照提婆达兜「为恶之首」→ 其三十余弟子闻偈悔改、皆证阿罗汉 → 结归「善者与善相应，恶者与恶相应」。
- **（四）象舍利弗事件**：比丘还俗扶妇 → 阿难愁忧，佛预言却后七日重来证果 → 梵志诽谤、众人质问 → 象舍利弗答：罗汉不犯戒、不还俗，世俗五通必失、漏尽六通真实 → 列「罗汉所不习十一法」→ 人民自归。
- **（五）十二因缘甚深**：无明→行→识→名色→六入→更乐→痛→爱→受→有→生→老死，逐支下定义 → 阿难轻言「不甚深」→ 佛举须焰阿须伦浴海喻（海水齐腰、底不可测）并斥之 → 三转十二说缘起。
- **（六）种姓论辩**：翅宁代问姓族 → 佛四番破婆罗门姓贵（随父定姓、驴马生驹、二子贤愚在行不在姓、边地唯人与奴且不定）→ 以光音天下生说人类起源 → 施罗梵志慕名观三十二相，唯见三十相（缺阴马藏、广长舌），以偈发问——悬念留至下卷。

## 三、关键结论
1. 修行如牧牛：守护六根（摩刷）、遮止恶念（护疮）、随时说法（起烟）、食知止足、敬奉长老，则现法饶益。
2. 十一头陀行是速证之道：一年乃至一月即得阿那含、阿罗汉二果；十二因缘尽摄其中。
3. 众生以类相从：近善知识则善，近恶知识则恶；提婆达兜弟子回头即证罗汉。
4. 真罗汉不还俗、不犯戒；世俗五通有漏必失，漏尽六通方是真实行。
5. 十二因缘极为甚深，非常人所能晓；佛法之中无高下种姓，贵贱由行不由姓。

## 四、易混辨析
- **痛 vs 受**：本卷「痛」即「受」（受阴），三痛＝乐、苦、舍三受；而「爱缘受」之「受」实为「取」（四受：欲、见、戒、我），一卷两用，勿混。
- **五通 vs 六通**：五通（天眼、天耳、他心、宿命、神足）属世间有漏，仙人生上界犹退堕；六通加漏尽通，唯阿罗汉所证不退。
- **世俗禅 vs 灭尽迹**：世间四禅八定「至竟不解脱」，须循灭尽之道方证圣果。
- **摩刷 vs 覆护疮**：摩刷喻对境时守护根门（未生令不生），覆护疮喻欲恚害念已起时立即舍离（已生令灭）。

## 五、阅读提示
带着两个问题读：牧牛的「留遗余」（挤奶留余饲犊）对应比丘哪条德目？施罗梵志为何独独看不出二相？答案在卷四十七。
