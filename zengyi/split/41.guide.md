# 增壹阿含经卷第四十一 导读

## 一、内容总览
本卷为《增壹阿含经》卷四十一，属〈马王品第四十五〉，全卷七经。前二经戒色欲、明僧团所依，中三经说住处取舍、利养之患与慈心功德，末二经赞叹空三昧为王三昧、记尸利掘长者毒食害佛终归化之事。全卷围绕「修行人当离什么、依什么」层层展开。

## 二、结构层次
- **（一）拒女色·说宿缘**：婆罗门献女 → 佛拒之，长老比丘求之 → 佛说女人九恶法 → 复引过去「普富商主堕罗刹岛、马王负渡」本生 → 授记人物（商主＝舍利弗，罗刹女＝今女，梵摩达王＝今比丘，马王＝佛） → 比丘悔过，成阿罗汉。现前之事 ↔ 过去之喻，层层印证「欲为不净」。
- **（二）遣众·众依**：舍利弗、目连将五百比丘来释翅村，声高被遣 → 释迦族人、梵天代为劝谏 → 佛受谏召回 → 问二人心念：目连愿收摄众，佛叹「众中之标首唯吾与汝二人」 → 随说比丘九恶法 ↔ 九善法对照收束 → 六十余比丘漏尽意解。
- **（三）住处取舍**：依村落住，恶增善灭则当去 ↔ 恶灭善增则可尽形寿住 → 阿难问衣食因缘，佛说四事供养有三等，归结「少欲知足」。
- **（四）乞食不获·忆古佛**：魔遮食缘，佛举过去拘楼孙佛同遭遮食 → 说九种食（人间四食 ↔ 出世五食） → 魔改以利养诱之，佛诫「利养堕恶趣」→ 魔遁去。先阻后诱，魔的两手与佛的两番破斥对应。
- **（五）慈心最胜**：恶鬼坐帝释座，诸天瞋则鬼转端正，帝释自称名则鬼灭 → 佛自述七岁修慈、经历成坏七劫之果报 → 列慈心诸功德 → 无佛之世自修得道者入辟支部，结「慈最第一」。
- **（六）空三昧**：佛问舍利弗游何三昧 → 答空三昧 → 佛忆未成道时于树下思惟众生流浪生死之因在无空三昧 → 空→无愿→无想递进 → 结「王三昧者，空三昧是也」。
- **（七）毒食害佛**：长者尸利掘事外道六师 → 设火坑毒食请佛 → 火坑化莲池，佛蹈莲而入 → 说至诚偈，食毒无恙 → 尸利掘忏悔，阿阇世王、耆婆伽登场 → 八万四千人得法眼净，归佛受五戒 → 说「祠祀火为上」偈收卷。

## 三、关键结论
- 欲想（男女想着）是生死陷阱：亲历其境者唯依不生男女想、随马王出离得脱。
- 僧众安危所系于上首，弟子当如目连收摄后学，勿令中退。
- 修行以道业为轻重之衡：住处、利养、饮食皆视其增善减恶而定去取，核心是少欲知足。
- 慈心是降魔第一铠：瞋心养魔，慈心退鬼；佛坐道树即以慈仁之铠降魔成道。
- 空、无愿、无想三三昧递进，空三昧为王三昧；至诚归命佛、法、僧，毒火不能害。

## 四、易混辨析
- **人间四食 vs 出世五食**：揣食（段食）、更乐食（触食）、念食（思食）、识食滋养凡夫生死；禅食、愿食、念食、八解脱食、喜食滋养出道之人——同一「念食」两处所指不同。
- **无想天 vs 无想三昧**：无想天是四禅外道果报之处；卷末「无想三昧」实即「无相三昧」之异写，是继空、无愿而得的解脱门，二者名近义远。
- **三乘归属**：无佛之世自剃发修行而得解脱者，不归声闻、不归佛部，佛判入辟支（缘觉）部。
- **遣众与召回**：佛遣舍利弗等非嫌恶，正为显「圣众之累」依于上首——遣是缘起，召回是慈悲，两端合看才见僧团相依之义。

## 五、阅读提示
带着两个问题读：一是「想」如何害人（商主与众商的差别只在起不起男女想着）；二是修行人靠什么立住（住处？利养？慈心？空三昧？），看佛在各经中如何依次给答。
