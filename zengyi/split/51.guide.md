# 增壹阿含经卷第五十一 导读

## 一、内容总览
本卷为《增一阿含经》卷五十一，属「大爱道般涅槃分品第五十二」，收该品第（四）至（九）经，共六部短经。主题集中于三处：布施（四五六七）、业报与忏悔（八）、末世预言（九）。波斯匿王与师子大将是两位主要当机者，佛借他们的问答，把「福从何来、罪向何去」讲得极接地气。

## 二、结构层次
全卷由「施福」到「罪报」再到「预警」，层层推进：
- **（四）劫量之喻**：比丘问劫有多长 → 佛举「石山天衣拂」喻（百年一拂，石犹磨灭）→ 由劫之长转入生死更长、无明所蔽 → 劝「当求巧便，免此爱着之想」。
- **（五）随时闻法五功德**：未闻得闻 → 已闻能持 → 除狐疑 → 无邪见 → 解甚深法。独立劝听经。
- **（六）师子大将问施**：施主五功德（名闻、无畏、被爱念、欢喜布施知四谛、生天五胜）→ 请佛应供 → 诸天空中评点僧众「施此福多、施此福少」→ 大将不为所动，引「施当普平等」偈 → 佛印可此即菩萨平等惠施，以「种五谷各获果实」偈说业报自受。
- **（七）波斯匿王问施**：随所欢处施 → 施「舍五成六、护一降四」之比丘福最难量 → 转论身口意三行、意行最重（「心为法本」偈）→ 破尼乾子「唯施我徒得福」之说 → 田喻：良田下种收获无量 → 王誓施四部之众，佛诫「施畜生福尚难量，况持戒人」。
- **（八）王杀庶母百子生悔**：忏悔求佛 → 佛说命极危脆、天人地狱寿量对比 → 四大畏（生老病死如四山压来）→ 十恶业报逐条展开 → 地狱苦相 → 劝以法治化、常念修福、「为恶寻当悔，更莫复犯」。
- **（九）夜梦十事**：婆罗门解梦，主杀生祠天禳灾 → 夫人摩利劝往问佛 → 佛逐一解说为后世人心败坏的瑞应（不养亲、官贪民困、早嫁、妻不贞、贵贱颠倒、母为媒、灾异示警、边地中信佛、兵戈流血）→ 王得定慧，立摩利为正后，逐婆罗门。

## 三、关键结论
- 劫已极长，生死更无边际，当求巧便出离爱着。
- 布施贵在平等普施、不拣择福田，此即「菩萨之心」；施福大小不在对方身份名望，而在持戒与否（田喻）。
- 三业之中意行最重，「心为法本，心尊心使」，身口随念而发。
- 十恶各有果报；悔过可使恶渐薄乃至消灭，但不可更犯。
- 夜梦十事皆是后世衰相的预警，唯一对治是「守善持戒、慈心不怒」。

## 四、易混辨析
- **舍五 · 成六 · 护一 · 降四**：舍五＝弃五盖（贪欲、瞋恚、睡眠、调戏、疑）；成六＝防护眼耳鼻口身意六根；护一＝系念在前（正念现前）；降四＝降四魔（身魔、欲魔、死魔、天魔）。是同一位「应施比丘」的四重功德，不是四类人。
- **苦谛 · 苦习 · 苦尽 · 出要谛**：即四圣谛旧译——苦、苦之集（习＝集起）、苦之灭（尽）、出离之要道（道）。
- **随所欢施 vs 施福田**：「随心所欢，便于彼施」是慈悲门；「施持戒人福难量」是福田门。佛说施畜生福亦难量，正是显持戒福田殊胜，而非轻贱余者。
- **身行 · 口行 · 意行**：三业。尼乾子只计身、意二行，佛判意行最重——命终身舌犹在而不能再作恶，正因无意根推动。

## 五、阅读提示
带着「我布施时是否在挑人」的问题读（六）（七）；带着「恶已铸成怎么办」读（八）；（九）的十梦不妨对照当下世相自省——经文明说这是「为将来后世现瑞应」。
