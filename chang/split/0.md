# 前言

佛家与道家的典籍卷帙浩繁，文辞讲究，义理深奥。然而对于初学者而言，其语言往往过于艰涩，不易入门。更遗憾的是，像《华严经》《瑜伽师地论》《阿含经》等许多重要经典，至今仍缺乏完整的现代汉语译本。笔者在学习过程中发现，市面上或网络上能获取的资料，大多仅收录原文及少量注疏，这无疑为初学者深入理解带来了不小的障碍。

经典本身是最珍贵的学习资源，若因文字隔阂而却步，实为可惜。随着信息时代的推进，人工智能技术迅速发展，笔者作为一名计算机工程师，遂萌生借助AI之力尝试对这些典籍进行翻译与整理的念头。于是决定将翻译内容陆续整理成书或博客，既是对个人学习的记录，也希望能为后来的学习者略尽绵薄，让更多人能够更便捷地亲近经典、深入经藏。

为了便利阅读、传播和校对，笔者会将所有内容开源和免费，放在gitee和github网站上作为托管。

## 版本 2.0 更新说明（2026年10月）

在 V1.0 全量翻译的基础上，V2.0 对《长阿含经》全部 22 卷做了一轮系统性的校对与增强，主要内容包括：

### 一、译文逐卷校对与修复

- 对全部 22 卷的译文与 CBETA 原文进行了**逐段对照校对**，检查漏译、添译、术语不一致、语义偏差、偈颂错位等问题，共发现并确认约 **149 处**问题，其中 148 处成立并已逐一修复。
- 校对与修复过程全部留档：每卷附有 `N.check.md`（校对报告，含原文、译文、问题描述与修改建议）与 `N.fix.md`（修复报告，含每条问题的处理结果），读者可逐条查验，判断是否同意我们的修改。
- 部分修复涉及补译 V1.0 遗漏的原文段落，并对个别术语统一了译名（如「至真」等如来尊号的对应关系）。

### 二、每卷新增「导读」

每卷新增导读文件（`N.guide.md`），按固定框架撰写，帮助读者在进入原文前建立整体认识：

- **内容总览**：本卷讲了什么、在全经中的位置；
- **结构层次**：经文的章节脉络逐层展开；
- **关键结论**：本卷的核心法义要点；
- **易混辨析**：容易混淆的概念、名相之间的区别；
- **阅读提示**：带着什么问题去读。

### 三、每卷新增「词语注释」

每卷新增注释文件（`N.notes.md`），对本卷的生僻字词、佛教术语、音译词（如「阿毗昙」「般泥洹」「䩭靽」「上章阉茂」等）逐一注释，标注读音与含义，并说明其在上下文中的具体所指，降低文言与名相的阅读门槛。
