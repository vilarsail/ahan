# 佛说长阿含经卷第一并序 导读

## 一、内容总览
《长阿含经》卷第一由两部分构成：卷首是僧肇所撰《长阿含经序》，交代三藏分科、「阿含＝法归」的名义及姚秦弘始年间的译经始末；正文为第一分《大本经》，佛应比丘之问，以宿命智遍说过去七佛（毗婆尸、尸弃、毗舍婆、拘楼孙、拘那含、迦叶、释迦牟尼）的劫数、人寿、种姓、成道树、说法大会、上首弟子等因缘，是汉译佛典中七佛传记的源头文献。

## 二、结构层次
- **序**：三藏之别（律／论／经）→「阿含」名义（法归、巨海百川所归）→ 罽宾佛陀耶舍诵出、竺佛念传译的译经记。
- **正文**以「七佛谱系」一线贯穿：
  - **总起**：比丘共议「如来何以知过去诸佛」→ 佛答二途：善解法性、诸天来语 → 引出宿命智说过去佛。
  - **七佛概要**（长行＋偈颂相间）：劫数 → 人寿 → 种姓 → 成道树 → 说法大会人数 → 上首二弟子 → 执事弟子 → 王子父母国土，每位佛逐项铺排，先长行陈述、后重颂概括。
  - **详说毗婆尸佛**：从兜率天下生、入胎出胎、七步宣言 → 相师占相、三十二相 → 四门出游（老→病→死→沙门）→ 出家 → 顺逆观十二因缘成道 → 梵天三请、初转法轮度提舍、骞茶 → 八万四千人出家、遣散大众六年游行。「诸佛常法」一语反复出现，明一佛如此、佛佛皆然。
  - **收束**：佛自说神足至无造天等处，诸天皆言「从七佛受化故来生此」→ 「欢喜奉行」结经。

## 三、关键结论
- 佛知过去诸佛事，凭「善解法性」与「诸天来语」二缘。
- 七佛谱系有定说：前三佛出刹利种，次三佛出婆罗门种，释迦佛复出刹利种；人寿随劫递减。
- 毗婆尸佛传演示了完整成佛路径：见老病死苦 → 出家 → 观十二因缘 → 成道 → 转法轮，此即「诸佛常法」。
- 十二因缘顺观成「苦集」（缘痴有行……缘生有老死），逆观成「苦灭」（痴灭故行灭……生灭故老死灭）。
- 佛成道后先自默然，经梵天三请方说法；说法次第为先施论、戒论、生天之论「渐教」，再示四谛。

## 四、易混辨析
- **劫的分际**：毗婆尸佛在九十一劫前，尸弃、毗舍婆在三十一劫前；拘楼孙以下五佛皆在此「贤劫」。
- **转轮圣王 vs 佛**：太子具三十二相，在家则王四天下的转轮圣王（七宝自至），出家则十号具足成正觉——两条路，佛取后者。
- **上首弟子 vs 执事弟子**：前者是大弟子中之第一（如舍利弗、目揵连），后者是常随侍者（如阿难）。
- **苦集 vs 苦灭**：十二因缘顺观即苦集，逆观即苦灭；四谛之「苦出要谛」即道谛的异名。

## 五、阅读提示
带着两个问题读：一、七佛名号哪些是纯音译、哪些有含义（如毗婆尸＝胜观）；二、毗婆尸佛传中哪些情节与释迦牟尼佛传平行——经文正是借「诸佛常法」宣告：每位佛的一生都是同一蓝本的重演。
