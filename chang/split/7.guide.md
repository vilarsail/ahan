# 佛说长阿含经卷第七 导读

## 一、内容总览
本卷属《长阿含经》第二分第七卷，即《弊宿经》第三。记童女迦叶率五百比丘游行拘萨罗国，止宿斯波醯村外尸舍婆林；村中富有而常怀断灭见的婆罗门弊宿（波斯匿王封其为梵分食邑）立宗「无有他世、无更生、无善恶报」，与迦叶展开七番论辩。本经是阿含经典中系统破斥「人死如灯灭」式断灭论的代表作，以连环譬喻取胜。

## 二、结构层次
- **起因**：村人日日往诣迦叶，弊宿在高楼望见，恐众人受其「欺诳」，主动登门问难，立宗「无有他世」。
- **七番问答**（固定格式：弊宿举一件「亲证」事例为据 → 迦叶应答「诸有智者，以譬喻得解」，翻出一喻反破）：
  1. 作恶的亲族许诺从地狱还来相告而不还 → 王不放死囚喻（同现世犹不放，况狱鬼非其类）；
  2. 行十善的亲族未从天上还来 → 人堕深厕不肯复入喻（并算忉利天时差：人间百年＝彼天一日）；
  3. 再引忉利天未还 → 生盲不识五色喻（汝自不见，便言其无）；
  4. 煮贼于釜观其神去来而不得 → 梦中山林喻（识神出入，同床眷属尚不能见，唯三昧修得的净天眼能观死此生彼）；
  5. 剥皮、脔割、打骨求识神不得 → 梵志小儿钻木取火喻（破析杵碎而求火，正是无方便）；
  6. 称量活人轻、死人重 → 热铁轻软、冷铁刚重喻；
  7. 病人临终能屈伸视瞻言语、死后不动 → 吹贝喻（有寿有识、有出入息，故能动作）。
- **劝舍不改**：弊宿自言长夜讽诵、玩习坚固，又以断灭见「多所教授」、名闻四方，拒不舍见 → 迦叶连出五喻层层警示：负麻喻（执麻不换取金）、商主喻（信罗刹幻语捐弃水谷者丧身）、戴粪喻、孕妇自决其腹喻（自杀复害胎）、毒丸喻（吞毒不觉）。
- **结劝归信**：弊宿道破实情——初闻（日月属他世的）「月喻」时已心解，故意往返不受，欲试迦叶辩才而生牢固信；遂归依灭度如来及法、众僧，受五戒为优婆塞。迦叶教其设不害众生、不杖楚僮仆的净施如良田种植。尾段记摩头梵志代营大施，先以粗食弊衣布施并咒愿无果报，弊宿改以自己所用食衣供养众僧；二人命终分别生下劣天与忉利天，以施报净秽收束全经。

## 三、关键结论
- 必有他世、更生与善恶报：肉眼不能彻见众生所趣，「不可以目前现事观于众生」。
- 识神出入，现居之人尚不能见，故煮釜、割身、称重诸「验证」皆无效，唯天眼知见死此生彼。
- 执守邪见如负麻不换金、戴粪而行，长夜自增苦恼。
- 布施之福在净秽：宰杀众生、挝打僮仆而施邪见众，非净福；净施如良田，必获果实。
- 同是设施，以自食自衣供养众僧者得报胜于以粗恶之物敷衍者。

## 四、易混辨析
- **他世 vs 更生 vs 善恶报**：断灭论否定的三件事——死后另有世界、死后再受生、业有果报；迦叶逐番分别破之，非笼而统之。
- **识神 vs 天眼 vs 肉眼**：识神是死此生彼的识，肉眼秽浊不能见；净天眼依三昧力修成，能观寿命长短、随行受报。
- **断灭学 vs 邪见**：断灭见专指否定后世的一类倒见，是邪见中最重者；文中「邪见」用其泛义。
- **大施 vs 净施**：大施言其规模（一切大施），净施言其性质（不害众生、以己所食所著而施）；本卷主张净施常续、不令断绝。

## 五、阅读提示
带着「这一喻破的是哪一条证据」的问题读，留意每番辩难先承接对方事例、再翻出譬喻的论辩章法；七喻之后五喻重在劝舍，可对照弊宿屡拒屡退、终道实情的口吻。
