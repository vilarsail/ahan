# 佛说长阿含经卷第五 导读

## 一、内容总览
本卷为《长阿含经》第一分之卷五，含两经：《典尊经第三》与《阇尼沙经第四》。两经都以在家人（乐神般遮翼）与鬼神（阇尼沙）向佛转述忉利天（三十三天）上的见闻开篇，主线是"佛弟子圣众尊贵，令天众增益、阿修罗减损"。前经由佛自述宿世本生（大典尊），后经以授记与圣果阶梯、禅法名目（四念处、七定具、四神足、三径路）见长。

## 二、结构层次
两经共用一个"天会"框架，前后勾连：

**《典尊经》**（神述天会 → 佛说本生 → 印可对比）：
- **开端**：般遮翼夜诣佛所 → 述忉利天集法讲堂、四天王列坐、帝释说"如来八无等法"，诸天欢喜（增益天众、减损阿须伦）。
- **梵童子现身**：大梵王化作五角髻童子于虚空坐 → 诵偈赞叹"佛智慧弟子，生此复殊胜"（此偈两经重出）。
- **本生故事（主体）**：往昔地主王、太子慈悲 → 大臣典尊卒，其子焰鬘继相，辅七王 → 分阎浮提为七分 → 修四无量求见梵天 → 梵童子示"臭秽"偈 → 辞七王、居士、梵志、妻子 → 八万四千人同时出家。
- **印可对比**：佛言"大典尊即我身" → 然彼道"极至梵天"，不能至安隐涅槃 ↔ 今佛道究竟，弟子得四果、终归灭度。

**《阇尼沙经》**（阿难疑问 → 神来自答 → 法递相传）：
- **起因**：阿难念摩竭国为佛亲任者命终独不蒙授记 → 向佛请记。
- **神现**：佛入那伽城乞食，大林树下，鬼神阇尼沙自称其名 → 佛唤阿难，阇尼沙自述因缘（前世人王、念佛命终、生为毗沙门天王太子、得须陀洹）。
- **转述**：阇尼沙述忉利天会与梵童子说法 → 说摩竭优婆塞命终得果 → 列四念处、七定具、四神足 → 如来"开三径路"分别对治贪、瞋、痴三种人。
- **传说链收束**：梵童子→忉利天→毗沙门→阇尼沙→佛→阿难→四众，层层下达。

## 三、关键结论
- 一世无二佛：欲令一时二佛出世"无有是处"；佛之八无等法，过、现、未来皆无等者。
- 佛于宿世为大典尊时已以道化众，但彼时所教"非究竟道"，其道胜者极至梵天；唯今佛道能令弟子"究竟梵行，终归涅槃"。
- 圣果阶梯：断三结得须陀洹（不堕恶道，极七往返）→ 三结尽、淫怒痴薄得斯陀含（一来）→ 断五下结得阿那含（不还，于天上般涅槃）。
- 修行纲目：四念处是"观"，七定具（正见至正念七支）与四神足（欲、精进、意、思惟四种定）是"定"；过现未来神通皆由四神足起。
- 贪、瞋、痴三种根性者皆可由遇善知识、闻法离恶，于欢喜中次第增进（"开三径路"）。

## 四、易混辨析
- **典尊 vs 大典尊**：典尊是地主王的老臣；其子焰鬘继任相印后天下称"大典尊"，出家化众、即释迦前世者是大典尊。
- **梵天/梵童子 vs 帝释/忉利天**：大梵王居梵世、化童子说法，位在帝释之上；帝释（释提桓因、因提）为忉利天之主，坐于四天王之前。
- **须陀洹 vs 斯陀含 vs 阿那含**：初果不堕恶道、极七往返；二果一来人间即尽苦际；三果断五下结、不还欲界，于天上般涅槃。
- **四念处 vs 四神足**：前者是内身、外身、受、意、法的正念观察；后者是依欲、精进、意、思惟之定修习神变之本。

## 五、阅读提示
带着两个问题读：大典尊的"臭秽"究竟臭在何处、为何在家人"无由得除"？佛道与梵天道（生梵天）的差别在哪一环？再对照两经重出的偈颂与"增益诸天众、减损阿须伦众"的欢呼声，体会"天众以佛弟子为荣"的叙事功能。
