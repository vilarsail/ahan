# 佛说长阿含经卷第十八 导读

## 一、内容总览
本卷是《长阿含经》第四分《世记经》的开卷三品（阎浮提州品第一、郁单曰品第二、转轮圣王品第三）。《世记经》相当于佛教的“世界记”，是专讲天地成败、宇宙结构与劫运的经群。本卷缘起：众比丘食后集于讲堂，议论“天地何由而败、何由而成”，佛闻之，先赞许出家二法（贤圣默然、讲论法语），继而应请宣说世界之相，遂成此三品。

## 二、结构层次
全卷按“从一世界推展到一佛刹，再落到人类所居之洲，最后归于人王”的顺序展开：
- **立宗**（阎浮提州品第一开篇）：比丘问天地成败 → 佛先说一日月所照为千世界，由小千 → 中千 → 三千大千世界，“周匝成败，众生所居名一佛刹”。
- **纵向推升**：大地深浅 → 须弥山（入水深、七宝阶道、下中上阶道各鬼神住）→ 山腰四埵为四天王宫 → 山顶三十三天 → 逐层上推欲界六天、色界诸天，至空处等四天，“齐此名众生边际”，受阴受有不出于此。
- **横向铺开**：须弥山四方四洲（地形与人面一一相像）→ 各洲大树王 → 山外群山层层渐低 → 雪山阿耨达池与四大河 → 诸龙三患、香山乾闼婆、善住象王“虽为畜生，受福如是”。
- **专述北洲**（郁单曰品第二）：郁单曰的自然如意（自然粳米、焰光珠炊饭、香树衣树鬘树器树果树乐器树）→ 善见池与四河四园 → 人民容貌平等、婚姻树曲荫、生七日而长成、命终不哭 → 推究寿命千岁之因：不受十善而举动自然与十善合。
- **转轮圣王**（转轮圣王品第三）：金轮宝忽现 → 王试轮、四兵随轮巡行四天下、诸小王献土 → 敕以正法治、行十善 → 七宝（金轮、白象、绀马、神珠、玉女、居士、主兵）逐一现前试成 → 四神德 → 治世德化之相（地平、自然饮食、八味水）→ 王终身修正见、命终生梵天，茶毗起塔收束。

## 三、关键结论
- 一佛刹即三千大千世界，以须弥山为中心，天地在“周匝成败”中循环不息。
- 四大洲地形各异而与人面相应；南洲阎浮提即人类所居。
- 众生生老病死、受阴受有，齐于无色界顶，不出“众生边际”。
- 郁单曰之所以最胜，不在刻意修十善，而在“不受十善，举动自然与十善合”，故命终生天。
- 转轮圣王以正法治国、勿使偏枉，七宝自至、四神德自成，是世间治道之极。

## 四、易混辨析
- **忉利天 vs 三千大千世界**：前者是须弥山顶的一层天（三十三天），后者是世界的数量单位（千世界三重相乘），切勿以数字相混。
- **七宝（转轮王） vs 七宝（建材）**：前者指金轮宝、白象宝、绀马宝、神珠宝、玉女宝、居士宝、主兵宝七种瑞宝；后者指金、银、琉璃、水精、赤珠、马瑙、车磲等质地，经中墙门栏楯罗网行树反复以“金墙银门”相间描写。
- **阎罗王 vs 阎浮提**：一为地狱之王，一为南洲之名，在千世界清单中前后并见，勿混。
- **转轮圣王 vs 佛**：转轮王以十善正法统治四天下，是世间之最；佛转法轮，是出世间之最，二者相映成趣。

## 五、阅读提示
按“大地 → 山 → 天 → 洲 → 海 → 北洲之人 → 转轮王”的方位顺序读，留意由旬数字层层减半或“由旬一倍”的递进句式，以及四洲、四河、七宝墙的对称排比；风景描写的程式化重复正是口诵结集体例的痕迹。
