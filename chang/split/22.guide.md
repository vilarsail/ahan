# 佛说长阿含经卷第二十二 导读

## 一、内容总览
本卷为《长阿含经》第四分《世记经》卷二十二，含《三中劫品第十一》与《世本缘品第十二》两品。《世记经》是汉译四阿含中系统讲述佛教宇宙观的集成之作，本卷前品讲住劫中人寿递减时的三种灾劫，后品讲成劫——火灾之后世界如何重新生成、众生从何而来、王政与四种姓如何产生，合起来是一部佛教版的「世界与文明起源记」。

## 二、结构层次
**前品《三中劫》：总起 → 三灾分述 → 各以业因收束**
- 总纲：佛告比丘「有三中劫」——刀兵、谷贵（饥饿）、疾疫 → 逐一设问展开。
- 刀兵劫：人寿从四万岁逐劫递减至十岁 → 十恶增盛、连善的名字都听不到 → 人手执草木瓦石皆化利刃、展转相杀 → 黠慧者躲藏七日复出，幸存者如重逢骨肉般相庆 → 结穴：由瞋恚害心，命终堕地狱。
- 饥饿劫：行非法故天不降雨、五谷不成 → 拾遗谷、煮白骨汁、掘草木花，饥荒层层加深 → 结穴：由悭贪不施，命终堕饿鬼。
- 疾疫劫：众人反行正法十善 → 他方鬼神乘隙侵扰、吸人精气（以「此间鬼神放逸与否」两喻对比）→ 结穴：众生慈心相问「病差不」，命终反得生天。

**后品《世本缘》：成劫的宇宙演化与社会起源，一环扣一环的长链**
- 火灾过后世界还欲成 → 光音天众生先下生空梵处 → 先至者自命大梵天王，「我自然有，能造万物」→ 揭示「造物主」观念是最先下生者的记忆错觉。
- 日月起源：暴风吹海水取日宫置于须弥山半 → 日宫构造、五风所持、日天子以宿业得千光明 → 日热十缘 ↔ 日冷十三缘 → 月宫圆损盈满三缘 → 四洲昼夜互错、阎浮树与阎浮金。
- 社会演化链（全品核心）：众生食地味 → 地皮 → 地肤 → 自然粳米，食物逐层粗劣 ↔ 贪着与彼我之诤逐层加深 → 颜色有优劣、生男女形、行不净 → 造屋舍、立夫妻、有胎生 → 积粮囤储 → 分田封疆 → 盗、诤讼、杖打 → 共立「平等主」，于是有王政与刹利种。
- 四姓起源与业报平等：婆罗门（入山求道者）、居士（营生者）、首陀罗（习技艺者）、沙门（四姓中舍家出家者）→ 无论何姓，身口意行善一向受乐、行恶一向受苦 → 出家修七觉意、证阿罗汉为最第一 → 梵天偈「刹利生为最」得佛印可。

## 三、关键结论
- 三中劫之祸皆由心造：瞋恚感刀兵劫，悭贪感饥饿劫，疾疫劫中众生以慈心相向反得生天。
- 大梵天王「无造我者、能造万物」只是最先下生者对众生自然出现的误认——佛教以缘起破创世神说。
- 私有、夫妻、王政、四姓皆非神授，而是众生贪着、诤竞逐步演化的产物。
- 业报面前四姓平等：行善俱乐、行恶俱苦，出家修道证阿罗汉为最。

## 四、易混辨析
- 刀兵劫 vs 饥饿劫 vs 疾疫劫：起因（瞋恚 / 悭贪 / 他方鬼神侵扰）与归宿（堕地狱 / 堕饿鬼 / 生天上）各不相同。
- 「民主」vs 今义民主：文中「民主」指人民共同推立之「主」，即最早的国王，非近代民主制度。
- 刹利种 vs 沙门种：刹利由立王而来，是血统种姓；沙门由四姓中舍家求道者组成，非血统之种。
- 地味 vs 地皮 vs 地肤：劫初依次出现的三层自然食物，一层比一层粗厚，前一层因诤竞贪着而消竭。

## 五、阅读提示
带着两个问题读：世界与社会的种种「开端」，佛教如何全部还原为众生的心与业而非神造？诸天（大梵天、日月天子、鬼神）在这幅图景中又扮演着怎样的角色？
