# 佛说长阿含经卷第十 导读

## 一、内容总览
本卷属《长阿含经》第二分，收三经：（一二）《三聚经》、（一三）《大缘方便经》、（一四）《释提桓因问经》。三经同以「法数」与「缘起」为轴：前经按一至十的数目罗列趣恶趣、趣善趣、趣涅槃之法；中间一经在人间为阿难细说十二因缘并破我见；末经由天帝释当面层层追问忧苦之源，是第二分中义理最紧凑的一卷。

## 二、结构层次
- **《三聚经》——数法总汇**：佛告诸比丘「三法聚」（一法趣恶趣、一法趣善趣、一法趣涅槃）→ 按 1→10 逐级铺开 → 每级皆「向恶趣 ↔ 向善趣 → 向涅槃」三分对照（如四法：爱恚怖痴四语 ↔ 四善语 → 四念处）→ 结以「自忧其身，勿为懈怠」的劝勉。
- **《大缘方便经》——缘起逐支反证**：阿难叹十二因缘甚深 → 佛顺观老死←生←有←取←爱←受←触←名色←识←行←痴 → 每支以「若使众生无有X，宁有Y不？」反问阿难，答「无也」，层层坐实 → 于爱支别开「求→利→用→欲→著→嫉→守→护→刀杖诤讼」的增广链 → 立「识缘名色、名色缘识」互依之枢 → 划定言说极限（「齐是为语」）→ 逐破「受是我」「我是受」「受法是我」「但爱是我」及少色、多色、少无色、多无色等计我 → 示七识住、二入处、八解脱，以慧解脱、俱解脱收束。
- **《释提桓因问经》——问答层层上溯**：帝释与忉利诸天、般遮翼诣佛，般遮翼鼓琴说偈（佛赞其「亦说欲缚，亦说梵行」）→ 帝释叙旧缘、发问：众生何以怨仇刀杖相向？→ 佛答贪嫉，帝释再三追问，逐层上推：贪嫉←爱憎←欲←想←调戏（心的掉举），调戏为「原首」 → 再问「尽除调戏在灭迹耶」「齐几调在灭迹」（口、想、求三调）→ 问贤圣舍心（喜、忧、舍三身）、贤圣律诸根具足（可亲/不可亲）、究竟梵行（为爱所苦身得灭）→ 帝释忆往昔向沙门问义不得的经历，说五功德果偈 → 梵童子现身赞叹，般遮翼受赐婚，八万四千诸天得法眼净。
- **三经关联**：数法示修行总纲 → 缘起明生死之链 → 帝释问经把忧苦之源追到心念躁动，再将舍心、根律仪、究竟梵行落到实践，正与首经「趣涅槃」诸法呼应。

## 三、关键结论
- 一至十每一数目的法皆分向恶趣、向善趣、向涅槃三类，修行取舍一目了然。
- 十二因缘各支皆可用「若无彼则无此」反证成立；识与名色互为缘，是生死相续的枢纽。
- 三受从触缘生、随触灭，无常非我，故种种计执「我」的说法皆不成立。
- 众生刀杖相向，源头层层上溯至「调戏」（心的掉举躁动）；调戏息则想、欲、爱憎、贪嫉随之而息。
- 于七识住、二入处、八解脱知集、灭、味、过、出要而不执住，方成慧解脱与俱解脱。

## 四、易混辨析
- **世正见 vs 八贤圣道**：同为八项，前者有漏世俗（向善趣），后者出世无漏（向涅槃）。
- **慧解脱 vs 俱解脱**：前者以无漏慧断惑而解脱；后者定慧俱足，于八解脱顺逆出入自在。
- **欲爱 / 有爱 / 无有爱**：分别渴求欲乐、渴求存在（感「有」）、渴求断灭（求不存在），三者皆能生「取」。
- **七识住 / 二入处 / 八解脱**：七识住是识安住的七类生存境界；二入处（无想入、非想非无想入）在七识住之外；八解脱是次第超越的定门，层次与性质均不同。

## 五、阅读提示
读《大缘方便经》可随佛每句「此为何义」先自问再往下看；读《释提桓因问经》可留意帝释每次「我今闻佛所说，无复疑也，但……」——正是这一再追问，把全经推向「调戏为原首」的深处。
