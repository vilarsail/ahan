# 佛说长阿含经卷第三 导读

## 一、内容总览
本卷为《长阿含经》第二分《游行经》的中段（卷第三），记述佛陀晚年从庵婆罗村一路北行、直至拘尸城双树间临灭的行程，是汉译"佛涅槃经"的主体部分。主旨是佛在宣告"是后三月当般泥洹"之后，完成对僧团的最后嘱托（四大教法）、接受最后供养（周那施食）、示范最后卧姿与葬法（如转轮圣王），并以大善见王的盛世旧事收束"有为无常"之意。

## 二、结构层次
本卷以"灭度倒计时"为主线，随佛行进一路铺展：
- **神德与宣告**：佛于八众中自在说法、知受·想·观之起住灭 → 魔波旬三请灭度，佛自知时，许以三月后般泥洹 → 比丘哀恸，佛以偈慰勉"无生不终"。
- **阿难之失**：佛曾三次暗示意 regarded（三现相），阿难三默然，未劝请佛住一劫 → 事后佛责其愚，点出"多修四神足可住一劫有余"的公案。
- **最后嘱托**：庵婆罗村说戒→定→慧→解脱，尽三漏 → 负弥城说**四大教法**：不论闻自佛、僧团耆旧、众多比丘或一比丘，皆"不应不信，亦不应毁"，依经、依律、依法勘验真伪 → 此为留给后世校经的总则。
- **最后行迹**：周那（工师之子）供栴檀树耳——佛最后一餐，功德与初成道时施食正等无异 → 偈答"沙门四种" → 福贵问定（五百车声、雷声觉而不闻），归依受戒为优婆塞 → 拘孙河饮水沐浴 → 周那先佛灭度。
- **葬法与真供养**：阿难问葬法 → 佛示"如转轮圣王"：缠身、金棺、阇维、收舍利、四衢起塔 → 如来、辟支佛、声闻、转轮王四种人应起塔 → 双树间头北面西、右胁如师子王卧 → "受法能行"方是真供养，"阴、界、入无我"乃第一供。
- **以古证今**：阿难嫌拘尸城鄙陋 → 佛追述大善见王：拘舍婆提城七宝四德、八万四千受用 → 盛极之后"百年听现一象"，盛衰无常，暗收全卷。

## 三、关键结论
- 天地人物无生不终，佛身亦不例外；唯戒具不放逸、修戒定慧能尽生老死。
- 教法真伪不看说法者身份高低，唯依经、律、法推究本末。
- 佛初成道与临灭度时能施食者，二功德正等无异，最后供养获大果报。
- 供养如来不在香花，而在受法、行法；观阴界入无我是第一供养。
- 佛、辟支佛、声闻、转轮王四人应起塔香花供养，为后世塔葬仪轨所本。

## 四、易混辨析
- **般泥洹 / 泥洹 / 灭度**：同一"涅槃"的异译，"般"＝入。经中周那证果后也"般涅槃"，圣者寂灭与佛灭度同用此词，不是普通死亡。
- **四念处·四意断·四神足·五根五力·七觉意·贤圣八道**：即三十七道品的分组，一组阶梯，不是七种互不相干的法门。
- **转轮圣王 vs 法王**：前者以金轮等七宝、正法治四天下的世俗圣王；后者指佛。佛葬仪规格"如转轮圣王"，塔却称"法王塔"。
- **供养塔像 vs 供养如来**：散花布地是世间供养；"人能受法，能行法者"才是经中所许的真供养。

## 五、阅读提示
带着两个问题读：其一，阿难为何三次都错失请佛住世之机——这对"亲侍二十五年"的他意味着什么？其二，佛临终反复叮咛的究竟是葬仪排场，还是"依经、依律、依法"四字？读罢自见轻重。
