# 佛说长阿含经卷第十九 导读

## 一、内容总览
本卷为《长阿含经》第四分《世记经》的〈地狱品第四〉全品与〈龙鸟品第五〉前半。《世记经》是佛教的"宇宙志"，系统铺陈世界结构：前半讲大地狱的刑罚、名号由来、寿量与堕落之因，并以阎罗王与"三天使"警策放逸；后半转向龙与金翅鸟的世界，由"持戒生趣"引出外道邪见，以盲人摸象喻收归四谛正见。

## 二、结构层次
**〈地狱品第四〉**总—分—颂—旁推—收束：
- **总起**：四天下、大海、二大金刚山的世界结构 → 列八大地狱之名，每狱各有十六小狱。
- **逐狱分述**（想→黑绳→堆压→叫唤→大叫唤→烧炙→大烧炙→无间）：每狱以"何故名为X"设问，并列铺陈数种酷刑以释名；狱与狱之间用"慞惶驰走……宿罪所牵，不觉忽至黑沙地狱，乃至寒冰地狱，然后命终"的循环句式串联，显八狱连环受苦。
- **偈颂总结**：身口意恶业、瞋恚杀生、邪见等对应堕八狱。
- **旁支推展**：金刚山间三种恶风（增佉大风、猛热风、臭风）被山遮止 → 山间另有十地狱，以莲花命名（厚云至钵头摩）→ 寿量以二十倍逐狱递进 → 瞿波梨谤圣堕钵头摩地狱 → 梵王说偈"斧在口中"，佛印可。
- **三使者**：阎罗王宫 → 老病死三天使逐一审问罪人 → "汝自有恶，汝今自受" → 阎罗王自念求出家 → 偈颂收束。

**〈龙鸟品第五〉前半**类比—展开—破邪—显正：
- 四种龙 ↔ 四种金翅鸟（各分卵、胎、湿、化四生）→ 诸龙宫、鸟宫七重严饰。
- 以大海北岸究罗睒摩罗大树为中心 → 金翅鸟按自身生类捕食同等及更低生类的龙 → 诸大龙王不受捕食。
- 由"奉持何戒、心向何趣即生何趣"引出兔枭戒、狗戒、牛戒、供养火戒等为邪见 → 铺陈外道论见：世间常无常、有边无边、命身一异、死后有无再生。
- **盲人摸象喻**：镜面王令生盲扪象，各执一端互诤 → 喻外道不知四谛、各执异见；能如实知四谛者则"同一水乳"，和合安乐。

## 三、关键结论
- 身口意行恶、瞋恚杀生、谤贤圣者堕八大地狱，狱狱相连，业未尽则死而复生、苦无出期。
- 老、病、死是"三天使"，常在世间警策；见而不放逸、修梵行者"决定般涅槃"。
- 罪福自作自受："汝自有恶，汝今自受"，非父母、天帝、先祖之过。
- 业随心趣：奉持龙戒、鸟戒、兔枭戒乃至火戒，心向何趣即生何趣。
- 外道诸见皆由我见、命见、身见、世间见而起；唯如实知四谛者能究竟苦本。

## 四、易混辨析
- **八大地狱 vs 金刚山间十地狱**：前者名号示刑罚（想、黑绳、无间等），后者以花命名（优钵罗、钵头摩等），寿量二十倍递进，"二十中劫名一大劫"。
- **鍑、镬、釜、陶**：皆为煮炙罪人之器——鍑、镬、釜是大锅，陶是烧窑瓮类，读时可统作"锅、瓮、窑"理解。
- **命是身 vs 命异身**："命"即命根／灵魂；前者主张命与身同一，后者主张二者相离，与"死后有无再生"四句配成外道的系列异见。
- **心解脱 vs 慧解脱**：由定离贪爱而心解脱，由慧断痴而慧解脱；偈中并举，二者俱失则不能究竟生老病死之本。

## 五、阅读提示
带着两个问题读：① 每狱为何反复说"余罪未毕，故使不死"？——业力未尽，苦不得尽，死而复生再受；② 狱名从何而立？——"想"狱因"自想言我今已活"得名，"黑绳"因铁绳絣身如木匠弹线，狱名多从受苦情状立义，读时留意各狱的释名问答。
