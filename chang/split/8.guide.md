# 佛说长阿含经卷第八 导读

## 一、内容总览
本卷属《长阿含经》第二分，含两经：（八）《散陀那经》第四、（九）《众集经》第五。《散陀那经》叙王舍城居士散陀那引佛降伏尼俱陀梵志及其五百弟子：外道讥佛“偏好独见如瞎牛”，佛自来破其慢，就“苦行”层层剖判净秽浅深，终于摄化。《众集经》是著名的“结集”型经典：佛患背痛，命舍利弗代为说法，舍利弗借尼乾子（外道）死后弟子分部诤讼之事，劝诸比丘按一至十的数字次第共同撰集如来正法，以防僧团分裂。

## 二、结构层次
**《散陀那经》**（缘起→论辩→进阶→收摄）：
- **缘起造势**：散陀那往梵志女林 → 尼俱陀与五百梵志子高声大论、说遮道之言，讥佛“如瞎牛食草”“当以一言穷彼如龟藏六” → 佛以天耳闻之，自来园中，梵志先立“勿起迎”之约，竟不觉自起相迎。
- **先破后立**：佛举裸形、节食、卧棘等无数苦役此身之行 → 问“可名净法不” → 于其“净法”中先说垢秽（求供养、爱染、瞋恨、邪见等），再反转为清净无垢之行，一一相对。
- **四层进阶**：梵志问是否已至第一 → 佛言“始是皮耳” → 树节（自不杀盗淫妄＋慈、悲、喜、舍遍满一方）→ 坚固（再＋教人不杀等＋自识宿命无数劫事）→ 第一（再＋天眼净观众生随善恶业所堕）→ “复有胜者”，即佛化声闻之法。
- **收摄**：尼俱陀头面作礼、自归世尊 → 佛慰谕勿疑（不为利养、名称说法，不置汝于黑冥聚）→ 魔波旬坏五百梵志意 → 佛以右手掌接散陀那乘虚而归。

**《众集经》**（缘起→立意→主体罗列→印可）：
- **缘起**：十五日月满，露地夜集 → 佛患背痛，命舍利弗说法。
- **立意**：舍利弗举尼乾子灭后弟子分为二部、互求长短 → 以“法不真正无由出要”反衬释迦正法 → 提出“宜集法、律，以防诤讼，使梵行久立”。
- **主体**：一法（众生仰食存、皆由行往）→ 二法（名与色、痴与爱、有惭无愧……）→ 三法（三不善根、三受、三三昧、三明……）→ 依法数递增至 → 十法（十无学法），每级末尾皆以“当共撰集，以防诤讼，使梵行久立，多所饶益，天、人获安”复沓作结。
- **结穴**：佛印可舍利弗所说，诸比丘欢喜奉行。

## 三、关键结论
- 苦行本身无净秽可言：为求供养、憍慢瞋恨、邪见边见所驱即是垢秽；不自计念、修慈悲喜舍、勤习禅智方是清净。
- 外道苦行只是“皮”；由自离恶到教人离恶、加修四无量与宿命、天眼二通，层层深入，犹有更胜。
- 诤讼根源在“法不真正”；如来正法可依数撰集、共同受持，以此防诤而令梵行久立。
- 佛自调伏亦能调伏人、自度彼岸亦能度人，故堪为归依处。

## 四、易混辨析
- **垢秽苦行 vs 清净苦行**：同是苦行，分别全在心行——动机上“常自计念得供养”与“不自计念”相对；待人上“毁訾他人”与“欢喜印可”相对；见地上“与边见俱”与“多修智慧”相对。
- **皮 → 树节 → 坚固 → 第一**：四级递进——仅自持戒离恶是外层之“皮”；加慈悲喜舍是“树节”；再能教人止恶、忆宿命劫是“坚固”；再以天眼彻见众生随业受报是“第一”，而佛所化声闻之法犹在其上。
- **七识住 vs 九众生居**：二者前四重（天与人、梵光音天、光音天、遍净天）重合；七识住说“识”所安住处，不含无想天；九众生居总说众生居住处，补入无想天与三无色，开合不同。
- **四梵堂 vs 四无色定**：前者是慈、悲、喜、舍的心地修法（对治瞋害等）；后者是越一切色想的空处、识处、不用处、有想无想处，是层层超越的三昧境界。

## 五、阅读提示
带着两个问题读：佛为何说外道苦行“始是皮耳”，判准究竟落在身行还是心地上？舍利弗依一至十集法，这种“数字递增、逐级复沓”的结构，与《增一阿含》的增一编法有何渊源？
