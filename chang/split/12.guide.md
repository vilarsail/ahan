# 佛说长阿含经卷第十二 导读

## 一、内容总览
本卷属《长阿含经》第二分，含三经：（一七）《清净经》、（一八）《自欢喜经》、（一九）《大会经》。《清净经》以尼乾子（耆那教）教团分裂诤讼为缘起，开示僧团如何辨明师法邪正、和合无诤；《自欢喜经》借舍利弗之口历数佛德「无上」；《大会经》记十方诸天云集礼拜，佛说偈、结咒、降魔。三经一破一立一赞，同归于「僧团清净、佛法第一」。

## 二、结构层次
- **《清净经》：由外道之乱立「和合」之义**
  - 缘起：沙弥周那报告尼乾子命终、弟子分为二分互相毁骂 → 阿难引其见佛。
  - 佛答周那：师邪见/正见 × 弟子成就是否，四组对照 → 法不真正则「二俱失道」，法真正而弟子勤修则「二俱见真正」。
  - 递进：导师出世使弟子忧/无忧 → 梵行「支具足」的标准——四众弟子皆受训诲、能演法、能破异论、能现神通。
  - 辨「见不可见」：驳郁头蓝子「刀可见刃不可见」之喻 → 正说「一切梵行清净具足、宣示流布」。
  - 僧团实务：论议起诤时以「句（文句）正／义（义理）正」四句勘验，不可妄下是非 → 共同推求，同一师受、同一水乳 → 举十二部经、衣食住药四依。
  - 答外道谤：五欲之乐佛呵责、四禅之乐佛称誉 → 此乐七果 → 沙门之法常住如门阃 → 如来记说原则 → 世间常无常等十六见皆「本生本见」→ 破「自造／他造／忽然而有」（缘起逆顺观）→ 结归四念处三行、八解脱，立经名「清净」。
- **《自欢喜经》：层层排比赞佛无上**
  - 舍利弗自说「三世沙门、婆罗门无与佛等」→ 佛三问「汝能知诸佛心中所念否」→ 舍利弗答以「总相法」：从佛所说转高转妙而信。
  - 主体为「无上法」长排比：制法、制诸入、识入胎、道、为灭、无上灭、言清净、见定、常法、观察、教诫、戒清净、解脱智、宿命智、天眼智、神足证，每段以「智慧无余，神通无余」作结。
  - 收尾：答「过去、未来佛等，现在无二佛出世」→ 郁陀夷叹佛少欲知足 → 舍利弗为四众数说，「以自清净故，故名清净经」，与前经呼应。
- **《大会经》：诸天大集的场景叙事**
  - 四净居天以偈赞佛 → 佛次第称说诸天名号 → 地神、雪山神、四天王各领眷属来集 → 佛为诸神、阿修罗、五通婆罗门「结咒」（音译咒文）→ 魔王率四兵来袭 → 佛说偈降魔 → 八万四千诸天得法眼净。

## 三、关键结论
1. 师怀邪见、法不真正，弟子愈精进愈堕罪；师法真正而弟子勤修，则二俱获福——外道分裂反衬佛法僧团当和合不诤。
2. 梵行「具足满」不止于师成道，而在四众弟子皆能受法演说、如法破异论。
3. 僧内论议分歧：不可轻言是非，当就「句」与「义」共同推求，同一师受、同一水乳。
4. 舍利弗非以他心知佛，而是依法次第（闻佛所说转高转妙）起信；现在世无二佛并出。
5. 飞行变化等凡夫神足是「卑贱下劣」，于爱色、不爱色二俱舍离的「贤圣神足」才是佛所称赞。

## 四、易混辨析
- **句正 vs 义正**：句＝文句表达，义＝义理内容；二者分别正误成四种情形，佛各授不同处理法。
- **五欲之乐 vs 四禅之乐**：五欲（色声香味触）之乐佛所呵责、当速除灭；离欲而生的初禅至四禅之乐，佛所称誉。
- **五种般涅槃（不还果）**：中间般涅槃（中阴位证）、生般、行般、无行般、上流至阿迦尼吒（色究竟天）般涅槃——皆断五下结的阿那含，唯般涅槃处所时机不同。
- **世间自造 / 他造 / 忽然而有**：三者皆邪见，佛同以「六入→触→受→爱→取→有→生→老死」的缘起破之。

## 五、阅读提示
可带两个问题读：僧团起诤时佛授的「句义四句勘验法」，以及舍利弗凭什么判定佛最上。本卷多组连环排比（四组师弟子对照、十六见、诸无上法、诸天名号）句式固定，抓住首例即可循式快读；《大会经》咒文皆音译名号，义不可解，可跳过只看前后叙事。
