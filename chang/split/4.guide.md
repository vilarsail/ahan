# 佛说长阿含经卷第四 导读

## 一、内容总览
本卷是《长阿含经》第一分《游行经》的后半（“游行经第二后”），记佛陀一生最后行程的终点：在拘尸那竭城娑罗双树间般涅槃的前后始末。以善见王本生收尾点出“无常”，中段是佛度最后弟子须跋、对阿难与诸比丘的最后教诫，随后详载入灭、诸天偈颂哀悼、末罗族葬仪、八分舍利起塔，是汉译佛典中最完整的佛涅槃记事。

## 二、结构层次
全卷以“死亡”为线索双线推进——先以王死喻佛死，再正面写佛灭：
- **善见王本生收束**：善见王自念福报源于布施、持戒、禅思三因缘 → 修四禅、四无量 → 玉女宝劝留，王反教以无常 → 忽然命终，七日后七宝皆隐、宫殿成土木 → 佛点题：“有为法无常变易，要归磨灭”，并自述“六返作转轮圣王，今最后身更不受有”。
- **临终度生**：佛遣阿难告末罗族来见 → 末罗悲号供养白叠 → 百二十岁外道须跋三请入见 → 佛以“有八圣道则有四沙门果”一语判摄诸道 → 须跋当夜出家证罗汉，“是为如来最后弟子”。
- **最后教诫**：佛止阿难之悲、赞其四未曾有法 → 依次答阿难四问（念佛四处礼敬 → 听释种与外道出家勿试四月 → 阐怒以梵檀罚处之 → 女人莫与相见共语、当自捡心）→ 听诸比丘“舍小小戒”，以经戒为护 → 三问大众无疑，记莂千二百弟子道果。
- **般涅槃**：示“如来时时出世，如优昙钵花时一现”，以“不放逸”为末后之教 → 顺入四禅→空处→识处→不用→有想无想→灭想定，逆出再由四禅入灭 → 地动放光 → 梵天、帝释、毗沙门、阿那律、阿难、佛母摩耶等十几位天人圣众次第说偈哀悼。
- **葬礼与分舍利**：比丘如“斩蛇”般失怙 → 诸天欲留舍利七日，人举床不动 → 末罗依转轮圣王葬法阇维 → 大迦叶于火化前赶到礼佛足（其间拔难陀放言“随我所为”，为日后结集伏笔）→ 诸国陈兵争舍利，香姓婆罗门调停均分八分，连同瓶塔、炭塔、发塔共起十一塔。
- **卷末偈颂**：以问答偈记佛以沸星出时生、出家、成道、灭度，总束全经。

## 三、关键结论
- 一切有为法无常变易，终归磨灭；合会有离，生必有死，唯圣智见道者乃知足。
- 有八圣道处才有四沙门果，外道异众无沙门果。
- 佛灭后“所说经戒即是汝护”，教团依法不依人；恶性比丘以默摈处之。
- “我以不放逸故，自致正觉，无量众善亦由不放逸得”——不放逸是如来末后所说。
- 佛金刚之身犹为无常坏；分舍利、起塔供养，是后世佛塔崇拜的起点。

## 四、易混辨析
- **般涅槃 / 灭度 / 阇维**：般涅槃（又作般泥洹、灭度）指佛证入不生不灭的究竟寂灭，是“死”的宗教义；阇维（荼毗）只是遗体的火化，属葬仪层面。
- **四禅 vs 四无量**：四禅是色界定次第（有觉观离生喜乐→无觉观定生喜乐→离喜住乐→不苦不乐）；四无量是慈、悲、喜、舍遍满十方，二者善见王兼修，但一个是定境深浅，一个是心量扩展。
- **灭想定 vs 有想无想定**：有想无想定尚有微细之想，是三有的最高处；灭想定（灭尽定）想受俱灭，更高一层。本卷佛从灭想定起、回入四禅而灭，表示灭度不在无色定中完成。
- **四念 vs 四念处**：本卷“四念”指念佛四处——生处、得道处、转法轮处、般涅槃处——的礼敬忆念；“四念处”是观身、受、心、法的禅观法门，二者并非一事。
- **须跋 vs 拔难陀**：同为佛灭前后出现的弟子——须跋当夜证果，是“最后弟子”的正面形象；拔难陀闻佛灭而喜“我得自在”，是佛灭后僧团需要结集整肃的反面伏笔。

## 五、阅读提示
带着“佛不在了，僧团怎么办”这一个问题去读：卷中每一段问答——礼塔、出家、罚阐怒、小小戒、以经戒为护——都是佛留下的遗嘱；再对照善见王与佛两条“死亡叙事”（王恋世而玉女劝谏舍寿、佛主动入灭而教诫大众），体会全卷以王喻佛、以死显法的编排。
