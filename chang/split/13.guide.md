# 佛说长阿含经卷第十三 导读

## 一、内容总览
本卷为《长阿含经》第三分第一经（二○）《阿摩昼经第一》，与巴利《小部·经集》及《中部·阿摩昼经》同源，是佛典中破斥婆罗门种姓傲慢的代表作。佛在俱萨罗国伊车林时，名声显赫的老婆罗门沸伽罗娑罗疑佛"三十二相"真伪，派第一弟子阿摩昼前往查验。阿摩昼轻慢释种，佛由种姓溯源反破其骄慢，进而正面开示"明行具足"之道，最后阿摩昼被折服，其师亦归依证果。

## 二、结构层次
全卷是一场完整的"考察—论辩—说法—摄受"，层层推进：
- **缘起**：沸伽罗娑罗闻佛名 → 疑三十二相虚实 → 派阿摩昼携五百弟子往观（考察者反成被调伏者）。
- **冲突起衅**：阿摩昼倨傲（佛坐己立、佛立己坐），讥释种为"厮细" → 佛追问其姓，揭出阿摩昼的"声王"姓实出释迦王家婢女之后 → 又说"释"姓源于声摩王四子雪山婚配的本缘 → 五百弟子自悔"无状"。
- **种姓对论**：佛以连串两难问答证明刹利女、刹利男胜于婆罗门 → 引梵天偈"刹利生中胜"自证，引出"何为无上士、明行具足"一问。
- **正说修道次第**（全卷核心）：出家持戒（不杀至不饮酒、离种种邪命自活：占相、咒术、通使命、斗诤嬉戏等逐一排除）→ 根门调伏、食知止足 → 昼夜精进修四念处一心 → 四禅（依次以浴药、山泉、莲花、白叠四喻说"现身得乐"）→ 神足、天耳、他心、宿命、天眼、无漏六种智证（三明六通）。
- **破外道四方便**：不得明行而采药、拾落果、起草庵、设堂阁施食行人，四种"苦行/福行"皆非正道 → 复举阿咤摩等十二大仙的简朴生活，对比今婆罗门的城墎高床、车马璎珞，讽刺其讽诵旧典欲生梵天"无有是处"。
- **收束摄受**：佛现广长舌、阴马藏二相证三十二相实有 → 阿摩昼见相归命却仍生白癞；其师来见，归依受五戒，设供七日 → 阿摩昼癞愈，师得法眼净，七日后命终，断五下结得不还果。

## 三、关键结论
- 具足三十二大人相者，在家为转轮圣王，出家必成正觉——佛相真实，考察者反成证人。
- 尊贵不在血统而在德行：种姓上刹利最胜，修行上"明行悉具足"者天人中最胜。
- 佛门沙门不事占相、咒术、通使命令等一切"遮道法、邪命自活"，唯以圣戒、根门、四禅、三明为道。
- 诽谤圣者自种罪根（阿摩昼即生白癞），至诚悔过则罪除。
- 归依三宝、供养布施、断五下结，能得不还果，不再来此世间。

## 四、易混辨析
- **摩纳 vs 沙门**：摩纳（māṇava）是婆罗门青年学子，承袭吠陀家学；沙门是舍家出家的修道人，本卷正是"摩纳"被"沙门"折服。
- **三十二相 vs 明行具足**：三十二相是果报身的庄严表相；明（宿命、天眼、漏尽三明）与行（戒行）才是佛道实质——佛先以相折其眼，再以明行服其心。
- **四方便 vs 圣戒梵行**：采药、拾果、草庵、施堂阁是外道以为的修行；佛教认的是持戒、修禅、发慧。
- **宿命智 vs 天眼净 vs 无漏智**：即"三明"——宿命明知过去世，天眼明见死此生彼的业报往来，无漏智证四谛而漏尽，是修行验证的终点。

## 五、阅读提示
可带一个问题读本卷："什么才是真正的尊贵？"看佛如何先顺婆罗门的种姓逻辑出牌（刹利胜），再把"最胜"彻底转移到明行具足上——这是全卷论辩的枢纽。
