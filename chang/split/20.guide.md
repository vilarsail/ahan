# 佛说长阿含经卷第二十 导读

## 一、内容总览
本卷为《长阿含经》卷二十，属第四分《世记经》的后半部，含三品：**阿须伦品第六**、**四天王品第七**、**忉利天品第八**。《世记经》是汉译四阿含中罕见的“世界论”专经，系统铺陈须弥山内外、四大洲、地狱诸天、众生种类与劫世灾变。本卷从海底的阿修罗宫城讲到须弥山半的四天王、山顶的三十三天，再汇总诸天寿命、四食、受生、斋日、鬼神、众生界趣，以云电雷雨之奇与占雨之谜收束，是一幅佛教式的“宇宙图志”。

## 二、结构层次
- **阿须伦品第六**：罗呵阿须伦城七重庄严 → 议堂、四园、昼度树、跋难陀池 → 臣下小城依级递减 → “王念臣、臣即知而至”的心念相召，凑齐游观队伍 → 自然风吹门散花、五侍卫、四风持海，“福报威神如是”收束。
- **四天王品第七**：用同一模板改写——东西南北四城（贤上、善见、周罗善见、可畏/天敬/众归）→ 园池 → 阶道 → 游观 → 五鬼神侍卫收束，与前品形成排比对照。
- **忉利天品第八**（全卷重心，层层推进）：
  - 城郭栏楯、善法堂与帝释宫殿、四园四石垛、难陀池昼度树（空间铺陈）→ 诸天入园，因“本行功德不同”而有得入不得入、得娱乐不得娱乐之别（福报的差别化）→ 四园与善法堂、昼度树的得名解释（释名体例）→ 帝释十大天子、诸天水陆贵花。
  - **总账式排比**：天有十法 vs 人有七色 → 萤火—灯烛—炬火—诸天光明层层递进，终至“合集尔所光明，不如苦谛光明”→ 身长衣重、寿命长短，从四洲、饿鬼、龙鸟、欲界六天到色无色界诸天依次列举 → 四食（抟、触、念、识）与众生所食之异 → 谋生、婚姻、淫欲方式之异 → 身坏命终“此后识灭，初识生，因识有名色，因名色有六入”的受生公式，配以天儿自然化现、树曲躬奉物的童话式描写。
  - **戒善与批判**：三斋日（八日、十四、十五）四天王遣使案行世间，孝亲敬师者“增益诸天众，减损阿须伦众”→ 帝释说偈自赞，佛以“淫、怒、痴未尽”否定之，唯漏尽比丘可说此偈 → 鬼神随所依得名，人初生有鬼神随逐 → 答外道问：行十恶者千人才有一神护，行十善者一人有百千神护。
  - **收束**：阎浮提以“勇猛强记、能造业行、能修梵行、佛出其土”三事与诸趣互胜 → 欲界十二种、色界二十二种、无色界四种种类的总清单 → 四大神各执“我大偏多”的恶见，佛（或先得法的神）次第破之 → 云电雷雨皆四大相触所致，相师占雨有五缘不可定知。

## 三、关键结论
- 诸天福报由“本行功德”（过去世的行业）决定，入园浅深、饭色青白皆随福而异。
- 一切光明层层相胜，最终不及四谛光明——智慧远胜天福，是全卷的点睛之论。
- 帝释虽为天主，淫、怒、痴未尽，其偈不得佛印可；唯漏尽阿罗汉“离于苦本”，天威不足恃。
- 世间行善则“增益诸天众，减损阿须伦众”，人天之间以善恶相感。
- 善恶业决定死后趣向与守护神多寡：十恶者百千人才有一神护，十善者一人有百千神护。

## 四、易混辨析
- **阿须伦 vs 诸天**：同属福报大者，但宫殿在海下、寿千岁、有嫁娶淫欲、与天战斗，是“似天非天”的一类。
- **四天王 vs 忉利天**：四天王居须弥山半四面，寿五百岁；忉利天在须弥山顶，帝释为主，寿千岁，故忉利胜于四天王。
- **欲界诸天 vs 梵迦夷天以上**：欲界六天有男女之事，且方式渐轻（相触→近→执手→熟视→暂视）；“自上诸天无复男女”，以禅定喜乐为食。
- **色界诸天异译**：光念、遍净、果实、无造、无热、善见、大善见、色究竟、阿迦尼吒等是本卷所用的异译名，层次依光明与寿命递进排列，勿以通行名硬套。
- **四天王遣使 vs 四天王躬身自下**：八日遣使者、十四日遣太子、十五日亲自案行，三斋日的检查规格逐级升高。

## 五、阅读提示
带着两个问题读：其一，佛在华丽的世界铺陈中如何插入批判与超越（帝释偈被否定、相师占雨不可定知、四谛光明第一）？其二，这些数字化的宇宙描写，哪些是当时印度的通行宇宙论，哪些是佛教自己的排序与价值观？
