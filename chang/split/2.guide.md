# 佛说长阿含经卷第二 导读

## 一、内容总览
本卷为《长阿含经》第一分《游行经》的前半。《游行经》记述佛陀晚年自王舍城一路北行、直至拘尸那竭双树间入灭的最后历程，相当于巴利经典中的《大般涅槃经》。本卷从摩竭陀阿阇世王谋伐跋祇写起，佛借答问说出"七不退法"，随后一路游行教化：在巴陵弗授归戒并预言城之兴衰、在拘利村说四深法、在毗舍离受庵婆婆梨园供养，终于因魔王波旬劝请而自定三个月后的涅槃之期，以"地动八因缘"作结。

## 二、结构层次
全卷是一条"一路北行、每到一地随缘施教"的游行线：
- **起因与主题**：阿阇世王欲伐跋祇 → 遣大臣禹舍问佛 → 佛历数跋祇七法，断言"其国久安，无能侵损" → 转向比丘，广说七不退法及令法增长的诸七法、六法（对国之七法 ↔ 对僧之七法，同一"和顺不退"主题的两面）。
- **巴陵弗城**：佛预言此城"诸方所推，不可破坏"，唯大水、大火、中人与外人相谋三事能坏 → 天神封地、诸清信士归戒 → 渡恒河，说"法桥渡河津"偈。
- **拘利村—那陀村**：说圣戒、圣定、圣慧、圣解脱四深法 → 阿难问亡者生处 → 佛说法镜（不坏信），以"三恶道尽，得须陀洹"收束。
- **毗舍离**：淫女庵婆婆梨先请佛供斋并献园 ↔ 五百隶车加价争供不得 → 佛说"五宝难得"。
- **结穴**：遇饥馑，分遣比丘往各地安居 → 佛身疾 → 暗示阿难"可住一劫有余"，而阿难被魔所蔽，三请不悟 → 魔波旬劝灭度 → 佛许"是后三月"于拘尸那竭灭度 → 地大震动 → 广说地动八因缘。

## 三、关键结论
- 国家久安与僧团不败之道相同：上下和顺、奉法敬戒，则"无能侵损，法不可坏"。
- "法镜"即于佛、法、僧、戒成就不坏信；圣弟子由此自知不堕三恶道，极七返生必尽苦际。
- "当自炽燃，炽燃于法，勿他炽燃；当自归依，归依于法"——以法为依、以自为洲，是佛涅槃前的根本嘱托。
- 佛寿本可一劫有余，因阿难三次被问而默然不对，佛遂定于拘尸那竭娑罗园双树间取灭度。

## 四、易混辨析
- **须陀洹 vs 斯陀含**：断三结得须陀洹（初果），不堕恶趣、最多往来七生；再加贪瞋痴薄，得斯陀含（二果），"还来此世"一返即尽苦本。
- **断五下分结者**：生天而"即般涅槃，不复还此"，即阿那含（不还果），比前二者更深一层。
- **般涅槃 vs 灭度 vs 般泥洹**：同义异译，均指佛的究竟入灭；长行用"灭度"，偈颂作"般泥洹"。
- **跋祇七法 vs 比丘七不退法**：前者是治国安邦的政治原则，后者移用于僧团修行，条目多相重合——同一套"不退"逻辑从世间法转出世间法。

## 五、阅读提示
带着两个问题读：佛临行前反复说"不退法"并嘱"自归依法"，与即将到来的涅槃之间有何呼应？阿难"默然不对"这一细节，如何决定了佛住世期限？
