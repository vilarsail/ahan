# 佛说长阿含经卷第六 导读

## 一、内容总览
本卷属《长阿含经》第二分（初），含两部经：《小缘经第一》（卷内第五经）与《佛说转轮圣王修行经第二》（第六经）。前经由婆悉吒、婆罗堕两位婆罗门出身的新比丘被本族讥嫌说起，破斥"婆罗门种最第一、从梵口生"的种姓论，并借天地成立的"小缘"讲四姓与沙门名号的起源，成立"四姓平等、依行不依种"的立场。后经由"自炽燃、自归依法"引出坚固念王七宝治世与"旧法"兴衰的传说，展示众生随善恶行而寿命增减、弥勒未来出世的大史观，最后归结到比丘的具体修行。

## 二、结构层次
本卷两经并列，各有完整骨架：

**《小缘经》**：提问 → 破斥 → 立宗 → 溯源 → 结偈
- **缘起**：二婆罗门弟子舍种姓出家遭同族嫌责 → 佛先立判："俗法须此（种姓憍慢），我法不尔"；
- **破斥**：四姓皆可杂十恶、皆可修十善，善恶报不由种姓 → 种姓优越论自破；
- **立宗**：佛弟子当自称"沙门释种子，从法化生"，大梵之名实是如来之号；
- **溯源**：劫坏众生生光音天 → 食地味、地肥、自然粳米而生美丑诤讼 → 分田立主生刹利、入山修道生婆罗门、营生生居士、工巧生首陀罗 → 四姓之外有第五"沙门众"，出"明行成就罗汉"为最第一；
- **结偈**：梵天颂"生中刹利胜，能舍种姓去；明行成就者，世间最第一"，佛印可其言。

**《转轮圣王修行经》**：立宗 → 引史 → 退化 → 复升 → 劝修
- **立宗**："当自炽燃，炽燃于法……自归依，归依于法"，落实为四念处观；
- **引史**：坚固念王七宝具足、以正法治世，轮宝离处即出家让位，传太子"转轮圣王旧法"；
- **退化**：后人"自用治国，不承旧法" → 贫穷 → 劫盗 → 兵杖 → 妄语等十恶次第现世 → 人寿由四万岁递减至十岁 → 刀兵劫七日相杀；
- **复升**：幸存者递修十善，不杀→不盗→不邪淫→不妄语→……→正见，人寿节节回增至八万岁 → 弥勒如来出世、儴伽王建宝幢布施后出家证果；
- **劝修**：以轮王旧法喻比丘修行——修四神足（寿命延长）、持戒（颜色增益）、四禅（安隐快乐）、四无量（财宝丰饶）、知四谛（威力具足），末以"漏尽比丘力能胜魔"收束。

## 三、关键结论
- 善恶报应通于四姓，贵贱由行为而非出身决定。
- 佛弟子的真正种姓是"从法化生"的沙门释种子；四姓之人皆可出家，皆出"明行成就罗汉"，于五种人中为最第一。
- 承"旧法"以正法治世则寿增世治，法坏则贫盗兵杀次第而起——本卷给出佛教独有的"道德史观"：世间寿夭是众生行为的刻度。
- 比丘当"自炽燃，炽燃于法"，以自身与法为依归，不倚他力。

## 四、易混辨析
- **地味 ↔ 地肥 ↔ 自然粳米**：劫后众生食物的三级递降——初食甘泉（地味），次食地肥，再食自生粳米；每降一级，色相转粗、诤讼加深一层。
- **刹利 ↔ 婆罗门**：刹利执世俗治权（经中谓其源出众人推举立王），婆罗门执祭祀与经典权威、自称从梵口生；佛以二者皆可善恶而抹平其高下。
- **四向 ↔ 四果**："向须陀洹"是正趋近初果之人，"得须陀洹"是已证初果；四双八辈即四向四果八类圣者，合称如来弟子众。
- **转轮圣王 ↔ 明行成就罗汉**：轮王以正法统四天下，是世间之最；罗汉舍种姓出家、漏尽解脱，是出世间之最——偈颂正以这一对比收束全经。

## 五、阅读提示
带着两个问题读：人为什么生来不平等？世间为什么由乐入苦？本卷的答案系于"食"与"心"——因食起贪，因贪起诤，因诤立王立法、渐生十恶；而逆转之路，恰是从"不杀生"一善一善修回去。
