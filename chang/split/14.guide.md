# 佛说长阿含经卷第十四 导读

## 一、内容总览
《长阿含经》第三分第二经，即汉译《梵网经》（对应巴利《长部》第一经）。缘起于善念梵志一路毁谤佛、法、僧，其弟子梵摩达却一路称赞三宝，佛借此事教诫比丘如何面对毁誉，并系统破斥外道关于「我与世间」的一切玄论——六十二见，显示唯有如来遍知诸见而不执著，这是「贤圣弟子如实赞叹如来」的「甚深微妙大法光明」。

## 二、结构层次
- **缘起立题**：师徒随佛、一谤一赞 → 比丘集讲堂议论 → 佛诫：闻谤不得怀忿（忿则自陷溺），闻赞不得生喜（喜亦陷溺）；凡夫所见只是「小缘威仪戒行」。
- **凡夫之叹**：从不杀、不盗、不淫、不妄语两舌恶口绮语，到离酒、离金银妻息僮仆等 → 佛判此仅为「持戒小小因缘」。
- **正说主干·破本劫本见十八见**：常论四见（忆二十/四十/八十成坏劫＋捷疾相智）→ 半常半无常论四见（大梵自慢、数数戏笑、展转相看、捷疾相智）→ 有边无边论四见 → 异问异答四见（诡辩避答）→ 无因论二见。每一见皆循「入定忆念或以己智推度 → 立论 → 尽入某见、齐是不过」的同一格式。
- **破末劫末见四十四见**：有想论十六 → 无想论八 → 非想非非想论八 → 断灭论七 → 现在泥洹论五（享五欲及入四禅皆自称涅槃）。
- **收束**：如细网覆小池，众说尽入六十二见 → 唯如来知此见处、知报应、虽知不著而得寂灭；比丘如实知六触的集、灭、味、过、出要，则为最胜 → 佛断生死如多罗树断头，永不复生。
- **流通**：大千世界三返六种震动，阿难请名，佛立经名「义动、法动、见动、魔动、梵动」。

## 三、关键结论
- 面对毁誉，忿恨与欢喜同为「陷溺」，不动心才是自护护法之道。
- 一切关于我与世间的玄论不出六十二见，其依据不外定中忆念宿世或以己智推度，皆依「触」缘而立，离触缘立论无有是处。
- 如来胜于诸见处在「虽知不著」：知见处、知报应、知受之集灭味过出要，故得无余解脱。
- 自称享五欲或入四禅即是现在涅槃，同样是「现在泥洹论」的执见；禅定境界不等于正见。

## 四、易混辨析
- **常论 vs 断灭论 vs 现在泥洹论**：常论执我及世间恒存（面向过去劫）；断灭论执死后一切断灭无余（面向未来）；泥洹论执现生已得究竟解脱（执著现在）——分别于三世执「我」。
- **有想论 / 无想论 / 非想非非想论**：同论死后所生之处，差别在彼处心识之想的有无，各再配「有色/无色、有边/无边、乐/苦」等而成十六、八、八见。
- **天净耳 vs 捷疾相智**：前者是禅定所成的超常听觉（佛用以闻比丘议论）；后者是敏捷锐利的推度智，本经中恰是外道妄立第四见的工具。
- **异问异答 vs 愚冥随答**：前者因怕答错有愧而故意模棱搪塞，后者因愚钝而人云亦云，同归「问答四见」。

## 五、阅读提示
带两个问题读：一、佛为何把「赞叹」与「毁谤」同等看待？二、六十二见的共同论证套路是什么？留意每见末尾反复出现的「齐是不过」「唯佛能知，亦复如是」——这是本经排比推进的结集体例，抓住格式即可快速通读。
