# 杂阿含经卷第十七 导读

## 一、内容总览

本卷为《杂阿含经》「杂因诵第三品之五」，收经三十四篇（四五六～四八九）。全卷由两大义群贯穿：前半论「界」——七种定境的了知与证得、「缘界故生说见想」的纲要句、种种界与三出界、止观二法与三解脱界；后半论「受」——六界无我、触为受缘、三受正观、凡圣受别，归结「诸所有受悉皆是苦」与受之集灭味患离，末四经以一法至十法收束。

## 二、结构层次

- **七界问答开篇**（四五六）：列光界、净界、无量空入处界、无量识入处界、无所有入处界、非想非非想入处界、灭界七界 → 逐界答「缘何可知」（光界缘闇、净界缘不净、灭界缘有身）→ 再答「以何正受而得」，定境阶梯与入手处一目了然。
- **纲要句与因生想**（四五七～四五八）：优檀那句「缘界故生说、见、想」立宗 → 婆迦利追问「于佛起非佛见亦缘界乎」，答「凡夫界者，是无明界」→ 四五八展开：缘欲界、害界生欲恚害想 → 身口心三处邪 → 现法苦住生恶趣 ↔ 缘出要界、不害界生正想 → 三处正 → 现法乐住生善趣，以旷野大火喻对照两途。
- **界的层层解说**（四五九～四六四）：婆罗门问自作他作，佛以方便界、造作界等反问作答 → 瞿师罗三问「种种界」，阿难三答（根境识三事和合生触生受 ↔ 欲色无色三界 ↔ 色无色灭三界与三出界），各以偈颂收束 → 四六四阿难遍问上座、五百比丘、佛，三方同答「止观二法」与断、无欲、灭三解脱界，佛印证「同法、同句、同义、同味」，并揭上座是阿罗汉。
- **罗睺罗四问**（四六五～四六八）：同一问「云何知、云何见得无我慢系着使」→ 依次以六界（地水火风空识）非我、不异我、不相在，触为受因，三受正观（乐作苦想、苦作剑刺想、不苦不乐作无常想），断贪恚痴三使作答。
- **受之譬喻与深观**（四六九～四八五）：大海深险喻、狂风喻、双毒箭喻（凡夫生身受心受、圣弟子唯生身受）、客舍喻，铺开乐苦、身心、食无食、贪与出要十八种受 → 「诸所有受悉皆是苦」，以一切行无常故 → 四七四「渐次诸行寂灭」从初禅言语寂灭层层排至想受灭，再归于贪恚痴心解脱之无上止息 → 四七五～四八一受的集、灭、道迹、味、患、离反复淬炼，佛因如实知受而成正觉 → 四八五优陀夷与瓶沙王诤二受三受，佛示一受乃至百八受皆应机异说，结以离欲、远离、寂灭、菩提四种乐。
- **法数收束**（四八六～四八九）：一法（食）至十法（十业迹）逐层排比 → 于彼生正厌离、不乐、背舍，观察无常、变易、离欲、灭、舍离，得尽诸漏、究竟苦边。

## 三、关键结论

1. 缘界故生说、见、想；凡夫界即无明界，所见所言不出其界。
2. 想必有因：缘欲、害则身口心三处邪，现法苦住；缘出要、不害则三处正，现法乐住。
3. 触是受之因缘，触灭则受灭、止、清凉、没；以一切行无常、变易故，说诸所有受悉皆是苦。
4. 凡夫于苦受如中双毒箭——身受之外更生心受；圣弟子唯生身受，贪恚痴三使不能驱使。
5. 于贪欲、恚、痴心不乐、解脱，是胜止息、无上止息，一切定乐不能过。

## 四、易混辨析

- **「界」之三义**：禅定境界（光界、无所有入处界）、元素（地水火风空识六界）、因类范畴（欲界、害界、凡夫界），须随文分别。
- **三受 / 五受 / 百八受**：乐、苦、不苦不乐以「相」分；乐、喜、苦、忧、舍以「根」分；百八受是三十六受配三世——应机异说，非自相矛盾（四八五正为此发）。
- **身受 vs 心受**：身受是身触所生，心受是随之而起的忧悲狂乱；圣凡之别在「唯生一受」。
- **食念·无食念·无食无食念**：「食」谓依五欲滋养；无食谓依初禅离欲喜乐；无食无食谓依二禅以上胜定。食乐、食舍、食解脱仿此。
- **断界·无欲界·灭界**：断一切行／断除爱欲／一切行灭——三解脱界的三个侧面；此「无欲界」不是无色界。

## 五、阅读提示

带着「同是说受，何以有一受、二受、三受乃至百八受？」的疑问读四八五经，再回看四七四「渐次寂灭」把四禅、四无色、想受灭排成止息阶梯，即可握住本卷「界—定—受」的枢纽。
