# 杂阿含经卷第二十五 导读

## 一、内容总览
本卷为《杂阿含经》卷第二十五，收两经：（六四〇）佛在摩偷罗国向天帝释、四大天王悬记未来——佛灭后百年优波掘多出世弘法，千岁后恶王乱国、恶比丘内坏，最后说戒中断，正法灭尽；（六四一）《阿育王施半阿摩勒果因缘经》记阿育王倾尽国财布施，临终唯余半枚阿摩勒果供僧，及其身后王统下传至灭法之王沸沙蜜多罗而终。两经一为预言、一为因缘：前经悬记法灭，后经以阿育王兴法、末王灭法作印证，一兴一灭互为对照。此二经与全书“一句一经”的教法汇编体例不同，属传记预言类，是“末法”观念与阿育王传说的重要篇章。

## 二、结构层次（文章的骨架与逻辑推进）
**（六四〇）法灭预言**：由“付法”到“法灭”的因果长链。
- **授记开场**：佛记商人子掘多之子优波掘多“灭度后百岁当作佛事，教授师中第一”→ 点出未来道场优留曼茶山。
- **付嘱立限**：正法付嘱人、天共摄受 → “教法则千岁不动”。
- **法灭展开**：千岁后十善悉坏 → 四恶王四方来乱、坏塔杀僧（外破）→ 拘睒弥王难当降伏恶王、发愿十二年供养五众（法似中兴）→ 恶比丘不读诵经书、贪着利养（内坏）→ 天龙厌离：“佛法却后七日灭尽”。
- **最后说戒**：百千僧集拘睒弥布萨 → 三藏上座自恃不学戒、拒绝说戒 → 阿罗汉修罗他挺身请说 → 遭上座弟子安伽陀杀害 → 鬼杀安伽陀、罗汉弟子杀三藏 → 正法顿灭，佛母摩诃摩耶下天悲泣，五百优婆塞一日造五百佛塔。
- **收束回扣**：佛重嘱四天王“勤力加于精进，护持正法”。

**（六四一）阿育王因缘**：极盛 → 极贫 → 圆满的转折结构。
- **兴施**：闻给孤独长者施亿千金 → 自誓施亿百千，起八万四千塔、设五岁大会。
- **夺施**：王病重，本愿唯欠四亿 → 太子断库，金器→银器→铜器→瓦器层层剥夺 → 手中唯余半阿摩勒果 → 送鸡雀寺作“最后布施”。
- **施成**：上座研果入石榴羹，众僧普得其分 → 王即以阎浮提施与三宝，书纸齿印封缄而终 → 群臣送四亿补足本愿，立三波提。
- **鉴戒收尾**：王统五传至沸沙蜜多罗坏塔杀僧 → 守塔神牙齿嫁女与虫神，虫神推山压杀恶王，孔雀苗裔永终 → 结劝“世间富乐不足为贪”。

## 三、关键结论
- 正法之灭，外缘是恶王，内因是僧团自坏——“形类比丘”不诵经、戏论眠卧、贪着利养，“是法中之大贼”。
- 法灭的标志是戒律中断：正法亡于布萨日无人再说波罗提木叉，修罗他是最后说戒者。
- 布施的分量在心不在物：半枚阿摩勒果研入羹中令众僧普得其分，即成圆满檀波罗蜜。
- 富贵无常，财物为五家所共：“凡盛必有衰”，可依恃者唯功德与系心三宝。

## 四、易混辨析
- **修罗他 vs “弟子”（三藏上座）**：修罗他是寡闻少欲、住揵陀摩罗山的阿罗汉，最后说戒的圣者；“弟子”是人名（梵语śiṣya的意译），是自恃多闻、拒绝说戒的三藏上座。
- **掘多 vs 优波掘多**：父子二人；受佛授记的是子优波掘多——佛灭百年后的教授第一师。
- **布萨（说戒）vs 波罗提木叉**：布萨是每半月集会诵戒的仪式，波罗提木叉是所诵的戒本；本卷法灭即始于布萨日无人说戒。
- **五众 ≠ 五蕴**：本卷“供养五众”指出家五众（比丘、比丘尼、式叉摩那、沙弥、沙弥尼），非色受想行识。
- **阿罗汉 vs 学人 vs 凡夫**：经中把僧众分为三分——阿罗汉（无学，断尽烦恼）、学人（有学，见道以上仍须修学的圣者）、真实凡夫。

## 五、阅读提示
带着两个问题读：前经问“法为什么会灭”——答案在僧团自身而非外敌；后经问“什么才真正属于我”——号令阎浮提的阿育王，最后能作主的只有半枚果子。
