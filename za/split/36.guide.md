# 杂阿含经卷第三十六 导读

## 一、内容总览
本卷为《杂阿含经》卷第三十六（九九三～一〇二二经），属全经后部的偈颂集（祇夜部分）：前两经是弟子说偈赞叹，后二十八经是天子于后夜来诣佛所、以偈问答。全卷以「天子问、佛偈答」的短经为主，话题从布施福报、善知识等世间善法，逐步深入到缚与脱、心与世间、有余与无余的解脱核心。

## 二、结构层次
- **弟子偈赞开场**（九九三、九九四）：婆耆舍先造长偈赞叹诸上座比丘与佛的功德 → 次经婆耆舍病笃，佛亲往探视 → 他自陈于过去、未来、现在六根境界「心不染、不着、不污、解脱」，再以「生者悉归灭」的临终大偈诀别大众，当夜般涅槃。两经一赞一别，前后呼应。
- **天子问答·世间善法**（九九五～一〇〇〇）：天子接连夜问：阿练若比丘何以颜色鲜明（答：于过去无忧、未来不欣、现在随所得）↔ 住林放逸者不度死彼岸（对比）；作何功德日夜增长、施何得大力妙色 → 悉鞞梨天子自述前世四门布施、与夫人王子大臣分福的因缘作证 → 四种善知识。以布施福德为主轴。
- **天子问答·解脱深义**（一〇〇一～一〇二二）：由「冥运持命去」的无常警策引入 → 「断五、舍五、增修五根、超越五和合」的修道总纲 → 五人眠觉、有余无余之辨 → 一连串「世间第一」之问（第一伴、大力妙色、两足尊、四足胜……）→ 收束于「心持世间、欲缚世间、老死掩世间、无明爱结覆世间、我慢为幢」的归纳 → 终以「名映世间」「见幢盖知车」等智答收卷。
- **体例印记**：每经一律「如是我闻……天子欢喜随喜，稽首佛足，即没不现」首尾闭环；天子必以「久见婆罗门，逮得般涅槃」一偈作谢，是祇夜结集的固定套式。一〇〇八经中「本为田家子」的天子抢答被斥，再由佛正答，可见偈颂集保存了问答现场感。

## 三、关键结论
- 心是一切枢纽：「心持世间去，心拘引世间」，能制御世间的就是这一颗心。
- 欲爱是世间之缚：「欲能缚世间，调伏欲解脱」；爱欲生众生，意念在前驱驰，业随其行。
- 世间的多重覆蔽：老死掩之，无明覆之，爱结系之，我慢如高幢标举。
- 渡生死駃流的纲目：断五盖、舍五结、增修五根、超越五取蕴。
- 唯有无余无忧：众生乐着「有余」（残余执取之身），故有母子相忧；无余则忧苦永灭。

## 四、易混辨析
- **有余 vs 无余**：有余＝仍执取残余身心、再受后有；无余＝无余涅槃，烦恼与五蕴俱尽、不再受生。九九四、一〇〇一、一〇〇四三经都立足于此组对照。
- **于觉眠 vs 于眠觉**：凡夫虽醒犹眠（眠于无明烦恼），漏尽圣者虽眠犹觉（正念不失）。
- **断除五、舍五 vs 五根 vs 五和合**：四个「五」各有所指——五盖／五下分结（一说五结）／信进念定慧五根／五取蕴，勿混为一。
- **结、缚、使**：同一烦恼的三种异名——如绳结系缚，如捆绑，如差使暗中随逐。

## 五、阅读提示
带着两个问题读：天子所问的种种「世间之最」，佛为何总能从世间一路答到出世间？婆耆舍临终一偈，如何把一生的修证浓缩进「受」「聚」「依怙」寥寥数字之中？
