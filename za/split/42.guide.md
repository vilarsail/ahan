# 杂阿含经卷第四十二 导读

## 一、内容总览
本卷为《杂阿含经》卷第四十二，收经十九则（一一四五～一一六三），处于全经后段与在家众相应的部分。主角多为憍萨罗国波斯匿王与舍卫国一带的诸婆罗门，主题集中于布施、无常、识人、忍辱与清净道，长行与偈颂交错，是阿含中「以王化俗、以偈摄义」的代表卷。

## 二、结构层次
全卷大体按「国王问法 → 辱骂应对 → 婆罗门问法 → 老年之叹」推进：
- **布施与业报**（一一四五～一一四六）：王问「应施何人」→ 佛以战场赏功为喻：赏勇不赏种姓 → 归结「远离五支、成就五支」的福田；再以「从冥入冥……从明入明」四句总说命运随行业、不随出身。
- **无常逼迫**（一一四七）：四方石山磨地而来之喻 → 老病死磨迮众生 → 唯当修法、修义、修福。
- **识人之难**（一一四八）：王误敬形貌粗大的外道 → 佛诫「勿速自决」，须久观戒行、听其言说 → 鍮石涂金喻揭其表里。
- **五欲孰胜**（一一四九）：七王争论色声香味触谁为第一 → 佛说「各随意适」，本无定胜 → 栴檀优婆塞赞佛收场。
- **生活化导与对治**（一一五○～一一五四）：节食偈令王瘦身 → 年少阿修罗、宾耆迦、健骂婆罗门先后骂佛 → 佛以「不受食」「胜伏二俱舍」「逆风坌土」应之，辱骂反成教化因缘。
- **婆罗门问法群**（一一五五～一一六一）：违义欲「反其义」、不害问名实、火与施食而出家、婆肆吒夫妇论「杀瞋」、魔瞿问布施生梵、持盖者问清净道（佛答八正道）、异婆罗门问尸罗与三明。
- **收束**（一一六二～一一六三）：老夫妇蹲火相视 → 叹其少壮失修 → 结以「唯有惠施福，为随己资粮」。

## 三、关键结论
- 布施果报随诚敬之心与所施对象而定，供养断五盖、成五分法身的圣者福田最胜；论功不论族姓。
- 命运由身口意三业的善恶决定，与出身贵贱无关——四种「冥明」人括尽一切。
- 老病死如石山四面碾来，无常卒至，人身难得，唯修法、义、福是怙。
- 不以相貌仓促取人，须「久而可知」：观其戒行、审其言说、以智慧决断。
- 骂不报骂即是「不受」；不怒胜于瞋，胜者增怨、伏者不安，二俱舍方得安眠。

## 四、易混辨析
- **舍离五支 vs 成就五支**：前者断贪欲、瞋恚、睡眠、掉悔、疑五盖（一破）；后者成就戒、定、慧、解脱、解脱知见五分法身（一立），合为「福田」。
- **从冥入冥 vs 从明入明**：冥指卑贱贫苦，明指富贵尊荣，先论出身；后半「入冥入明」看善恶行业——出身不可择，去向可自造。
- **斯陀含 vs 阿那含**：斯陀含（一来果）尚须再返人间一次；阿那含（不还果）不再还生此界。本卷谓老夫妇若中年出家，可依修行深浅证此二果。
- **清净道 vs 无上清净**：清净道是八正道之「行」；无上清净是贪瞋痴一切烦恼永断之「果」。

## 五、阅读提示
带着「佛如何应机」来读：同一句辱骂，佛分别以譬喻、反问、偈颂化解；同一问布施，答语随王的执见步步转深。偈颂多是长行要义的复述，可先读长行再对读偈颂。
