# 杂阿含经卷第三十一 导读

## 一、内容总览
《杂阿含经》卷三十一，收经八六一至九〇四共四十四经，属道品修学与圣果阶位汇编之卷。前半以诸天寿命警策、四禅八定与五种般涅槃开篇；中段大篇幅讲四正断与「不放逸」连环譬喻；末段归摄于无学三明、无为法、内六入处与缘起诸支，是「修什么、怎么修、修到什么果位」的一次集中展示。

## 二、结构层次
- **天寿警策**（八六一~八六三）：兜率陀天、化乐天、他化自在天一日一夜分别当人间四百、八百、千六百岁 → 凡夫于彼命终仍堕三恶道，圣弟子不然 → 以天寿之长反衬堕落之易；附「异比丘问、佛问诸比丘」同类各六经。
- **禅定与涅槃阶梯**（八六四~八七二）：初禅至四禅逐经展开，每经同一套路「修禅具足住 → 于五阴作如病、如痈、如刺、如杀观 → 厌离怖畏防护 → 甘露门自饶益，乃至涅槃」→ 不得现证者按「中般涅槃→生般→有行般→无行般→上流般」及色界诸天递列 → 复以「四无色定亦如是说」收束 → 插入风云雷电诸天经与「伞盖覆灯」记事经。
- **四众与四正断**（八七三~八七九）：四众善好调伏（偈颂）→ 三种子（随生/胜生/下生配五戒）→ 四正断五经重出：名录 → 偈颂 → 逐义广解（断断、律仪断、随护断、修断）→ 连带「四念处乃至正观修习亦如是说」。
- **不放逸喻海**（八八〇~八八二）：地、沉水香、赤栴檀、优钵罗华、象迹、须弥山、大海、月……三十余喻层层类比，一切善法皆「不放逸为根本，乃至涅槃」。
- **三昧、三明与问道**（八八三~九〇四）：四种禅「三昧善/正受善」十四组对辨 → 无学三明（宿命、生死、漏尽）→ 婆罗门以「三明」「名信」「名增益」「名等起」来问，佛皆舍其名而转以法义 → 无为法及种种同义异名 → 毛端渧水喻见谛所断之苦 → 内六入处中信行、法行、须陀洹、阿罗汉阶位 → 五种子喻缘起生灭 → 三爱、三有漏「当求大师」→ 罗睺罗问尽诸有漏 → 眼灭则苦灭收尾。

## 三、关键结论
- 诸天寿长万岁，命终仍随业受生，唯圣弟子不堕恶趣。
- 禅定非究竟：须于五阴观无常苦非我而厌离，方以甘露门证涅槃。
- 一切善法皆以不放逸为根本，乃至涅槃。
- 佛所立三明是无学的宿命、生死、漏尽三智证通，非婆罗门诵习典籍之学。
- 见真谛者如截多罗树头：所断之苦如大湖水，所余之苦如毛端渧水。

## 四、易混辨析
- **三昧 vs 正受**：三昧指心一境性的定，正受指正入禅定之受。本卷从住、起、时、处、迎、念等十四方面对辨「三昧善／正受善」，即得定与善入定受的巧拙四格配对。
- **断断 vs 律仪断 vs 随护断 vs 修断**：断断断「已起」之恶，律仪断防「未起」之恶，随护断令「未生」善起，修断令「已生」善增长——四正断即对善恶四态的精勤对治。
- **婆罗门三明 vs 佛教三明**：婆罗门以父母七世清净、通晓五种记论为三明；佛以无学宿命、生死、漏尽三智证通为真三明。
- **信行 vs 法行**：同是对内六入处观察忍可，随信而入者名信行，增上观察随法而入者名法行，二者皆离凡夫地、必得须陀洹。

## 五、阅读提示
带着「禅定与涅槃是什么关系」读八六四~八七二，带着「不放逸何以是一切善法之根」读八八〇~八八二的连环譬喻，即可抓住全卷骨干。
