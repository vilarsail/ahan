# 杂阿含经卷第九 导读

## 一、内容总览
本卷为《杂阿含经》卷第九（经二三〇～二五五），属六入处诵，二十六经一气贯注于一个主题：眼、耳、鼻、舌、身、意六根与所对色、声、香、味、触、法六境，以及由此生起的识、触、受——佛说「六入处集则纯大苦聚集，六入处灭则纯大苦聚灭」，甚至「世间」本身就以六根六境来定义。卷中既有佛与比丘、魔王的短经交锋，也有舍利弗、阿难、二十亿耳、摩诃迦旃延等尊者的著名论议与譬喻（芭蕉中空、二牛共轭、调琴弦）。

## 二、结构层次
全卷按「立宗定义 → 反复演练 → 问答抉择 → 弟子纪实」推进：
- **立宗定义「世间」**：（二三〇～二三二）比丘三弥离提三问「云何名世间」→ 佛答：六入处即世间、世间危脆败坏、世间本空（「此性自尔」）→（二三三）转对比丘说世间集、灭、灭道迹的四谛式定义（有爱为集，八圣道为道迹）。
- **略说广解**：（二三四）佛略说「世界边」即入室坐禅 → 众比丘请阿难广解 → 「世间名、世间觉、世间言辞、世间语说，皆入世间数」，末以度世间偈收束。
- **正反演练**：（二三五～二四七）十二经围绕根境正反对照：乐独住 ↔ 苦独住 → 舍利弗空三昧、清净乞食住 → 结与取皆在欲贪 → 宁烧其目不取色相、睡眠是愚痴活 → 味着即入魔手（六魔钩、四品法）↔ 不味着则脱魔系 →（二四六）魔化作觅牛人扰佛，佛以「无眼触入处，汝所不到」破之。
- **问答抉择**：（二四八～二五一）阿难与纯陀论「识非我」（芭蕉中空喻）→ 阿难与舍利弗遮破涅槃「有余、无余」四句戏论 → 摩诃拘絺罗与舍利弗两番问答：欲贪为系（二牛共轭喻）、无明与明（于六入处知与不知）。
- **弟子纪实与化导外道**：（二五二）优波先那中毒身坏如糠糟而「无我、我所」不动，末附防蛇毒咒 →（二五三）优陀夷破苦乐自作、他作、自他作、非自非他作四论，婆罗门尼得法眼净 →（二五四）佛以弹琴调弦教二十亿耳中道精进，证果后自说六种解脱 →（二五五）摩诃迦旃延为婆罗门说守护根门，偈斥徒存形相的当代婆罗门。

## 三、关键结论
1. 六根缘六境生识、触、受，「六入处集则纯大苦聚集，灭则灭」——离六入处则无世间可得可说。
2. 世间空是「此性自尔」：本来无一常恒不变易之法，并非修行之后才空。
3. 系缚不在根境相接，而在中间的「欲贪」——断欲贪则心解脱。
4. 于六触入处如实知无常生灭即破无明；涅槃「离诸虚伪」，问有余、无余皆是虚言。
5. 精进如调琴弦：太急增掉悔，太缓生懈怠，不缓不急方成圣道。

## 四、易混辨析
- **结所系法 vs 结法**：前者是被系缚的对象（眼色……意法），后者是能系的欲贪；「所取法／取法」同此结构。
- **味 vs 味着**：「味」作动词即贪恋执取（「于眼味者」），非滋味义；「眼味着色」＝以味着之心钩取色境，即是魔钩。
- **是我、异我、相在**：我见三型——即蕴计我、离蕴别立我、「相在」（我在蕴中或蕴在我中），三者一并遮破。
- **无明 vs 明**：同一对象（六触入处），不如实知、不见、不无间等即无明；如实知见即明，只差「如实」二字。

## 五、阅读提示
带着两个问题读：佛为何把「世间」定义在六根六境而不在山河大地？二十亿耳的琴弦之喻，对治的是你用功中太急还是太缓的那一端？
