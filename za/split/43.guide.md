# 杂阿含经卷第四十三 导读

## 一、内容总览
本卷属《杂阿含经》"六入处诵"（入处诵），收经十四部（一一六四～一一七七），是全经中"守护根门"法门最集中的一卷。主线只有一个：六根门头如何用功——从"二边与中"的问答决疑，到亲想、不净观、根律仪三重进阶，再到龟藏六、六众生、箧毒蛇、水流大树、守城、灰河等一连串譬喻，反复锤打同一件事：于可意、不可意境不取不着，心不随境转，直趣涅槃。

## 二、结构层次
- **问答决疑**：（一一六四）诸比丘于讲堂对"二边、中、缝紩"各执一说（内六入/外六入、三世、苦乐受、身集等）→ 同往问佛 → 佛以"触是一边，触集是二边，受是其中，爱为缝紩"作决定说。
- **王臣问法**：（一一六五）婆蹉王优陀延那问年少比丘何故"极安乐住"→ 宾头卢三答递进：作母、妹、女想（思惟）→ 观身三十六物不净（不净观）→ 守护根门（律仪）；王自述入宫"烧燃/不烧"亲证作结。
- **譬喻群展开**：（一一六六）～（一一七二）：有手故有取舍，喻根在则触受在 → 龟藏六喻摄根防魔 → 䵃麦六打、阿修罗五缚喻六触捶打与"心动摇魔即缚" → 守田栏牛、宫中求琴声喻识无常 → 癞病人喻不律仪之苦 → 六众生系于坚柱喻修身念处 → 箧毒蛇喻总括四大、五受阴、六爱喜、内外六入、三爱，以八正道之筏渡至无余涅槃。
- **护心不退**：（一一七三）五欲如火坑、㮈林棘刺喻防"利刺伤圣法律"，恒河东流不可令西，喻多闻圣弟子绝不还戒退减 → （一一七四）恒河大树"八不着"直趣涅槃；牧牛人难屠先还牛后出家，补足净行因缘。
- **知见收束**：（一一七五）紧兽喻四人所见各异，终以守城喻结出见清净之要：四念处守四识住之门 → （一一七六）目揵连代佛说漏、无漏法经 → （一一七七）灰河喻总收全卷，逆流而上、见八分水坐四层堂，并简别六师外道。

## 三、关键结论
- 二边是触与触集（根与境），中是受，缝合缠系一切的是爱；"以智知，以了了"则"作苦边，脱于苦"。
- 少欲少年比丘安乐住的三个因缘：视女如亲想、观身不净、守护根门，其中根律仪最切实用。
- 心一动摇即被魔缚，心不动摇则缚自解——缚在自心之念，不在外境。
- 修行者当如恒河大树：不着此岸（内六入）、彼岸（外六入），不入洄澓（退转），不腐败（犯戒），直浚输于涅槃。
- 见清净之要：以四念处为四守门，护住识所住的色受想行四门，依四谛正观、八圣道而还。

## 四、易混辨析
- **律仪 vs 不律仪**：同是见色闻声，随可念、不可念起贪瞋、觉想相续为不律仪；不起欲想恚想、见过患能舍离为律仪。
- **六内入处 vs 六外入处**：内是眼耳鼻舌身意六根，外是色声香味触法六境；箧毒蛇喻中"空村"譬内入处，"空村群贼"譬外六入处。
- **动摇 vs 洄澓**：动摇是当下心念于我、我所、当来有无上摇摆（魔缚随之），洄澓是行者还戒退转、如落漩涡打转不出。
- **有漏法 vs 无漏法**：凡夫于六境"不能胜法"、烦恼漏心是有漏；圣弟子"能胜彼色"、已起恶法无余灭尽是无漏。

## 五、阅读提示
带着一问读：我的眼耳鼻舌身意，今天在哪一根上"取相、取随形好"？卷中诸喻任选其一（龟藏六、六众生系柱、箧毒蛇、灰河）对照自心，即可入门。
