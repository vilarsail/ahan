# 杂阿含经卷第八 导读

## 一、内容总览
本卷是《杂阿含经》「六入处诵」的开端（第一八八～二二九经）。全卷以眼、耳、鼻、舌、身、意六根及其对象（色、声、香、味、触、法）为所观，反复申明一条主线：正观六入处无常、苦、非我 → 生厌 → 离喜贪 → 心解脱 → 自知「不受后有」。经文极短、高度重演，属典型的「一义多说」练习卷。

## 二、结构层次
全卷按「立公式 → 扩范围 → 示教学 → 成道迹」四步推进：

- **立公式（188～192）**：短经连发，立下基本链——正观眼无常 → 生厌 → 离喜离贪 → 心正解脱；再正反对比：于眼「不识、不知、不断、不离欲」则不堪任正尽苦、不堪越生老病死苦 ↔ 识、知、断、离欲则堪任——把检验标准钉死在「离欲」上。
- **扩范围（193～199）**：所观由「眼」扩为「眼→色→眼识→眼触→眼触因缘生受（苦、乐、不苦不乐）」整条链；197经以三种示现（神足、他心、教诫）度千萦发婆罗门，「一切烧然」以贪瞋痴火收摄全链；198～199经借罗睺罗之问立正观总纲——于内识身及外一切相，一切「非我、非异我、不相在」。
- **示教学（200～216）**：罗睺罗次第受教（为众说五受阴→说六入处→说尼陀那→独处思惟其义→方受「一切无常」增上法而证阿罗汉），示范「解脱智未熟，不堪任受增上法」的教学次第；随后多角度展开——诸比丘问次第漏尽（201～206）、六触入处地狱天（210）、佛略说「当觉六入处」而阿难广释为「灭六入处」（211）、像类比丘与不放逸行（212）、二法与三事和合触（213～214）、佛法六种当生功德（215）、大海喻（216～217）。
- **成道迹（217～229）**：以「道迹」系列收束——苦集道迹/苦灭道迹（缘起顺逆观）、涅槃道迹、趣一切取/断一切取道迹，再以断一切计（226～227）、增长法与灭法（228）、有漏与无漏（229）作结，归于「纯大苦聚灭」。
- **结集体例**：每经以「如是我闻……欢喜奉行」首尾呼应；篇末「如无常，如是苦、空、非我，亦如是说」「如内入处四经，如是外入处……亦如是说」，表明一经说眼、余根依例略说——读阿含须习惯这种「省文」。

## 三、关键结论
1. 六根门头即是道场：正观眼等无常、离欲，即是解脱，不假外求。
2. 检验唯在离欲：于六入处不知、不断、不离欲，则不堪任越生老病死苦。
3. 缘起的入口是「三事和合触」：根境识和合生触→受→爱→取→有→生，顺观即苦集，逆观即苦灭。
4. 结、缚、使、流、轭、盖、缠、垢一大串名相皆是烦恼异名，实质是于六触入处不如实知。
5. 有漏无漏以心分：世俗者是名有漏，出世间者是名无漏。

## 四、易混辨析
- 内入处 vs 外入处：内＝六根（能取），外＝六境（所取）；「眼、色」「耳、声」对举即是213经的「二法」。
- 苦集道迹 vs 苦灭道迹：前者顺观（触→受→爱→取→有→生→老死），后者逆观（触灭则受灭……），一经首尾相照，是全卷缘起观的骨架。
- 心解脱 vs 慧解脱：心解脱偏指离贪爱，慧解脱偏指以慧断无明；212经并举「无漏心解脱、慧解脱」，二者具足方为究竟。
- 涅槃道迹（219）vs 似趣涅槃道迹（220）：一观眼无常，一观眼非我——由无常入与由无我入，同为趣涅槃之路。

## 五、阅读提示
带着一问去读：眼见色的一瞬，「触」在哪里发生，「爱」从哪一步溜进来？抓住「三事和合触」与「离欲」两端，全卷的重演便不是枯燥的重复，而是同一公式的反复演练。
