# 杂阿含经卷第三十四 导读

## 一、内容总览

本卷为《杂阿含经》卷第三十四，收经九四〇～九六九共三十经，位于全经中后段。两大主题：前半（九四〇～九五六）以一连串譬喻反复敲打同一个事实——「众生无始生死，长夜轮转，不知苦之本际」，归结于「断除诸有，莫令增长」；后半（九五七～九六五婆蹉种相应，九六六～九六九诸外道问答）集中处理「十四无记」：命与身是一是异、世间常无常有边无边、如来死后有无等问题，佛为何一概置答，并以中道缘起立正见。

## 二、结构层次（★重点）

- **无始生死譬喻群（九四〇～九四六）**：大地草木斩为筹签数累世父母 → 土丸如婆罗果数父母 → 见众生享乐念「我亦曾受斯乐」→ 见众生受苦念「我亦曾更受」→ 见恐怖念过去杀生 → 见亲爱念「过去必为我父母」→ 数不尽、无人不曾是亲 → 「断除诸有，莫令增长」。每经同一框架（无始生死 → 譬念 → 劝学），是「一喻一经」的排比结集。
- **劫之长久譬喻群（九四七～九五五）**：一劫积骨如毗富罗山 → 铁城满芥子百年取一、劫犹不竟 → 迦尸劫贝百年一拂石山 → 日忆三百千劫忆不到边际 → 「无一处不生不死」「无一处无父母眷属」→ 大雨渧泡一生一灭 → 掷杖空中头尾不定、堕趣不定 → 转五趣轮不息 → 从「时间久」推到「受苦多」，再推到「去向不定」。
- **转入无常（九五六）**：毗富罗山四次易名（长竹山→朋迦→宿波罗首→毗富罗），配迦罗迦孙提、拘那含牟尼、迦叶、释迦四佛皆般涅槃 →「一切行无常……唯寂灭为乐」，为前半收束。
- **十四无记问答群（九五七～九六五）**：婆蹉问「命即身／命异身」「如来有后死、无后死」→ 佛答「无记」→ 火譬辨「有余／无余」（乘意生身仍「因爱故取，因爱而住」，非无余）→ 目揵连以「不如实知五蕴集灭味患出故生取著」解释不答 → 诜陀迦旃延以「彼因彼缘彼行无余灭，云何于彼记说」重申同义（婆蹉叹「师及弟子义同义、句同句、味同味」）→ 佛对「有我／无我」默然，为阿难说中道缘起、离常见断见二边 → 九六四经婆蹉问善不善法、四众得果、异道四月听出家，出家后佛授「止、观」二法，婆蹉证阿罗汉，佛说「第一记」；九六五守门者喻：尽苦之道唯此一门。
- **外道诸问（九六六～九六九）**：富邻尼答外道——佛非教「断灭坏有」，是教断「我慢、邪慢」；阿难答俱迦那——「见可见处、见所起处、见缠断处」故非不知不见；给孤独长者以「所见真实、有为、思量、缘起故无常，无常是苦」一一破外道十四见；长爪外道「一切见不忍」仍是一见，佛为说三种见与三受之观，尊者舍利弗在佛后执扇闻法，观无常生灭，「不起诸漏，心得解脱」。

## 三、关键结论

1. 生死无始，累世父母数之不尽，一切众生都曾互为眷属——出离刻不容缓。
2. 「命即身／命异身」「如来死后有无」等十四问皆属无记：答有答无都增长邪见。
3. 佛不答「有我／无我」，而说「是事有故是事有，是事起故是事生」的缘起中道，离常见、断见二边。
4. 名山屡易其名、四佛皆般涅槃——一切行无常，「唯寂灭为乐」。
5. 阿罗汉才是真正的「无余」：不再「因爱故取，因爱而住」，身坏命终「一切受永灭」，是为苦边。

## 四、易混辨析

- **有余 vs 无余**：火依薪柴而燃＝有余（有所依著，生死相续）；不添薪而永灭＝无余（依著永尽）。本卷以此简别凡夫受生与圣者灭度。
- **常见 vs 断见**：执「先有我」恒存是常见，执「从今断灭」是断见；如来「离于二边，处中说法」。
- **记说 vs 无记**：随问明确作答称「记说」；对戏论四句置而不答称「无记」。佛只记说「令正尽苦，究竟苦边」之道。
- **断「我慢、邪慢」 vs 断灭众生**：佛所教是灭除慢见，不是把众生断灭掉——这是富邻尼答外道的关键区分。

## 五、阅读提示

读前半可留意每个譬喻各击中哪种「觉得轮回不够久、不够苦」的死角；读婆蹉诸经时注意同一「无记」理由由佛、目连、迦旃延三种身份重复宣说——同义异宣，正是口诵结集体例的痕迹。
