# 杂阿含经卷第四十 导读

## 一、内容总览
本卷为《杂阿含经》卷第四十，属「八众诵」中的**帝释相应**（一一〇四～一一二〇），专集佛陀述说天帝释（释提桓因）往昔因缘的故事：他为何得生忉利天为王、种种名号的来历，以及以忍辱、不瞋、真实、精勤、恭敬三宝而胜阿修罗的诸般本事，末尾结归于比丘的修行。

## 二、结构层次
全卷按「总说得生之因 → 品德故事群 → 问法断疑 → 品格结成」四步推进，每经大体为「过去世时，释提桓因……」的本生故事 + 偈颂 + 结劝「汝等比丘……应当学」：
- **总起**：（一一〇四～一一〇六）先立帝释因前世行「七种受」得生天上 → 再逐一解说其八种名号（富兰陀罗、憍尸迦、舍脂钵低、千眼、因提利等）的来历。
- **品德故事群**：（一一〇七～一一一五）以「天对阿修罗」为主线层层展开 → 不瞋（瞋恚对治鬼）↔ 忍不受忏之失 → 善论议伏阿修罗 → 于劣者行忍为上忍 → 恭敬礼佛、法、僧 → 精勤备战得胜 → 除五饰恭敬仙人。每经末皆折回「比丘当如是学」。
- **问法断疑**：（一一一六）帝释问「杀何等得安隐眠」→ 佛答「害凶恶瞋恚」，点出全卷眼目。
- **布萨评判**：（一一一七）四天王三时下察人间持斋布萨 → 善则天众增、恶则阿修罗增 → 佛评帝释「八支斋」偈「非善说」，因帝释未离贪恚痴；阿罗汉说之方为善说。
- **结成**：（一一一八～一一二〇）拒受阿修罗幻法（真实不伪）→ 与婆稚阿修罗王偈答（利满足已，修忍无过上）→ 自受「不反报」之戒、要阿修罗立约誓（不娆乱）收束全卷。

## 三、关键结论
- 帝释的果位源于人间的德行：供养父母尊长、软语真实、勤施不悭，是生天之因。
- 瞋恚是「毒根」「苦种子」；不瞋、忍辱、不娆乱，是帝释常胜阿修罗的根本。
- 于劣者行忍是「上忍」，于胜者行忍只是「恐怖忍」——忍的价值在有力而不报。
- 帝释虽为天王仍东向礼佛、敬法敬僧、恭敬出家人；人间持斋布萨直接关涉天上兴衰。
- 帝释未脱生老病死，其言不如阿罗汉所说善——天龙福报不及圣者解脱。

## 四、易混辨析
- **天帝释 / 释提桓因 / 憍尸迦 / 舍脂钵低**：同一人。梵语 Śakra devānām indra 的不同译名与别名：憍尸迦指出身族姓，舍脂钵低指其为天后舍脂之夫，「千眼」「因提利」等各有来历（一一〇六经逐条说明）。
- **布萨 / 八支斋**：布萨是定期集会持戒（出家诵戒、在家受斋）；八支斋是居士于月八日、十四日、十五日等受持的八条斋法，二者于本卷连言。
- **恐怖忍 / 忍诤忍 / 上忍**：对强者忍是畏惧，对平等者忍是避诤，对己劣者忍才是真正有力的忍（一一一〇经）。
- **无为安隐乐（宿毗梨天子所求）与精勤**：天子两次怠缓、希求「无所作」之处，帝释答「汝得是处者，亦应将我去」——涅槃须由不放逸精勤净除烦恼而得。

## 五、阅读提示
带着一问读：一个天界之王，凭什么「于三十三天为自在王」又屡胜阿修罗？把每经末尾佛的结劝与故事对照看，即可见「天德即人德」的全卷旨趣。
