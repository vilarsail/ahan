# 杂阿含经卷第二 导读

## 一、内容总览

《杂阿含经》卷第二属全书最初的"五阴诵"，收经二十六篇（三三～五八），全部围绕**五受阴**（色、受、想、行、识）展开。本卷是卷一"观色无常"的纵深推进：从"五阴非我"的论证出发，剖析"取著如何生苦"的心理机制，辨析阴与受、识与住等核心概念，最后汇归"七处善、三种观义"的修行总纲与两场大型问答。

## 二、结构层次（骨架与逻辑推进）

- **立宗·非我论证**：（三三）（三四）以"若色是我，不应于色病苦生"反证无我 → 实有病苦、不得自主 → 无常 → 苦 → 非我，一条链反复演练；三四经对"余五比丘"说，遥应初转法轮。
- **教诫实例**：（三五）三正士（阿㝹律陀等）断欲得解脱 →（三六）"住自洲自依"，十六比丘闻法解脱。
- **世谛不诤**：（三七）（三八）"我不与世间诤" → 一器多名之喻 → 佛法随顺世间言说，而"世间世间法"（五阴无常、苦、变易）正是世间智者所共许。
- **识住缘起**：（三九）五种子喻——五种子譬取阴俱识，地界譬四识住，水界譬贪喜润泽 →（四〇）"封滞者不解脱"；离贪则攀缘断、识无住处、不复增长 → 涅槃。
- **义理总汇**：（四一）五受阴的"集、味、患、离"如实知 →（四二）七处善＋三种观义（阴、界、入），以八圣道为"灭道迹" →（四三）（四四）"取故生着""生则系着"的心理链条 →（四五）我见三形态（是我、异我、相在）与无明触、明触 →（四六）逐阴下定义（可阂、觉相、想、为作、别知）＋"为现在色所食"。
- **劝修与对外道**：（四七～五一）修厌离住、知生灭法、明梵行所为何事、坏法与不坏法 →（五二）郁低迦经存目 →（五三）（五四）对婆罗门说"有因有缘集世间"（十二因缘）、"异生异灭" →（五五）（五六）辨阴与受阴、有漏与无漏。
- **问答收束**：（五七）（五八）两场长问答：云何疾得漏尽（三十七道品；二十种我见层层展开）→ 五受阴欲为根、阴与受非即非异、阴阴相关 → 破"若无我，谁受报"之疑 → 归于正见。
- **结集体例**：每经"如是我闻……欢喜奉行"首尾呼应；卷中夹"摄颂"（"竹园．毗舍离　清净．正观察"等），以关键词串起前文诸经，是口诵结集的痕迹。

## 三、关键结论

1. 五受阴是无常、苦、变易之法，"彼一切非我、不异我、不相在"。
2. 于五受阴如实观察、都无所取 → 无所著 → 自觉涅槃："我生已尽，梵行已立，所作已作，自知不受后有"——解脱必自证自知。
3. 识不能离色受想行独存：识依四识住而攀缘增长，离贪则识无所住、不复增广。
4. 有因有缘集世间，有因有缘世间灭——苦的生起与止灭皆循十二因缘，佛所论者唯"因"。
5. 五阴有漏、是取，才名"受阴"；不生爱恚即无漏法——"受"（取）字点出苦的关键在执取。

## 四、易混辨析

- **阴 vs 受阴**：一切色总说为色阴（五五经）；唯有漏、是取的五阴才称"受阴"，受＝取；二者非即非异（五八经）。
- **色集 vs 色灭 vs 色灭道迹**：集＝爱喜（苦之因）；灭＝爱喜灭（苦之止）；灭道迹＝通向灭的八圣道（灭苦之路）。
- **我 / 异我 / 相在**：即五阴计我；离五阴另有我；我在阴中或阴在我中——三种妄执展开即为二十种我见。
- **心解脱 vs 慧解脱**：四二经并举，心解脱指离贪爱而心得自在，慧解脱指如实知见、断除无明的智慧解脱。

## 五、阅读提示

带着两个问题读：①"若色是我，不应于色病苦生"这一反证为何成立？（"我"的本义即自主主宰）②"取著 → 心随转 → 恐怖障碍心乱"的链条，能否在自己面对得失的经验里对号入座？
