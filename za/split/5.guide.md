# 杂阿含经卷第五 导读

## 一、内容总览
本卷为《杂阿含经·五阴诵》第五卷，收经八篇（一〇三～一一〇），通卷只做一件事：从各个角度确立“五受阴（五取蕴）非我、非我所”的正见。场景有僧团病中论义、舍利弗勘破恶见、佛答外道之问、长者求法、临行授法、论师降伏——对象不同，所观皆是五阴。

## 二、结构层次
八经一线贯穿，逐层外推：
- **（一〇三）差摩经**：病僧差摩与诸上座经陀娑比丘往反传语 → 立全卷核心命题：观五阴非我非我所 ≠ 漏尽阿罗汉，“我慢、我欲、我使未断、未知、未离、未吐” → 莲华香、浣衣薰香二譬 → 上座得法眼净，差摩法喜病愈。
- **（一〇四）焰摩迦经**：焰摩迦执“阿罗汉身坏命终更无所有”的断灭见 → 舍利弗以“色是如来耶？异色耶？色中耶？如来中耶？”四句穷诘 → 诈亲怨家譬 → 焰摩迦漏尽解脱。
- **（一〇五）仙尼经**：外道仙尼疑“六师不记弟子往生、佛独记说” → 佛说三种师：见今世我是断见、见今世后世我是常见、不见是我为如来 → 结归“慢断则命终更不相续” → 仙尼出家证果。
- **（一〇六）阿㝹罗度经**：外道四问“如来死后有无”，皆答“无记” → 佛印可，归于“色集、色灭、色灭道迹如实知”。
- **（一〇七）那拘罗长者经**：百二十岁老者求法 → “于苦患身，常当修学不苦患身” → 舍利弗以集、灭、味、患、离五门分判“身心苦患”↔“身苦心不苦” → 长者归依三宝。
- **（一〇八）西方比丘经**：比丘还西方安居，佛令向舍利弗奉辞 → 授“答客问”教纲：大师唯说于五阴调伏欲贪，兼陈断欲贪的过患与福利。
- **（一〇九）池譬经**：佛说池水之譬——见谛所断之苦如五十由旬大池，毛渧之水喻其残余 → 舍利弗广开身见二十种相（五阴×我／异我／相在，以六受、想、思、识身逐层算立）→ 结归四真谛、自觉涅槃。
- **（一一〇）萨遮经**：耆那教论师萨遮挟五百离车来论 → 佛以“国王于自土赏罚自在”诘“色是我” → 默然受破：金刚杵怖、芭蕉无实、现胸示毛 → 请供悔谢，佛说三种无上与随喜偈。

推进线索：僧团内辨“观与证”→ 破断见 → 答外道疑 → 济居家老病 → 立教纲 → 广析身见 → 摄伏论师，由内而外收束。卷末摄颂“差摩、焰、仙尼、阿㝹罗、长者、西、毛端、萨遮”即本卷八经名目。

## 三、关键结论
1. 观五受阴非我、非我所，尚非漏尽阿罗汉；须我慢、我欲、我使一切悉除，再于五阴增进思惟生灭，方名真实正观。
2. 阿罗汉死后“更无所有”是断见，死后计有亦是邪见——如来见法真实、住无所得，死后有无四问皆不记说。
3. 五受阴应观如病、如痈、如刺、如杀，无常、苦、空、非我；于五阴欲贪不断，彼阴变异则忧悲恼苦生。
4. 身苦而心不苦的分水岭：于色集、色灭、色味、色患、色离如实知，心不随转。
5. 见谛者所断之苦深广如池水，身见断已如折多罗树，永不复生。

## 四、易混辨析
- **观非我 vs 证阿罗汉**：一〇三经的分际只在我慢我欲我使“未断未离”与“一切悉除”——见道与漏尽之别。
- **断见 vs 常见 vs 如来中道**：执今世我是断见，执今世后世我是常见，今世后世俱不见我是如来之说。
- **记说 vs 无记**：弟子尚有余慢，佛记说其往生处；“如来死后有无”属无记不可答——同为“记”，一可说一不可说。
- **心解脱 vs 慧解脱**：心解脱约离贪说，慧解脱约以慧断惑说；漏尽者成就智、解脱、解脱知见三种无上。

## 五、阅读提示
带着两个问题读：观察无我与漏尽阿罗汉的差别何在（差摩是“我慢未尽”的活样本）？“如来死后有无”为何不作回答（一〇四破断灭、一〇六明无记）？
