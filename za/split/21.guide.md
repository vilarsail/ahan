# 杂阿含经卷第二十一 导读

## 一、内容总览

本卷属《杂阿含经》"弟子所说"（弟子记说）部分，由两组论议经组成：前七经（五五九～五六五）为**阿难相应**，记尊者阿难答迦摩比丘、婆罗门、离车外道弟子、比丘尼与婆头聚落童子之问；后十经（五六六～五七五）为**质多罗相应**，以在家居士质多罗长者为轴心，与诸比丘及尼犍、阿耆毗外道反复辨析法义。主旨：无想三昧是智果、依欲断爱、调伏三毒方为善到、四三昧同归无诤、身见为诸见本、欲贪为系缚本，终以长者临终往生，示现在家圣者的果证。

## 二、结构层次

全卷如两串"问—答—印证"的论议珠链：

**前半·阿难相应（五五九～五六五）**：一问一答、逐经换题的论议体 →
- 五五九 迦摩问"有想／无想而不觉知" → 阿难以四禅、三无色定与无想心三昧作答 → 归结为"智果、智功德"
- 五六〇 阿难自立"四道"（住心、善住心、局住心、调伏心，止观一心等受而断诸使）→ 作为印证比丘尼自记说的标准
- 五六一 婆罗门连环追问"何故修梵行" → 断爱 → "依欲断爱" → 以欲定断行等四如意足，释"有边际"之疑
- 五六二 瞿师罗问"说法者／善向／善到" → 能调伏贪瞋痴为说法者，断尽无余为善到
- 五六三 离车二弟子持外道"苦行灭炽然"来问 → 阿难举净戒、四禅、谛智三种离炽然清净超出道
- 五六四 比丘尼染着因缘 → 依秽食断食、依慢断慢、依爱断爱 → 得法眼净、发露悔过
- 五六五 对婆头童子说四种清净 → 戒、心、见、解脱层层增上

**后半·质多罗相应（五六六～五七五）**：以长者一人为线索贯穿 →
- 会通义理：释偈（五六六）→ 四种三昧种种名义、同归"无诤"（五六七）
- 辨析法相：三行与灭尽定出入次第（五六八）→ 种种界即十八界（五六九）→ 身见为世间诸见之本（五七〇）
- 显扬德化：摩诃迦神通"以不放逸为本"（五七一）→ 轭鞅喻"欲贪是其系"（五七二）
- 摄化外道：度阿耆毗迦出家证果（五七三）→ 折服尼犍若提子（五七四）
- 结示果证：临终却转轮王之愿、说偈命终生不烦热天，天子还林礼僧（五七五）

## 三、关键结论

- 无想心三昧"不涌不没，解脱已住"，世尊说是智果、智功德。
- 断爱"依于欲而断爱"：以四如意足为道，爱断则欲自息，故是有边际而非无边际。
- 能调伏贪瞋痴是"世间说法者"，已断无余方名"善到"。
- 世间"有我、众生、寿命"诸见皆以身见为本；非眼系色、非色系眼，中间欲贪是其系。
- 神通与无上菩提，一切功德皆以不放逸为本。

## 四、易混辨析

- **无想心三昧 vs 无相心三昧**：前者"一切想不忆念"，后者"于一切相不念"，名近义别。
- **死 vs 入灭尽定**：死则寿、暖、识俱舍，诸根悉坏；灭尽定则三行灭而不舍寿、不离暖，身命相属。
- **身行／口行／意行**：出息入息＝身行，有觉有观＝口行，想思＝意行；入灭定先灭口行，出定时意行先起。
- **尼犍 vs 阿耆毗**：两派皆主苦行灭业的外道；尼犍若提子立"信在前、智在后"，佛弟子则"不以信故"，以亲证的智慧为先。
- **种种名 vs 一义**：无量、无相、无所有、空四种三昧，可作种种分别，亦可同归于"无诤"一义。

## 五、阅读提示

带着两个问题读：阿难如何随不同对象（外道、婆罗门、比丘尼、童子）而说法有浅深？在家居士质多罗凭什么折服出家二十年的外道？——本卷几乎全为论议体，每经以"欢喜随喜"收束，可见"记说"辨义在弟子闻法中的分量。
