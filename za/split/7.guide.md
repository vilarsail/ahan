# 杂阿含经卷第七 导读

## 一、内容总览
《杂阿含经》卷第七收经一三九至一八七，属“五阴诵”（阴相应）的末段，卷八起即转入六入处诵。全卷仍围绕五阴（色、受、想、行、识）展开，方向有二：前半顺着“于五阴起我见”这一病根，把外道的种种异见逐一罗列；后半转到修行面，以“火烧头衣”的警喻策励比丘，为断五阴无常而勤修道品。可以说，本卷是“破我见”与“修道品”两大主题的交接处。

## 二、结构层次
- **一问立宗**（一三九～一四一）：佛问“何所有故，何所起？何所系着，何所见我？”→ 答：色受想行识“有、起、系着、于中见我”→ 忧悲恼苦生起增广 → 由“非常→是苦”推出“非我、非异我、不相在”的正慧 → 于六见处观察非我、非我所 → 于佛、法、僧（次经换作苦集灭道）狐疑断 → 极七有天人往还、作苦边。
- **同式广演**（一四二～一五一）：同一问式反复重演，只换“差别者”——我慢系着使、有漏障碍烧然、三受、三苦、世八法、我胜我等我卑——显示一切烦恼过患皆自“见我”流出。
- **邪见长廊**（一五二～一七一）：逐经陈列外道异说——常见（有我、此世他世常恒）、断灭论（死后断坏无所有）、无因论、七身常存论、无善恶业报论、宿命定量论（缕丸之喻）、大梵造物论、种种我论、十四无记（世间常无常、命与身一异、如来死后四句）、现法涅槃论（执五欲或四禅为涅槃）；每经仍以同一问式起首，暗示万见归于一我见。
- **转向修行**（一七二～一八六）：“无常法当断”→ 为断故当求大师（并排比出“种种教、随顺说、真知识……”等一一八经）→ “火烧头衣”警喻 → 依次展开四念处、四正断、四如意足、五根、五力、七觉分、八圣道、四谛道、无贪等法句、止观——道品层层铺开，宗旨只一句“为断五阴无常”。
- **结归一法**（一八七）：贪欲乃至恼苦，一法映翳于心，则不堪知五阴无常、不堪证灭尽；无此一法则堪任——以此收束全卷。

## 三、关键结论
- 忧悲恼苦的总根源是于五取阴起我见；“非我、非异我、不相在”三句一齐遮破。
- 无常即是苦；圣弟子于六见处观察非我、非我所，则于三宝、四谛的狐疑永断，极七返生必尽苦边。
- 五阴无常如火燃头衣，救灭不容迟疑；为断无常故修三十七道品乃至止观，不出“断、知、尽、吐、止、舍、灭、没”诸义的重演。
- 贪欲（恼苦）一法蔽心，则不堪知无常、不堪证灭尽；离之则堪任。

## 四、易混辨析
- **非我 / 非异我 / 不相在**：非我破“五阴就是我”，非异我破“五阴外另有我”，不相在破“我在阴中、阴在我中”——三种我执一次说尽。
- **三受 / 三苦**：三受是“受”的分类（苦受、乐受、不苦不乐受）；三苦是“苦”的分类（苦苦、坏苦、行苦），角度不同。
- **五根 / 五力**：信、精进、念、定、慧同体两名义——说“根”取其能生善法，说“力”取其不可摧伏。
- **止 / 观**：止是摄心专一（奢摩他），观是以慧拣择（毗婆舍那）；本卷二者同为“断五阴无常”而修。

## 五、阅读提示
带着一问读全卷：“何所有故，何所起？”先看根源在首经如何立定，再看中段诸邪见如何皆由我见流出（名目不必逐条细究），最后看“断无常”如何落实为求大师、修念处乃至止观的一连串功夫。
