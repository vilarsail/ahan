# 杂阿含经卷第三十九 导读

## 一、内容总览
本卷属《杂阿含经·魔相应》（卷三十九，经一○八一～一一○三），是整部《杂阿含》集中讲「魔波旬」的一卷。魔（Māra）是欲界之主、贪爱与死亡的象征，此卷收集了佛陀成道前后及晚年，魔王波旬以化作少年、壮士、大龙、大牛、魔女等各种形相来「娆乱」「留难」佛陀与弟子的二十余则短经。全卷主旨：凡有爱欲即落魔境，离欲解脱者魔不能动；同时借魔的失败，从反面衬托佛与圣弟子的境界。

## 二、结构层次
全卷大致可分三段：
- **弟子对治恶觉（一○八一～一○八三）**：前二经以「苦种—生臭—汁流—蛆蝇」一连譬喻展开：树生恶种则发臭流汁、蛆蝇竞集 → 比丘起不善觉、依恶贪亦然 → 治法是内心寂静、修八正道；一○八二经借天神以「疮疣—铁镬—正念正智能复」问答再演同一主题。一○八三经以「龙象拔藕根洗净而食，小象效之合泥而食」对比宿德比丘与年少比丘乞食护根与否 → 得利养而不染则安乐，染著则「转向于死」。
- **魔娆乱佛陀（一○八四～一一○二主体）**：一连串结构几乎相同的短经：佛说某法／独处禅思 → 魔念「我当往作娆乱」→ 化形说偈挑衅 → 佛以偈破斥 → 「惭愧忧戚，即没不现」。内容包括：寿命短促当勤精进（一○八四）、一切行无常（一○八五）、佛离五欲第六意（一○八六）、佛之安眠（一○八七、一○九○）、雷雨巨石大龙不能动佛一毛（一○八八、一○八九）、魔以琵琶试探瞿低迦自杀事（一○九一）、魔三女爱欲、爱念、爱乐百般变现诱惑而不遂（一○九二）、化净不净色（一○九三）、劝修苦行（一○九四）、令空钵（一○九五）、缚以「人天绳索」（一○九六）、讥勤说法（一○九七）、诱作转轮王（一○九八）、化作婆罗门讥出家（一○九九）、怖善觉（一一○○）、疑师子吼（一一○一）、化牛入钵群（一一○二）、化壮士（一一○三）。
- **两处特例**：一○九一经瞿低迦六度退失「意解脱」而以刀自杀，魔遍求其识神不得，佛受第一记——是全卷唯一涉及弟子的重头戏；一○九七经魔讥佛勤说法，佛答以哀愍众生故不能不教化。

## 三、关键结论
- 起不善觉、依恶贪，如种苦种而发臭流汁、招集蛆蝇；对治之道是守护六根、正念正智、内心寂静。
- 五欲与第六意（意根对法尘之贪）是最恶之贪，能系缚凡夫；超越它即度魔境界。
- 一切行无常不安、非可苏息，唯当厌离解脱，勤修梵行如救头然。
- 已离爱欲者，魔王不能系缚、娆乱、倾动分毫；魔眷属的诱惑如飞鸟啄凝膏之石，徒劳而返。
- 佛说法出于哀愍众生，非为自了。

## 四、易混辨析
- **苦种 / 生臭 / 汁流 / 蛆蝇**：同喻四环节——忿怒烦怨是苦种（种子），五欲功德是生臭（恶臭），不摄律仪是汁流（恶汁外渗），贪忧恶不善心竞起是蛆蝇（聚虫）。
- **娆乱 / 留难**：皆魔之干扰，娆乱重在扰乱心神，留难重在障碍阻挠，义近而换用。
- **现世乐 / 他世非时之乐**：魔所化的婆罗门倒说，比丘依佛说纠正——离炽然、现前可证的现法安乐才是真乐，魔语是「舍现世乐求非时乐」。
- **意解脱身作证与退转**：瞿低迦时得时退，至以刀自杀后佛记其已般涅槃，与一般阿罗汉不退不同，特指其「不住心」自杀时已断爱欲。

## 五、阅读提示
读时留意每经「魔化形—说偈—佛答偈—没不现」的固定套式，比较各经中魔从哪个角度进攻（寿命、苦行、名利、女色、王位、说法动机），佛又以哪个法义回应，即可见魔与贪爱的对应关系。
