# 杂阿含经卷第四十七 导读

## 一、内容总览
《杂阿含经》卷四十七，收经二十六篇（一二四一～一二六六），是修道实务的短篇荟萃：居士给孤独长者的「生天」法语、僧团威仪次第、惭愧二法、临终业相，以及炼金、牧牛、慈心等一系列譬喻，末尾以两桩病重比丘「以刀自杀」的事件作结。全卷从居家信仰到出家行持、从修心次第到临终检验，正好串成一条「生前修什么 → 临终得什么」的线索。

## 二、结构层次
- **居士行（一二四一）**：给孤独长者说「在我舍者皆生天」作师子吼 → 佛步步追问其依据（大德比丘？比丘尼？诸天？自见知？）→ 长者自述教家人、婢仆、买者受三归五戒、称名咒愿的因缘 → 佛印可「汝以信心故能作是说」。
- **僧团行持（一二四二～一二四五）**：恭敬住 → 威仪 → 学法 → 戒定慧乃至解脱知见五身 → 无余涅槃的递进链条；惭愧二净法护世间；烧燃法与不烧燃法对比临终二种心相；舍身口意恶行得安乐。
- **炼金牧牛二喻群（一二四六～一二四九）**：铸金淘洗喻修心除垢的先后次第 → 金师鼓韛火候喻止、举、舍三相须随时调适 → 恒水渡牛喻四果声闻次第横截生死流 → 牧牛十一法喻比丘不知则不能自安安他。以世俗技艺类比修行，层层推进。
- **生活教诫（一二五〇～一二六四）**：不受利养、不贪睡眠（那提迦两经）→ 离车子枕木枕自警的不放逸（一二五二）→ 慈心四连经（一二五三～一二五六：惠施不如须臾慈心、防盗贼劫夺、匕手剑反伤、爪上土与大地土）→ 四士夫接箭喻命行迅速 → 阿能诃鼓喻后世比丘不修四修、深法渐灭 → 铁丸、猫狸、木杵、莲花、野狐、知恩诸喻护根门、知食量、断诸有。
- **临终二事件（一二六五～一二六六）**：跋迦梨、阐陀病笃自杀，佛与舍利弗皆以五蕴非我、见灭知灭相问答，佛为二人「说第一记」，全卷在此收束。

## 三、关键结论
- 惭愧二法是护世间的根本净法，无此二者则尊卑人伦颠倒浑乱，同于畜生趣。
- 修心如炼金：粗烦恼、欲恚害觉、亲里人众生天觉、乃至似金微垢层层淘净，三昧方能轻软光泽、于诸入处随意作证。
- 止、举、舍三相不可一向偏修：一向止则心下劣，一向举则掉乱，一向舍则不得正定；须随时对症调节。
- 慈心功德远胜布施：日施三百釜食不如一搆牛乳顷修慈，须臾慈心即令恶鬼神伺求不得其便。
- 断三结、贪瞋痴薄、断五下分结，对应须陀洹、斯陀含、阿那含，如牛群先大后小次第安隐得度。

## 四、易混辨析
- **烧燃法 vs 不烧燃法**：同为临终病苦沉顿床褥，前者忆念先恶、心生追悔堕恶趣，后者攀缘善法、善心命终生善趣——差别全在生前所修。
- **止相 vs 举相 vs 舍相**：止是压伏掉举（心太浮时），举是策举昏沉（心太沉时），舍是平等安住；三者对症是药，过量是病。
- **须陀洹 vs 斯陀含 vs 阿那含**：断三结是初果（七有天人往生），加贪瞋痴薄是二果（一来此世），再断五下分结是三果（于彼受生、不还此世）。
- **圣者自杀 vs 凡夫自杀**：同是执刀自杀，已见五蕴非我、见灭知灭者「余身不相续」，佛记无过；若尚有贪欲、余身相续，则有大过。

## 五、阅读提示
带着「临终一念是如何被生前业行决定的」这个问题，先读烧燃经（一二四四）与两桩自杀事件（一二六五、一二六六），再回头对照炼金喻与五分法身的次第，全卷脉络即可贯通。
