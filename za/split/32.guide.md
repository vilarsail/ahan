# 杂阿含经卷第三十二 导读

## 一、内容总览
本卷为《杂阿含经》卷三十二，收第905～918经共十四经，主体是"聚落主相应"——佛陀与各种在家聚落主（村长、豪族、职业人）的问答，另兼两类：舍利弗与摩诃迦叶论"如来死后有无"（905）、迦叶问制戒因缘与正法久住（906），卷末以三种良马喻三种修行人（917、918）。全卷多以外道的世俗邪见（伎儿生天、战士生天、杀生尽堕地狱）与民间职业（驯马师）为话头，佛随其行业设喻破执，宣说离欲、持戒、中道之行。

## 二、结构层次（★重点）
- **905 一问一释，立"无记"之例**：外道问舍利弗"如来有后生死耶"→ 四种问法皆答"此是无记" → 舍利弗转问迦叶 → 迦叶释因：说"有后"即落在色受想行识中，而如来五蕴已尽、爱已尽、寂灭涅槃，故不可于五蕴上说有无 → 二正士共论而散。
- **906 因果问答，释正法兴衰**：迦叶问"昔制戒少而乐学者多，今制戒多而乐学者少"→ 佛以五浊、相似像法（伪宝出则真宝没）解释 → 收束为对称两组：五因缘令正法沉没 ↔ 五因缘令法、律不没不退。
- **907～913 对聚落主的连续开示**，多为"俗问 → 佛设喻 → 破邪见 → 归依三宝"的统一套路：伎儿生欢喜天（破）、战斗生箭降伏天（破）、调马三法（柔软／刚强／柔软刚强）、瞋恚源于不修八正道、沙门释子不应受畜金银、二边（纵欲↔苦行）与中道八圣道、一切忧苦以欲为本。
- **914～916 刀师氏聚落主三诣佛所**：受师尼揵教唆，先以"蒺䔧论"两头设刺（施食有损？为一种人说法？）→ 佛以施者无损、三种田／三水器喻显"为谁先说法" → 再以爪甲土喻显慈心对治、悔责离恶 → 聚落主屡惊怖悔过、归依。
- **917～918 收卷于马喻品目**：三种良马 ↔ 三种善男子，以捷疾具足（证悟速）、色具足（能解答阿毗昙与律）、形体具足（名闻感供）三事分判，果位由须陀洹进至阿那含。

## 三、关键结论
1. 如来已尽五蕴与爱欲，不可说死后有、无、亦有亦无、非有非无——"无记"是对戏论的遮止。
2. 五浊之世相似法兴而正法灭；于大师恭敬下意、随顺教法，是法住不没之因。
3. 歌舞戏笑增长贪瞋痴缚、战斗先起害心，皆邪见之业，不得生天。
4. 比丘不得自为受畜金银宝物，所需但"须木索木、须草索草"。
5. 离纵欲与苦行二边、行八圣道；众生一切忧苦皆以欲（爱）为本，无爱念则无忧苦尘劳。

## 四、易混辨析
- **捷疾具足 vs 色具足 vs 形体具足**：分别指速疾证圣（修证）、能次第解答阿毗昙与律的问难（学问辩才）、有大德名闻而感得四事供养（名声利养）——是三条不同线，可具足其一而缺其余。
- **意解脱 vs 慧解脱**：前者即心解脱，约定心离贪；后者约智慧断惑。本卷谓二者皆不满足则堕谤圣邪见，须俱足方离。
- **相似像法 vs 正法**：像法是形似佛法的伪法，如伪宝乱真宝，其炽然于世即正法消没之相。
- **须陀洹 vs 阿那含**：前者三结断、于人天最多七度往返；后者更断五下分结，生般涅槃、不复还生此世。

## 五、阅读提示
带着"佛陀如何回应职业与业报的世俗疑问"这一问题读905～916，注意其设喻套路；再看917～918如何用相马的"快、才、名"三尺，重新衡量修行人的价值次第。
