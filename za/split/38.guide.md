# 杂阿含经卷第三十八 导读

## 一、内容总览
本卷为《杂阿含经》卷第三十八，收经一〇六二至一〇八〇，共十九经（其中一〇六六仅一句「如手比丘，难陀修多罗亦如是说」，是省略重出的结集体例）。全卷是一部「弟子故事」专辑：多以一位比丘或一桩事件为引子，佛就地断疑、说偈收束，多与南传《相应部》诸经对应。主题围绕修道人的内外两面：外相与道行、利养与堕落、独处与独住、谤法与澄浊、恶人与成道。

## 二、结构层次
全卷为短经连排、一事一经，可分三段看：
- **前段（一〇六二—一〇七三）**：十余则小品，结构高度整齐：「某比丘如何如何 → 众比丘禀佛 → 佛断其事 → 即说偈收束」。递进线索：勿以外相量人（新出家即证果的善生、形貌丑陋的比丘）→ 勿贪利养（提婆达多得阿阇世王供养）→ 贪瞋痴结缚堕恶趣（手比丘）→ 调伏威仪与憍慢（好衣嬉笑的难陀、自恃亲戚的低沙）→ 说法与独住（毗舍佉说法受赞、上坐比丘问独住）→ 于情爱、于香尘不动（僧迦蓝面对前妻亲子、阿难答戒香喻）。
- **中段（一〇七四—一〇七七）**：转为长篇叙事。摩竭提王瓶沙率众礼佛，郁鞞罗迦叶自陈舍「事火」外道之由 → 陀骠摩罗子遭慈地比丘与比丘尼蜜多罗诬谤，僧团以「忆念」「自言灭」的程序处断 → 同一人复于佛前升空自焚、取无余涅槃 → 央瞿利摩罗由杀人恶贼被佛度化出家证阿罗汉。谤法与取灭两经前后相连，是全卷的叙事中心。
- **末段（一〇七八—一〇八〇）**：河畔天子两番问难（舍现前乐求非时之利、「丘冢夜起烟」一连串谜语喻）→ 末以一比丘乞食时见佛自摄诸根作结，回到最日常的威仪修持。

## 三、关键结论
1. 唯有如来能量人：形貌丑陋、年少、有亲属关系，都不是道行的准据，勿妄量于人。
2. 利养如芭蕉生果、駏驉受胎，得之则今世后世俱坏，故「设有利养起，莫生染着」。
3. 真正的「胜妙一住」是于过去（前）枯干、未来（后）灭尽、现在（中）无贪喜，不在身体的独处。
4. 戒德之香顺风逆风皆熏、上闻于天，胜过栴檀、莲华等一切世香。
5. 宁食热铁丸，不以犯戒而食僧信施——因饮食而知而妄语，是堕落的起点。
6. 恶业深重如央瞿利摩罗，闻法亦能当生证阿罗汉，「宿责食已食」，业报偿尽即是清净。

## 四、易混辨析
- **忆念 vs 自言灭**：皆为僧团处断罪事的程序。「忆念」依当事人自言「不忆念」（不记得有犯）且其人素行清净，即宣告无罪；「自言灭」则令作妄语者自己如实陈白认罪，以自白灭除其罪。
- **心解脱 vs 慧解脱**：前者以定力离贪爱，后者以智慧断无明，阿罗汉二者俱足。
- **现前乐 vs 非时乐**：天子谓出家是舍现前乐而求非时（遥远未来）之利；比丘翻转其说——五欲才是少味多苦的「非时之乐」，离欲现证才是现前之乐。
- **独一住 vs 胜妙一住**：独行独坐只是形式上的「一住」；三世不起贪喜、群聚使断，才是佛所许的胜妙一住。

## 五、阅读提示
读时留意两点：一是每经末偈如何把长行的寓意重新收束一遍，偈往往即该经义理的浓缩；二是陀骠摩罗子两经（一〇七五、一〇七六）前后相承，借之可以具体看到僧团断诤程序与阿罗汉「空中涅槃」的示现。
