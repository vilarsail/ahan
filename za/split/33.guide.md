# 杂阿含经卷第三十三 导读

## 一、内容总览
本卷为《杂阿含经》卷第三十三，收经九一九至九三九，共二十一经。前半（九一九~九二六）集中在王舍城迦兰陀竹园，以种种「马喻」说比丘之道：良马喻好比丘、恶马喻恶丈夫、调马师对话喻如来调伏众生，末以「真实禅」不依一切所缘收束。中段（九二七~九三六）移至迦毗罗卫尼拘律园，是全经著名的「优婆塞（在家居士）教法」群，以释种摩诃男为当机者，系统给出信、戒、施、闻、慧五具足、六随念、四双八辈、七种圣弟子等框架。后半（九三七~九三九）以恒河、四大海喻无始生死长夜所流身血、泪水、所饮母乳之无量，归结到五阴无常、苦、非我而解脱。

## 二、结构层次
全卷三段，各自成群而义脉相承——以「调身（如马）」起，以「调心（念与解脱）」终：
- **马喻立宗**（九一九~九二五）：三种良马（捷疾、色、形体三具足）→ 四德良马（无学戒定慧解脱身）→ 鞭影四马喻闻他聚落死讯、亲见、近亲病故、自身老病死四等修行人 → 调马师只尸问佛，柔软、粗涩、柔软粗涩三教授，且以「不复与语、不教、不诫」为佛法中之「杀」→ 恶马八态喻丈夫八过 ↔ 良马八德喻丈夫八德，对比展开。
- **禅法点睛**（九二六）：强良马只念谷草 ↔ 真生马念驾乘；强良禅贪着所缘 ↔ 真实禅「不依地水火风、空、识乃至觉观而修禅」，诸天莫知其所依。
- **在家法轨**（九二七~九三六）：摩诃男系列问答层层递进——优婆塞定义 → 信戒施闻慧五具足 → 须陀洹、斯陀含、阿那含在家所证 → 自安安他八法、十六法 → 狂象之怖与念佛念法念僧 → 学地比丘修六随念疾得涅槃 → 正受与解脱之先后（阿难代答学人、无学之别）→ 须陀洹四法与三法之争（佛判四法为正）→ 百手释氏犯戒而佛记说得初果，借问引出俱解脱、慧解脱、身证、见到、信解脱、随法行、随信行七种圣弟子。
- **长夜收束**（九三七~九三九）：恒河水 vs 长夜流血 → 流泪 → 饮母乳，三喻同构；每经皆由喻入法，归结「色无常→苦→变易法→非我、不异我、不相在→厌离→解脱」。

## 三、关键结论
- 比丘之「捷疾具足」在四圣谛如实知见、诸漏心解脱，名闻供养（形体具足）只是末事。
- 真实禅不依地水火风乃至觉观而修，伏尽一切想，诸天主皆不能知其所依。
- 如来调伏众生用柔软、粗涩、俱用三教授；终不杀生——「不与语、不教、不诫」即法中之「死」。
- 在家弟子具足信、戒、施、闻、慧，修念佛、法、僧、戒、施、天六随念，命终神识上升，不堕恶趣。
- 无始生死长夜，流血泪、饮母乳多于恒河四大海；五阴无常是苦、是变易法，应厌离而得解脱。

## 四、易混辨析
- **色具足 vs 形体具足**：此卷「色」非指相貌端正，指能对阿毗昙、毗尼「决定解说」的义辩之才；「形体」指名闻大德、能感汤药众具的供养，二者皆非修道根本。
- **俱解脱 vs 慧解脱**：俱解脱兼得八解脱「身作证」并以慧断漏；慧解脱未得八解脱具足住，唯以慧断漏。
- **学人 vs 无学**：学人尚在戒、定、慧、解脱之学地（如阿那含）；无学即阿罗汉，四事成就更无须学。
- **真实禅 vs 强良禅**：强良禅如恶马系槽只念谷草——带着贪欲、瞋恚等缠求禅定；真实禅不依一切处所乃至觉观，是伏想无所依而禅。
- **须陀洹三法 vs 四法**：只说不坏净三法不完整；佛判「于佛、法、僧不坏净＋圣戒成就」四法方成须陀洹。

## 五、阅读提示
读前半可逐经追问「这匹马对应修道的哪一步」；读摩诃男诸经可拿「信戒施闻慧＋六念」当一份在家修行清单；末三经体会佛陀如何用最朴素的血、泪、乳之喻，把「无始生死」讲得可感可畏。
