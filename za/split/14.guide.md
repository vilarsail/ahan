# 杂阿含经卷第十四 导读

## 一、内容总览
本卷属《杂阿含经》"杂因诵"的因缘（缘起）相应，收经二十二部（三四三～三六四），全卷一线贯穿十二缘起：从"苦乐从缘起生"破斥外道，到对老死乃至行每一支"如实知"其集与灭，再到"先知法住，后知涅槃"的修行次第，是整部《杂阿含》中缘起义理最集中的一卷。

## 二、结构层次
本卷前四经为长篇叙事经，后十七经为格言式短经群，共用同一缘起主干：
- **（三四三）破外道**：外道问浮弥比丘"苦乐自作／他作／自他作／无因作"→ 佛皆答"无记"→ 正说"苦乐从缘起生" → 舍利弗印可"彼诸说法亦从缘起、缘触生" → 阿难转白，佛述往昔答外道旧事印证。
- **（三四四）正面展开**：舍利弗与摩诃拘絺罗问答"见具足"→ 由不善法／善法 → 食 → 病 → 苦 → 老死乃至行，一支支"如实知其法、集、灭、道迹"层层递推，拘絺罗追问不止，舍利弗以"断除无明而生明，何须更求"收束。
- **（三四五）～（三四七）三则故事**：《波罗延那》偈问"何为学、何为法数"，舍利弗三问默然、发喜问后开解，佛赞其"善入法界" → 老病死三法世间不爱，十组"三法"断一离一的逆推连锁 → 须深"盗密出家"，见诸比丘不得禅定而自记解脱，佛开示"先知法住，后知涅槃"，并以劖三百矛之譬说盗法之报。
- **（三四八～三六四）短经群反复演练**：如来十力转梵轮说"此有故彼有"（三四八）→ 圣处难得（三四九）→ 不待推问直知缘起（三五〇）→ "异信"不如自觉知，井水之喻（三五一）→ 六入处为如实知之门户（三五二～三五四）→ 觉知老死（三五五）→ 四十四种智、七十七种智的数目化（三五六～三五七）→ 增法／减法（三五八）→ 思量妄想与攀缘识住（三五九～三六一）→ 以"多闻比丘""说法比丘""法次法向"三个定义收卷。

## 三、关键结论
1. 苦乐"自作、他作、自他作、无因作"四说皆斥为无记；正说唯是"从缘起生"。
2. "此有故彼有，此起故彼起"是全卷总纲；增法（集）与减法（灭）是一体两面。
3. 先知法住（缘起因果的差别安立），后知涅槃（寂灭）；不必先得四禅八定，但以智慧断惑即是"慧解脱"。
4. 对老死乃至行每一支，都应如实知其"法、集、灭、道迹"四行相，道迹即是八圣道。
5. 无明灭则行灭，乃至纯大苦聚灭；"断除无明而生明"是修行的究竟处。

## 四、易混辨析
- **无记 vs 记说**：无记是对错误提法不予肯定或否定的回答；记说是分别决择、明白判说。一拒一立，正好相反。
- **慧解脱 vs 禅定解脱**：须深所问初禅至四禅、身作证具足住是定成就；诸比丘未得而定而记说解脱，名慧解脱——不以禅定为必要条件。
- **法住智 vs 涅槃**：法住智是了知缘起因果的如实安立，涅槃是"有灭寂灭"；次第是先法住、后涅槃，不可颠倒。
- **增法 vs 减法**：缘无明行乃至纯大苦聚集是增法；无明灭则行灭乃至纯大苦聚灭是减法。

## 五、阅读提示
带着两个问题读：佛陀为何拒答"苦乐自作／他作"？不修禅定凭什么说"生死已尽"？两个答案都落在"缘起"二字上。
