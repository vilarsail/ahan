# 杂阿含经卷第十九 导读

## 一、内容总览
本卷收《杂阿含经》第504～536经，主角是「神通第一」的大目犍连。504～507经记帝释说施偈、目犍连上忉利天看天宫，以及佛升忉利天为母说法、安居三月后应四众之请、约期还阎浮提的著名传说；508～534经是一整组「目犍连于路中见大身众生受宿业之报」的故事；末二经转入阿那律与目犍连论四念处。全卷以神通见闻为线，串起「果报可畏」与「修道解脱」两大主题。

## 二、结构层次
- **帝释说施（504–505）**：帝释夜访目犍连，说「伏悭垢、随时施」之偈 → 自述因此福报得毗阇延堂，遍小千世界无与伦比 →（505）目犍连入天宫，追问昔日界隔山「爱尽解脱」之问，帝释避而不答、只顾夸耀新成堂观 → 目犍连见其极自放逸，以一足指撇堂令其震动，令帝释与诸天女心生厌离。
- **请佛下天（506–507）**：佛在忉利天骢色石上夏安居，为母及诸天说法 → 人间四众请目犍连上天问讯、劝请还阎浮提 → 诸天众各自记说得佛、法、僧不坏净与圣戒成就，证须陀洹 → 佛约定「却后七日」下生僧迦舍城优昙钵树下。
- **见报系列（508–534）**：固定套路反复演练——与勒叉那晨朝入城乞食 → 途中见大身众生受异苦（无皮、毛如针、铁轮在胁、铜镬灌身……）→「所问非时」→ 还至佛前问答 → 佛证实并说其宿业（屠牛屠羊、猎师、调象、卜占惑人、锻铜伪器、邪淫、盗僧物、恶口逐僧、斗乱众僧……）→「欢喜奉行」。二十余经并列，一业一身，罪报一一对应。
- **四念处论议（535–536）**：阿那律独静思惟，立「四念处是一乘道」之论 → 目犍连以神通知其心念，屈伸臂顷现身印证 → 一问一答：云何乐四念处（正念住调伏止息）→ 云何修习多修习（于内外身受心法作厌离想、不厌离想、俱舍想）。

## 三、关键结论
1. 能伏悭垢、应时布施，来世得殊胜果报——帝释的天宫即其福报。
2. 天福妙乐亦是放逸之源，圣者以神变令贪着者生厌离。
3. 于佛、法、僧得不坏净、圣戒成就者，身坏命终生天，并证须陀洹。
4. 种种怪异巨苦之身皆宿业所感：先堕地狱受正报，「地狱余罪」复感空中恶身续受余报。
5. 四念处是一乘道：信乐修习则得甘露（涅槃），远离则不得脱生老病死。

## 四、易混辨析
- 释提桓因＝帝释＝天帝释＝憍尸迦：同一人，忉利天天主；憍尸迦为其姓。
- 目揵连／目犍连：同一人，音译用字不定，卷中两形互见。
- 三不坏净与圣戒成就：佛、法、僧三不坏净属信，圣戒成就属戒，合为入预流位（须陀洹）的四条件。
- 地狱正报与余罪：堕地狱受无量苦是正报；「地狱余罪，今得此身」指正报后残余罪业所感的空中恶身余报。

## 五、阅读提示
读508–534不必逐条记罪目，抓住「见身→问缘→佛说宿业→受持」的复沓结构，体会罪业与身形的对应之巧（断人头者身无头、卜占惑人者身如旋风）；末二经由「见苦知因」转向「修道出苦」，宜对照四念处章句细读。
