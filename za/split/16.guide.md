# 杂阿含经卷第十六 导读

## 一、内容总览

本卷属《杂阿含经》"杂因诵第三品之四"，收经四〇七至四五四共四十八经，一条主线：**四圣谛**。前半（四〇七～四三四）以比丘食堂闲谈为引，令其舍戏论、思四谛，再以一连串譬喻渲染"不知四谛"之可怖与"知四谛者"之少；中段（四三五～四四三）借须达长者之问确立四谛"渐次现观"的次第；后半（四四四～四五四）转入"种种界"，说众生与界俱起、十八界及缘界生触的相续。

## 二、结构层次

全卷三大板块推进，经末多以"未无间等者，当勤方便……学无间等"复沓收束：

- **食堂纠偏（四〇七～四一五）**：九经同一起点"比丘集于食堂"，闲谈逐经更换——世间思惟 → 常无常等十四戏论 → 贪、瞋、害觉 → 亲里、国土、不死觉 → 王贼俗事、诤讼、两王比力、宿命作业、嫌檀越粗食——佛一一叫停，同归"当论四圣谛"。先破后立。
- **正受四谛（四一六～四二〇）**：受持四谛的标准是"如如、不离如、不异如" → 想"舍佛所说更立四谛"者只是空话（非其境界） → 疑佛、法、僧即疑四谛。
- **譬喻警策（四二一～四三四）**：深险岩、大热地狱、大闇地狱、世界中间闇冥——不知四谛比这一切更险、更热、更暗 ↔ 掷杖、五节相续轮——不知者于五趣轮转；正面立论：禅思内寂、修无量三摩提，四谛方能"如实显现"；末以黠慧之问收束。
- **渐次现观（四三五～四四三）**：须达长者问"渐次无间等？一顿无间等" → 佛答渐次，同一问答三度重出（须达、异比丘、阿难），譬喻由两细树叶不能盛水换为四阶登堂 → 三组数量喻（手中土石对大雪山、指端渧水对大湖、爪甲上土对大地），显知谛者少 → 末归佛自证"正思惟……正见已生"。
- **种种界（四四四～四五四）**：界无量，当善界学 → 众生常"与界俱"，举十三位大比丘各以同类相聚为实例 → 缘界生触、缘触生受、缘受生爱，扩展至想、欲、觉、热、求，反复以"非缘……但缘……"锁死因果方向。

## 三、关键结论

- 僧团言谈思惟当围绕四圣谛，世间戏论不向涅槃。
- 四谛是如如不异的真实，任何人不能另立新的四圣谛。
- 不知四谛是最深的险、最热的热、最暗的暗；不知者堕五趣，如掷杖、如转轮。
- 四谛须**渐次**无间等：先于苦谛现观，才可能次第于集、灭、道现观。
- 众生与界俱：起何种心便与何种界和合，故当善分别种种界。

## 四、易混辨析

- **无间等 vs 受持**：受持是闻而忆持不失；无间等（现观）是与谛理相契的亲证，四一六、四一七两经正辨此别。
- **"觉"的两义**："贪觉觉""不死觉"之"觉"是寻思、念头，非"觉悟"之觉；"贪觉觉"后一"觉"作动词用。
- **"界"的两类用法**：四四四～四五〇的"界"指心念习性之类（同类相引）；四五一以后的"界"指十八界（根、境、识），为缘起链起点。
- **世间思惟 vs 正思惟**：前者是世界常无常等戏论；后者如理思惟四谛（四四三经"正思惟……正见已生"）。

## 五、阅读提示

带两个问题读：佛为何连"两位国王谁大富"都要叫停？每经结尾的复沓句即是答案；"界"是什么、为何要"善分别种种界"？读通后半自明。
