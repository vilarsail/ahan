# 杂阿含经卷第二十六 导读

## 一、内容总览
本卷属《杂阿含经》"道品诵"，收经（六四二）至（七一一）共七十经，围绕三七道品中的**根、力、觉支**三大主题展开：前段为五根经群，中段为各种"力"的经群，末段转入五盖与七觉支的对比。全卷以极短的契经逐经排列，大量使用"如上说，差别者"的省略体例，是典型的结集汇编形态。

## 二、结构层次
全卷可分三大块，各有内部推进：

- **五根经群（六四二~六六一）**：先列根之名目（信、精进、念、定、慧）→ 再释内容（信根即四不坏净、精进根即四正断、念根即四念处、定根即四禅、慧根即四圣谛）→ 观五根断三结得须陀洹、漏尽得阿罗汉 → 佛自述如实知五根的集、灭、灭道迹乃至味、患、离，方成正觉 → 按"利、满足"与"软、劣"分判圣果阶位，历数俱分解脱、身证、见到、信解脱、一种、家家、法行、信行诸有学 → 反复以"堂阁众材，栋为其首"喻**慧根为五根之首**。
- **力经群（六六一~七〇四）**：按数目层层排列——二力（数力、修力）→三力→四力（觉力、精进力、无罪力、摄力）→四力能离五恐怖→五力→五学力→**五学力与如来十力之比较**（六八四经为本卷重心，详列十力并辨佛与阿罗汉之别）→六力→七力→八力（世俗八种力）→九力→十力，末以"处非处智力是定非不定"收束。
- **盖与觉支经群（七〇四~七一一）**：不正思惟则五盖起、七觉支退；正思惟则反之 → 五盖是黑暗、无目，能羸智慧；七觉支是大明、是目，转趣涅槃 → "五种心树"喻五盖增长则荫覆善心 → 专一听法者断五法、修七法 → 末经（七一一）以无畏王子问答说"觉支经"，展示念→择法→精进→喜→猗→定→舍的觉支次第生起。

## 三、关键结论
- 五根之中**慧根为首**，统摄信、进、念、定，如栋梁摄持堂阁。
- 五根圆满程度决定圣果高下：利满得阿罗汉，渐劣者依次得三果、二果、初果及诸有学位。
- 五学力是声闻与佛共的，**如来十力唯佛独有**——根本差别在佛"先未闻法能自觉知"、能创说正法。
- 数力（思惟恶行恶报而自警）是修力（修四念处等道品）的前行，二者相成。
- 五盖覆心、削弱智慧、障蔽涅槃；七觉支照明、增长智慧、转趣涅槃，二者正相反对。

## 四、易混辨析
- **五根 vs 五力**：同一组五法（信进念定慧），从"能生发、能增上"说名为根，从"不可屈伏、破诸邪障"说名为力；体一而用二，故本卷信根、信力同指四不坏净。
- **如来十力 vs 五学力**：五学力为一切圣者共有；十力（处非处、业报、禅定、宿命、天眼、漏尽等智力）唯佛成就，故能"转梵轮、师子吼"。
- **惭力 vs 愧力**：惭是自耻——对自己起恶烦恼而羞耻；愧是对他知愧——对可愧之事、对世间讥嫌而知可耻。
- **慧解脱 vs 俱分解脱**：阿罗汉中只以慧断烦恼者名慧解脱；定慧二者俱得（八解脱身证）者名俱分解脱，为利根。
- **五盖 vs 七觉支**：贪欲、瞋恚、睡眠、掉悔、疑五者覆心；念、择法、精进、猗（轻安）、喜、定、舍七者明心，是修行中此消彼长的两股力量。

## 五、阅读提示
读五根经群时不妨自问："慧为首"的堂阁喻在哪些经里反复出现？读力经群时注意数目由二递增到十的编排；读末段时对照五盖与七觉支逐支的相反效果。遇见"如上说，差别者"，只读差别的部分即可。
