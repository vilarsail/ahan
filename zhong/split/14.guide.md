# 中阿含经卷第十四 导读

## 一、内容总览
本卷属《中阿含经·王相应品》（第二小土城诵），收两经：《大天㮈林经》（六七）与《大善见王经》（六八）。两经同为佛陀追述自己过去世作转轮王的故事：前者是佛路过大天㮈林"欣然而笑"，因笑说往事；后者是佛在拘尸城娑罗林最后欲取般涅槃之际，因阿难问"何以于小城入灭"而说此城昔日的辉煌与本生。两经都以"昔王的有限功德 ↔ 今佛的究竟解脱"作今昔对照，并落到嘱托弟子传法不断。

## 二、结构层次
**《大天㮈林经》**：佛笑 → 阿难问因缘 → 追述大天王：先说七宝（轮宝随行、诸小王归服 → 象、马、珠、女、居士、主兵臣逐一"云何成就"试宝）→ 再说四种如意之德 → 见白发、说"天使已至"之颂 → 传国太子、剃发出家 → 展转八万四千转轮王皆如是，最后尼弥王行法布施 → 三十三天称叹、帝释亲迎王上天，王辞归修福 → 点破"大天王者即是我"→ 昔说法"不至究竟"，今成佛"得至究竟"→ 嘱阿难"转相继法，莫令佛种断"（即八支圣道）。

**《大善见王经》**：敷床双树间 → 阿难问"何故在此小土城般涅槃" → 佛说拘尸城昔为拘尸王城：城池七重堑墙、多罗树、华池庄严 → 大善见王七宝具足 → 却小王献殿、献宝，请上尊沙门梵志受供 → 独升大殿，历四楼（金楼坐银床……）次第入初禅 → 八万四千夫人渴仰来见，王闭塞诸根，教她们以"死想" → 却夫人后，于四楼修慈、悲、喜、舍四无量 → 修四梵室，舍念欲已命终生梵天 → 点破"大善见王者即是我"→ 佛于此处"七反舍身"（六反为转轮王，今第七为如来）→ 最后生、最后有，"我说是苦边"。

## 三、关键结论
- 过去诸王虽成就七宝、出家梵行，但"说法不至究竟"，不离生老病死；唯成佛后说法"得至究竟"，方脱一切苦。
- 白发是"天使"——老死之使登门，警策人趁早舍家学道。
- 佛嘱阿难展转相传的"相继法"即八支圣道；法脉不断即"莫令佛种断"。
- 大善见王修慈、悲、喜、舍四无量心，舍念欲已命终生梵天——四无量为生梵天之因。
- 佛在此地七反舍身，今是最后身，是苦的边际，更不复受生。

## 四、易混辨析
- **七宝 vs 四种如意之德**：七宝（轮、象、马、珠、女、居士、主兵臣）是转轮王的王政庄严；四种如意之德（长寿、无病、色美、为人爱念）是他个人人身的福报，两组成就互不替代。
- **尼弥王 vs 大善见王**：皆佛前生。尼弥被帝释迎上天，以"车如假借"之颂辞归人间继续修福；大善见王则入四禅、修四无量，命终生梵天。
- **初禅 vs 四梵室**："有觉有观，离生喜乐"的初禅是禅定层次；"心与慈俱"乃至悲、喜、舍是与之相应的四无量心行，本卷中大善见王在四楼依次修习。
- **说从解脱 vs 法斋**："说从解脱"是月十五日诵说别解脱戒（布萨诵戒），属出家人法；"法斋"是月八日、十四日、十五日在家人受持斋戒并行布施。

## 五、阅读提示
带着"佛为什么在临涅槃前讲自己做国王的往事"来读：两经皆以过去转轮王的极盛福报反衬其仍不离生死，从而托出今佛究竟解脱的分量，并把"莫令佛种断"的重任交到阿难与比丘众手中。
