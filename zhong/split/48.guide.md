# 中阿含经卷第四十八 导读

## 一、内容总览
本卷为《中阿含经》卷四十八，属「双品第四」（第四分别诵）。「双品」本有十经，后五经移属第五诵，故每两经主题成对，得名「双品」。本卷收五经：《马邑经》第一、第二，《牛角娑罗林经》第三、第四，《求解经》第五。全卷围绕一个大问题展开：**什么样的比丘才配称「沙门」**——前三经从反面（徒有其表的苦行）与正面（层层升进的修行阶梯）定义沙门；后两经以两幅僧团生活图景（月夜论道、三人和合）与一套「如何检验如来」的方法论作收束。

## 二、结构层次
- **《马邑经》第一：阶梯式升进说教**。佛在马邑问比丘「汝自称沙门耶」→ 立下「莫令求沙门义失沙门义」的警策 → 身清净 → 口清净 → 意清净 → 命清净 → 守护诸根 → 正知出入 → 独住远离、断五盖 → 第四禅 → 知四谛、漏尽。每上一层便堵住一次「我所作已办，不复更学」的自满 → 最后以四个定义收束：沙门＝息止恶法，梵志＝远离恶法，圣＝远离，净浴＝洗净恶法。
- **《马邑经》第二：正反对比**。先列「非沙门道迹」——贪伺、恚、瞋等十二种烦恼不息，以「钺斧裹僧伽梨」为喻，谓外衣再庄严也遮不住斧刃 → 再举无衣、编发、持水等外道苦行，指出若以「我见」行之仍非沙门 → 反转说「沙门道迹」：十二垢息 → 慈俱心遍满一方乃至一切世间 → 浴池之喻（入池快浴、去垢除热）→ 仍以四定义收束，与前经首尾同构。
- **《牛角娑罗林经》第三：问答连珠式**。月夜林中，舍梨子依次问七位大弟子「何等比丘起发牛角娑罗林」：阿难（多闻）、离越哆（坐禅）、阿那律陀（天眼）、迦旃延（论阿毗昙）、迦叶（少欲知足）、目揵连（神通）→ 舍梨子自答「随用心自在而不随心」→ 众人诣佛，舍梨子复述全部问答，佛一一印可 → 佛总结「一切悉善」，并给出自己的答案：入村乞食后敷座而坐，「不解结跏趺坐乃至漏尽」。
- **《牛角娑罗林经》第四：叙事展示式**。阿那律陀、难提、金毗罗三族姓子共住林中，各行其职、五日一集、或说法或圣默然 → 佛来访，问「安隐无所乏」之由 → 阿那律陀层层作答：和合无诤、自舍己心随彼诸贤心 → 四禅 → 四无量心 → 非有想非无想处 → 漏尽 → 长鬼天、地神乃至梵天次第传声赞叹，以诸天见证作结。
- **《求解经》第五：方法论**。提出难题：不能知他心，如何「求解于如来」？→ 给出以「二事」勘验的次第：眼见色、耳闻声中，有无秽污法 → 有无杂法 → 有无白净法 → 是否长夜行之 → 为名誉利义抑或离欲 → 层层排除后得「知断一法，于诸法得究竟」，成就「信见本不坏智相应」，世间无人能动。

## 三、关键结论
1. 沙门之名贵在其实：贪伺、恚、瞋、悭、嫉等十二种烦恼有一不息，纵披僧伽梨、修苦行，也「我说非是沙门」。
2. 修行不可得少为足：身口意命清净只是起点，每一层都当「求上」，否则「求沙门义失沙门义」。
3. 多闻、坐禅、天眼、论议、少欲、神通、心自在，佛印可「一切悉善」——皆是庄严此林之道，而佛自举「不废坐禅乃至漏尽」为极。
4. 僧团安乐之本在「自舍己心，随彼诸贤心」，行慈身口意业，见与不见等无有异。
5. 认识善知识（乃至如来）不必他心通：由眼见耳闻的身口之业，长期、反复地勘验即可。

## 四、易混辨析
- **沙门 vs 梵志**：沙门指出家修道者（本卷特指佛门比丘）；梵志本指婆罗门，经中与沙门连用泛称修道求净之人。两经末的四定义（沙门、梵志、圣、净浴）名义各异而实指同一：息灭、远离、洗净诸恶不善法。
- **第一经之「净浴」 vs 第二经之浴池喻**：前者是定义——真正的「洗浴」是洗净贪瞋等恶法；后者是譬喻——如渴乏之人入池快浴「去垢除热」，喻出家者以道涤除烦恼，一个为义，一个为喻。
- **非沙门道迹之苦行 vs 沙门道迹**：无衣、编发、常扬水、持水等外形苦行非道迹；息灭十二垢才是道迹——批判的矛头不在苦行本身，而在「以我见」行之。
- **天眼 vs 如意足**：天眼是于千世界须臾尽见的视觉神通；如意足是变一为众、履水升空的神变自在。二者皆尊者之德，但经中明示唯漏尽解脱方是究竟，「更无有余」。

## 五、阅读提示
带着一个问题读本卷：我学佛，是在学「沙门的样子」，还是在息灭贪伺、恚、痴？卷中反复出现的「莫令求沙门义失沙门义」，正是对每一名自称「沙门」者的当头棒喝。
