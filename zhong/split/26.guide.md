# 中阿含经卷第二十六 导读

## 一、内容总览
本卷为《中阿含经》卷第二十六，属"因品"（第二小土城诵），收四经：一〇三《师子吼》、一〇四《优昙婆逻》、一〇五《愿》、一〇六《想》。四经同显一意：佛法之"第一、真实"在于离欲恚痴、断尽执取、离神我之计，故佛弟子敢于在大众中作师子吼。

## 二、结构层次
- **《师子吼经》——论辩式递进**：先立命题（唯佛教内有一至四沙门果）→ 教比丘应答异学：以信尊师、信法、信戒德、爱敬同道四法为据 → 随即设外道反诘，一问一答步步收窄（一究竟还是众多究竟？有欲者还是无欲者得究竟？有恚、痴、爱受者得究竟吗？）→ 逼出结论：外道皆依有见、无见二边 → 再进一层：外道虽也"施设断受"，但只断欲受、戒受、见受，不断我受；唯佛于现法断一切四受，四受以无明为本，无明尽则般涅槃。
- **《优昙婆逻经》——戏剧式折服**：实意居士本欲供佛，转访异学园 → 异学无恚自夸"以一论灭彼，如弄空瓶"，命众嘿然以诱佛 → 佛以天耳闻之，晡时自至其园 → 无恚问"如何教训弟子"，佛层层剖析"不了可憎行"：其行具足 → 为无量秽所污 →（离秽）仍只得皮、得节 → 最上真实在第四禅发起漏尽智、三漏心解脱 → 无恚心服；佛点破大众默然乃魔王所制，携居士以神通飞去。傲慢起、折服收，是全卷叙事最详的一篇。
- **《愿经》——阶位排比**：一比丘愿佛慰劳说法 → 佛顺此广陈比丘之愿：忍饥渴寒热 → 离三恶念 → 四禅 → 四果（须陀洹、一往来、不还）→ 八解脱、六神通 → 阿罗诃，从低到高逐级铺开，末段以比丘修成阿罗诃作结。
- **《想经》——对照式极简**：外道"计地即是神"故不知地 ↔ 佛"不计地即是神"故知地；从地、水、火、风、诸天、梵天、无色界诸处直到"一切"，同一句式反复排比，只换对象不换理路。

## 三、关键结论
- 异道之见终不外有见（常见）与无见（断见）二边，且不离欲、恚、痴、爱受、憎诤，故非究竟。
- 断受必须断尽欲受、戒受、见受、我受四受，四受以无明为因；无明尽则不恐怖、断因缘、必般涅槃。
- 苦行"不得第一、不得真实"，至多得皮（四无量心）、得节（宿命通）、得第一真实（天眼见业果）；弟子依佛行梵行，为证第四禅与漏尽智通，三漏心解脱。
- 于一切境界不执为神我（不计"即是神"），方能如实知一切。

## 四、易混辨析
- **四受 vs 受阴之"受"**：本卷"受"多作"取"解——欲受、戒受、见受、我受即四种执取（约当"四取"），不是苦乐感受。
- **有见 vs 无见**：执死后我永存为常见 ↔ 执死后一切断灭为断见；佛说离此二边。
- **得皮 / 得节 / 得第一真实**："不了可憎行"的三层成果，由浅入深——四无量心是皮，宿命通是节，天眼见业果是第一真实，但仍非解脱本身。
- **须陀洹 vs 一往来 vs 不还 vs 阿罗诃**：《愿经》一次排比的声闻四果：极受七有、人天七往来 → 再一来即得苦边 → 五下分结尽、不还此世 → 漏尽无生。

## 五、阅读提示
读《师子吼》《优昙婆逻》两经，留意问答如何一步步锁定结论；读《想经》时把"神"读作"神我（真我）"，"地即是神"即"地就是我"，全文顿时可通。
