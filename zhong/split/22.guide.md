# 中阿含经卷第二十二 导读

## 一、内容总览
本卷为《中阿含经》卷二十二，属「秽品第三」（第二小土城诵，本诵收十经）之开首二经：（八七）秽经、（八八）求法经。两经皆以尊者舍梨子（舍利弗）的论议为主轴：一破比丘心中争胜求名的污垢，一劝弟子求法而非求饮食，合观正是一部「出家人内心卫生」的教导。

## 二、结构层次
**秽经**：四句分别 → 喻释 → 释秽 → 补喻。
- **立四句**：舍梨子说四种人——有秽不自知（最下贱）、有秽自知（最胜）、无秽不自知（最下贱）、无秽自知（最胜）；比丘问：同是有秽（无秽），何以一贱一胜？
- **铜槃喻逐句解释**：有秽能知、勤求方便断秽者如数数洗拭铜槃，命终生善处；无秽而不护由眼耳所知法者，被欲心所缠，仍生秽而堕恶处 → 结论：关键在自知与自护。
- **释「何等为秽」**：无量恶不善法从欲生谓之秽——列犯戒怕人知、怕在众中被诃、争佛前坐、争第一座食、争为居士说法、争名闻供养等种种心欲 → 以铜合槃外覆盖内盛粪（／内盛净食）两喻，斥表里不如一的伪沙门。
- **目揵连补喻**收尾：车师治轴喻善知识知人心，献华鬘喻净行弟子闻法欢喜。

**求法经**：佛诫 → 喻证 → 四句分别 → 代说广分别。
- 佛诫「当行求法，莫行求饮食」→ 以一钵残食为喻：取食者一夜安隐却失少欲知足乃至涅槃；不取者虽饥苦却得可佛意。
- 四句分别：尊师乐住远离，弟子亦乐住远离，法才饶益多人。
- 佛患背痛小息，命舍梨子代为说法 → 舍梨子广分别上弟子、中下弟子「三事可毁／三事可称」→ 复说两种中道：断念欲、恚、悭嫉、贡高、放逸等心垢；及八支圣道 → 佛起赞叹，劝「受法如法，诵习执持」。

## 三、关键结论
- 决定高下的不是有无秽，而是能否自知：知秽而断者最胜，无秽而不护根门者仍堕。
- 无量恶不善法从欲生，谓之秽——争座位、争名闻、争供养之心即是秽。
- 求法不求饮食：不取一钵残食，换得少欲知足乃至涅槃。
- 师离弟子亦离，法方饶益世间；弟子三事可称：学舍离、断可断法、不舍方便。
- 两种中道（断诸心垢、八支圣道）皆能得定得乐，得通得觉，亦得涅槃。

## 四、易混辨析
- **有秽不自知 ↔ 无秽不自知**：同判最下贱——前者不能断秽，后者自恃无秽、不护由眼耳所知法，反为欲心所缠。
- **求饮食 ↔ 求法**：同一残食，取者得一夜之安而失诸功德，不取者受一时之苦而得可佛意。
- **秽 ↔ 欲**：欲是心因，从欲而生的恶不善法才称为秽；故「心不生欲」则「二俱善」。
- **三事可毁 ↔ 三事可称**：同一三项（学舍离、断可断法、于所受证是否舍方便），弟子做与不做，毁称立判。

## 五、阅读提示
带着问题读：「我心里的『第一座、第一澡水』之念有多频繁？」秽经的铜槃与粪槃两喻是照妖镜；求法经则问：我每日用心，是在求法，还是在求饮食？
