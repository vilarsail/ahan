# 中阿含经卷第三十五 导读

## 一、内容总览
本卷属《中阿含经·梵志品第二》的开头（"第三念诵"），收三经：《雨势经》第一（经一四二）、《伤歌逻经》第二（一四三）、《算数目揵连经》第三（一四四）。三经同为"答外来之问"型：一答摩竭陀大臣的军国大事，二答婆罗门关于福德之问，三答外道算数师关于修行次第之问——由护国而护法，由福德而道次，层层引向佛法本位。

## 二、结构层次
- **雨势经（一四二）**：摩竭陀王欲灭䟦耆 → 遣大臣雨势问佛 → 佛举"七不衰法"（数数集会、守旧法、敬重名德、拥护阿罗诃等），雨势自悟"成一法尚不可伏，况具七"而退 → 转折：雨势去后，佛集比丘于讲堂，将"七不衰法"移用到僧团身上，一连七组（集会持戒、尊师奉法、离业离哗说、七圣财、五力、七觉支、七灭诤），末以"六慰劳法"收束——由"国不衰"转到"法不衰"。
- **伤歌逻经（一四三）**：梵志问：作斋教斋行无量福，出家学道只行一福？→ 阿难追问"二道迹何者最胜"，被其以"俱恭敬"回避再三 → 佛出面，以"三示现"（如意足、占念、教训）设问 → 伤歌逻自认教训示现最上最胜 → 三自归依。
- **算数目揵连经（一四四）**：算数师以学堂登梯、调象御马、学算数皆"渐次第作至成就"为喻问佛法 → 佛说渐次教授：身口意护命清净 → 观身受心法 → 守护诸根 → 正知威仪 → 远离无事处断五盖 → 得第四禅 → 究竟漏尽 → 又以王舍城道喻答"何故同受教而有得有不得" → 目揵连以娑罗林、栴檀、莲华诸喻自承佛为论士第一，归依。

## 三、关键结论
1. 团结集会、遵行旧法、敬重长老、拥护圣者是国与僧共同"不衰"的条件——政治兴亡之道与僧团住持之道同构。
2. 三示现之中，神足与占念只"自作自有，自受其报"，唯教训示现能展转教人、度无量百千人，故最上最胜——佛不以神通为贵。
3. 佛法如登阶、学算，"渐次第作至成就"；但导师只能指路，得涅槃与否"但各自随比丘所行"，不一向得。

## 四、易混辨析
- 国之"七不衰法" ↔ 僧之"七不衰法"：前者是政治伦理（不犯他妇、修旧寺、敬旧法），后者是修行制度（持戒、宴坐、七圣财、七觉支、七灭诤），名目相承而内容两套。
- 如意足示现 ↔ 占念示现 ↔ 教训示现：神变、他心、教诫三种化导方式；前二者炫于外而利有限，后者以法展转相传。
- 渐次第教 ↔ 究竟漏尽：如来之教是阶梯而非保证，"不一向得，或有得者，或不得者"，果报在人自随行。

## 五、阅读提示
带着一问去读：王问的是"能否打赢"，佛为何答"七不衰法"？再看三经如何各借外道的问话为梯，把话头从斋福、神通、算数引到解脱道上。
