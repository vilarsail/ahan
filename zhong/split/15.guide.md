# 中阿含经卷第十五 导读

## 一、内容总览
本卷为《中阿含经》卷十五，属"王相应品"（第二小土城诵），收两经：第69经《三十喻经》、第70经《转轮王经》。两经都以"王"作枢纽：前者以国王的三十种随身资具，逐一譬喻比丘的三十种法功德；后者借转轮圣王七宝与轮宝的兴衰，讲治国正法与众生善恶性命的升降，最后归到比丘当"燃法灯、自归己法"，以戒定慧为王之真宝。

## 二、结构层次
**《三十喻经》——一问一答，逐喻排比：**
- **序起设问**：佛见比丘众静坐甚深（无睡眠、除五盖）→ 问舍梨子："谁能敬重奉事比丘众？" → 舍梨子答：唯世尊能敬重奉事法、比丘众、戒、不放逸、布施及定。
- **正说三十喻**：佛以"犹如王及大臣有……"起头连下三十喻，每喻固定句式"比丘、比丘尼以X为Y……便能舍恶，修习于善"，排比推进。
- **喻义递进**：戒德为严饰具 → 持禁戒为卫梵行 → 护六根为守合人 → 正念为守门将 → 善知识为沐浴人 → 惭愧为衣服 → 四禅为床座 → 喜为食、法味为饮 → 三定（空、无愿、无相）为华鬘 → 四念处为租税、四正断为四军、四如意足为掆舆 → 止观为车、八支圣道为道路 → 四圣种为宗正卿 → 无碍定为御床 → 不动心解脱为名珠宝 → 以自观己心为身极净收束。

**《转轮王经》——一个故事套三层转折：**
- **嘱咐立宗**：佛诫诸比丘"当自然法灯，自归己法" → 引出往昔坚念转轮王的先例。
- **第一轮（正例）**：坚念王见轮宝移位 → 付国太子、出家学道 → 传授"相继之法"（观法如法、奉持法斋、修行布施、问法受法、赈济贫穷） → 其子依法而行，轮宝复现。
- **第二轮（反例）**：又一代新王失轮后不忧戚，"自出意治国" → 不学相继之法 → 国民贫困 → 偷盗 → 刀杀 → 妄言、两舌 → 邪淫 → 非法恶贪 → 邪见，恶法层层转增 → 人寿由八万岁逐级减至十岁 → 七日刀兵劫。
- **反转（善例）**：劫后余生者共离杀断杀 → 十恶逐一递离 → 人寿由十岁倍增回八万岁 → 螺转轮王出世。
- **归结**：轮王"行自境界，从父所得" → 比丘亦然：观内身如身（自境界）、四如意足（比丘之寿）、持戒威仪（比丘之色）、第四禅（比丘之乐）、漏尽解脱（比丘之力）。

## 三、关键结论
- 三十种法功德如王之严饰具，能究竟敬重奉事者唯佛。
- 转轮王以轮宝为信；轮宝移没预示王命将尽，唯有"相继之法"能令轮宝再现。
- 恶法辗转相增则人寿、形色俱减；共行十善则寿色俱增——本经是共业感果的完整演绎。
- 比丘的真"七宝"：四念处观身、四如意足、禁戒、四禅、漏尽解脱；降魔之力在无上圣慧，不在神力。

## 四、易混辨析
- **四念处（租税）vs 四正断（四军）vs 四如意足（掆舆）**：同属三十七道品而喻象各异——念处是日日受用的观察资粮，正断是策励精进的力量，如意足是承载所愿的运载。
- **"相继之法" vs "自出意治国"**：依法传承、问法而行，与凭私意独断专行，一兴一衰，是全经的对比轴。
- **转轮王的寿、色、乐、力 vs 比丘的寿、色、乐、力**：前者是世间福报，后者分别对应四如意足、禁戒、第四禅、漏尽——同名异实，读结尾时须换算到修行义。
- **轮宝 vs 七宝**：七宝是转轮王的全部资具（轮、象、马、珠、女、居士、主兵臣），轮宝为其标志；轮宝在，王位在。

## 五、阅读提示
读《三十喻经》可对照"王具 → 法义"逐条配对体会；读《转轮王经》时留意人寿增减与十恶十善的一一对应，最后思考"自归己法"何以落在四念处与漏尽解脱上。
