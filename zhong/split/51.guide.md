# 中阿含经卷第五十一 导读

## 一、内容总览
《中阿含经》卷第五十一，属「大品」（第五后诵），含两经：（一九四）跋陀和利经、（一九五）阿湿贝经。两经同以「饮食之戒」为引子：前经佛制「一坐食」戒，比丘跋陀和利三次推辞、躲藏一个夏坐，经佛呵责慰勉而转变；后经佛制「日一食」戒，阿湿贝、弗那婆修二比丘公然违拒，佛借机纠正他们「觉苦则善法增」的倒见。一经私下呵责、一经当众勘问，共同显明：于佛所制之戒应随顺学，于觉受则不应一概取舍。

## 二、结构层次
**跋陀和利经**（问答推进，一呵一摄）：
- **制戒起衅**：佛三说一坐食之利 → 跋陀和利三辞「不堪任」 → 佛仍施设此戒，他竟躲藏一夏不见佛 → 结夏结束，佛当面呵责（「汝非如空屋耶？」）→ 复令欢喜。
- **呵责中嵌圣者阶位**：俱解脱→慧解脱→身证→见到→信解脱→法行→信行，七种人闻教皆「不可住而移避」，反衬跋陀和利一种也未证得。
- **慰勉说法**：持戒者住远离处 → 欢悦→喜→止身→觉乐→心定→见如实知如真 → 依次得四禅（四增上心）→ 三明（宿命、生死、漏尽三明达）→ 漏尽解脱。
- **两番问答收束**：①同犯于戒，为何有的苦治、有的善共将护？——看犯者态度；护其信、爱、靖，如亲属护一眼人。②昔制戒少持者多，今制戒多持者少？——为断后世漏故施设戒 → 清净马喻：调马由口至支节「数数治」而成就，喻智人成就十无学法。

**阿湿贝经**（违戒→勘问→正说）：
- 众多比丘劝二人不听 → 佛亲问，斥其「我不一向说，汝等一向受持」。
- **正说法义**：乐觉、苦觉各分「善法增／善法减」两种，故有断有修；身乐、身苦、心乐、心苦皆以「恶不善法增减」定可修不可修。
- **推展收束**：七种比丘中唯俱解脱、慧解脱「不行无放逸」，其余皆须行 → 欲得究竟智须渐渐习学趣迹、受教受诃 → 信弟子入世尊境界者，于二果中必得一。

## 三、关键结论
- 持戒与离欲是定慧之道的前行：不诬谤戒 → 欢悦 → 喜 → 止身 → 觉乐 → 心定 → 见如实、知如真。
- 觉受本身无善恶，关键在觉已令善法增还是减——增则修，减则断，佛说法「不一向」。
- 佛制戒「不以断现世漏，以断后世漏」，为弟子长夜利益。
- 教化当观根器：对少信、少爱、少靖者如亲属护一眼人般将护，不轻易苦治。

## 四、易混辨析
- **信行 vs 法行**：闻法以信为先者为信行，以慧观察为先者为法行，皆须精勤的初学圣者。
- **信解脱 vs 见到**：同是「一向决定信佛法僧」，见到以慧「增上观、增上忍」更深，信解脱仅「以慧观忍」。
- **身证 vs 慧解脱 vs 俱解脱**：身证亲证八解脱而慧未尽漏；慧解脱慧尽漏而未证八解脱；俱解脱二者兼备。
- **修乐觉 vs 断乐觉**：同一乐觉，令恶法增者断，令善法增者修。

## 五、阅读提示
带着一问读：佛为何对同一种「觉」既说断又说修？再对照跋陀和利从「不堪任」到请佛说法的翻转，体会制戒与受戒之间的师弟之道。
