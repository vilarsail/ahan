# 中阿含经卷第二十一 导读

## 一、内容总览
本卷为《中阿含经》卷二十一，属「长寿王品」（第二小土城诵），收三经：（八四）无刺经、（八五）真人经、（八六）说处经。三经共同主题是**评估修行的真正价值**：无刺经说每一修行阶段都有其「刺」（妨碍）；真人经以「自贵贱他」与否判定圣者与非圣者；说处经则是阿难教年少比丘的法目总纲，几乎囊括阿含核心法数，卷末补说「顶法与顶法退」。

## 二、结构层次
- **无刺经（八四）**：事缘起 → 毗舍离离车贵族以大神变、王者排场盛装拜佛 → 诸上尊大弟子为避喧闹，退往牛角娑罗林宴坐 → 佛叹许，并**逐层列举「刺」**：持戒者以犯戒为刺 → 修慈者以恚为刺 → 入初禅以声为刺 → 递进至想知灭定以想知为刺（→ 阶位越高，妨碍越微细）→ 结归根本三刺：欲、恚、痴，唯漏尽阿罗汉断尽无刺。
- **真人经（八五）**：立「真人法／不真人法」二分 → 十组同一句式对比推进：豪贵族 → 端正 → 才辩 → 长老名闻福报 → 诵经持律学阿毗昙 → 粪扫衣 → 乞食（过中不饮浆）→ 住无事处 → 得初禅 → 得四无色定（→ 从出身、外相、学识、苦行到禅定，凡是依之「自贵贱他」的都不是真人法）→ 偈颂总结。
- **说处经（八六）**：阿难携年少比丘问佛「云何教呵」→ 佛命「说处及教处」，历数约二十组法目：五盛阴 → 六内处、六外处 → 六识身、更乐、觉、想、思、爱身 → 六界 → 缘起 → 四念处、四正断、四如意足、四禅、四圣谛 → 四想、四无量、四无色、四圣种、四沙门果 → 五熟解脱想、五解脱处、五根、五力、五出要界 → 七财、七力、七觉支 → 八支圣道（→ 每组皆以同一劝益句「得安隐……终身行梵行」收束，是排比式总纲）→ 佛补说**顶法与顶法退** → 嘱咐宴坐精进、勿得放逸。

## 三、关键结论
- 一切修行阶段皆有其「刺」，妨碍由粗至细递减，唯断欲恚痴三毒的漏尽阿罗汉真正无刺。
- 圣者与否不看出身、容貌、才辩、名闻、多闻、苦行乃至禅定，只看是否因此「自贵贱他」；凡有执取（「有计」）即是爱。
- 教导后学须「说处」（解说法目）与「教处」（教以修习）并进，法目之学为的是安隐梵行，不是知识。
- 顶法（对无常苦空非我生忍可乐欲）可得可退，须修守护、精勤不放逸。

## 四、易混辨析
- **阶位之「刺」vs 三刺**：前者（声之对初禅等）是相对的阶段妨碍，后者（欲、恚、痴）是根本烦恼，断三毒才是一切刺的终点。
- **「觉」的两义**：说处经「六觉身」之觉＝受（感受）；无刺经「觉观」之觉＝寻（粗思），观＝伺（细分别），二禅以上须舍。
- **五力 vs 七力**：五力＝信、精进、念、定、慧；七力再加惭、愧二力。
- **真人法 vs 不真人法**：外缘（贵、美、辩、定）本身中性，取著自贵即堕不真人法，离执如法即真人法。

## 五、阅读提示
带一个问题读：修行上每进一层，我赖以自贵的资本是否也换了一层？本卷十组对比就是十面镜子。
