# 中阿含经卷第二十九 导读

## 一、内容总览
本卷为《中阿含经》卷二十九，「大品第一」的开端（大品共二十五经，本卷收前九经：柔软、龙象、说处、说无常、请请、瞻波、沙门二十亿、八难、贫穷）。九经各自独立成篇，但共同回答一件事：什么才是真正的修行——佛陀自述太子生涯（柔软）、以「龙」赞佛（龙象）、立论议规范（说处）、五阴无常观（说无常）、布萨自恣与僧团清净（请请、瞻波）、精进调弦（沙门二十亿）、修道时机（八难）、圣法中的贫穷喻（贫穷）。

## 二、结构层次
- **佛陀现身说法**：柔软经——佛自述父王悦头檀家的极乐享受 → 因见看田人树下结跏趺坐得初禅，转观自身「病、老、死」三法 → 断贡高、行净梵行。
- **赞颂与自证并行**：龙象经——河边巨象引出「谁是大龙」之问 → 佛言不以身口意害者名龙 → 乌陀夷以龙相应颂赞佛；请请经——夏坐圆满自恣日，佛自说「我是梵志，而得灭讫」→ 舍梨子三问佛是否嫌其身口意行 → 傍耆舍作赞颂。
- **论议与观法**：说处经立「三说处」（因过去、未来、现在世说）→ 再立可共说／不可共说的四组观察 → 结以圣者论议之仪；说无常经直演「色无常 → 无常则苦 → 苦则非神」一线，修七道品而三漏尽。
- **僧团清净**：瞻波经——布萨之夜佛三度默然 → 揭出众中有一不净比丘 → 目揵连入如其像定察知、牵臂逐出 → 佛以秽麦、扬谷、通水槽三喻明「摈弃恶比丘」之理。
- **修道要诀与时机**：沙门二十亿经以调琴喻「精进不急不缓」，并说学根／无学根之递进；八难经列八难八非时，唯「佛出世＋生中国＋有正见」为「一不难、一是时」；贫穷经以借债六阶段（贫穷→举贷→长息→责索→数往求索→收缚）喻圣法中无信戒闻施慧者的堕落轨迹。

## 三、关键结论
- 五阴无常，无常则苦，苦则非神（无我）。
- 精进如调琴弦：弦急心调乱，弦缓心懈怠，不急不缓适得其中方能证果。
- 布萨诵戒须清净众；似真梵行的覆藏者应共摈弃，勿令染污诸梵行。
- 生逢佛世、得生中国、具足正见，是人行梵行唯一「不难、是时」。
- 圣法中无信、无戒、无闻、无施、无慧，虽有多财宝仍是「不善贫穷」。

## 四、易混辨析
- **本卷「龙」vs 畜生龙**：经中「龙」取其义译，指不以身口意害一切众生者，如来为「龙中龙」，非神话中的蛇龙；身形巨大之物「众人见已」皆称龙，只是世俗说法。
- **俱解脱 vs 慧解脱 vs 三明达**：俱解脱定慧俱得（兼八解脱与漏尽慧），慧解脱唯以慧断漏，三明达则通达宿命、天眼、漏尽三明；五百比丘中各九十余众。
- **学根·学戒 vs 无学根·无学戒**：有学位（求无上涅槃而学未得意）成就学根学戒；诸漏已尽证阿罗汉后，转为无学根、无学戒，如幼童小根长成后具足学根。
- **八「难」与八「非时」**：二名同指——生地狱、畜生、饿鬼、长寿天、边国、聋哑、邪见、佛不出世，凡障修行之时皆非修道之时。

## 五、阅读提示
带着两个问题读：请请经中佛为何三答「我不嫌汝身口意行」、并细数五百比丘的果位？贫穷经的借债六阶段如何一步步对应破戒者从无信到堕落的轨迹？
