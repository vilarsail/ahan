# 中阿含经卷第二十 导读

## 一、内容总览
本卷为《中阿含经》卷第二十，收三经，均属「长寿王品」第二小土城诵：《念身经》（八一）佛广说修习念身（身念处）的方法与十八功德；《支离弥梨经》（八二）尊者大拘絺罗呵责质多罗象子比丘在僧中不敬上尊、抢先发言，以六喻断言其将退失，后果然舍戒还俗；《长老上尊睡眠经》（八三）佛以神足到目犍连处，教以次第灭除睡眠之法，兼说入村乞食与说法的态度。三经同摄一主题：修行须念念相续、敬慎不放逸——念身则魔不得便，放逸争胜则定慧俱失。

## 二、结构层次
- **《念身经》：问答起兴 → 十六段修法 → 一喻总摄 → 四喻辨魔 → 十八德收束**
  - 缘起：比丘食后集坐讲堂，共论「念身有大果报，得眼有目见第一义」→ 佛来印证，应问自说。
  - 修法递进：正知行住坐卧语默 → 以善念对治恶念（墨绳斧斫喻）→ 齿齿相着以心治心（力士打锻喻）→ 安般念觉知入出息长短 → 初禅离生喜乐 → 二禅定生喜乐 → 三禅无喜生乐 → 净心遍满 → 光明想不颠倒 → 观相受持 → 观身不净（发毛爪齿至小便）→ 观身六界（屠牛分肉喻）→ 九段死尸观（自乌鸱啄食到骨白如螺）。
  - 归结：诸善法尽在其中，如小河归大海 → 四组对比喻（空瓶受水/满瓶不受、重石入淖泥/毛鞠掷户扇、燥钻槁木得火/湿钻湿木不得）明「有念身、无量心则魔波旬终不得便」→ 列十八功德：堪忍苦痛、不着不乐恐怖三恶念、证四禅、次第得四果乃至无漏心解脱慧解脱。
- **《支离弥梨经》：事件 → 劝诫 → 辩护 → 六喻预言 → 应验**
  - 众多比丘论法律时，质多罗象子比丘「竞有所说，不待说法讫竟」→ 拘絺罗劝其恭敬上尊 → 亲朋友为之辩护 → 拘絺罗申明「不知他心者，不得妄说称不称」，举六喻（牛入他田、湖池水满复见鱼鳖、四衢道泥还燥作尘、山泉湖起波浪、居士饱食还饥、闹处不闻支离弥梨虫声）说一人于世尊前善守善护，离佛后调笑贡高，心生欲→身心热→舍戒罢道；得初禅乃至无想心定而自足不求者亦然 → 后质多罗象子果然舍戒，预言应验。
- **《长老上尊睡眠经》：神通警策 → 灭睡十法 → 谦敬之道 → 究竟梵行**
  - 目犍连宴坐睡眠，佛入如其像定瞬至（屈申臂顷）→ 逐层教灭睡眠：莫修睡相 → 诵法、为他说法、心念心思 → 扪耳、冷水澡洗 → 外瞻星宿、露地经行 → 敷座跏趺 → 右胁而卧、作明想、常欲起想 → 诫莫贪床乐利养 → 入村当厌利养、莫以诤说法、下意说法如师子 → 末答究竟义：觉苦乐而观无常断灭舍，不受此世则不疲劳，不疲劳便般涅槃。

## 三、关键结论
- 念身修习广布，则三十七道品诸善法尽在其中，如众河归海。
- 有念身、游行无量心者，魔波旬伺求其便终不能得；空无念身、游行少心者必被魔乘。
- 得定非圣果：得初禅乃至无想心定而自安住、不复更求，遇白衣共会之缘仍会身心热恼而舍戒罢道。
- 灭睡眠有可操作次第：从不修睡相起，直至作明想、立正念正智、常欲起想。
- 于苦乐受不起执著（不受此世）→ 不疲劳 → 般涅槃，是究竟梵行的路径。

## 四、易混辨析
- **离生喜乐 vs 定生喜乐 vs 无喜生乐**：分别对应初、二、三禅——初禅由离欲界恶不善法生喜乐，二禅由定（内心一趣）生喜乐，三禅舍去粗动之喜、唯存绵密之乐。
- **游行少心 vs 游行无量心**：少心谓心量狭小有所拘局；无量心谓慈悲喜舍四无量心遍满无涯，与念身相辅则魔不能入。
- **觉观**：觉即「寻」（粗略推度），观即「伺」（细密伺察）；本经末段谓对每一觉受都要以觉观之心观其无常、断、灭、舍，非指散乱的分别念。
- **须陀洹 → 一往来 → 不还 → 无漏解脱**：极受七有而尽苦际（初果）；一往来天上人间已得苦际（二果）；五下分结尽、生于彼间便般涅槃（不还果）；诸漏已尽、心解脱慧解脱（阿罗汉）——十八功德正按此阶位排列。
- **睡眠**：非泛指夜里睡觉，特指五盖之一的昏沉盖，坐禅中现起；故经中立「作明想、常欲起想」以对治。

## 五、阅读提示
带着两个问题读：一是《念身经》十六段修法与呼吸、不净、六界、白骨观如何由粗到细递成一套完整的身念处；二是《支离弥梨经》六喻为何把「得定」与「退道」联在一起——定若不求上进，与未得何异。
