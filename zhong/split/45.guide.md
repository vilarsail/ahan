# 中阿含经卷第四十五 导读

## 一、内容总览
本卷为《中阿含经》卷第四十五，属「心品第三」（第四分别诵），品内收十经，本阅读段含前四经：心经第一（一七二）、浮弥经第二（一七三）、受法经第三（一七四）、受法经第四（一七五）。四经皆以「心」与「行」为纲：第一经论心主导世间，第二经论行梵行能否得果，第三、四两经同名《受法》，分别从具体事例与智者抉择两个角度讲四种「受法」（现前与当来苦乐的四组合）。

## 二、结构层次
本卷四经可视为「由心到行、由问到择」的递进：
- **心经第一**：比丘宴坐发问 → 佛答「心将世间去，心为染着，心起自在」→ 连环三问层层定义理想比丘：多闻比丘（闻四句偈能知义知法、趣法向法）→ 多闻明达智慧（于四圣谛以慧正见如实知见）→ 聪明黠慧广慧（自饶益、饶益他、愍伤世间）→ 尾声以比丘精进修证得阿罗诃收束。
- **浮弥经第二**：王子耆婆先那问尊者浮弥「作愿／无愿／愿无愿／非有愿非无愿行正梵行，是否必得果」→ 浮弥不敢自专，以「世尊或如是说」含糊作答 → 浮弥向佛禀报 → 佛连出四喻（挤牛角、抨水求酥、压沙求油、钻湿木求火，与各自对治的正喻配对）→ 结论：有正见、行正梵行则四类皆得果，邪见邪行则四类皆不得果。
- **受法经第三**：佛在舍卫国开演四种受法 → 逐一定义（现乐当苦／现苦当乐／现苦当苦／现乐当乐），每种配一具体情境（狎昵女人、强抑苦行、外道苦行清单、不重浊者修行生天）→ 插入「葛藤子覆娑罗树」一喻，说明小种子如何长成缠裹大树、树神始觉受苦 → 回扣「现乐当来受苦报」。
- **受法经第四**：同题重说于拘楼国 → 先明「如是欲、如是望……令不喜法灭、喜爱法生」是难见难觉的不痴法 → 再讲四种受法，但换一个维度：痴者不知如真，故错乱「习行／不习行」；慧者知如真，故当断则断、当行则行 → 配药喻（杂毒的阿摩尼药、大小便和药、酥蜜和药）→ 结以「习行法知如真、不习行法知如真」为慧法。
- **体例印记**：每经以「我闻如是……欢喜奉行」首尾呼应，经末附字数（如「千五十四字」），是口诵结集与抄经时代的痕迹。

## 三、关键结论
1. 是心引导世间、染着世间、于世间得自在；圣弟子不随心自在，而是心随圣弟子。
2. 多闻的标准不在闻法之多，而在闻一句偈能知义知法、趣向梵行；「明达智慧」在于对四圣谛如实知见。
3. 得果的关键在正见与正行，不在有无愿求：行正梵行则作愿、无愿等四种皆必得果，行邪梵行则四种皆必不得果。
4. 判断一种受法（行为方式）当行当断，不看现前苦乐，而看当来果报与是否趣向涅槃——慧者于习行法、不习行法皆如实知，故取舍不错乱。

## 四、易混辨析
- **受法经第三 vs 受法经第四**：同名异说。第三经讲四种受法各配具体情境与譬喻（重「事例」）；第四经讲痴者与慧者对四种受法的「习行／断除」抉择（重「判断力」），并以药喻对照。
- **现乐当来受苦报 vs 现乐当来亦受乐报**：同为现前快乐，前者如沉溺欲乐，后者如「不重浊欲、恚、痴」者以乐以喜修行梵行——分别在于当来果报与是否趣向涅槃。
- **多闻比丘 vs 聪明比丘黠慧广慧**：前者以「闻法知义、趣法向法」为相；后者以「不念自害他害、但念饶益自他、愍伤世间」为相，一个重闻慧，一个重慈悲利他。
- **苦习 vs 苦灭**：「习」同「集」，苦习是苦之集起（集谛），苦灭是苦之止息（灭谛），二者与苦、苦灭道合成四圣谛，勿把「习」误读为修习。

## 五、阅读提示
带着两个问题读：一是我此刻是被心牵着走，还是心随我（第一经）；二是哪些当下舒服的事当断、哪些当下辛苦的事当行（两篇《受法经》）。
