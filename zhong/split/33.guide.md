# 中阿含经卷第三十三 导读

## 一、内容总览
本卷属《中阿含经·大品》，收两经：（一三四）《释问经》第十八、（一三五）《善生经》第十九。前者写天帝释（天王释）率三十三天与乐神五结乐子下到王舍城因陀罗石室问佛，由「悭嫉→爱不爱→欲→念→思」逆推苦的因缘，问到灭戏论之道与解脱标准；后者写佛把婆罗门教少年善生「礼拜六方」的习俗，重释为六种人伦之间双向的义务，是在家伦理的代表作（与巴利《长部》的《帝释所问经》《善生经》相当）。

## 二、结构层次
**《释问经》**——「引出→追昔→问法→得果」四段推进：
- **缘起通佛**：帝释闻佛住因陀罗石室 → 命五结乐子先通，弹琉璃琴唱四类歌偈（欲相应、龙相应、沙门相应、阿罗诃相应）→ 佛从三昧起 → 帝释三自称名，佛令近坐，石室忽然广大。
- **追昔证法**：五结乐子自述往昔佛初成道时求耽浮楼王女贤月色而不得，住彼女后歌四类偈，得女回顾含笑之应（事后帝释以贤月色嫁与五结作妇）；帝释亲述三事——昔佛入定石岩中遣鞞沙门王家妾槃阇那代为问讯、瞿毗释女转女成男生三十三天为帝释子、亲见三比丘堕伎乐宫受瞿婆天子偈诃责，偈颂群插于长行之中。
- **问法主体**：佛许帝释「自恣问」，形成固定节律：帝释问 → 佛答 → 帝释复述印可「断疑度惑」→「欢喜奉行」。问的内容层层递进：种种身的二结（悭嫉）→ 爱不爱 → 欲 → 念 → 思（一条逆推的缘起链，收于「纯大苦阴集灭」）→ 灭戏道迹（八支圣道）→ 断三法行三法（念、言、求）→ 六根护从解脱 → 喜忧舍 → 沙门梵志所说不一（界差别）→ 得至究竟与否（爱尽解脱）。
- **收束**：帝释自陈发愿舍天身下生人间出家求究竟智，佛问其因 → 帝释言今坐即于此身增寿见果 → 闻法远尘离垢得法眼净，自归三宝受优婆塞 → 赏五结乐子，与诸天礼佛隐没；梵天夜旦来印证「婆娑婆问事」。

**《善生经》**——「破→立」两步：
- **破**：善生依父遗教清晨沐浴向六方礼拜 → 佛先说四种业秽（杀盗淫妄）、四恶因（欲恚怖痴）、六非道（种种戏、非时行、饮酒放逸、亲近恶知识、喜伎乐、懒惰，各举六灾患）→ 再辨「四似亲」与「四善亲」。
- **立**：逐一正释六方——东方父母、南方师徒、西方夫妇、北方主仆、下方亲友、上方施主与沙门梵志，每方皆「二俱分别」（双方各以几事相待）→ 结以四摄事与分财理财偈。

## 三、关键结论
- 天、人、阿修罗等种种身共有二结：悭与嫉；悭嫉因爱不爱，爱不爱因欲，欲因念，念因思——思灭则纯大苦阴灭。
- 灭戏论之道即八支圣道；修行功夫全在「可行、不可行」的二分取舍：念、言、求、六根触境乃至喜忧舍，凡增善法者成就之，增恶法者断之。
- 世间沙门梵志各执一说，因所知「界」不同；唯于无上爱尽得正善心解脱者，才真至究竟梵行。
- 世俗伦理以「礼事—回报」双向成立，各尽其分则「必有增益，无有衰耗」。

## 四、易混辨析
- **须陀洹 vs 阿那含**：帝释自说得须陀洹（预流，初果），发愿未来得阿那含（不还，三果，生色究竟天）——一为现前果位，一为期望趣向。
- **喜、忧、舍三受**：佛说三者皆各分「可行、不可行」，不是一概断除，而看其增长善法还是恶法。
- **似亲 vs 善亲**：知事、面前爱言、言语、恶趣伴四种「非亲似如亲」貌似亲近实夺财陷害；同苦乐、愍念、求利、饶益四种才是真善亲。
- **四摄事 vs 六方**：惠施、爱言、行利、等利是摄受众生的总纲；六方则把总纲落到父母、师徒、夫妇、主仆、亲友、施主—沙门六重具体名分上。

## 五、阅读提示
带着两问去读：帝释身为天主、五欲自足，为何反而发愿舍天身下生人间？（天乐无常，闻法信戒之乐胜于天福）六方礼拜本是求福仪式，佛为何把它重释为人伦义务？（宗教仪式转为在家道德，福由尽责而来）
