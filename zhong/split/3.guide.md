# 中阿含经卷第三 导读

## 一、内容总览
《中阿含经》卷第三，属**业相应品第二**（品题称十经，本卷收其前七经：盐喻、和破、度、罗云、思、伽蓝、伽弥尼）。全卷围绕一个主题——**业与果报**：什么决定报的轻重、外道对业的误解如何破、防止造业的关键何在、已造之业能否转化。七经同扣「业」字，是理解佛教业报观的纲要之卷。

## 二、结构层次
- **盐喻经**（总起）：立宗「随人所作业则受其报」→ 以一两盐投入少水（咸不可饮）与投入恒水（不觉其咸）对比 → 夺羊、负债四喻反复演练 → 结论：**修身、戒、心、慧**者重业轻受（现世报），不修者轻业重受（地狱报）。
- **和破经**（对外道）：尼干（耆那教）弟子和破与目连问答 → 佛判：身口意护、无明尽明生者，善护不生不善漏 → 树灭则影绝之喻 → 和破三番自归佛法僧。
- **度经**（破立结构）：先逐破外道三种「度处」——宿命造、尊祐造、无因无缘，谓其令人放弃善恶取舍 → 再立佛自知自觉法：六处、六界 → 以六界合故生胎，六处→更乐→觉 → 归结四圣谛。
- **罗云经**（对爱子）：水器四喻（少水、泻尽、覆、仰）教罗睺罗不得戏笑妄言 → 王大象护鼻喻 → 偈颂 → 镜喻：身口意三业于**将作、现作、已作**三个时段皆当观察净秽、为自为他。
- **思经**（定义）：「故作业」必受报，不故作业不必受报 → 详列身三、口四、意三十种不善业 → 以修**慈心解脱**（悲、喜、舍同）净化业：恶业不能牵引，得阿那含。
- **伽蓝经**（答疑）：伽蓝人问「沙门梵志各称己毁他，何所信从」→ 佛教以贪恚痴为业之因，离十不善业、修四无量 → 得**四安隐住处** → 伽蓝人尽自归。
- **伽弥尼经**（收束）：天人子伽弥尼请佛令恶人命终生天 → 佛以重石沉水不能祈浮、酥油破瓶自然浮上二喻答：**业各随其类，非他人称叹所能移**。
- 七经皆以「我闻如是……欢喜奉行」「某经第几竟」首尾呼应，是口诵结集体例。

## 三、关键结论
- 果报轻重不完全由业的大小决定，而在行者是否修身、戒、心、慧——重业可轻受，轻业可重受。
- 唯「故意作业」必受其报；非故作则不定受报。
- 宿命论、神造论、无因论都取消善恶责任，故佛破之，自立六处六界、四圣谛。
- 妄语是众恶之门：「知已妄言，不羞不悔，无惭无愧」者无恶不作。
- 修慈心等四无量能转化旧业：恶业「不能将去、不能秽污、不复相随」。

## 四、易混辨析
- **地狱之报 vs 现法之报**：后者指今生即受的果报（现报），与「现法」相对的是后世的地狱等重报。
- **宿命造 vs 尊祐造 vs 无因无缘**：定命论（一切由前世注定）↔ 神意主宰论（一切由尊贵天神创造）↔ 偶然无因论，三者同被破斥。
- **苦习 vs 苦灭**：「习」训「集」，苦习＝苦生起之因（渴爱）；苦灭＝爱尽之灭，正对四圣谛之集、灭二谛。
- **伽蓝人**：此处是族姓名（Kālāma，羁舍子村民），非「寺院」义的伽蓝。

## 五、阅读提示
带着「什么决定果报的轻重」这一个问题读全卷——盐、羊、债、水器、大象、重石、酥油瓶，每个譬喻都在回答它。
