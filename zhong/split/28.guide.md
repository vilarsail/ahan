# 中阿含经卷第二十八 导读

## 一、内容总览
本卷为《中阿含经》卷第二十八，属"林品"（第二小土城诵），收四经：（一一三）诸法本经、（一一四）优陀罗经、（一一五）蜜丸喻经、（一一六）瞿昙弥经。前二经在舍卫国胜林给孤独园对比丘说法；第三经起于佛陀回故乡迦维罗卫，由"宗本"之问答引出大迦旃延解经；第四经记大爱道瞿昙弥求出家、佛为女众立八尊师法（八敬法）而许其受具足戒，是研究比丘尼僧团成立的第一手文献。

## 二、结构层次
四经并列，各自独立成篇，同属"林品"：
- **诸法本经**：外道问"一切诸法以何为本" → 九问九答（欲为本 → 更乐为和 → 觉为来 → 思想为有 → 念为上主 → 定为前 → 慧为上 → 解脱为真 → 涅槃为讫）→ 结劝修习种种想（无常想、不净想、死想等）→ 断爱除结、便得苦边。
- **优陀罗经**：举佛的仙人旧师优陀罗罗摩子为反面例证——自称一切知而实无，修至非有想非无想处，寿尽犹生狸中 → 正说正观六更触、知三觉 → 剖析"痈"（此身）、"痈本"（三爱）、"痈一切漏"（六更触处）→ 嘱比丘往无事处燕坐，勿得放逸。
- **蜜丸喻经**：情节最曲折——执杖释拄杖问佛"以何为宗本" → 佛略说"不爱、不乐、不着、不住，是说苦边"而入室燕坐 → 诸比丘以佛未广分别，往请大迦旃延 → 迦旃延自谦后广分别：缘根境识三事共会生更触 → 觉 → 想 → 思 → 念 → 分别 → 诸比丘回禀，佛印可并说蜜丸之喻 → 阿难请经名，得名"蜜丸喻"，嘱讽诵读。
- **瞿昙弥经**：瞿昙弥三次问"女人可得第四沙门果耶" → 三次被拒（一而再、再而三的复沓笔法）→ 阿难代请 → 佛设二喻（多女少男之家、田中秽生）明女人出家令梵行不得久住 → 阿难以"瞿昙弥鞠养世尊"之恩再请 → 佛说八尊师法，瞿昙弥欢喜顶受而出家 → 卷末佛警示：正法本住千年，今失五百岁，且女人不得作佛、转轮王等五事。

## 三、关键结论
- 诸法相待而起：欲为本、更乐（触）为和、觉（受）为来、思想（想）为有，乃至念为上主、定为前、慧为上、解脱为真、涅槃为讫。
- 身是痈，三爱是痈本，六更触处是痈一切漏；修行之要在拔爱断漏，而非上求非想非非想处——定境再高，福尽还堕。
- 认知层层相依：三事共会生触，缘触有受（觉），觉生想、想生思、思生念、念生分别；于过去未来现在诸法不爱、不乐、不着、不住，即是苦边。
- 女众于正法、律中出家受具足，以尽形寿奉持八尊师法为条件；佛并预言正法因此由住世千年减为五百年。

## 四、易混辨析
- **更乐 vs 觉 vs 想 vs 思 vs 念**：更乐即"触"的旧译，觉即"受"。蜜丸喻给出完整认知链：三事共会生更乐（触）→ 缘更乐有所觉（受）→ 觉生想 → 想生思 → 思生念 → 念生分别。诸法本经"以欲为本、以更乐为和、以觉为来、以思想为有"正是这条链的浓缩。
- **痈 vs 痈本 vs 痈一切漏**：痈指此身（四大所成、无常坏散之毒疮）；痈本指三爱（欲爱、色爱、无色爱）；痈一切漏指六更触处（眼耳鼻舌身意六根门漏落烦恼）。三者是"疮——病根——溃漏之处"的关系。
- **燕坐 vs 受夏坐**：燕坐（后文亦作"宴坐"，异写）是日常独处静坐禅思；受夏坐是雨季三个月的结夏安居，须有比丘住处方得受。
- **僧伽婆尸沙 vs 行不慢**：僧伽婆尸沙是律中重罪（僧残）；"行不慢"是犯此罪者于两部众中行十五日的除罪仪程，二者是罪与治罪法的关系。

## 五、阅读提示
可带着"佛如何应对不同问者"的问题读本卷：对外道九问，给出缘起序列的正面回答；对执杖释，略说而不与辩（"不是不非，奋头而去"）；对瞿昙弥，以制度（八尊师法）作答。三种应对方式，本身就是读这四经的一条暗线。
