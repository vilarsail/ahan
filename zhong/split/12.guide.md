# 中阿含经卷第十二 导读

## 一、内容总览
本卷属《中阿含经·王相应品》，收两经：（六三）鞞婆陵耆经、（六四）天使经，均标「初一日诵」。前经是本生故事：佛在一处迦叶佛旧讲堂遗址微笑，借阿难之问追述自己过去世——迦叶佛时为婆罗门童子优多罗，由在家第一的陶师难提波罗引路，从迦叶佛出家；又借迦尸颊鞞王请安居被拒、陶师供佛却事事随顺的对比，说明供养的分量在受者的清净德行，不在财物多少。后经佛以净天眼见众生随业升沉，借阎罗王审问罪人的「五天使」——生、老、病、死与王法刑戮——警策世人勤修妙行，并铺陈地狱诸苦、业尽方出，以阎王发愿生人间出家作结。

## 二、结构层次
**前经（鞞婆陵耆经）**：现前缘起 → 宿世追述 → 王与陶师对比 → 点破自述
- 缘起：佛行道中路笑 → 阿难问笑因 → 佛指此处是迦叶佛说法旧地 → 阿难敷座请佛坐此说法。
- 追述：鞞婆陵耆村 → 优多罗童子 ↔ 陶师难提波罗：陶师逐条离杀、盗、淫、妄及种种受蓄（戒目铺陈两遍：对阿难一遍，对颊鞞王又一遍）→ 佛自取饮食、拆陶屋覆佛屋皆欢喜无碍。
- 推进：陶师引优多罗见迦叶佛 → 优多罗求出家 → 颊鞞王五百房、五百车米之供被婉拒 ↔ 陶师一碗麦饭一釜豆羹却令佛「随意自在」。
- 收束：佛自认「尔时优多罗即是我」，过去说法「不至究竟」↔ 今成佛说法「得至究竟」，显今佛之胜。

**后经（天使经）**：总说 → 五喻 → 五天使 → 地狱 → 阎王发愿 → 偈颂
- 总说：净天眼见众生身口意善恶业，身坏命终升善处或堕恶处。
- 五喻连排（水泡生灭、雨渧上下、琉璃珠、两屋一门、高楼观下），同一句式反复演练，喻天眼观生死之分明。
- 五天使：生（婴孩）→ 老 → 病 → 死 → 王法刑罚，每段同一套式：「汝颇曾见某天使来耶？」→ 罪人早曾亲见却未修行 → 阎王断语「汝本自作恶不善业，是故汝今必当受报」。
- 地狱长文：四门大地狱 → 峰岩 → 粪屎 → 铁鍱林 → 剑树 → 灰河，环环递进，反复出现「受极重苦，终不得死，要令彼恶不善业尽」，业尽乃转入畜生、饿鬼或生天。
- 结：阎王自述发愿生人间、出家学道、证无上梵行 → 偈颂收束。

## 三、关键结论
- 恶业自作自受：「汝此恶业非父母为，非王非天，亦非沙门、梵志所为」，无可代赎，必当受报。
- 供养以德行为胜：受供者的清净胜过国王五百车米的排场。
- 生老病死及刑罚即「天使」，见者应自念「我自有生老病死法」而修妙行，不可放逸。
- 过去佛说法尚不究竟，唯今释迦佛「究竟白净、究竟梵行」，能令众生脱一切苦。
- 「无受灭无余，便为生老讫」：不执取则苦灭，即阎王亦发愿于现法出家证灭度。

## 四、易混辨析
- 「非梵行」≠「不修圣行」：此处「梵行」特指不淫，故「离非梵行」即离淫欲。
- 「苦、习、灭、道」之「习」：非「练习」，是「集」的古译，四谛即苦、集、灭、道。
- 佛「受郁单曰法」自取羹饭 vs 偷盗：郁单曰（北俱卢洲）财物公有、随取随用，佛依其俗自取，不算犯「不与取」。
- 「患漏」之「漏」：谓佛屋「竟夏四月都不患漏」，是屋顶漏雨，非「烦恼漏」义。
- 「天使」：非天人的使者，而是生、老、病、死、王法刑戮五种警世示现。

## 五、阅读提示
前经抓「王的厚供被拒 ↔ 陶师的薄供随顺」一条对比线及末尾「尔时优多罗即是我」的点题；后经不必为地狱名目所困，盯住五天使的重复套式与「终不得死，要令彼恶不善业尽」一句，即得全经意旨。
