# 中阿含经卷第三十二 导读

## 一、内容总览
本卷为《中阿含经》卷三十二《大品》所收第133经《优婆离经第十七》（相当于巴利《中部》56经）。佛在那难陀城的波婆离柰林，与耆那教（尼揵）教团展开一场关于「什么是造恶的根本」的著名论辩：外道主张身罚（苦行禁制）最重，佛主张意业最重。论辩的结果是外道大施主优婆离居士当场归佛证果，其师尼揵亲子气绝而亡。全经是佛世佛与外道争信众、以理服人的经典样本。

## 二、结构层次
全经以「立论 → 请战 → 论辩 → 归信 → 对决 → 结局」一线推进：
- **立论交锋**：长苦行尼揵与佛对答，佛再三「审定」其师之说（身罚最重、意罚最下）→ 苦行返告其师，其师大加赞叹，反衬外道的自以为是。
- **请战与劝阻**：优婆离居士自负辩才，誓要「降伏已还」→ 长苦行两度劝阻（恐佛以「幻化咒」化其为弟子），尼揵亲子两度不许，埋下「到底谁化度谁」的伏笔。
- **层层设问**：优婆离至佛所，佛先令其立誓「住真谛以真谛答」，再连设三问（尼揵断水而亡生「意着」天、屠人不能一日剁尽那难陀众生、仙人一瞋念能烧尽国土）→ 优婆离前后自违，自悟「意业为最重」，三自归命。
- **归信余波**：佛嘱「默然勿宣」「随力供养旧师」→ 优婆离倍加敬信，回家后拒尼揵于门外、只出食供养，显佛不夺人旧福的胸怀。
- **上门对决**：尼揵亲子率五百人问罪 → 优婆离高座结跏趺坐，以「猕猴戏具染不得捣」↔「波罗奈白衣染捣皆可」一喻收束全经：外道法经不起难问思择，佛法堪受锤炼。
- **偈颂赞佛 → 结局**：优婆离诵长偈赞佛赞己，尼揵亲子吐热血，至波和国命终；优婆离远尘离垢、法眼生，证果收束。

## 三、关键结论
- 身口意三业之中，**意业（思）为造恶最重**——业的根本在心念，不在身口的禁制苦行。
- 衡量教法高下的标准是**能否堪受难问、经得起思惟观察**：猕猴染不得捣，白衣染捣皆可。
- 布施得福**不分自他，只看受施者是否精进**——破「当施与我，莫施与他」的门户之见。
- 佛教化在家人有次第：先说**端正法**（施、戒、生天），根基成熟再为说**四圣谛**。

## 四、易混辨析
- **罚 vs 业**：尼揵以「罚」（戒禁、苦行约束）止恶，是外在管制；佛以「业」（身口意造作）说止恶，重心在内心之思。一字之差，是本经全部论辩的焦点。
- **优婆离居士 vs 优波离尊者**：本卷的优婆离（婆离）是那难陀的在家富商，归佛后居家证果；并非佛十大弟子中持律第一的优波离尊者。
- **苦、习、灭、道 vs 苦、集、灭、道**：同一四圣谛，古译以「习」表「集」（招集苦果之因），读时不可误作「修习」义。

## 五、阅读提示
带着一个问题读：佛自始至终不正面驳斥「身罚最重」，而是让优婆离在自己答应过的「住真谛」承诺下自相矛盾——对比尼揵亲子只靠赞叹弟子与咒骂对手的做法，谁在论理、谁在护短，一望即知。
