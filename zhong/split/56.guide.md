# 中阿含经卷第五十六 导读

## 一、内容总览
《中阿含经》卷五十六，属《晡利多品》（第五后诵），收三经：二〇四《罗摩经》、二〇五《五下分结经》、二〇六《心秽经》。三经同为「修道通例」类经典：佛陀自述求道成佛经历，立「圣求」典范；说五下分结的受持正解与断除道迹；说比丘心中五秽五缚不除则必退、除则清净乃至涅槃。

## 二、结构层次
**《罗摩经》**（佛自述成佛经历，一线直贯）：
- **缘起**：佛于鹿子母堂燕坐毕，与阿难往阿夷罗婆提河浴 → 至梵志罗摩家，见比丘集坐说法，赞「比丘集坐当行二事：一曰说法，二曰默然」。
- **立宗**：开讲「二种求」——非圣求：自身实是病、老、死、愁忧戚、秽污法，反而去求这些；圣求：知其实为病老死秽，转求「无病、无老、无死……无上安隐涅槃」。
- **自述**：佛二十九岁出家 → 先从阿罗罗伽罗摩证「无所有处」，再从郁陀罗罗摩子证「非有想非无想处」，两度判断「不趣智、不趣觉、不趣涅槃」而舍之 → 于尼连禅河畔、觉树下「要不解坐」，得无上正尽觉。
- **初转法轮**：欲先度二师，均已命终，遂往波罗㮈度五比丘——优陀途中问师，佛以偈答「自觉谁称师」；五比丘先约不迎礼，见威德而不能自持 → 破「着欲乐」与「自烦自苦」二边，立中道八正道 → 以野鹿离猎师之缚喻漏尽者「自在行住坐卧」，点出「无余解脱、无上安隐涅槃」。

**《五下分结经》**（问答推进）：
- 佛问「我曾说五下分结，汝等受持耶」，众默然 → 鬘童子自认受持却错解（以为初下分结是身见等，第五是欲恚）→ 佛以**婴孩喻**诃责：婴孩仰眠无欲想、无众生想，然「性使」潜藏故，说欲使、恚使等——结非从眼前心念来。
- 阿难请法 → 佛说正受持：缠一生起「即知舍如真」则结灭；断结必「依道、依迹」，以持斧入林截根茎方得果实为喻。
- **修道路径**：依四禅 → 空处 → 识处 → 无所有处，层层「升进得止息处」；于所受（觉）观无常、兴衰、无欲、灭、断、舍 → 不受此世、不恐怖 → 般涅槃；又以芭蕉中无实喻受无实体。
- 结尾：阿难叹诸比丘「不速得无上」，佛答「人有胜如故，修道便有精粗」。

**《心秽经》**（正反对照）：
- 先说「必退法」：不拔心中五秽（疑世尊／法／戒／教、责数轻毁梵行）、不解心中五缚（身染欲、于欲不离、闻正说不趣向、数与道俗共会、得少为足不复求升进）。
- 再反说「清净法」：善拔五秽、善解五缚 → 住此十支已，复修五法（欲定断如意足、精进定、心定、思惟定等，依离、无欲、灭、舍）。
- **母鸡孵卵喻**收束：鸡子自以㭰以足啄破卵壳安隐而出——喻比丘成就十五法者必至甘露门、必得涅槃。

## 三、关键结论
1. 求道分「圣求／非圣求」：别在是否如实知自身与所求皆病老死秽之患，圣求者转求无病、无老、无死、无秽污的无上安隐涅槃。
2. 外道最高定境（无所有处、非有想非无想处）不趣智、不趣觉、不趣涅槃，故佛两度舍之，别求正道。
3. 五下分结如「性使」潜藏（婴孩亦有），断除必依道依迹，循四禅、四无色定升进，于所受观无常、无欲、灭、断、舍，方得般涅槃。
4. 心中五秽五缚不除，修道「必退」；「得少为足、不复求升进」本身就是一缚。
5. 「人有胜如，修道有精粗」——同在修行，进度高下因人而异，不必齐等。

## 四、易混辨析
- **非圣求 vs 圣求**：二者皆在「求」，区别只在能否如实知病老死秽的过患——不觉而求其类为非圣，知患而求无患为圣。
- **五下分结 vs 五盖**：五下分结（欲、恚、身见、戒取、疑）是系缚人于欲界的结使，须依道迹禅定断除；五盖（本卷《罗摩经》亦提及）是现前障碍禅定的遮蔽，二者层次不同。
- **心五秽 vs 心五缚**：秽是「意不靖」的疑与轻毁（对佛、法、戒、教、梵行）；缚是身欲、闻法心不趣向、好聚会、得少为足等令心「不趣向、不住、不解」的缠缚。
- **无所有处 vs 非有想非无想处**：无色界第三、第四定，佛未成道时先后从二外道师证得，是外道所极、非究竟解脱处。

## 五、阅读提示
带着两个问题读：「佛陀为何舍弃两位老师的最高定境？」与「婴孩喻究竟驳斥了鬘童子怎样的受持？」——即可抓住三经一以贯之的线索：唯有依正道逐层升进、观受无常无实，才得「无病无上安隐涅槃」。
