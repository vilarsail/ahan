# 中阿含经卷第五十八 导读

## 一、内容总览
本卷为《中阿含经》卷第五十八，属「晡利多品」（第五后诵），收两经：（二一〇）《法乐比丘尼经》与（二一一）《大拘絺罗经》。两经均为问答体论议经，主体由一连串简短的「问—答—叹善哉—欢喜奉行」构成，集中辨析名相：五盛阴、身见、八支圣道、灭尽定、三受、三解脱门等；但并非全无叙事与譬喻——（二一〇）有毗舍佉稽首礼足、问毕绕三匝而去、比丘尼诣佛求印证的叙事框架，（二一一）说寿暖「合不别」时举「油炷灯焰」之喻。前经是在家女信众问比丘尼，后经是比丘问比丘，一僧一俗、一女一男，恰成对照。

## 二、结构层次
本卷两经并列，各以「逐条问答」一线到底：

**（二一〇）法乐比丘尼经**：毗舍佉优婆夷问法乐比丘尼——
- **自身四问**：何谓自身（答：五盛阴）→ 何谓自身见（答：于五阴执「神/我」的四种妄见）→ 何谓无身见（圣弟子不见神我）→ 何谓自身灭（五盛阴断尽）→ 进问阴与盛阴是一是异（答：有漏有受即是盛阴，无漏无受则非）。
- **道品四问**：八支圣道 → 道有为 → 三聚（戒定慧）→ 三聚摄八道支而非相反。
- **定与死**：初禅五支 → 定、定相（四念处）、定力（四正断）、定功（四如意足）、修定 → 死与入灭尽定的差别（寿暖识去否）。
- **灭尽定与无想定**：入定差别（想知灭与不灭）→ 起定差别 → 入定不起念、以本修习故趣向 → 起定后心乐离。
- **受论**：三觉（乐苦不苦不乐）皆缘更乐 → 三觉各如何乐、如何苦、如何无常灾患、为何使所使 → 但非一切乐觉皆欲使（如初禅乐、求解脱之忧、四禅舍皆反证）→ 层层问「对」：乐苦互为对、不苦不乐以无明为对、无明以明为对、明以涅槃为对、涅槃无对 → 尾声：比丘尼诣佛求印证，佛认可以此问答即是佛说。

**（二一一）大拘絺罗经**：舍黎子问大拘絺罗——
- **善不善章**：不善与不善根（三恶行、贪恚痴）↔ 善与善根（三妙行、不贪不恚不痴）。
- **慧与识章**：何谓智慧（知四圣谛）→ 何谓识（识色声香味触法）→ 智与识「合不别」，不可别施设 → 智慧有厌、无欲、见如真三义 → 正见及其二因二缘 → 五支摄正显得心、慧解脱。
- **生死章**：生当来有（无明覆、爱结系）↔ 不生当来有 → 三觉缘更乐 → 觉、想、思三法合不别 → 五根异行异境界，意为依 → 意依寿、寿依暖，寿暖合不别（油炷灯焰之喻）→ 寿暖识三法离身则如木无情。
- **定论章**：死与灭尽定、灭尽定与无想定、起定差别 → 入定先灭身口意三行、起定先生意口身三行 → 起定触三触（不移动、无所有、无相）→ 空、无愿、无相异义异文 → 不移动定（第四禅）、无所有定、无想定的因缘——卷末二尊更相称叹而散。

## 三、关键结论
- 五阴有漏有受即是「五盛阴」（苦聚），无漏无受则五阴非盛阴——身见与苦的根源在漏与受，不在阴本身。
- 三受各为一使所使：乐觉为欲使、苦觉为恚使、不苦不乐觉为无明使，但修道所生的禅乐、求解脱之忧、四禅之舍不受三使所缚。
- 问至极处成一条链：乐苦→不苦不乐→无明→明→涅槃，而涅槃「无对」，不可与任何对待之法并立。
- 智慧与识、觉与想与思、寿与暖，皆是「合不别、不可别施设」——所知即所识，功能不同而体一。
- 死与入灭尽定的分判在寿、暖（及识）：死则三者俱离，入定则寿暖不去、诸根不坏。

## 四、易混辨析
- **五阴 vs 五盛阴**：五阴是色受想行识的通称；「盛阴」特指有漏、有取著的五阴，即苦聚的当下，无漏五阴不名盛阴。
- **灭尽定 vs 无想定**：灭尽定中「想及知（了知）」俱灭，出定不起「我出定」之念；无想定只是压伏想而「想知不灭」，出定反生「我为有想、为无想」之疑。
- **死 vs 入灭尽定**：死者寿灭、暖去、诸根败坏；入定者三者俱存，故身不坏。
- **智慧 vs 识**：识以了别六尘为相，智慧以知四谛如真为相；但「智慧所知，即是识所识」，二者所依境不二，故不可分开安立。
- **欲使 vs 恚使 vs 无明使**：随三受而起的三种随眠烦恼——贪欲随乐受起，瞋恚随苦受起，无明随不苦不乐受起。

## 五、阅读提示
带着两个问题读：一是「涅槃为什么无对」——顺着乐苦→无明→明→涅槃的「对」链体会极限；二是「寿、暖、识三法」如何界定生死与定的边界——这是本卷最有医学与禅观意味的段落。两经问答高度重合处（三觉、灭尽定诸问）可对照读，见早期论议经的共有骨架。
