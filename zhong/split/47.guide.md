# 中阿含经卷第四十七 导读

## 一、内容总览
本卷为《中阿含经》卷四十七，属「心品」（第四分别诵），收四经：（一七八）猎师经、（一七九）五支物主经、（一八○）瞿昙弥经、（一八一）多界经。四经皆以「心」为枢纽：前二经辨修行人被什么系缚、善恶从何而生；后二经讲布施福报的层级、以及破除愚痴所须了知的法类。卷末「多界经」是一篇纲领性的法数总集。

## 二、结构层次
- **猎师经**：猎师饲鹿之喻 → 四群鹿四种应对，层层淘汰 → 法合为四类沙门梵志 → 正面立宗「魔所不至处」。
  - 第一群鹿贪食猎师食 → 憍恣放逸 → 随猎师被猎 ↔ 喻贪受世间信施利养而堕魔王境。
  - 第二群鹿避入深山苦行 → 春后草木水尽、身体极羸 → 仍被猎 ↔ 喻舍弃信施却因苦行羸弱、定慧衰退而复堕。
  - 第三群鹿「依住不远」 → 猎师作长围罝网住 ↔ 喻虽离利养但「受持二见」（有见、无见），仍被邪见之网罩住。
  - 第四群鹿依住猎师所不至处 → 猎师舍罝而去 ↔ 喻依第四禅、慈悲喜舍四无量、无色界定乃至想知灭、诸漏尽断知，方是魔王眷属所不能至。
- **五支物主经**：外道文祁子立论「身不作恶业、口不恶言、不行邪命、不念恶念」即第一义沙门 → 物主持疑问佛 → 佛以婴孩反破（婴孩尚无身想、口想、命想、念想，岂非已成圣者？）→ 正说：戒从心生，念从想生 → 依次说不善戒、善戒、不善念、善念各自的「从何而生—何处灭无余—云何行灭」→ 收摄于「因正见故生正志……因正念故生正定」，学人八支、漏尽阿罗诃十支，才是真「质直沙门」。
- **瞿昙弥经**：佛姨母大生主献金缕衣 → 佛三拒令「施比丘众，施众已便供养我」→ 阿难请问 → 佛说因人而得自归三尊、不疑苦习灭道者，物供不足以报恩 → 展开七种施众、十四私施的福报等差 → 归结四种布施「三净施」（施主净、受者净、俱净、俱不净）→ 偈颂收束。
- **多界经**：阿难独坐思惟「恐怖、灾患、忧戚一切从愚痴生」 → 佛印可并以苇秸生火烧楼阁为喻 → 问答展开四门：知界（十八界乃至共六十二界）、知处（十二处）、知因缘（缘起还灭）、知是处非处（以「终无是处／必有是处」的对句逐一列举）→ 结出经名「多界」，兼摄法界、甘露界、法镜等名。

## 三、关键结论
- 贪受利养则随魔，逃避利养而无定慧支撑仍随魔；唯有依禅定、四无量乃至漏尽，才是魔王力所不及的依止处。
- 善、不善戒从心生，善、不善念从想生；以慧如实知其生处与灭处，即能灭之——道支由正见起，次第生正志乃至正定，心定则解脱淫怒痴。
- 施于僧众即等于供养佛；布施福报随受者道果位次悬殊（施畜生百倍至施如来无量），而以施者、受者双方精进有信为最净。
- 一切恐怖、遭事、灾患、忧戚皆从愚痴生，不从智慧生；对治之道在知界、知处、知因缘、知是处非处。

## 四、易混辨析
- **四类沙门梵志**：第一贪利养放逸、第二苦行避世（羸弱反堕）、第三离利养却执有见无见二见、第四依禅定漏尽而脱——「离欲」不等于「离见」，第三种正是败在邪见。
- **不善戒 vs 不善念**：戒指身、口、意的行为造作，从不善心（有欲、有恚、有痴）生；念指欲念、恚念、害念，从想生。二者生处不同，灭处也不同（前者灭于修身口意善业，后者灭于得初禅）。
- **七施众 vs 十四私施**：向比丘众、比丘尼众等「众」布施，福在僧田、稳定广大；向特定个人布施，福随受者身份果位上下悬殊。
- **学八支 vs 阿罗诃十支**：有学圣者成就「学正见至学正定」八支；漏尽阿罗汉成就「无学正见至无学正智」十支——同一道支，有学带「学」字而未圆，无学圆满并更增无学之智。

## 五、阅读提示
带着两问读：我日常受用的利养，是在喂养我，还是在围猎我？恶与恐怖从何而来、从何而断？猎师经与五支物主经正好给出「境」与「心」两面的答案。
