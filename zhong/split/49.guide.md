# 中阿含经卷第四十九 导读

## 一、内容总览
本卷为《中阿含经》卷四十九，属「双品第一」之首五经（第一八七～一九一经，标为「第五后诵」）。五经围绕一条总线索展开：如何验证一个自称漏尽（烦恼断尽）的比丘是否真实，以及与此配套的修行地图——从持戒、护根、离盖、得定到观空。前两经谈「验证」，第三经谈「道品」，后两经（小空、大空）是本经最著名的空观修行次第。

## 二、结构层次
本卷五经并列而内在递进，可作三层读：
- **验证漏尽者**（说智经）：佛先立总纲——闻比丘自称「我生已尽」当善然可，但须追问 → 依次以五盛阴、四食、四说、内六处、六界、断我慢六组法义层层勘验 → 再令其自述出家因缘与修行全程（舍家 → 持戒净心 → 知足护根 → 独住离盖 → 第四禅 → 知四谛漏谛而漏尽），一问一答如资格考试。
- **反例与决疑**（阿夷那经）：外道阿夷那之师自称「一切知」反遭难诘，是「非法众」的活标本 → 佛略说法众、非法众 → 诸比丘请阿难广分别「法、非法，义、非义」→ 阿难以正见生善、邪见生恶广说 → 佛印可，显「弟子能广分别师之略说」的僧团学风。
- **修行地图**（圣道→小空→大空）：圣道经讲八正道——圣正定以正见至正念七支为习、助、具，正见最在其前；正见至正智，「学者成就八支，漏尽阿罗诃成就十支」，并以二十善品、二十不善品合成四十大法品转梵轮 → 小空经把「多行空」排成拾级而上的阶梯：空村想→空人想→存无事想→存地想→无量空处→无量识处→无所有处→无想心定→空三漏，层层「空于下、存于上」，最后唯余六处命存而漏尽 → 大空经把这阶梯落到日用：先持内心一定，念内空、外空、内外空、不移动，不成则退而调御其心再进，并以正知贯穿经行、坐定、起念、说法诸事，末了以「烦师、烦弟子、烦梵行」警策独住者勿因还家聚众而染污。

## 三、关键结论
- 验证漏尽不在自称，而在能否于五阴、四食、六入、六界等一一知见「无所受、漏尽心解脱」。
- 圣正定不是单打独斗：以正见为首的七支为修习之缘，正见能照见邪见，正方便求断、正念持守，方入正定。
- 行空的要诀是「空于所无、见于实有」：此中无者见空，此中有余者见真实有，不落断无。
- 漏尽犹有此身六处命存之疲劳，唯有空尽三漏方是如来行真实、空、不颠倒之道。
- 独住远离若还恋著弟子眷属、功高还家，则禅悦反成烦热之因。

## 四、易混辨析
- **小空经 vs 大空经**：小空经以「所缘」层层换替作空（由村想直上无想心定）；大空经以「内空、外空、内外空、不移动」就心之住处作空，兼说日常正知与事师之道。
- **更乐 vs 意念**：四食中「更乐」即触食，以根境识相触为滋养；「意念」即思食，以意欲思愿为滋养。
- **正方便 vs 正念**：正方便是四正勤——断已生恶、防未生恶、生未生善、住增已生善；正念是观身受心法、如念而住。
- **学者八支 vs 阿罗诃十支**：有学之人具正见至正定八支；漏尽阿罗汉则加无学正解脱、无学正智成十支。
- **烦师 vs 烦弟子 vs 烦梵行**：三者同是「得定还家、功高聚众」而染烦热，只是施点不同——师自身、弟子效师、乃至如来所立的梵行传承；如来独住则唯为现法乐居与慈愍后学，不在此列。

## 五、阅读提示
读时可自问：若有人对我说他已证漏尽，我该按经中哪几问去勘验？小空经的十级阶梯，每一级「空」掉了什么、又「存」下什么？大空经说独住本为离烦，为何师徒还家反成大空之障？
