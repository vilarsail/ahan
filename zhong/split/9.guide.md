# 中阿含经卷第九 导读

## 一、内容总览
本卷为《中阿含经》**未曾有法品**（第十七品）的前半，收六经（三六～四一），均属「初一日诵」。全卷主题是「未曾有法」——佛与圣弟子身上稀有难思的功德事迹：大地震动之因、僧团说戒之制、在家长者见佛证果与大布施、以四摄摄众与四无量心修行等。

## 二、结构层次
全卷六经各自独立成篇，以「我闻如是……欢喜奉行」「某经第几竟（若干字）」首尾呼应，是口诵结集体例；六经同归「未曾有」一题：

- **地动经（三六）**：阿难见地动风起、彗星出而生怖 → 问因缘 → 佛答三因缘（空中风起水扰地动 → 有大神通者于地作小想、于水作无量想 → 如来三月后当般涅槃）→ 佛自述于刹利、梵志乃至诸天无量众中「即彼处没」隐没现身、说法教化，人非人莫辨 → 甚奇甚特收束。
- **瞻波经（三七）**：月十五说戒之夜，佛连三夜默然 → 目连入「如其像定」以他心智查出众中「不净比丘」，牵臂逐出 → 佛自此令弟子代说戒，并举大海八种未曾有法喻正法律：渐深成岸（渐作渐学、渐尽渐教）、潮不失时、甚深无底、同一咸味（无欲、觉、息、道之味）、多珍宝（三十七道品）、大神所居（四向四果）、不受死尸、众流入而不增减。
- **郁伽长者经第七（三八）**：长者饮酒大醉，遥见佛即醉醒 → 佛先说端正法（施、戒、生天），再为说四谛，长者「犹如白素，易染为色」即于坐上见法 → 自归三宝、尽形寿五戒、梵行为首 → 归家散财嫁女、以大夫人赠人无悔 → 次日比丘来访，长者自述八未曾有法，佛在大众中称叹印证。
- **郁伽长者经第八（三九）**：佛般涅槃后不久，长老比丘嫌长者布施太甚（又失海船之财），托佛侍者阿难去劝止 → 长者答以「转轮王愿」：从村中最富逐级上达转轮王，最终愿如族姓子出家、现法自证涅槃 → 复举敬礼一切比丘、施无分别、以自净智信佛、得第四禅等自证 → 与第七经平行对照（佛在世 ↔ 佛灭后，佛说法 ↔ 阿难转述）。
- **手长者经第九（四○）**：佛问「以何法摄此大众」→ 长者以四事摄（惠施、爱言、以利、等利）答，佛印可过去未来现在一切沙门梵志皆以此摄众 → 长者还家，一路逢人说法，升堂结跏趺坐，心与慈俱遍满一方乃至一切世间，悲、喜、舍亦然 → 三十三天集法堂称叹，毗沙门天王夜访，长者「以尊重定、守护定故」不观不视 → 佛称其七未曾有法，更补「无求无欲」为第八。
- **手长者经第十（四一）**：佛对诸比丘逐条解说八法——少欲、信、惭、愧、精进、念、定、慧，每法以「此何因说」自问自答，是释经（论议）体例，为第九经的注脚。

## 三、关键结论
- 大地震动有三因缘：风起水扰、神通者作意、如来将般涅槃，第三因缘是本经的着眼点。
- 佛的正法律如大海：渐作渐学、渐尽渐教，甚深一味、圣众所居、不容秽杂。
- 郁伽长者示范在家信行的极致：尽形寿五戒、梵行为首、大施无悔，其愿最终指向出家证果而非世间富贵。
- 手长者外以四摄摄众，内修四无量心与第四禅，天神赞叹而不动其定，佛许以少欲乃至慧八法。

## 四、易混辨析
- **两篇郁伽长者经**：第七经佛在世，叙醉中见佛、闻法证果的因缘；第八经佛灭后，叙阿难劝止大施与长者的「转轮王愿」，所举法目各不相同。
- **两篇手长者经**：第九经是佛在众中称叹其七法并补第八「无求无欲」；第十经是佛对众比丘逐条解释八法的内容，一赞一释。
- **向须陀洹 ↔ 须陀洹**：四沙门果各有「向」（趋向其果而未证）与「果」（已证），合为四向四果、八辈圣者；阿罗诃与向阿罗诃同理。
- **说从解脱 ↔ 受持五戒**：前者是僧团布萨诵戒（波罗提木叉），后者是在家居士所受戒法，一出家一在家，不可混。

## 五、阅读提示
带着「未曾有」凭什么成立来读：每经都在回答「佛／圣弟子稀有在何处」。留意反复出现的套语——「劝发渴仰，成就欢喜」「甚奇！甚特！」「欢喜奉行」，它们既是行文骨架，也是口诵结集的痕迹。
