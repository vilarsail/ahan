# 中阿含经卷第五十七 导读

## 一、内容总览
《中阿含经》卷五十七收三经，均属“晡利多品”（第五后诵）：（二〇七）箭毛经第六、（二〇八）箭毛经第七、（二〇九）鞞摩那修经第八。三经都是佛与外道论辩的记事：前两经的主角是王舍城孔雀林异学园的异学箭毛（佛称他“优陀夷”），第三经的主角是舍卫国的异学鞞摩那修（佛称他“迦旃”）。两场论辩都以外道执见被层层击破收场——一者归依三宝，一者出家乃至证阿罗汉。

## 二、结构层次
**（二〇七）箭毛经第六**——“弟子为什么恭敬佛”：
- 开场：外道园中众人喧论“畜生之论”，见佛来而噤声 → 佛问向论何等。
- 箭毛转述拘萨罗梵志的议论：六师外道（不兰迦叶等）弟子不敬其师、甚至当面责骂而去，唯佛弟子恭敬供养、常随不离 → 提出问题。
- 箭毛自答：佛有粗衣、粗食、少食、粗床座、燕坐五法 → 佛一一否斥：弟子若因这些“苦行表相”而称说，反而不恭敬、亦不相随 → 佛自说真正的五法：无上戒、无上智慧、无上知见、为厌离者答四谛、以宿命/漏尽二通作证明。
- 收束：箭毛叹善说如甘露，自归佛、法、僧。

**（二〇八）箭毛经第七**——从“谁是一切知”到“第四禅最上”：
- 同园同缘开场 → 箭毛自夸有策虑辩才，讥六师自号“一切知”却答不上所问 → 佛答：我有弟子以宿命通知过去、以天眼见善恶果报，随问随答。
- 箭毛自承：此生之事尚不能忆、飘风鬼尚不能见 → 却又执“最胜最上之色” → 佛以“国中美女”喻破其“说最胜而不知”，再以萤火→油灯→积火→太白星→月→日的光明阶梯层层降伏 → 箭毛两番“悔过此说”。
- 佛顺其语转正：说“世一向乐”与“一道迹一向作世证”（皆初三禅；如来自证不共诸天，比丘修得则与诸天戒、心、见等）→ 更上一层：第四禅“乐灭苦灭、舍念清净”才是弟子学梵行所欲作证的最上 → 箭毛欲礼佛足，其弟子出言阻挠作障。

**（二〇九）鞞摩那修经第八**——从执“最色”到证阿罗汉：
- 外道鞞摩那修开口便执“最色最色” → 佛以同样的“美女喻＋光明阶梯”两番破其执。
- 诃责之后“复令欢悦”：说五欲功德、随顺其意 → 彼反生瞋恚，质疑“不知世前际后际者，怎记得究竟智”。
- 佛答“置世前际，置世后际”：以缚缚儿喻（彼唯忆解缚时）、灯油炷尽喻、薪尽火灭喻说正教化 → 鞞摩那修远尘离垢、法眼生，出家受具足，乃至证阿罗诃。

## 三、关键结论
1. 弟子亲近佛不因苦行表相（粗衣粗食少食等），而因戒、慧、知见、应机说法与二种神通证明。
2. 自号“一切知”而答不上所问，不成一切知；佛不执最胜之色，却有宿命、天眼如实作证。
3. 光明阶梯之喻：执为“最上”的境界在层层对比中不过萤火之光；执见不除，便是“问已不知”。
4. “置世前际、置世后际”：解脱不倚赖谈论世界边际；不谀谄、质直、随教而行，必得知正法——如油尽灯灭、薪尽火灭，苦蕴永尽。
5. 外道从“欲为人师”到“愿为弟子”，折服人的是道理与实证，不是高大声量。

## 四、易混辨析
- **第六经外道所举五法 ↔ 佛自说五法**：前者是衣食住卧的知足之相（表），后者是无上戒、无上智慧、无上知见、答四谛、二通作证（里）。
- **世一向乐 ↔ 一道迹一向作世证**：同是初三禅——前者如来自证，“不共彼天戒等、心等、见等”；后者比丘修得，与诸天齐等。二者之上更有第四禅，才是“最上、最妙、最胜”。
- **“记说得究竟智” ↔ “知如真”**：外道不知世边际而妄称得究竟智，为佛所斥；佛弟子“生已尽、梵行已立、所作已办……知如真”是如实所证。
- **畜生之论 ↔ 正法之论**：论王、论贼、论饮食妇人等世俗戏论，与四谛、禅定、作证之道相对。

## 五、阅读提示
带着两问读：外道凭什么被折服？佛如何先破其执（诃责）、再予其路（欢悦、说法），直至归依乃至证果？
