# 中阿含经卷第五 导读

## 一、内容总览
本卷属《中阿含经》舍梨子相应品第三（品含十一经，此处为前五经，经号二一~二五），全部围绕"智慧第一"的舍梨子（即舍利弗）展开：或由他说法，或由他人论及他的境界与德行，塑造出一位能说法、能入深定、能自证阿罗汉、又谦忍无诤的大弟子形象。

## 二、结构层次
全卷五经一线推进，从"教义"走向"境界"再走向"德行"：
- **开演法义**：〔等心经〕舍梨子夜集讲堂，分别"内结人阿那含不还、外结人还生"二种人 → 等心天夜诣佛前转述 → 佛次赞叹：等心天数十共住锥尖之地互不妨碍，因善心极广甚大 → 劝诸比丘学"寂静"。
- **法义诤论与佛裁**：〔成就戒经〕舍梨子立论"成就戒定慧者能出入想知灭定" → 乌陀夷再三反对（执意生天为色、不能入灭定）→ 佛面诃乌陀夷、责阿难失于护持 → 白净比丘以"长老比丘五法"（戒、多闻、禅定、智慧、漏尽）收束。
- **自证境界问答**：〔智经〕黑齿比丘以舍梨子"自称得智"相告 → 佛召问 → 舍梨子以缘起链作答：生←有←受←爱，爱即于三觉（三受）中生起的乐欲著，见三觉无常是苦则爱著断 → 佛更出略答"所觉所为即皆是苦"，并印证舍梨子"深达法界"。
- **德行自陈与僧团净化**：〔师子吼经〕舍梨子结夏毕欲游行人间，遭一梵行诬告"轻慢" → 佛召还 → 舍梨子以"身身念"自白，连举九喻（截角牛、截手旃陀罗子、地、水、火、风、扫帚、晡旃尼、裂膏瓶、系三尸）→ 诬告者悔过，佛命舍梨子受悔。
- **教授对治恚恼**：〔水喻经〕"五除恼法"：对五类净秽不同的道友生恚恼时如何除——取其净分而舍其秽分，全净者常念其净；每类配一喻（粪扫衣、深水池、牛迹水、护病者、好池水）。

## 三、关键结论
- 持戒修善是入道根基，但唯断内结（烦恼）方得不还果；徒有外相威仪仍受后有。
- 成就戒、定、慧三者，才能出入灭尽定；深法不可凭主观臆断妄论。
- 生死之链为生←有←受←爱，而爱即对三觉（乐、苦、不苦不乐）生起的乐欲著；见三觉无常是苦，爱著即断。
- 身身念（随念此身、观身不净）与心如地水火风的无诤心，是忍辱不轻他、不受诬谤扰动的根本。
- 见道友有过，取其净分、以哀愍心对治恚恼，方合僧团相处之道。

## 四、易混辨析
- **内结人 vs 外结人**：内结人于内断除结缚（厌欲、断欲），证阿那含，不还生此间；外结人只是外相上持戒、守护根门，未断内结，命终还来人间。
- **四增上心 vs 想知灭定**：四增上心即四禅，是"现法乐居"的定境；想知灭定（灭尽定）更深，想与知俱灭，唯成就戒定慧者能出入，不可混同。
- **阿那含 vs 阿罗汉**：阿那含（不还）断五下分结，生于意生天，于彼成道；阿罗汉诸漏已尽、不更受有。本卷舍梨子"生已尽、梵行已立"是自证阿罗汉。
- **心解脱 vs 慧解脱**：心解脱指以定离贪而心得自在，慧解脱指以慧离痴、明达解脱，经中二者并举，标示漏尽阿罗汉的两种面向。

## 五、阅读提示
