# 中阿含经卷第十三 导读

## 一、内容总览
本卷属《中阿含经》"王相应品"（第二日诵"小土城"品），收两经：第（六五）《乌鸟喻经》与第（六六）《说本经》。前者以七种禽兽的"谋生方式"为喻，诫比丘莫贪利养、莫行邪命；后者由阿那律说过去世施福，佛说未来人寿八万岁、螺转轮王出世、弥勒成佛，是阿含经中最著名的"未来佛"文献之一。

## 二、结构层次
**《乌鸟喻经》**：引子 → 喻体铺陈 → 一一配对说义 → 结劝，三段往复。
- **引子**：佛忆昔转轮王夜竖高幢试珠宝，引出梵志往观、栖于池边的因缘。
- **七兽问答**：梵志在枯池边依次遇獭兽、究暮鸟、鹫鸟、食吐鸟、豺兽、乌鸟、狌狌兽，各答"从何来、欲何去"：前六者皆弃枯池、觅死尸为生，唯狌狌"饮清泉水、食好果、不畏于人"。
- **配对说义**（主体）：每兽对一种比丘——獭、究暮、鹫喻入村乞食不护诸根、染着利养者；食吐鸟喻借比丘尼之手受利养者；豺喻专挑无智梵行者的贫村沽名而住；乌鸟喻依贫无事处受夏坐、故作苦行沽名者；狌狌喻善护诸根、断五盖、得四禅、证漏尽的正行比丘。每段同以"莫依非法以自存命……应学如是"收束。
- **结劝**："当行如狌狌，世中无著真人如狌狌兽。"

**《说本经》**：过去事 → 未来事，两相呼应。
- **起**：诸比丘食后集讲堂，论"居士在家何者为胜"。
- **过去事**：阿那律自述前世贫穷，减己食施辟支佛，因一钵之福"七反生天、七反为人王"，今生大富出家；自说偈历数宿命通、天眼通等成就，自记将在耶离竹林般涅槃。
- **未来事**：佛说人寿八万岁时螺转轮王出世、弥勒如来成佛 → 阿夷哆求作螺王，佛诃"应更一死，而求再终" ↔ 弥勒愿作佛，佛叹"发心极妙"（对比推进）→ 佛授金缕织成衣付弥勒。
- **结**：魔波旬三番说偈以世乐诱（貌美、名衣、名财），佛以偈答"我已相降伏"，魔王"忽没不现"。

## 三、关键结论
- 染着利养即"依非法以自存命"，是当来烦热苦报、生老病死之因。
- 贫人减食施一钵，能感"七反生天、七反为人王"之福；若知受施者是无著真人，福报"当复转倍"。
- 同求未来：求世间的转轮王位被诃，求佛道被叹——发心的所求是分水岭。
- 断五盖 → 第四禅 → 趣漏尽智 → 欲漏、有漏、无明漏三漏解脱，是本卷给出的修行次第。

## 四、易混辨析
- **前六兽 ↔ 狌狌**：前六种各有一项具体过患（弃池觅尸、食他吐、栖僻处沽名等），狌狌独喻远离罪浊、不畏于人的无著真人。
- **阿夷哆求作螺王 ↔ 弥勒愿作佛**：同为未来之愿，一贪世位（仍是"更一死、再一终"的轮回），一求度尽生老病死的佛果。
- **施福的世间果 ↔ 出世间果**：生天为王、大富食邑是施的世间报；知所施者为阿罗汉则福"转倍"、趋向涅槃，是同一布施的两个层次。
- **转轮王 ↔ 佛**：本卷两处十号与七宝的铺陈刻意平行（"犹如我今"反复），但转轮王"以法教令"仍属世间，佛则"断生老病死"。

## 五、阅读提示
带着两个问题读：佛如何用禽兽的觅食方式，逐一点破比丘的"谋生方式"？弥勒与螺王段中，哪些是福报的铺陈，哪些才是佛真正许叮的抉择？
