# 中阿含经卷第四十二 导读

## 一、内容总览
本卷属《中阿含经·根本分别品》（第四分别诵），收经十部，此处正文含前三部：第一六二《分别六界》、第一六三《分别六处》、第一六四《分别观法》。「分别」是本卷关键词——佛陀对原本简略的教法逐一拆解、广说，是阿含经中「经师解经」式的论议典范：或由佛亲自广说，或由弟子（大迦旃延）代佛广说而蒙佛印可。

## 二、结构层次
三经同属「解经体」，皆以「略说→广分别」推进：
- **《分别六界》**：佛陀寄宿陶屋，比丘弗迦逻娑利不知对方即是佛，以「君」相称 → 佛为其广说「人有六界聚、六触处、十八意行、四住处」→ 逐一分别六界（地·水·火·风·空·识皆「非我有，我非彼有，亦非神」）→ 觉受（乐苦喜忧舍）从「更乐」（触）生，灭更乐则觉灭 → 以炼金为喻，清净舍依次移入四无色处，又观其有为、无常、苦而不再移入 → 命终漏尽，证第一正慧、真谛、惠施、息四处 → 比丘悔过称「君」之罪，佛听许忏悔。
- **《分别六处》**：佛于舍卫国总标「六处、六更乐处、十八意行、三十六刀，于中断彼成就是，无量说法，三意止，无上调御士趣一切方」→ 逐项自问「此何因说」而广释：三十六刀即六喜·六忧·六舍各分「依着」「依无欲」→ 断依着、取无欲 → 以四弟子百年闻法不尽喻如来说法无量 → 三意止：弟子受教与否，世尊皆不忧不喜、舍念常存 → 「趣一切方」以八方（四禅、四无色、想知灭尽、漏尽断智）喻佛调御之功遍一切处。
- **《分别观法》**：佛略说「心出外洒散……不受而恐怖；心住内……不受不恐怖」即入室燕坐 → 比丘推举大迦旃延广分别 → 迦旃延先谦让（「舍来就我，如触枝叶而不触根茎」）→ 再逐句展开：心外散是识着六尘之相；心不住内是于四禅八定犹「着味」而缚；心住内是同样的禅境而识「不着」→ 恐怖源于执五阴为我、我所，识「扪摸」之，境变则怖 → 比丘回禀，佛印可「如迦旃延所说，应当受持」。

## 三、关键结论
- 地水火风空识六界总摄此身，一一如实观知「非我有、非神」，则心不染著。
- 一切觉受以「更乐」（触）为因缘，触灭则受灭，如钻木火熄、灯尽不续。
- 同样的喜忧舍，依贪着生即是刀，依无欲观无常生则可取；修行是「断彼取是」。
- 定境本身也会成为系缚：识着禅味则「心不住内」，不着禅味方是住内。
- 弟子行与不行，世尊皆「舍无所为，常念常智」——说法者于得失平等住。

## 四、易混辨析
- **六界聚 vs 六触处 vs 十八意行**：六界是构成身心的元素分析；六触处是眼耳鼻舌身意与境接触的门径；十八意行是六根各生喜、忧、舍三种心理反应，6×3=18，是更细的心行分析。
- **依着 vs 依无欲（三十六刀）**：同样是喜、忧、舍，前者缘可爱的境界、贪恋得失而生；后者缘观无常苦灭而生（连求道不得之忧也属此类），是「断彼取是」的分界。
- **心不住内 vs 心住内**：不是有无禅定之别，而是同一禅定中识是否贪着定境之「味」——着味即缚、即不住内。
- **不受而恐怖 vs 不受不恐怖**：「不受」谓不执取；执五阴为我我所者，境界变易即生恐怖，离我我所者则否。

## 五、阅读提示
带着一个问题读：同样在禅定、同样在见色闻声，差别只在识「着」与「不着」——本卷三经都在教你辨认这一微细分际。
