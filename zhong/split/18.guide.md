# 中阿含经卷第十八 导读

## 一、内容总览
本卷为《中阿含经》卷十八，属"长寿王品"（第二小土城诵），收五经：〈天经〉（七三）、〈八念经〉（七四）、〈净不动道经〉（七五）、〈郁伽支罗经〉（七六）、〈娑鸡帝三族姓子经〉（七七）。五经同以"禅定修习"为轴心：从光明想的神通境界，到八念配合四禅，再到超越三界的"净道"与圣解脱，最后落到出家动机与如来授记的本怀。

## 二、结构层次
五经并列而层层深入，都以"远离独住、心无放逸、修行精勤"为底色：
- **〈天经〉——修行的阶梯**：佛自述成道前修光明想的八个台阶：得光明见色 → 与天共会问答 → 知其姓字生处 → 知其食与苦乐 → 知其寿命久住 → 知其业报往生 → 知诸天彼此差别 → 知其曾生未生。每级都以"我复作是念……"递进推展，末尾以"正知此八行则可一向说得"收束成佛之凭。
- **〈八念经〉——补足第八念**：阿那律于静处自思七念（无欲、知足、远离、精勤、正念、定意、智慧）→ 佛以他心智入定，瞬息移形现身印可，补"不戏"为第八 → 依次解释八念，并以王臣的美衣、美膳、宫舍、床座四喻反衬粪扫衣、乞食、树下坐、草座为第一 → 举四禅、四无量、二果为成就之效。
- **〈净不动道经〉——层层超越的净道**：佛说七种净道（净不动道三、净无所有处道三、净无想道一），格式一律：观欲色无常 → 得心净 → 入定或以慧为解 → 命终生彼处。随后阿难问"修无我者必涅槃否" → 佛答"乐著于舍则不得，不著则得" → 结于圣解脱（三漏尽、离生老病死）。
- **〈郁伽支罗经〉——略说的完整版**：一比丘求"善略说法" → 佛教以四念处（内外身、觉、心、法各如如其）配合有觉有观至无觉无观诸定 → 再修慈悲喜舍四无量遍满世间 → 得究竟智或阿那含二果。
- **〈娑鸡帝三族姓子经〉——问动机与问行止**：三少年出家，佛先问其出家之心（厌生死苦）→ 答"离欲者能堪忍" → 答如来住阿兰若只为现法乐住与慈愍后人两义 → 广说佛为比丘、比丘尼、优婆塞、优婆夷授记命终生处，皆为令闻者"心愿效"而修行。

## 三、关键结论
- 光明想等境界须在"远离独住、心无放逸、修行精勤"中一级一级渐次成就，正知此八行方是成佛之据。
- 解脱之道具足大人八念（无欲、知足、远离、精勤、正念、定意、智慧、不戏），与四禅（四增上心）相辅而行。
- 修"无我、无我所"尚不足保证涅槃：若乐著、住著于这"舍"本身，仍不得解脱；于舍亦无所受，方必得般涅槃。
- 如来独住静处、为弟子授记往生处，皆非为自求，而是为现法安乐与慈愍后人，令其见贤思齐。

## 四、易混辨析
- **不动 vs 无所有处 vs 无想**：三种净道所至，一层高于一层——"不动"为不为爱欲所扰的定境（通指四禅一类），"无所有处"为无色界第三定，"无想"则连想也灭尽。
- **有想、无想处 vs 无想处**："有想、无想处"即非想非非想处，是三界"有"中之最胜，受之则尚有余行；与灭想的"无想处"不同。
- **四增上心 vs 四无量心**：四增上心即四禅（定学之四种成就）；四无量即慈、悲、喜、舍遍满一方至一切世间，二者在〈郁伽支罗经〉中先后并修。

## 五、阅读提示
带着一个问题读全卷：同样是"离欲"，为什么对"舍"本身生起乐著仍然不得涅槃？〈净不动道经〉与〈天经〉对读，可见"能舍"与"于舍亦不著"之间那一层，正是圣凡的分界。
