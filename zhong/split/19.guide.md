# 中阿含经卷第十九 导读

## 一、内容总览
《中阿含经》卷十九，属"长寿王品"（第二小土城诵），收三经：梵天请佛经第七（七八）、有胜天经第八（七九）、迦絺那经第九（八○）。主线是"境界与修行"：第一经破对梵天常住的邪执；第二经辨大心解脱与无量心解脱之深浅、三种天光明胜劣之由来；第三经以阿那律陀自述为例，给出由戒生定、由定发通乃至漏尽的次第。

## 二、结构层次
**第一经 梵天请佛经（斗法记式的破执）**
- 梵天自夸"此处有常、有恒、长存……更无出要过其上" → 佛以他心智知其邪见，入"如其像定"瞬息至梵天。
- 魔波旬冒充梵天眷属，以"排却吉祥""堕山堕树"讥吓佛莫违逆梵天 → 佛识破："若说有魔波旬者，汝即是魔波旬"，魔羞愧隐没。
- 梵天再三坚执 → 反讥佛"寿短""不得出要"，称爱乐称叹者"为我自在" → 佛顺其所言后反破：执"地是我所"者便不知地，不计我者方能如实知地乃至梵天、无烦、无热。
- 梵天欲自隐形而不能隐，佛放光照一切梵天而隐身、"但闻其声而不见形" → 摄伏梵天 → 魔再出，劝佛莫教弟子说法 → 佛揭其私心（怕弟子"出我境界"）→ 结出经名。

**第二经 有胜天经（问答辨义）**
- 缘起：仙余财主请阿那律陀等四人受供，食后问："大心解脱、无量心解脱，为一义文异耶？"
- 大心解脱：所缘从一树 → 二三树 → 一林 → 一村 → 一国 → 大地乃至大海，逐级扩展而"齐限是心解脱不过是"（仍有边际）↔ 无量心解脱：慈、悲、喜、舍遍满一方乃至一切世间，无量无际。
- 真迦旃延三问：光天、净光天、遍净光天共住一处何以有胜如？ → 光天由光明想所依广狭而有明暗；净光天由"定修习／不修习"决定止息寂静与否（莲华在水底、出水上之喻）；遍净光天由"止睡眠、息调悔"与否决定光之明净（油有滓无滓之喻）→ 收归一句："因人心胜如故，修便有精粗，因修有精粗故，得人则有胜如。"

**第三经 迦絺那经（自述修证）**
- 缘起：阿那律陀三衣坏尽，阿难倩众比丘作衣，佛亲为舒张衣裁，八百比丘一日成三衣。
- 佛腰痛，令阿那律陀说"迦絺那法" → 自述：厌离生老病死而出家 → 修行禁戒、守护从解脱（离杀盗淫、四种口过、种种受畜）→ 极知足 → 守护诸根 → 正知出入 → 独住远离、断五盖 → 得第四禅 → 依次证如意足、天耳、他心、宿命、生死、漏尽六通。
- 以登梯为喻收束：犯戒者欲"以戒为梯，升无上慧堂正法阁"，终无是处；不犯戒者必有是处 → 佛赞叹，嘱诸比丘"受、诵习、善持迦絺那法"——"为梵行本，致通致觉，亦致涅槃"。

## 三、关键结论
- 梵天身亦无常、非出要；执"此处有常"正是无明。
- "计地是我"则不知地，不计我我所者方能如实知——知见的关键在破我执。
- 众生"爱有、乐有、习有"，如来已拔有根本（于有见恐怖，故莫乐有）。
- 天身光明的胜劣由生前修行精粗决定：人心胜如 → 修有精粗 → 果有胜如。
- 戒是升进的阶梯，缺戒者欲依戒入慧堂，终无是处。

## 四、易混辨析
- **大心解脱 vs 无量心解脱**：前者靠逐级扩大所缘，有"齐限"；后者以四无量心普覆一切世间，无有限量——本卷判为"义异文亦异"，并非一义异名。
- **光天 vs 净光天 vs 遍净光天**：感果差别各有所在：光天看所依广狭，净光天看定之修不修，遍净光天看能否止睡眠、息掉悔。
- **六通之中**：如意足、天耳、他心、宿命、生死（天眼）五通共世间；漏尽智通知四谛、断三漏，唯圣者有。
- **梵天 vs 魔波旬**：本卷魔自称梵天，二者之辨不在身份而在所说——引人贪著有常者是魔，说无常出要者是佛。

## 五、阅读提示
带着三个问题读：什么是真正的"出要"（第一经）？修行的精粗如何决定果报的胜劣（第二经）？从持戒到漏尽要拾级而登哪几阶（第三经）？
