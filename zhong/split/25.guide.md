# 中阿含经卷第二十五 导读

## 一、内容总览
本卷为《中阿含经》卷二十五，属"因品"（第二小土城诵），收四经：〈苦阴经〉第三（九九）、〈苦阴经〉第四（一〇〇）、〈增上心经〉第五（一〇一）、〈念经〉第六（一〇二）。前两经从欲、色、觉三者的"味—患—出要"论证欲乐无实义、苦以欲为本；后两经转向修行实操——如何灭除已生的不善念、如何在成道前拣择善念而修心。全卷由"知苦"一路推进到"修心得定"。

## 二、结构层次
- **〈苦阴经第三〉——对外道挑战的应答**：众多异学于讲堂质问"沙门瞿昙施设知断欲、知断色、知断觉，与我等有何差别" → 诸比丘不辨不驳，默然请佛 → 佛教比丘反问异学"云何欲味、欲患、出要"，断言异学必答不上而瞋诤退散 → 佛自说正答：欲（五欲功德之乐 → 求财营谋之苦 → 亲族相诤 → 王民国国相争 → 征战刑戮 → 恶行临终悔恼 → 身坏堕地狱）、色（从美人少年到衰老、病卧、死弃、冢间骸骨的层层观察）、觉（第四禅之乐 → 觉是无常苦灭法），各以"味—患—出要"程式展开，末尾反复强调"不知如真者自不能断，况能断他"。
- **〈苦阴经第四〉——对在家居士的开导**：释摩诃男问"我已知灭三秽之法，心中为何仍生染恚痴" → 佛答：因"住在家"这一法不灭 → 广说欲患（与第三经文句大体重出）→ 结论"欲一向无乐"，并插叙佛与尼揵论辩"谁乐胜"：频鞞娑罗王不能七日静默得乐，佛能，以证寂静禅悦胜于王乐。
- **〈增上心经第五〉——灭不善念的五相**：欲得增上心者当数数念五相：①念异相善相应（喻木工弹墨线斫木令直）→ ②观此念恶有灾患（喻颈系死蛇死狗而生恶秽）→ ③不念此念（喻闭目避色）→ ④以思行渐减其念（喻行道之人由急行渐次到住、坐、卧，渐息身行）→ ⑤齿齿相着、舌抵上腭、以心修心受持降伏（喻二力士捉一羸人）→ 五法递进备用，得"欲念则念，不念则不念"的大自在。
- **〈念经第六〉——佛自述成道前的拣念法**：未证无上正尽觉时，先把诸念分作二分（欲恚害念／无欲无恚无害念）→ 觉察恶念自害害他、灭慧障涅槃，即"不受、断、除、吐" → 两个牧牛喻对比：春后月牛入他田须执杖遮拦，秋后月收谷已讫放牛无忧 → 因"随所思、随所念，心便乐中"，故广修三善念 → 依次得第二、三、四禅 → 以定心证知四谛与三漏之灭 → 大泉水群鹿喻逐项配释：五欲是大泉水，沙门梵志是群鹿，魔波旬塞正路开恶道，三恶念与八邪道是恶道，无明是坑堑，魔眷属是守视人；如来则开平正路、闭恶道，三善念与八正道是道 → 结劝比丘宴坐精勤，勿得放逸。

## 三、关键结论
- 味、患、出要是观察欲、色、觉的完整程式：知味而不贪着，知患而生厌离，知出要而得解脱；不知如真者，自不能断，况复断他。
- 现法（今生）与后世的种种苦阴，皆"因欲缘欲，以欲为本"。
- 欲一向无乐；如意静默无言的禅悦，远胜频鞞娑罗王的五欲之乐。
- 已生不善念有五相对治，由转缘善相、观其灾患、置之不念、渐减其念，到以心降心，层层加码。
- 心"随所思、随所念，心便乐中"，故拣择所念即是修心之门：三善念通八正道，三恶念通八邪道。

## 四、易混辨析
- 苦阴经第三 vs 第四：同品同名，欲患一大段文句几乎重出；差别在对机——第三经回应外道异学的挑战，第四经解答在家居士摩诃男的疑虑，且第四经多出与尼揵论辩"谁乐胜"一节。
- "觉"（受）vs "念"：〈苦阴经〉"知断觉"之"觉"是古译，指受阴；〈增上心经〉〈念经〉之"念"指心中生起的念头（寻思），两者并非一事。
- 三恶念 vs 三善念：欲念、恚念、害念自害害他、灭慧障涅槃；无欲、无恚、无害念则不自害不害他，修慧得涅槃。
- 二牧牛喻：春后月（庄稼在田）执杖遮牛，喻善念未熟时须防护根门、遮止恶念；秋后月（收谷已讫）放牛无惧，喻善念纯熟后的自在无犯。

## 五、阅读提示
带着"欲到底有没有乐"的问题读前两经，再带着"恶念起了怎么办"的问题读后两经——注意每一法都配一个生活化譬喻（弹墨线、颈系死蛇、渐次止行、牧牛、群鹿），譬喻是本卷记忆的钩子。
