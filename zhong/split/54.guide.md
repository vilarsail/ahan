# 中阿含经卷第五十四 导读

## 一、内容总览
本卷为《中阿含经》卷五十四「大品」（第五后诵）之末两经：第200《阿梨吒经》、第201《嗏帝经》。两经同属「纠正恶见」主题：比丘阿梨吒自言亲闻佛说「行欲者无障碍」，比丘嗏帝自言亲闻佛说「今此识，往生不更异」（执识为常），都被诸比丘举发，佛为此诃责并借机宣说捉蛇喻、筏喻、六见处、十二缘起等核心教法，是阿含部中著名的「正确闻法」之经。

## 二、结构层次
两经平行对举、结构同构：恶见提出 → 诸比丘劝诃不服 → 白佛 → 佛召问诃责 → 借机正面说法 → 比丘信受奉行。

**《阿梨吒经》：**
- **破恶见**：诸比丘举正说「欲有障碍」，并出骨锁、肉脔、把炬、火坑、毒蛇、梦、假借、树果诸喻 → 佛责阿梨吒「颠倒受解义及文」。
- **捉蛇喻**：徒手捉蛇被螫 ↔ 执杖按顶捉头不遭螫——喻学法须善解义，不得但执文句。
- **筏喻**：法如渡河之筏，到岸当舍，「况非法耶」。
- **六见处**：色、觉、想及种种见乃至「此是神」，一一观「彼一切非我有，我非彼有，亦非是神」 → 「内有恐怖／内无恐怖／外有恐怖／外无恐怖」四番问答 → 度堑、过堑、破墎、无门、圣智慧镜五种成就。
- **结劝**：如来于骂詈、恭敬中不动，诸比丘当如胜林门外「燥草枯木」，无神、无神所有；末列不还、一往来、须陀洹诸果，显法之功德。

**《嗏帝经》：**
- **破「识常」见** → **火喻**：识随所缘生，如随木、随草粪聚而名其火，缘眼色生眼识……缘意法生意识。
- **「真说」系列问答** → 持见当为「厌、无欲、见知如真」 → 四食之因 → **十二缘起顺观**（缘无明有行……大苦阴生），逐支问答确认，再**逆观还灭**（无明灭则行灭……淳大苦阴灭）。
- **连串「颇作是念」检别**：不念过去未来之有无、不作五逆、不罢道、不外求福田、不以吉祥咒术为清净、不受八有 → 三事合会入胎、爱系相续 ↔ **爱尽解脱** → 三千大千世界三反震动。

## 三、关键结论
- 欲有障碍；学法贵在善解义理，不可以文害义——法尚应舍，何况非法（筏喻）。
- 于一切法观「非我、非我所、亦非是神」，执「此是神」者内外皆生恐怖。
- 识是因缘所生：随所缘而立名，有缘则生、无缘则灭，绝非往来生死中常住不变的神识。
- 十二缘起顺生逆灭，觉灭则爱灭，爱灭则苦阴灭，故名「爱尽解脱」。

## 四、易混辨析
- **内有恐怖 vs 外有恐怖**：前者由自身执我之见（惧「我不得」）起怖；后者闻说「灭一切自身、舍离一切我」之法，怖其断灭。
- **度堑／过堑／破墎／无门／圣智慧镜**：分别对应无明尽、有爱尽、无穷生死尽、五下分结尽、我慢尽。
- **阿梨吒之恶见 vs 嗏帝之恶见**：一坏戒行（欲无碍），一执识常（我常见），同属「颠倒受解」世尊言教，故两经以捉蛇喻、筏喻同一药方对治。

## 五、阅读提示
带着一问读：为何两经结尾都归于「筏喻」——闻法得益之后，连正法也不应执著不舍？
