# 中阿含经卷第三十九 导读

## 一、内容总览
本卷为《中阿含经》卷三十九，属"梵志品"，收第154～156三经，主题都围绕婆罗门（梵志）：其一驳斥"婆罗门种姓最胜、从梵天口生"的神话并讲出一段世界起源传说；其二借给孤独园长者须达哆之问说布施与福田的次第；其三以长偈对比古昔梵志与当世梵志的堕落。《婆罗婆堂经》注明"第四分别诵"，《须达哆经》注明"第三分别诵"。

## 二、结构层次
三经并列，各成起讫：

**《婆罗婆堂经》（一五四）**——由种姓之诤引出世界起源，是全卷主体：
- **缘起**：婆私吒、婆罗婆二梵志随佛出家 → 遭同族痛骂"舍白从黑、断种无子" → 二人以此问佛。
- **破斥**：佛以问答证明刹利、梵志、居士同样作恶行善 → 出身、种姓、憍慢只关婚姻世法（"因坐因水"），与佛的"无上明、行、作证"毫无关系。
- **立说**：讲劫初演化神话 → 晃昱天众生寿尽下生人间 → 依次贪食地味、地肥、婆罗、自然粳米，身体转粗、光明转灭 → 因食量不同生美丑胜如，众生相轻慢 → 生男女形、行欲、起家法 → 懒惰储米、粳米不再生 → 争田成讼 → 共立田主，是谓刹利；舍守护而往无事处学禅者，是谓梵志；诣诸方作田业者，是谓鞞舍 → 三种姓之外立第四沙门种。
- **结劝**：三姓行善恶各有苦乐报，唯修七觉法、断三漏才真解脱，种姓不能代受 → 引"刹利二足尊"偈收束。

**《须达哆经》（一五五）**——问答＋层递：
- 佛问须达哆行施否 → 答"家行布施，但为至粗" → 佛言粗施妙施皆得报，差别在信施、故施、自手施、自往施、思惟施、由信施、观业果报施七种心行。
- 举佛本生"随蓝"大施为基准 → 福田层层递胜：凡夫 ＜ 须陀洹 ＜ 斯陀含 ＜ 阿那含 ＜ 阿罗诃 ＜ 辟支佛 ＜ 如来 ＜ 施四方比丘僧房 ＜ 欢喜归命三尊受戒 ＜ 为一切众生行慈 ＜ 观一切法无常、苦、空、非神。
- **收束**：佛自说"彼随蓝即是我"——昔日施虽广大而说法不至究竟，今成佛方究竟白净、究竟梵行。

**《梵波罗延经》（一五六）**——问古答今：
- 拘娑罗国梵志问：今有无梵志学故梵志法者？→ 佛答"梵志久已越故梵志法"，以长偈说古梵志自调御、舍五欲、不蓄钱财、按食时乞求、立斋布施、如父母般爱牛而不杀 → 反观今梵志蓄财贪欲、教大王杀牛行斋、堕于爱欲婚姻 → 诸梵志闻已归命三宝。

## 三、关键结论
- 种姓不由出生定：刹利、梵志、居士同样行善作恶，尊卑唯在业行，不在"从彼口生"。
- 三种姓之外有第四沙门种：出家修道者超越种姓出身。
- 布施果报不在食之粗妙，而在心之至诚；福田以三宝、慈心与观无常苦空非神之慧为最胜。
- 古梵志以不害、苦行、乞食为法；今梵志贪财溺欲、杀牛祭天，早已背离故法。

## 四、易混辨析
- **地味／地肥／婆罗**：劫初依次出现的三种自然食物，一层比一层粗；每消亡一次，众生色相德行便退一步，最终堕入耕种争讼。
- **婆罗（食物）vs 婆罗婆（人名）**：同名易混，前者是劫初食物，后者是二比丘之一。
- **晃昱天 vs 梵天**：晃昱天即光音天，劫初人类由此下生；梵天是婆罗门所尊之神，本卷佛借"梵"字转说"梵是如来"，以佛法取代神话。
- **刹利 vs 梵志 vs 鞞舍**：起源分别为共立田主（守护者）、舍守护而学禅者、诣诸方作田业者——佛给出的种姓社会分工说。
- **四沙门果 vs 辟支佛 vs 如来**：须达哆经的福田次第按断惑深浅递升，观慧之行胜于一切财物之施。

## 五、阅读提示
带着两个问题读：佛如何用一则"世界起源神话"釜底抽薪地瓦解种姓的神圣性？施报的高低究竟由"施给谁"决定，还是由"以何种心施"决定？
