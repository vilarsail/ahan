# 中阿含经卷第六十 导读

## 一、内容总览
本卷是《中阿含经》最后一卷（卷六十），属全书末尾的「例品」（第五后诵），共收七经（二一六～二二二）。作为全藏收官之卷，它把叙事与义理合拢：前有佛陀与梵志、国王、皇后关于「爱」与「见」的对话，中有佛灭后尊者弟子的开示，终以遍举修行法目的「例经」收束——先示苦之因（爱），再示答之度（置而不答与一向而说），最后归于修道总纲。

## 二、结构层次
- **（二一六）爱生经**：梵志独子忽死 → 佛说「若爱生时，便生愁戚、啼哭、忧苦、烦惋、懊恼」→ 梵志不服，转问博戏儿，众口一词反对 → 此论辗转传入王宫 → 末利皇后以「王爱大将、爱象、爱国土、爱我」层层设问，证明所爱一旦「变易异」必生苦恼 → 王当下三皈依。一条论题经「外道质疑→社会议论→宫内验证」三级推进。
- **（二一七）八城经**：佛般涅槃后不久，居士八城只问阿难「有一法令圣弟子漏尽否」→ 阿难一口气举出十二甘露法门（第四禅、四无量心、无色诸定），每一门都说「住彼得漏尽，或断五下分结、化生般涅槃、终不还此」→ 居士以「开十二户之屋」作喻赞叹，设供并买屋奉施阿难。一问多答的「总起→铺陈→叹供养」结构。
- **（二一八）（二一九）两篇阿那律陀经**：同一问答骨架——比丘问「云何贤死」「云何不烦热死」，阿那律陀以阶梯式答案步步加深（四禅→六通漏尽；质直持戒→四念处→四无量→无色定→灭尽定、漏尽），比丘数问「极是耶」，末以「极是」定谳。两经互为姊妹篇，比出「善终」的深浅两阶。
- **（二二○）见经**：阿难对未出家时的旧友（异学梵志）重申：佛对「世有常、世无常……如来终不终」十问「舍置除却，不尽通说」，但知之「如应」。
- **（二二一）箭喻经**：鬘童子要求佛对十难「一向」作答，否则舍师而去 → 佛面诃其愚痴 → 说「身被毒箭」之喻：中箭者不先拔箭，却要问清射者姓名、弓材、箭羽、箭镞来历，必死于中途 → 十见「非义相应，不趣智、不趣觉、不趣涅槃」故不说；唯四圣谛「一向说」。
- **（二二二）例经**：以「欲断无明（老死）者，当修四念处……十无学法」的固定句式，对「断」与「别知」两种目标，把四念处、四正断、四如意足、四禅、五根、五力、七觉支、八支圣道、十一切处、十无学法逐一排比复沓，卷名之「例」即此通例句式。

## 三、关键结论
1. 爱生则苦生：凡有所爱，所爱一旦变易失去，愁戚忧恼必随之而起——这是入道观苦的起点。
2. 佛对「世常无常、命身一异、如来死后有无」等十问置而不答，因其非义相应、不趣涅槃；一向宣说的唯有苦、苦习、苦灭、苦灭道迹四谛。
3. 解脱不止一途：四禅、四无量、无色定等十二甘露法门，随所依修，皆可趋向漏尽或不还。
4. 断无明与老死，当修四念处乃至十无学法——道品次第是全卷义理的归宿。

## 四、易混辨析
- 「觉」与「受」：例经缘起支中「六处→更乐→觉→爱→受→有」，其中「觉」即「受」（感受，vedanā），而再往下的「受」实当后世所译「取」（执取）——古译与今译名目错位，切莫按字面混同。
- 贤死 vs 不烦热死：两经同说「善终」，前者以第四禅为下限、六通漏尽为极，后者从质直持戒起阶、以灭尽定漏尽为极，深浅有别。
- 舍置除却 vs 一向说：对十无记之问佛「不说」，对四圣谛佛「一向说」——不说与说各有其理由，非回避。
- 苦习 vs 苦灭：「习」通「集」，苦习即苦之集起（集谛），非「习惯」义。

## 五、阅读提示
带着「爱为什么是苦根」「佛为什么拒答十四难」两个问题读，前半卷的故事与后半卷的义理即可贯通；卷末例经可细读首节，其余为同一句式的复沓，浏览即可见其排比之例。
