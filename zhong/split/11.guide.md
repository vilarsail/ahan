# 中阿含经卷第十一 导读

## 一、内容总览
《中阿含经》卷第十一属「王相应品」（本品共十四经，本卷收前五经，即经五八至六二，为「初二日诵」）。全卷以「王」为线索：从转轮王七宝、大人三十二相，到顶生王本生、佛自述昔为王之福业，最后落到频鞞娑逻王迎佛归佛——借世间最尊贵的王者，衬托「王权不及法宝、欲乐无有厌足、五阴无常非我」。

## 二、结构层次
- **《七宝经》（五八）**：对喻立宗 → 转轮王出世有七宝（轮、象、马、珠宝、女宝、居士、主兵臣），如来出世则有七觉支宝（念、择法、精进、喜、息、定、舍），全经极短，纯是一则类比。
- **《三十二相经》（五九）**：问答推进 → 比丘食后集坐讲堂，共论「大人三十二相，在家必为转轮王、出家必成正觉」→ 佛以净天耳闻知，晡时往问 → 应请逐一广说三十二相，每相以「是谓大人大人之相」结句，末重申「必有二处真谛不虚」收束。
- **《四洲经》（六○）**：由阿难燕坐思惟「世人于欲难有满足」引出 → 佛说顶生王本生：先有阎浮洲，再依次收取瞿陀尼、弗婆鞞陀提、郁单曰，雨宝七日，上三十三天与帝释分半座，唯「眼眴异」→ 一念贪心欲逐帝释，即失如意足、堕而命终 → 临终九事皆「意不满足而命终」→ 结偈「天雨妙珍宝，欲者无厌足」→ 佛自指「顶生王即是我」，以昔「说法不至究竟」对照今日「究竟梵行」。
- **《牛粪喻经》（六一）**：比丘疑「色、觉想行识颇有常住不变、一向乐、恒久存耶」→ 佛以手指爪抄少牛粪作喻，自述长夜作福：七年行慈、七反成败、作大梵天、帝释、顶生王等无量世福报 → 「色为有常、为无常」层层问答，归于「彼一切非我、非我所」→ 比丘独住精勤，得阿罗诃。以「福报再多亦尽灭」破「常乐」之执。
- **《频鞞娑逻王迎佛经》（六二）**：纯叙事长经 → 王集四种军迎佛，除却五仪式威仪、步进自称名姓 → 摩竭陀人疑「瞿昙从迦叶学梵行耶」→ 佛令迦叶现如意足、入火定，迦叶自承「佛是我师」→ 佛为王说法：先端正法（施、戒、生天，毁呰欲为灾患），后说正要（苦、习、灭、道）与五阴生灭观 → 王及八万天、万二千人远尘离垢、法眼生，王自归三宝、请为优婆塞——佛陀感化首位国王护法的记事。

五经由「宝 → 相 → 王故事 → 佛本生 → 王归佛」层层递进，把「王」一步步引向「佛」。

## 三、关键结论
- 转轮王有七宝，如来有七觉支宝：以世宝喻出世法，法宝胜于王宝。
- 大人三十二相必有二处：在家为转轮王，出家成正觉。
- 顶生王统四洲、坐帝释半座，仍「意不满足而命终」——欲苦无有乐。
- 五阴无常、苦、变易法，佛昔无量福报亦「如意足亦失」，故一切非我、非我所，当以慧观知如真。
- 「先端正法、后四圣谛」是阿含说法的典型程序；频鞞娑逻王自归三宝，开摩竭陀王室护法之始。

## 四、易混辨析
- **转轮王七宝 vs 如来七觉支宝**：前者轮、象、马等七种世间瑞宝；后者念、择法、精进、喜、息（轻安）、定、舍，是出世善法。
- **转轮王 vs 顶生王**：转轮王是「不以刀杖、以法教令」的圣王通称；顶生王是佛过去世为刹利转轮王时的具体本生人物，因从顶上生得名。
- **晃昱天 vs 三十三天**：晃昱天（光音天）是色界二禅天，劫坏时众生所生处；三十三天（忉利天）是欲界天，帝释所居，顶生王所上者为此。
- **事火 vs 火定**：事火是迦叶归佛前奉事火祠的外道旧业；火定是他归佛后所示神变禅定，入定身出火焰。

## 五、阅读提示
带着「佛为何偏以王说法」来读：每一经都以最世俗的权势、财富、相好为跳板，落到无常与解脱。读《迎佛经》时留意「先施戒生天、后苦集灭道」的说法次第与迦叶现神变止疑，这是理解阿含说法风格最好的标本。
