# 中阿含经卷第二 导读

## 一、内容总览
《中阿含经》卷第二，属“七法品”（初一日诵），收经六至经十共五经，全卷以“七”为纲：七善人所往至处（善人往经）、七世间福与七出世间福（世间福经）、七日出灾变（七日经）、七车之喻（七车经）、七断漏法（漏尽经）。

## 二、结构层次
- **善人往经（六）**：佛立“七善人所往至处”→ 七段排比，每段同一起句“我者无我……然未得证”，只有譬喻与果位递异：烧䴸才燃便灭（中般涅槃）→ 迸火三种灭处（中般三品）→ 堕地而灭（生般）→ 堕少薪、多薪（行般、无行般）→ 烧至村邑旷野（上流阿迦腻吒般涅槃）→ 末段转出“无余涅槃”：不至四方上下，现法中息迹灭度，收束全经。
- **世间福经（七）**：问答体。摩诃周那问世间福 → 佛列七福（施房舍、床座卧具、新衣、朝粥中食等）→ 再问出世间福 → 又列七福（闻佛及弟子来而欢喜，乃至躬往奉见、受三自归与禁戒）→ 以恒伽入海、阎浮洲五河入海两喻明其福不可限量 → 说颂收束。
- **七日经（八）**：先立宗“一切行无常、不可猗法” → 以不雨枯槁、二日至七日出、大海递减、须弥山崩坏层层递进 → 引善眼大师本生：佛自说过去世为外道仙人之师宗，教弟子梵世法，再修增上慈生晃昱天 → 以“尔时说法不至究竟”对“今说法得至究竟”作今昔对比。
- **七车经（九）**：缘起（安居讫，生地比丘共誉满慈子）→ 舍梨子与满慈子林中问答：连环否证“以戒净故修梵行耶？不也”，乃至道迹断智净皆否 → 立正答：七净次第相因，以无余涅槃为归 → 波斯匿王一日行七车之喻（乘一舍一，展转而至）→ 互报名号，更相赞善。
- **漏尽经（十）**：总纲“以知、以见故诸漏得尽” → 欲漏、有漏、无明漏随正/不正思惟生灭 → 七断漏法逐条展开：从见断、从护断、从离断、从用断、从忍断、从除断、从思惟断，各以“云何……是谓……”定格 → 结“一切漏尽诸结已解，能以正智而得苦际”。

## 三、关键结论
1. 断五下分结而少慢未尽者，不还生欲界，依中有的迟速与勤修与否，分中般、生般、行般、无行般、上流五种般涅槃。
2. 出世间福不止于布施财物，而在闻法欢喜、亲近礼敬、受三自归与禁戒，其福不可限量。
3. 一切行无常：七日并出时大海竭尽、大地须弥烧坏无余，诸行不当乐着，当求舍离解脱。
4. 戒净、心净、见净、疑盖净、道非道知见净、道迹知见净、道迹断智净七净次第相因，任前一净皆非涅槃本身；梵行以无余涅槃为究竟。
5. 漏尽不离知见：须由见、护、离、用、忍、除、思惟七门断漏，方得苦际。

## 四、易混辨析
- **中般 / 生般 / 行般 / 无行般 / 上流般**：同为断五下分结的不还者生色界而证涅槃，差别只在：中有未至即灭（中般）、生已不久即灭（生般）、勤加行而灭（行般）、无功用而灭（无行般）、辗转上生至色究竟天而灭（上流）。
- **世间福 vs 出世间福**：前者是施物（房舍、卧具、衣、食），后者是闻法、亲近、归戒；前者有量可数，后者不可限、不可量。
- **无余涅槃 vs 有余**：无余谓烦恼与后有俱尽；若说戒净等任何一净“本身就是涅槃”，是以有余称说无余。
- **正思惟 vs 不正思惟**：不正思惟者于六见起执、三漏增广；正思惟者知如真，不应念的法不念，应念的法便念。

## 五、阅读提示
带着“次第”读全卷：善人往经的果位次第、七车经的七净次第、漏尽经的七断次第，皆前前引生后后、舍前无以后——这正是本卷反复用“乘一车舍一车”要说明的道理。
