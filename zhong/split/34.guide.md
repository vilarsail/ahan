# 中阿含经卷第三十四 导读

## 一、内容总览
本卷属《中阿含经》「大品」（第三念诵），收六经：商人求财经（一三六）、世间经（一三七）、福经（一三八）、息止道经（一三九）、至边经（一四〇）、喻经（一四一），皆在舍卫国胜林给孤独园所说。全卷枢纽是「执取则被害、放下则得度」的无我主线：以海上商人为罗刹所食的长篇譬喻开篇，再从「不执世间」「不畏修福」「不净除欲」「不恋二边」「不放逸」多面展开。

## 二、结构层次
六经并列，各有首尾（「我闻如是」起、「某经第几竟（字数）」讫），内在互相呼应：
- **商人求财经**：故事层——商人入海 → 摩竭鱼王坏船 → 大风吹至西岸 → 罗刹女以财色留人 → 智慧商人窥探南行，闻亡者揭底，困于大铁城 → 天音指点䭷马王 → 「贪念男女财宝者堕水被食，不起念者虽持一毛亦得度」。法义层——同一抉择套在四组名相上逐级检验：六入 → 六境 → 五阴 → 六界；念「X是我、我有X」者必被害，念「X非是我、我无有X」者得安隐度。
- **世间经**：四谛框架收摄世间——如来自觉世间、世间习（集）、世间灭、世间道迹 → 佛语真谛不虚、师子吼 → 颂劝「当自作灯明」。
- **福经**：立宗「莫畏于福」→ 佛自述宿世福德：七年行慈、经七返世界成败，上生晃昱天、作大梵天、天帝释、刹利顶生王 → 铺陈八万四千象马车城楼座衣食女 → 收结：此是布施、调御、守护三业之果。
- **息止道经**：对治淫欲的操作——年少比丘数数诣息止道观骨、青、腐、食、骨锁诸相 → 还归趺坐系念此相 → 颂推进到观内身不净、四大皆空 → 永断淫怒痴。
- **至边经**：出家乞食是「世间大讳」，族姓子为厌苦之义而受 → ↔ 愚痴人出家而染欲憎嫉，如以墨浣墨、如旷野烧人残木，两处皆不用 → 俱忘失二边。
- **喻经**：立宗「无量善法以不放逸为本、为习、为首」→ 一连串「最第一」的排比喻（田依地、象迹摄诸迹、师子王、须弥山、大海、酥精……）→ 终极一喻：如来于一切众生中为极第一。

## 三、关键结论
- 贪执（我、我所）如罗刹女；于六入、六境、五阴、六界不起「是我、我有」之念，即安隐得度。
- 佛语真谛不虚，因其自证世间、世间集、世间灭、世间道迹。
- 福德当乐不当畏，佛多劫福报皆从布施、调御、守护三业而来。
- 淫欲以不净观对治：观尸相、观内身、观四大空，则诸觉息止。
- 一切善法以不放逸为根本与最第一。

## 四、易混辨析
- **「X是我」vs「我有X」**：前者计五阴等即是我，后者计其为我所拥有，两路皆执，故每组分列破斥，各配「非是我／我无有」的正答。
- **世间习 vs 世间灭**：「习」是集起义（四谛之「集」），指世间生起之因；「灭」指还灭之果——即苦、集二谛的佛自证。
- **本卷「三业」vs 常说身口意三业**：福经中特指布施、调御、守护三事，是得大福报之因。
- **至边经「二边」vs 中道「二边」**：此处指欲乐与沙门义两头俱失，并非通常「有无二边」。

## 五、阅读提示
读商人求财经时留意譬喻与法义的逐一对应：罗刹女＝贪执，抱儿说财宝＝念「我有男女、我有钱财」，骑马背或持一毛＝执与不执。叠唱的「我法善说……如桥筏浮具，遍满流布，乃至天、人」是结集套语，标示此法普被天人。
