# 中阿含经卷第四 导读

## 一、内容总览
本卷为《中阿含经》卷四，三经同属「业相应品」：（一八）师子经、（一九）尼干经、（二○）波罗牢经。全卷以「业」为轴心，是佛与外道的论辩集：师子经驳耆那教（尼干）信徒加于佛陀的「一切不可作」之诬；尼干经正面破尼干「宿作因、以苦行销旧业」之说；波罗牢经答「杀生皆现世受报」的质疑，并教村主伽弥尼以「远离法定」（四无量心）自断疑惑。三经一破一立：破外道业论，立佛门业果正见。

## 二、结构层次
- **师子经（一八）**：鞞舍离贵族数数称叹佛 → 尼干弟子师子大臣先谒师门受阻，遂不辞而往见佛，以「沙门瞿昙宗本不可作」相诘 → 佛不作否认，而以八事层层判分：不可作（恶行）→ 可作（善行）→ 断灭（断恶之因）→ 可憎恶（憎恶恶行）→ 法、律（为断贪瞋痴而说）→ 苦行（非外道自苦，乃断尽苦行之法）→ 不入于胎（不再受生）→ 安隐（自安安他）→ 师子三自归奉持。一条指控、八个判分，是「以分别义答笼统诘难」的典型。
- **尼干经（一九）**：先立外道见——人所受皆因宿作，苦行灭故业、不造新业则诸业尽、苦得尽 → 佛责其「自无净智」，以拔箭医疮喻明「断苦须亲证」 → 再以「上断生上苦、中断生中苦、下断生下苦」三问答破其苦行自相矛盾 → 又以业报不可互转（乐报业不能因苦行转作苦报等六对）断其为「虚妄方便，空断无获」 → 转立正说：比丘自断其苦，断五盖、得第四禅、知四谛、尽三漏 → 末以五盖缠心则忧苦、除则忧灭、八支圣道为现法究竟收束。
- **波罗牢经（二○）**：村主伽弥尼以「知幻是幻」问难 → 佛以拘丽瘦兵卒作恶、非长官之过为喻，破其「知幻者即幻」的以人废言 → 伽弥尼悔过发露 → 再举「杀生不与取妄言皆现世受报」之说，以王赏王罚两两对照判为妄言 → 举四论士（无业报论、有业报论、无作恶论、有作恶论）异说生疑 → 佛教「远离法定」：离十恶业道、得一心，心与慈、悲、喜、舍俱遍满一方乃至一切世间，四段排比一一化导四种异见，「不是不非，得内心止」 → 末以远尘离垢、净眼生、三自归作结。
- 三经纯为长行问答，无偈颂；各经以「我闻如是」起、「欢喜奉行」结，中段皆由「外道立论 → 层层诘破 → 转立己说 → 归信奉行」一线推进。

## 三、关键结论
- 恶行不可作、善行应作，佛陀之教在断恶修善，并非「一切不可作」。
- 业报各有其类：乐报业不能因苦行转作苦报，故「苦行灭宿业」是虚妄方便、空断无获。
- 断苦必须亲证：「自无净智」而随信师说，只是信受虚妄之言。
- 断五盖、得四禅、知四谛、尽欲漏有漏无明漏，是现法解脱的实证次第。
- 对异说不必强判是非，修四无量心、内心得止，疑惑自断而得升进。

## 四、易混辨析
- **「宗本不可作」vs 尼干宿作苦行论**：前者是外道加于佛的「无作用论」罪名，佛以分判善恶行作答；后者是尼干自宗「宿业必以苦行销尽」之说，佛以业果不可互转破之，两者不可混为一谈。
- **「宗本断灭」vs「不入于胎」**：断灭指断除身口意恶行之因，非否认后世；不入于胎指断尽当来胎生之因、不再受后有。
- **现法报业 vs 后生报业**：今生受报与来生受报，业熟有迟早，彼此不能因苦行互转。
- **心与慈俱、与悲俱、与喜俱、与舍俱**：同属「远离法定」中四无量心的次第扩展（一方→四方→四维上下→一切世间），不是四种不同的定。

## 五、阅读提示
带着「苦行能不能灭业」这一个问题读全卷：师子经看佛如何正面立己，尼干经看佛如何步步诘破，波罗牢经看佛如何教弟子与异说共处——由破他而立自、由立自而安心，是本卷读法的线索。
