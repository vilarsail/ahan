# 中阿含经卷第三十八 导读

## 一、内容总览
本卷为《中阿含经》卷三十八「梵志品」之首，收两经：〈鹦鹉经第一〉（一五二）与〈须闲提经第二〉（一五三）。两经都是佛与婆罗门、外道当面论辩：〈鹦鹉经〉破婆罗门「五法得大果」的传统主张，显明得果的关键在行正行或邪行，不在在家出家之身份；〈须闲提经〉破外道「此身即无病涅槃」的邪见，示以亲近善知识、观四圣谛、净圣慧眼之道。

## 二、结构层次
**〈鹦鹉经第一〉**：
- **起问立宗**：鹦鹉摩纳问「在家／出家谁得善解、谁得大利」→ 佛答「此事不定」→ 一卷之纲：行正行必得善解大果，行邪行则否，与身份无关。
- **破五法执**：摩纳举梵志五法（真谛、诵习、热行、苦行、梵行）→ 佛层层追问：今人无人能「于现法自知自觉自作证」→ 师祖七世亦无 → 远溯十位古仙梵志亦然 → 五法唯是「因信受持」，信向中无根本 → 众盲相扶之喻收破。
- **设喻转进**：斥弗袈裟裟罗「人上法不可知见」之说为生盲论色；又以五盖障碍覆盖、五欲功德、因草木／离草木燃火之喻，对照因欲之乐与离欲之舍乐。
- **收束归宗**：佛说五法真义「从心起」→ 无结无怨无恚无诤之心与慈、悲、喜、舍俱，遍满一方乃至一切世间成就游 → 问梵道迹，摩纳自归三宝为优婆塞。

**〈须闲提经第二〉**：
- **缘起挑衅**：须闲提外道讥佛「坏败地、无可用」→ 佛以六根调御与不调御之苦乐报设问，再以五欲「习、灭、味、患、出要」如实观层层问答，破其「未离欲者可评断离欲者」的立足点。
- **一连串譬喻**：病癞人以爪擿疮、临火坑炙反以为乐 → 脱癞后见同病者不复意乐 → 慞惶避火之冷暖对照 → 生盲受垢腻衣而信为白净 → 显「身即是病、是痈、是箭，以之为乐是颠倒想」。
- **正说证果**：圣慧眼未净者说之无益（唐烦劳我）→ 开示四法：亲近善知识、闻善法、善思惟、趣向法次法 → 由是知苦、苦习、苦灭、苦灭道四谛 → 须闲提远尘离垢法眼生，出家证阿罗诃。

## 三、关键结论
- 得果不系于在家出家之身份，而系于行正行、离邪行。
- 婆罗门五法无一人实证，唯凭信辗转相传，如众盲相扶，前不见后。
- 未离欲者于苦欲生「乐欲想」，心有颠倒；离欲者于苦如实知苦，得舍乐与止息。
- 无病第一利，涅槃第一乐；八支圣道是住于安隐甘露之道。
- 慧眼未净，虽闻正法终不能知；必由亲近善士、闻法、思惟、法随法行，四谛现观，法眼生而证果。

## 四、易混辨析
- **梵志五法之「真谛」vs「梵行」**：真谛指守真实语（不妄语）之诫，梵行指清净离欲之行；佛说二者真义皆「从心起」，以无结无怨无恚无诤之心为本。
- **因欲之乐 vs 舍乐**：前者如因草木而燃之火，因欲、恶不善法而生，不得舍乐止息；后者如离草木之火，因离欲、诸善法而生。
- **未离欲者的评断 vs 已离欲者的知见**：未离欲者为欲爱所食、以欲为乐，如病癞人安于火炙，故不能称量、评断离欲者（如佛）。
- **慧眼未净 vs 法眼生**：前者如生盲听人说青黄赤白，终不能知；后者远尘离垢、见四圣谛，是转凡入圣的关键。

## 五、阅读提示
带着两个问题读：一是身份（在家／出家、婆罗门／沙门）与修行成效之间究竟是什么关系？二是「无病第一利、涅槃第一乐」为什么不能靠听说、甚至摸触身体来知道，而必须净治慧眼自见？
