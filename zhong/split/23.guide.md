# 中阿含经卷第二十三 导读

## 一、内容总览
本卷为《中阿含经》卷二十三，属「秽品」（第二小土城诵），收录第九十至九十六共八经（经号八九~九六）。「秽」即心的污垢——贪伺、瞋恚、睡眠、调悔、疑、悭、嫉、欺诳、谀谄、无惭无愧、慢、放逸等。全卷围绕一个主题反复演练：**找出心中之秽、断除心中之秽**，而由目揵连、周那、舍利弗等弟子代佛说法，是「弟子说法」较集中的一卷。

## 二、结构层次
八经并列而层层换角度，共说「心秽」一事：
- **（八九）比丘请经**：目揵连立总纲——比丘应主动请求同梵行者「语我、教我、诃我」→ 列「戾语法」与「善语法」逐项对照 → 以「以镜自照」喻自省 → 结出「欢悦→欢喜→止身→觉乐→定心→见如实知如真→厌→无欲→解脱」的修行链。
- **（九○）知法经**：承接自省——口称「知法无增伺」而心中实有秽，如穷汉自称巨富 ↔ 不自称而实有者，如巨富自谦；判准在「心是否向增伺尽、无余涅槃」。
- **（九一）周那问见经**：把「如何灭见」落到方法——「当学渐损」→ 五层递进：渐损法 → 发心法 → 对法（恶与善相对）→ 升上法 → 般涅槃法。
- **（九二）青白莲华喻经**：说身行、口行之秽以身口改，意地之秽（增伺等）唯以慧见灭 → 如来如青白莲花，出水面而不著水。
- **（九三）水净梵志经**：以「二十一秽污于心」答外道水浴净罪之说 → 心与慈俱（悲、喜、舍）遍满十方，「洗浴内心，非浴外身」。
- **（九四）黑比丘经**：反面人物例——黑比丘喜斗诤，佛列八种恶法 ↔ 八种善法，以恶马/良马系枥为喻。
- **（九五）住法经、（九六）无经**：收束为自检清单——逐项观「我有增伺耶？有瞋恚耶？……」，有则如救头燃急断，无则令善法住、增、不忘退。

## 三、关键结论
- 修行人当求人诃谏、自照如镜：见秽不欢悦而求断，无秽则欢悦而「求学尊法」。
- 判断是否真「知法」，不看口头宣称，看心是否朝向秽尽的解脱方向。
- 对治有次第：先渐损恶法，次发心向善，再以善与恶相对治，由此升上，终至般涅槃。
- 意地之秽（增伺、瞋、疑等）非身口苦行能除，唯以慧见灭。
- 真正的洗净是修慈、悲、喜、舍四无量心遍满世间，不是到河里沐浴。

## 四、易混辨析
- **戾语法 vs 善语法**：前者使梵行者「不语彼、不教不诃而难彼」，后者使梵行者「善语彼、善教善诃而不难彼」——同是教诫互动，果报相反。
- **增伺 vs 瞋恚心**：增伺是贪求、觊觎（属贪类），瞋恚心是恼害（属瞋类），在自检清单中常并列而不可混。
- **渐损 vs 发心**：渐损是已具戒定者层层减损恶法；发心是初下手时先于心中立志向善，故经言「但发心念欲求学诸善法者，则多所饶益」。
- **净法衰退 vs 净法转增**：已闻之法忘失不忆为衰退；得闻、不忘、常忆念为转增。

## 五、阅读提示
带着「我心中有哪几种秽」的问题读：八经其实是一份不断加详的病历与处方——先会自照，再认得二十一种心秽，最后学会以渐损与四无量心自己清洗。
