# 中阿含经卷第四十一 导读

## 一、内容总览
本卷为《中阿含经》卷四十一《梵志品·梵摩经第十》（全经第161经，属"第四分别诵"）。记述弥萨罗国年逾百二十岁的大婆罗门梵摩，由闻名、遣徒验相、亲觐佛陀、偈问法义，到闻四圣谛见法证果、卷末蒙佛授记得阿那含的完整归佛历程，是"外道长者归佛"类叙事经的代表作。

## 二、结构层次
全卷以"闻名→验相→亲觐→问答→证果"一线推进：
- **闻名遣使**：梵摩闻佛十号具足、说法初中后皆妙，又闻"具三十二相者在家必为转轮王、出家必成正觉"之预言 → 派弟子优多罗（摩纳）前往勘验。
- **验相观仪**：优多罗见三十相，于阴马藏、广长舌二相生疑 → 佛以如意足现之令见 → 又随佛行四个月，观察威仪礼节、游行所趣。
- **复命详述（全经最长铺陈）**：优多罗归而向师逐一复述三十二相（足安平立、千辐轮、黄金色、师子颊车……）与佛陀日常行止（着衣、行步、受食、洗钵、入村、宴坐、说法），以亲眼所见证实所闻。
- **出家与亲觐**：优多罗从佛受具足为比丘 → 佛众至弥萨罗大天㮈林 → 梵摩乘车来见，大众避道，谛观佛身，仍于二相生疑 → 以偈问佛，佛现如意足并说偈。
- **偈问偈答（法义核心）**：梵摩问"云何为梵志、三达有何义、以何说无著、何等正尽觉" → 佛一一以颂答：灭恶修净行是真梵志、成就三明是三达、远离不善住第一义是无著、普知诸法尽是正尽觉。
- **说法证果 → 授记收束**：大众惊叹（梵摩于出生、学问、财富、寿命四事为国中第一）→ 佛先说施、戒、生天等端政法，再具说苦、习、灭、道四谛 → 梵摩见法得法，自归三宝受优婆塞，设供请斋，佛说"唯佛最第一"咒愿偈 → 后梵摩命终，佛记其五下分结尽、得阿那含、不还此世。

## 三、关键结论
1. 具三十二大人相者必有二处果报：在家为转轮王，出家必得等正觉——本经以此预言为验佛的框架。
2. 真正的"梵志"不由出身种姓定义，而由灭恶不善法、修清净梵行而成就。
3. 三达即三明（宿命明、天眼明、漏尽明），由尽脱淫怒痴而得；无著、正尽觉皆由离不善法、遍知诸法而立。
4. 佛度人循次第：先说施、戒、生天等端政法，待心柔软堪受，再为具说四圣谛。
5. 梵摩最后知法，五下分结尽，生上而般涅槃，得不退法，为阿那含果。

## 四、易混辨析
- **梵志（种姓义）vs 梵志（圣者义）**：本卷通篇用前者称婆罗门出身者，而经末偈问"云何为梵志"用后者——什么样的人才配称真正净行者，佛答以灭恶修梵行，正是借双关完成对婆罗门自诩的翻转。
- **摩纳 vs 梵志**：摩纳意为儒童、青年婆罗门，是种姓身份；优多罗先以摩纳身份奉师命验佛，后出家为比丘。
- **三达 vs 三明**：同实异名，偈中明言"成就于三明，以此为三达"。
- **转轮王 vs 佛**：同具三十二相的两种出路——居家的理想圣王与出家成正觉者。
- **阿那含 vs 阿罗汉**：阿那含（不还）五下分结尽，生上界而般涅槃、不再还生欲界，然尚未如阿罗汉之究竟。

## 五、阅读提示
带着"外道如何被折服"的问题读：本经的折服之道不在论辩，而在验相、观威仪、闻法三层递进。优多罗四月观察所得一段（P24–P29），是早期文献中对佛陀日常行止最细致的描写，可与诸大经中"大人相"段落对读。
