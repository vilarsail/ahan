# 中阿含经卷第六 导读

## 一、内容总览
本卷为《中阿含经》卷六「舍梨子相应品」，以舍利弗（经中作「舍梨子」）为中心，收三经：瞿尼师经（二六）、梵志陀然经（二七）、教化病经（二八），每经末附字数与结集偈颂。三经同示舍利弗观机教化：对失仪的阿兰若比丘说威仪法门，对倚势作恶的旧友说业报与四梵室，对病危的大施主说离怖法门。

## 二、结构层次
- **瞿尼师经**：阿兰若比丘瞿尼师「调笑、憍慠、躁扰、喜忘」→ 舍利弗借其人告诸比丘「无事比丘」当学的功课 → 以「不学则致比丘诃数诘责」的同一句式层层排比，从敬重随顺、不调笑、不畜生论、不憍慠少言，到护根、食知止足、精进、正念正智、知时善坐，直到能论律与阿毗昙、息解脱、漏尽智通 → 大目连问「唯无事比丘当学？」→ 答「无事比丘尚当学，何况人间比丘」收束。
- **梵志陀然经**：两段式。前段：舍利弗得知旧友陀然「依傍于王，欺诳梵志、居士」→ 登门拒食 → 连问「为父母／妻子／奴婢／王天先祖沙门梵志作恶，地狱卒可脱否」破其借口 → 正说「如法、如业、如功德」得财孝养眷属 → 陀然自归三宝。后段：数年后陀然病笃 → 以「地狱＜畜生＜饿鬼＜人＜四王天＜三十三天＜……＜梵天」优劣递升问答引其心向上 → 说四梵室（慈悲喜舍）→ 陀然修之生梵天 → 佛赞「若上化者，速知法如法」。
- **教化病经**：长者给孤独病笃遣使迎舍利弗 → 舍利弗以「莫怖」一句十番开导：愚痴凡夫因不信／恶戒／不多闻／悭贪／恶慧／邪见、邪志、邪解、邪脱、邪智堕恶道，而长者具足十种净法，「本已得须陀洹」→ 长者闻法病愈 → 自述昔年闻佛名、夜出王舍城、天神劝行、见佛闻四谛、金布买童子胜园建精舍的因缘 → 佛赞舍利弗将略说「四种须陀洹」广为十种。

## 三、关键结论
- 阿兰若（无事）比丘并非独处即成，威仪、学问、待众样样须学；人间比丘更当如此。
- 在家赡养父母妻子、供奉奴婢先祖，必须「如法、如业、如功德」得财；为亲人而作恶，恶报不因动机可开脱。
- 修慈、悲、喜、舍四梵室，断欲舍欲念，命终生梵天——是舍利弗对久来爱着梵天的婆罗门所设的应机法门。
- 临终开示的原理是「以自功德离怖」：具信、戒、多闻、惠施、慧与正见、正志、正解、正脱、正智十法者，已住须陀洹果，不堕恶处。

## 四、易混辨析
- **无事比丘 vs 人间比丘**：前者住阿兰若寂静处（「无事」即阿兰若意译），后者住村落近人间；经意两者所学相同，不可借独居废威仪。
- **四梵室 vs 四禅**：四梵室即慈、悲、喜、舍四无量心，缘一切众生而修，果在生梵天；不是色界四禅定境本身。
- **须陀洹 vs 斯陀含 vs 阿那含**：初果预流（给孤独所证，不堕恶道）；二果一来（再受人天一次）；三果不还（不再返欲界）。经中「因上信故或得斯陀含果、阿那含果」谓依十法更能进证。
- **「端正」两见**：「名曰端正」的端正是人名（陀然爱妻）；「端正法」的端正指施、戒、生天等令行善端正的世间法，佛说法先说此、后说四谛。

## 五、阅读提示
三经一以贯之的是「舍利弗应机说法」：对放逸者说诃责与功课，对作恶者说地狱业报，对临终者说自身功德令离怖畏。另须留意本卷古译用字：「苦、习、灭、道」的「习」即「集」谛，「差」（chài）即「瘥」病愈，勿以今义读之。
