# ahan —— 四部阿含经现代汉语译本

本项目使用 AI 辅助翻译，将《长阿含经》《中阿含经》《杂阿含经》《增一阿含经》四部阿含经完整译为现代汉语，并提供逐卷导读与词语注释，帮助初学者降低文言与佛教名相的阅读门槛。

所有内容**开源免费**，托管于：

- github: https://github.com/vilarsail/ahan
- gitee:  https://gitee.com/vilarsail/ahan

## 版本说明（V2.0）

在 V1.0 全量翻译的基础上，V2.0 做了一轮系统性校对与增强：

1. **译文逐卷校对与修复**：将全部译文与 CBETA 原文逐段对照，检查漏译、添译、术语不一致、语义偏差、偈颂错位等问题，确认成立并修复：

   | 经典 | 卷数 | 校对发现 | 修复 |
   |---|---|---|---|
   | 长阿含经 | 22 | 149 处 | 148 处 |
   | 中阿含经 | 60 | 1034 处 | 1007 处 |
   | 杂阿含经 | 50 | 703 处 | 647 处 |
   | 增一阿含经 | 51 | 648 处 | 609 处 |

2. **每卷新增「导读」**（`N.guide.md`）：内容总览、结构层次、关键结论、易混辨析、阅读提示。
3. **每卷新增「词语注释」**（`N.notes.md`）：对生僻字词、佛教术语、音译词逐一标注读音与含义。

- 原文来源：中华电子佛典协会（CBETA）
- 辅助 AI：GLM-5.3（V2.0 校对修复）；Gemini 3.1 pro/flash、deepseek-v4、glm-5.1/5.2（V1.0 翻译）
- 整理人：君言

```

za/杂阿含经(2.0导读注释版).epub / .pdf
zengyi/增一阿含经(2.0导读注释版).epub / .pdf
```

## 目录结构

```
ahan/
├── package.sh          # 一键打包脚本（pandoc 生成 epub，calibre 转 pdf）
├── epub.css            # 电子书译文引用块样式
├── chang/  zhong/  za/  zengyi/    # 四部经，各含：
│   ├── cover.png / cover.jpg       # 封面
│   ├── split/
│   │   ├── 0.md        # 前言
│   │   ├── N.md        # 各卷正文：原文与译文逐段对照
│   │   ├── N.guide.md  # 各卷导读
│   │   ├── N.notes.md  # 各卷词语注释
│   │   ├── N.check.md  # 各卷校对报告（问题、依据与修改建议）
│   │   └── N.fix.md    # 各卷修复报告（每条问题的处理结果）
│   └── origin/         # CBETA 原文
└── translate-prompt.md # 翻译任务提示词
```

**正文排版约定**：`N.md` 中原文为正体段落，紧随其后的 `> ` 引用段为对应译文，一一成对。

## 重新打包电子书

依赖 `pandoc` 与 `calibre`（ebook-convert）：

```bash
./package.sh              # 打包全部四部
./package.sh chang        # 只打包长阿含经
```
