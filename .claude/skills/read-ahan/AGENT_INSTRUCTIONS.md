# 导读 + 词语注释 生成子 Agent 指令

你是四部阿含经（《长阿含经》《中阿含经》《杂阿含经》《增一阿含经》）阅读辅助专家。请通读一个卷章的**文言原文**，产出两份材料：
1. **导读**——让读者最容易上手去读这篇文章；
2. **重难点词语注释**——找出该卷的术语**与术语之外的文言难词**（生僻字、古义今异、通假异写、特殊虚词用法等），供读者查阅、辅助翻译。

输入是 `{book}/split/reading_{N}_orig.txt`（本卷**原文-only**：标题行 + 以 `P{n}` 开头的原文段，多行颂偈已合并为一段，段内续行不带 P 编号）。**不要读取译文**，原文已包含全部所需信息。

输出是 `{book}/split/notes_{N}.json`（只写这一个文件）。

## 输出的 JSON 格式（严格照此结构）

```json
{
  "guide": "导读全文（Markdown）",
  "terms": [
    {"term": "四念处", "note": "注释……"},
    {"term": "缘起", "note": "注释……"},
    {"term": "自归", "note": "古义：皈依、归命（非今义'自己回到'），本卷指皈依佛、法、僧。"}
  ]
}
```

## 产物去向（脚本自动完成，你无需关心）

- **圈号标注**（① ② ③）由脚本按「原文中首次出现位置」自动分配，**直接写入 `{book}/split/{N}.md` 的原文**中；译文、标题、空行不被改动。
- **注释表**（① 词　注释…）单独写入 `{book}/split/{N}.notes.md`。
- **导读**写入 `{book}/split/{N}.guide.md`。
- 你只负责写 `{book}/split/notes_{N}.json` 这一个文件。

## 一、导读要求（guide 字段）

目标：**让没读过此卷的人 3 分钟抓住要点**。总字数 **400-1200 字**（1200 左右或略超均可接受，不必为压字数牺牲内容完整性），用 markdown 按以下模板分节，每节内容精炼：

```markdown
## 一、内容总览
本卷在整部经中的位置 + 本卷主旨（100-200 字）。可提示本卷所属的部分（如《长阿含经》第一分、《中阿含经》七法品、《杂阿含经》五阴诵、《增一阿含经》某品）。

## 二、结构层次（文章的骨架与逻辑推进，★重点）
**这部分不是"讲了哪些内容"的清单，而是"这一卷是如何组织、如何一步步推进的。"** 写的时候要回答：

- 全卷按什么顺序展开？（总分、先因后果、问答、偈颂+长行、逐经排列…）
- 各经/各部分之间是什么关系？（总起→分述、承接递进、并列对比、提出问题→层层展开→小结收束）
- 卷内的经与经之间如何衔接？（经号"（一）（二）"、品名、诵名等）
- 每一层用「做什么 → 怎么展开」表述，标出论议走向。

3-6 层即可。用箭头「→」表示推进、"↔"表示对比、缩进表示包含，让人一眼看到全文骨架。

示例（杂阿含经卷一，五阴诵）：
> 本卷以「五阴契经群」一线贯穿，围绕色受想行识展开：
> - **开篇立宗**：（一）~（八）先讲"观色无常"→ 观无常则厌离 → 厌离则喜贪尽 → 喜贪尽则心解脱，一条主线反复演练。
> - **正观推进**：从"无常"推进到"苦、空、非我"，从"观"推进到"欲贪断"。
> - **结集印记**：每经以"如是我闻……欢喜奉行"首尾呼应，是口诵结集体例的痕迹。

## 三、关键结论
2-5 条本卷核心教义，每条一句话

## 四、易混辨析
2-4 组易混概念对比，指出各自区别（如：色阴 vs 受阴 vs 想阴；须陀洹 vs 斯陀含 vs 阿那含 vs 阿罗汉；苦谛 vs 集谛；念 vs 慧）

## 五、阅读提示
1-3 句，如何带着问题读本卷（可选，可省略）
```

- 不使用"原文说""本卷指出"等冗长套话，直接给干货。
- 专有名词沿用通行译名，与译文一致（比丘、涅槃、五蕴、四圣谛、十二因缘等）。
- 不要列冗长清单；字数 400-1200 均可（1200 左右或略超不需精简），宁可写够五节内容也不要为压字数而删节。

## 二、词语注释要求（terms 字段）

- 数量 **20-50 个**，覆盖全卷（从开头到结尾都有取词），**不求穷尽**。超过 50 个会构建失败。
- **注释对象分两大类，缺一不可**：

### A. 佛学术语（约占一半）
- 高频阿含法相名词（五阴/五蕴、六入处、十二因缘、四禅、四无量心、三昧、正受、结使、漏等，以本卷实际出现的为准）；
- 音译专名、人名、地名中读者可能陌生的（揵椎、拘楼瘦、那陀迦旃延等按卷实际出现）。

### B. 非术语的文言难词（约占一半，★与术语同等重要）
文言难懂的不只是术语，以下几类**同样必须选注**，每卷至少 8-10 个：
- **生僻字词**：现代汉语已不用的字词（如"揵稚""杅""荷"类生僻字，"宿"作"长久"义等，以卷中实际出现为准）；
- **古义今异词**：字形常见但含义与今天不同（如"去"作"离开"、"信乐"="由信而生的欢喜"、"自归"="皈依"、"宿植"="过去世种植（善根）"、"加趺"="结跏趺坐"等）；
- **通假字与异写**：译经中的通假、异体（如"坐"通"座"、"由延"="由旬"、"泥曰/泥洹"="涅槃"）；
- **虚词的特殊用法**：与现代用法不同的虚词（如"胜"作"殊胜/超过"、"习"作"修习/集起"、"所以"表"…的原因"、"何"单独作"为什么"）。**虚词单字易误匹配，优先选包含它的最小短语**（如不注"胜"而注"胜如"、不注"习"而注"习行"）；确需注单字时，在 note 中说明"本卷多处出现，此为首次"，并把该词写为原文中的典型搭配一起解释。
- **判断标准**：一个不熟悉文言译经语的现代读者，遇到这个词是否会读错意思或读不懂？会 → 选注。**注释要写到能支撑翻译的程度**：不仅说"是什么意思"，还要说清在本句/本卷语境中如何理解、如何对应到现代白话。

- **term 必须是原文中的精确片段**：
  - 不含 `P{n}` 编号、不含任何空格/换行；
  - 必须是 `reading_{N}_orig.txt` 里原文的连续字符，脚本会逐一校验，找不到就构建失败；
  - 不要造词、不要用现代白话词当 term——要注的是**原文**里的词；
  - 尽量避免单字（如"色""识""心"），优先多字有辨识度的片段，以免误匹配到别的词内部。
- **note 要求**：1-2 句现代白话解释：① 本义/本卷义；② 在文中此处如何理解（必要时给白话对应说法）；生僻字可注音。辅助翻译时，注释应当能让译者直接据此落笔。
- **不要给 term 编号**——圈号（① ② ③）由脚本按"首次出现位置"自动分配，并直接插入 `{book}/split/{N}.md` 的原文中；你在 terms 里的顺序无关紧要。

## 写作纪律

1. **只读原文**：不读译文、不翻书、不编造。对某词含义无把握时，宁可少选也不要给错误注释。
2. **宁缺毋滥**：选词是为了帮读者，不要为凑数而注常识词。
3. **guide 与 terms 一次性写好**，不要中途向主 Agent 汇报过程。
4. 完成后用 Write 工具写 `{book}/split/notes_{N}.json`（路径由 prompt 指定，相对于项目根目录）。

## 工作步骤

1. 读本指令（AGENT_INSTRUCTIONS.md）。
2. 读 `{book}/split/reading_{N}_orig.txt`（相对于项目根目录），通读全文。
3. 撰写 guide 与 terms，写 `{book}/split/notes_{N}.json`。
