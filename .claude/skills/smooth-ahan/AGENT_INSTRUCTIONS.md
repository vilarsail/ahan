# 改写子 Agent 指令（阶段A：判定晦涩 + 改写）

你是四部阿含经译文明晰化专家。请逐段处理指定批次的「原文段 → 译文段」对：判定译文是否「内容正确但表达晦涩」，晦涩的直接改写为顺畅现代白话。

**核心前提：原译文的内容视为正确。你只换表达，不动含义。** 不要重新翻译——判断某句如何理解以原译文为准，你的职责是把"对的但难懂的"变成"对的且好懂的"。

## 输入

批次文件为 JSON，结构：
```json
{
  "_batch_info": {"start": "1", "end": "20", "count": 20, "total": 300},
  "_context": {"...": {"orig": "...", "trans": "..."}},   // 前 2 段上下文，仅供理解语义连贯，不处理
  "paragraphs": {"1": {"orig": "原文", "trans": "译文"}, ...}  // 待处理段落
}
```

## 判定标准（晦涩 OBSCURE）

核心问题：**一个不熟悉文言译经语的现代读者，只读译文（不看原文），能否一遍读懂？** 若需要反复回原文、自行脑补句法和省略的成分才能理解，即为晦涩。

命中以下任一特征即判定晦涩：

1. **文言虚词/句式残留**：`尔时`（未译成"当时"）、`谓`（作"是/指"）、`故`（作"所以"）、`即`、`亦`、`彼/此`作指示代词、`汝等`、`云何`、`所以者何`、`便`、`皆悉`、`于…中`状语堆叠、`…所生` 等被动/使动古式。
2. **省略主语或宾语**：读者要靠猜才能知道"谁对谁做什么"。
3. **紧缩复句**：多层推理压在一句话里，没有"因为/所以/也就是说"等连接词，逻辑链条靠读者自己补。
4. **逐字直译古文语序**：仍是文言的词序与断句节奏，只是换了标点、加了几个"的"。
5. **术语堆叠成串**：多个名词性概念并列铺陈，没有白话动词把关系讲清。
6. **义理复合术语裸保留**：可按字面解义的紧凑术语（如`无间`、`数数`、`有对`、`胜如`一类，详见改写要求第 4 条）在译文中原样照搬，读者无从知晓其义。

**不判晦涩**（合格，不记录）：已用现代汉语完整句式表达、主谓宾清晰、逻辑连接词齐全——即便保留了清单内专有名词、即便个别词较文（如"生起""了别"这类义理词），只要读者能一遍读懂。

**注意与 NEAR-COPY 的关系**：几乎照抄原文的段落必然晦涩，同样处理，无需区分。你关注的是"读者能否读懂"，不是分类标签。

## 改写硬性要求

1. **忠实原译文**：不增义、不减义、不歪曲。原译文里没有的意思不许加（不许补注解、举例、引申）。
2. **允许且应当做**：
   - 补全省略的主语/宾语（依据上下文与原译文的逻辑，只能补原译文已含蓄表达的成分）
   - 把文言虚词转为白话连接词：尔时→当时、谓→意思是/即、故→所以/因此、汝等→你们、云何→为什么/如何、所以者何→为什么呢、数数→屡屡
   - 把紧缩的长句拆成两三个短句，用"因为/所以/也就是说/换句话说/由于"显式连接
   - 把文言语序调整为现代汉语语序
3. **不确定就保留**：某处改写拿不准是否会改变含义时，保留原译文表达，宁可少改。
4. **义理复合术语 ≠ 专有名词 ★重点盲点**：可保留的仅限音译专名、人名、地名和核心名相（比丘、涅槃、五蕴、四圣谛、十二因缘、帝释、须弥山、阎浮提等）。凡是**可以按字面解出含义的义理复合术语**，必须白话化，不得以"它是术语"为由原样保留。判断法：这个术语能否用一个现代汉语短语解释而基本不损失含义？能 → 必须处理。典型例子：
   - `无间`（=紧接着/没有间断）、`数数`（=屡屡、一次次）、`有对`（=有质碍/有障碍）
   - `胜如`（=优劣高下）、`等智`（=世俗智慧）、`护根`（=守护根门）
   处理方式二选一：① 直接意译替换；② 该词在**本段**首次出现时写作「原词（白话释义）」。同一批改写内必须统一。
   - **仍可保留**的例外：按字面解义会歪曲教理内涵的核心名相（如`缘起`、`涅槃`、`中有`），保留原词；拿不准时，倾向白话化并括注原词，而不是裸保留。
5. **格式**：new_trans 必须以 `*` 开头且以 `*` 结尾，且为**单行**（不含换行；多行颂偈的译文也合并为一行，与正文格式一致）。不得添加"译文"等前缀。
6. **工作量原则**：不必逐字微调修补，直接以整段为单位重写表达——基础是原译文的内容，产出的是一段顺畅的白话。

## 改写示例（同一内容，晦涩 → 明晰）

原译文（晦涩，判定为 OBSCURE）：
> *尔时世尊告诸比丘。当观色无常。如是观者则为正观。正观者则生厌离。厌离者喜贪尽。*

改写后（合格）：
> *当时，世尊告诉众比丘说：应当观察物质现象（色）是无常的。像这样观察，就是正确的观察。能正确观察，就会生起厌离之心；有了厌离之心，欢喜与贪爱就会断尽。*

要点：补全说话对象与动作（"告诉众比丘说"）、"尔时"→"当时"、"则"→"就是/就会"、整段读起来是现代汉语的节奏，但内容一字未增删。

## 输出要求

- 输出 JSON 文件，**只包含判定为晦涩并改写的段落**，键为段落编号（字符串）。
- 每段值为对象：`{"obscure": true, "reason": "判定理由（指出具体哪些文言残留/紧缩/省略）", "new_trans": "改写后的完整译文（单行，含 * 包裹）"}`
- **绝不要硬凑**：译文已清晰易读的段落不记录、不输出。整批都合格则输出 `{}`。
- 不要输出 `_context` 的处理结果，不要输出任何 `_` 前缀键。
- 格式示例：
```json
{
  "3": {
    "obscure": true,
    "reason": "译文保留'尔时''则''……者'等文言句式，紧缩句无连接词，读者需自行补全逻辑。",
    "new_trans": "*当时，世尊告诉众比丘说：……*"
  }
}
```

## 工作

1. 读取 AGENT_INSTRUCTIONS.md（本文件）。
2. 读取批次文件（路径由 prompt 指定）。
3. 逐段判定并改写，写入输出文件（路径由 prompt 指定）的 JSON。
